Raspberry Pi 搭載エッジデバイス

はじめに​

Edge Solution における Raspberry Pi 搭載デバイスの最先端の世界へようこそ。ここでは、エッジコンピューティング向けに Seeed Studio が開発した、Raspberry Pi CM4/CM5 および Raspberry Pi 4/5 に特化した革新的なソリューションを紹介します。これらのカスタマイズ可能なデバイスには、ヒューマンマシンインターフェース（HMI）ユニット、多用途なエッジコントローラ、AI スイートボックスが含まれます。シームレスかつ効率的なエッジコンピューティング機能によって、あなたのプロジェクトを強化するために設計された、これら強力なデバイスの精緻な世界を一緒に探検していきましょう。

製品ファミリー​

エッジ AI コンピュータ​

Seeed Studio reComputer Industrial R & AI R シリーズ – IIoT とスマートオートメーション向けに構築された、堅牢で手のひらサイズのエッジ AI コントローラ

高性能な Raspberry Pi 5 / Compute Module 5 と Hailo-8 AI アクセラレータを組み合わせた reComputer Industrial R および AI R ラインは、エッジにおけるリアルタイムのマルチストリーム映像解析とディープラーニング推論のために、最大 26 TOPS の演算性能を提供します。

産業グレードの接続性を標準搭載：デュアル Gigabit Ethernet、アイソレートされた RS-485/RS-232、マルチチャネル DI/DO、さらに M.2 および mini-PCIe スロットにより、4G/5G、LoRa®、NVMe SSD を数秒で追加可能です。ファンレスのフルメタル筐体は –20 °C ～ 60 °C の範囲で静音かつ防塵動作を保証し、ハードウェアウォッチドッグとオプションの UPS スーパーキャパシタにより、ミッションクリティカルなタスクを 24 時間 365 日稼働させ続けます。

DIN レールまたは壁掛けに対応した reComputer R シリーズは、スマートビルディング、Industry 4.0 のマシンビジョンセル、遠隔資産制御キャビネット、分散型映像解析ネットワークにスムーズに組み込むことができ、プロトコル変換、データ収集、AI モデルの実行を、現場で直接行います。

エッジコントローラ​

Seeed Studio の reComputer R および Edge Box ファミリーは、産業用 IoT とインテリジェントオートメーション向けに設計された堅牢なエッジコントローラです。高性能な Raspberry Pi Compute Module（CM4/CM5）を中心に構成され、クアッドコア Arm の処理能力と最大 16 GB の RAM を提供します。デュアル Gigabit Ethernet（PoE 対応）、アイソレートされた RS-485/RS-232 に加え、4G/5G、LoRa®、NVMe SSD 用の M.2/mini-PCIe ベイを備え、あらゆる IIoT、プロトコルゲートウェイ、エッジ AI の要件をカバーします。–30 °C ～ +70 °C に対応したファンレスのフルメタル筐体、ハードウェアウォッチドッグ、オプションの UPS スーパーキャパシタにより、過酷な環境でも 24 時間 365 日の信頼性の高い動作を保証します。DIN レールまたは壁掛けに対応しており、スマートビルディング、エネルギー管理システム、遠隔制御アプリケーションにスムーズに組み込むことができます。

reTerminal​

reTerminal と reTerminal DM は、高性能エッジコンピューティングとヒューマンマシンインターフェース（HMI）機能を統合した高度なデバイスです。これらはコアとして Raspberry Pi CM4 を搭載し、高解像度の静電容量式マルチタッチスクリーンを備え、現場でのインタラクションハブとして機能するよう設計されています。これらのデバイスは、モノのインターネット（IoT）およびクラウドシステムとのシームレスな統合を実現し、エッジ環境におけるデータ収集、デバイス管理、協調アプリケーションを効率的に解放することを目的としています。物理世界とデジタル世界をつなぐ重要なブリッジとして機能します。

reRouter​

reRouter はデュアル Gigabit Ethernet ポートとデュアル USB 3.0 ポートを備えており、ハードウェア構成を最小限に抑えつつ、ソフトウェアルーター用途に適しています。4GB RAM と 32GB eMMC を搭載した Raspberry Pi Compute Module 4 をあらかじめインストールしており、高速な起動時間とスムーズな全体体験を実現します。

クラウド​

主要なクラウドプロバイダへのシームレスな接続により、Raspberry Pi デバイスはデータサービス、分析、IoT プラットフォームと統合できます。Seeed のサポートにより、ユーザーは安全にスケールし、デジタルトランスフォーメーションを加速させるクラウド対応ソリューションを容易に構築できます。

AWS

先進的な幅広いサービスを提供する、世界をリードするクラウドプラットフォーム。

Azure

Microsoft のパブリッククラウドプラットフォームで、統合クラウドサービスを提供します。

プラットフォーム​
