主な特長​

  2. デュアルエンコーダ

入門​

使用前の環境準備​

PC の Windows システム

  • Damiao Debugging Tools のダウンロード を行います。
  • USB2CAN Tools をダウンロードします。

回路を PC に接続する​

ここでは CAN 通信方式を使用します。Windows 上の上位コンピュータでデバッグするために、別途 USB-CAN インターフェースが必要です。

ここでは、モーター用に別途 24V 電源を用意し、USB をコンピュータに接続する必要があります。

Debugging_Tools_v.1.6.8.8.exe を使用してモーターをテストする​

アプリの下部で、中国語と英語を切り替えることができます。

シリアルポート接続パラメータの設定モーターに接続Read ParamCAN ID を設定Write Param.
シリアルポートには、コンピュータが自動認識したポートを使用し、その他の設定はすべてデフォルトのままにします。「Open Port」ボタンをクリックすると、自動的にホストコンピュータに接続されます。初回接続の場合、ダイアログボックスにモーター情報が表示されます。「Set Parameters」セクションで「Read Param」をクリックすると、モーターの現在の詳細情報と動作モードが表示されます。ここで、まず CAN ID を設定してください。設定後、「Write Param」をクリックしてパラメータを更新します。
ヒント

​CAN_ID: ドライブが CAN コマンドを受信するために使用するフレーム ID（16 進数）。

​Master ID: ドライブがフィードバックを送信するために使用するフレーム ID（16 進数）。

​Master ID はホスト ID です。各モーターに対して一意の Master ID を設定することを推奨します。

良い運用方法として、​Master ID を ​CAN_ID より ​0x10 高く設定します（例：CAN_ID = 0x01 の場合、Master ID = 0x11）。

​例:

​モーター 1: CAN_ID = 0x01, Master ID = 0x11

​モーター 2: CAN_ID = 0x02, Master ID = 0x12

​Master ID を 0x00 に設定しないでください!!!

(1) 基本パラメータ​

  • NPP: モーターの極対数。キャリブレーションによって自動的に決定されます。
  • UV: 電源電圧がしきい値（最小 15V）を下回ると、ドライブは動作を停止します。
  • OV: 上限電圧を設定します。ドライブは起動時に電源電圧をチェックし、上限を超えている場合は動作を無効にします（起動時に 1 回のみチェック）。
  • Acc/Dec: 非 MIT モードで速度変化率を制限するために使用されます。
  • GR(Gear Ratio): 出力速度/位置に影響し、間接的にトルクフィードバックにも影響します。浮動小数点値をサポートします。
  • OT: コイル温度のしきい値（推奨 ≤ 100°C）。これを超えるとフォルトモードがトリガーされ（モーターを無効化しエラーを報告）、動作が停止します。
  • CAN_ID: CAN コマンドを受信するためのフレーム ID（16 進数）。
  • Master ID: ドライブがフィードバックを送信するためのフレーム ID（16 進数）。推奨設定: MasterID = CAN_ID + 0x10（例: 0x01 → 0x11）。決して 0x00 に設定しないでください。
  • CAN Timeout: タイムアウト時間を定義する 32 ビット整数（単位: 50µs サイクル）。この間に CAN コマンドが検出されない場合、モーターは保護モードに入ります。
  • Speed Limit (速度モードのみ): 減速が始まる前の最大速度（単位: rad/s）。
  • Overcurrent: 最大相電流の上限（パーセンテージ）。

(2) モーターパラメータ​

  • ドライブによって自動的に識別されます。ドライブボードを交換する場合は再キャリブレーションが必要です。パラメータはドライブ内に永続的に保存されます。

(3) コマンドスケーリング（振幅設定）​

  • PMAX: MIT モードではコマンド入力をスケーリングし、その他のモードではフィードバック出力をスケーリングします。マッピングルールについては CAN プロトコルを参照してください。
  • VMAX: PMAX と同様です。
  • TMAX: PMAX と同様です。
  • KT_OUT: モーターのトルク定数。モーターパラメータが正確に識別されている場合は 0 に設定します。
  • Gear Ratio Coefficient: ギアのトルク伝達比。

注: ドライブは MIT 通信プロトコル形式を使用します。

(4) 制御設定​

  • 制御モード:
    • MIT モード
    • 位置・速度モード（台形加減速）
    • 速度モード
  • Current Bandwidth: 電流ループゲイン（デフォルト: 1000）。
  • Speed KP/KI, Position KP/KI: 速度ループおよび位置ループ用の PID パラメータ。

MIT 制御モード​

1. MIT トルク制御モード:

  1. 「Set Parameters」セクションで ​Read Param をクリックし、現在のモーターパラメータを表示します。
  2. ​Control Mode を MIT Mode に設定します。
  3. 設定した ​CAN ID を確認します。
  4. ​Write Param をクリックして、すべての設定を保存します。
  1. ​Test タブで、​**"Enable Motor"** ボタン（Ente）をクリックします。
  2. ​MIT Control セクションで:
    • Torque (Nm) を ​1 に設定します。
    • ​Update → ​Send をクリックします。

モーターが回転を開始します。

CAN データ（16 進数形式）をコピーし、シリアルポートデバッグツールを使用してモーターを駆動することもできます。

2. MIT 速度制御モード:

  1. ​Test タブで、​**"Enable Motor"** ボタン（Ente）をクリックします。
  2. ​MIT Control セクションで:
    • Vel (rad/s) を ​5 に設定します。
    • KD (N*s/r) を ​1 に設定します。
    • ​Update → ​Send をクリックします。

モーターが回転を開始します。CAN データ（16 進数形式）をコピーし、シリアルポートデバッグツールを使用してモーターを駆動することもできます。

3. MIT 位置制御モード:

  1. ​Test タブで、​**"Enable Motor"** ボタン（Ente）をクリックします。
  2. ​**"SaveZero"** を使用して、現在位置をゼロ点として設定できます。
  3. ​MIT Control セクションで:
    • Pos (rad) を 3.14 に設定します。
    • KP (N/r) を ​2 に設定します。
    • KD (N*s/r) を ​1 に設定します。
    • ​Update → ​Send をクリックします。

モーターが回転を開始します。CAN データ（16 進数形式）をコピーして、シリアルポートデバッグツールを使用してモーターを駆動することもできます。

速度制御モード​

  1. Set Parameters セクションで ​Read Param をクリックし、現在のモーターのパラメータを表示します。
  2. ​Control Mode を Vel Mode に設定します。
  3. 設定されている ​CAN ID を確認します。
  4. ​Write Param をクリックして、すべての設定を保存します。
  1. ​Test タブで、​**"Enable Motor"** ボタン（Ente）をクリックします。
  2. Vel Control セクションで：
    • Vel (rad/s) を 5 に設定します。
    • ​Update → ​Send をクリックします。

モーターが回転を開始します。CAN データ（16 進数形式）をコピーして、シリアルポートデバッグツールを使用してモーターを駆動することもできます。

位置制御モード​

  1. Set Parameters セクションで ​Read Param をクリックし、現在のモーターのパラメータを表示します。
  2. ​Control Mode を Pos Mode に設定します。
  3. 設定されている ​CAN ID を確認します。
  4. ​Write Param をクリックして、すべての設定を保存します。
  1. ​Test タブで、​**"Enable Motor"** ボタン（Ente）をクリックします。
  2. Pos Control セクションで：
    • Pos を 3.14 に設定します。
    • Vel (rad/s) を 5 に設定します。
    • ​Update → ​Send をクリックします。

モーターが回転を開始します。CAN データ（16 進数形式）をコピーして、シリアルポートデバッグツールを使用してモーターを駆動することもできます。

​reComputer Mini Jetson Orin を使用してモーターを制御する​

現在、市場で一般的なモーター用 CAN 通信インターフェースには、XT30 (2+2) と JST コネクタ が使用されています。弊社の reComputer Mini Jetson Orin および reComputer Robotics デバイスには、デュアル XT30 (2+2) ポート と JST ベースの CAN インターフェース が搭載されており、高い互換性を提供します。

reComputer Mini:

reComputer Robotics

CAN の使用に関する詳細については、この wiki を参照してください。

CAN インターフェースを有効化する​

Step1: CAN0 と CAN1 を使用する前に、底面カバーを取り外し、両方の 120Ω 終端抵抗を ​ON 位置に設定してください。

Step2: モーターを XT30 (2+2) インターフェース経由で reComputer Mini の CAN0 に直接接続します。

ヒント

reComputer Mini の CAN インターフェースでは、H/L ピンがモーター側の H/L と逆になっています。そのため、XT30 2+2 ケーブルハーネス内の H/L 接続を入れ替える必要があります。

危険

この電源は単一モーターの学習およびテスト用途のみに使用してください。複数のモーターを使用する場合は、別途電源ボードを設計し、Jetson の電源とモーターの電源を分離して、Jetson に大電流が直接流れないようにしてください。

Jetson の CAN 通信を有効化する​

ターミナルを開き、次のコマンドを入力して GPIO ピンを High にし、CAN0 を有効化します：

gpioset --mode=wait 0 43=0

JST インターフェースの CAN1 を使用する場合は、ピン 106 を High にします。

gpioset --mode=wait 0 106=0

このターミナルは開いたままにして、新しいターミナルを起動し、CAN0 を設定します。

sudo modprobe mttcan
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up

C++ のサンプルについて​

インストールとコンパイル​

  • CMake をインストール
sudo apt update  
sudo apt install cmake
  • CAN Tools をインストール
sudo apt install can-utils
  • プログラムをダウンロードしてコンパイル
  1. ワークスペースを作成し、リポジトリをクローンします：
mkdir -p ~/orin_ws/src  
cd ~/orin_ws/src  
git clone https://gitee.com/xauter/orin-control.git
  1. コンパイル：
cd ~/orin_ws/src/orin-control/dm_hw  
mkdir build  
cd build  
cmake ..  
make

使用方法​

  1. CAN デバイスを確認

ターミナルを開き、次を実行します：

ip -brief link | grep can
  1. プログラムを実行

build フォルダ内で、次を実行します：

cd ~/orin_ws/src/orin-control/dm_hw/build  
./dm_main

モーターが 緑色 に点灯し、正弦波状の速度 で回転します。

  • Python 環境をインストール
pip install python-can numpy
  • Python スクリプトを保存するために、~/damiao/scripts ディレクトリの下に scripts という名前のフォルダを作成します。
mkdir -p ~/damiao/scripts
  • damiao_motor.py ファイルを作成します
cd ~/damiao/scripts
touch damiao_motor.py

        """

    def recv_data(self, q: float, dq: float, tau: float, tmos: int, trotor: int):
        self.state_q = q
        self.state_dq = dq
        self.state_tau = tau
        self.state_tmos = tmos
        self.state_trotor = trotor

    def getPosition(self):
        """
        get the position of the motor 获取电机位置
        :return: the position of the motor 电机位置
        """
        return self.state_q

    def getVelocity(self):
        """
        get the velocity of the motor 获取电机速度
        :return: the velocity of the motor 电机速度
        """
        return self.state_dq

    def getTorque(self):
        """
        get the torque of the motor 获取电机力矩
        :return: the torque of the motor 电机力矩
        """
        return self.state_tau

    def getParam(self, RID):
        """
        get the parameter of the motor 获取电机内部的参数，需要提前读取
        :param RID: DM_variable 电机参数
        :return: the parameter of the motor 电机参数
        """
        if RID in self.temp_param_dict:
            return self.temp_param_dict[RID]
        else:
            return None

        MotorType = DM_Motor.MotorType
        Q_MAX = self.Limit_Param[MotorType][0]
        DQ_MAX = self.Limit_Param[MotorType][1]
        TAU_MAX = self.Limit_Param[MotorType][2]
        q_uint = float_to_uint(q, -Q_MAX, Q_MAX, 16)
        dq_uint = float_to_uint(dq, -DQ_MAX, DQ_MAX, 12)
        tau_uint = float_to_uint(tau, -TAU_MAX, TAU_MAX, 12)
        data_buf = np.array([0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00], np.uint8)
        data_buf[0] = (q_uint >> 8) & 0xff
        data_buf[1] = q_uint & 0xff
        data_buf[2] = dq_uint >> 4
        data_buf[3] = ((dq_uint & 0xf) << 4) | ((kp_uint >> 8) & 0xf)
        data_buf[4] = kp_uint & 0xff
        data_buf[5] = kd_uint >> 4
        data_buf[6] = ((kd_uint & 0xf) << 4) | ((tau_uint >> 8) & 0xf)
        data_buf[7] = tau_uint & 0xff
        self.__send_data(DM_Motor.SlaveID, data_buf)
        self.recv()  # receive the data from serial port

    def __process_packet(self, data, CANID, CMD):
        if CMD == 0x11:
            if CANID != 0x00:
                if CANID in self.motors_map:
                    q_uint = np.uint16((np.uint16(data[1]) << 8) | data[2])
                    dq_uint = np.uint16((np.uint16(data[3]) << 4) | (data[4] >> 4))
                    tau_uint = np.uint16(((data[4] & 0xf) << 8) | data[5])
                    t_mos = data[6]
                    t_rotor = data[7]
                    MotorType_recv = self.motors_map[CANID].MotorType
                    Q_MAX = self.Limit_Param[MotorType_recv][0]
                    DQ_MAX = self.Limit_Param[MotorType_recv][1]
                    TAU_MAX = self.Limit_Param[MotorType_recv][2]
                    recv_q = uint_to_float(q_uint, -Q_MAX, Q_MAX, 16)
                    recv_dq = uint_to_float(dq_uint, -DQ_MAX, DQ_MAX, 12)
                    recv_tau = uint_to_float(tau_uint, -TAU_MAX, TAU_MAX, 12)
                    self.motors_map[CANID].recv_data(recv_q, recv_dq, recv_tau, t_mos, t_rotor)
            else:
                MasterID=data[0] & 0x0f
                if MasterID in self.motors_map:
                    q_uint = np.uint16((np.uint16(data[1]) << 8) | data[2])
                    dq_uint = np.uint16((np.uint16(data[3]) << 4) | (data[4] >> 4))
                    tau_uint = np.uint16(((data[4] & 0xf) << 8) | data[5])
                    t_mos = data[6]
                    t_rotor = data[7]
                    MotorType_recv = self.motors_map[MasterID].MotorType
                    Q_MAX = self.Limit_Param[MotorType_recv][0]
                    DQ_MAX = self.Limit_Param[MotorType_recv][1]
                    TAU_MAX = self.Limit_Param[MotorType_recv][2]
                    recv_q = uint_to_float(q_uint, -Q_MAX, Q_MAX, 16)
                    recv_dq = uint_to_float(dq_uint, -DQ_MAX, DQ_MAX, 12)
                    recv_tau = uint_to_float(tau_uint, -TAU_MAX, TAU_MAX, 12)
                    self.motors_map[MasterID].recv_data(recv_q, recv_dq, recv_tau, t_mos, t_rotor)


    def __process_set_param_packet(self, data, CANID, CMD):
        if CMD == 0x11 and (data[2] == 0x33 or data[2] == 0x55):
            masterid=CANID
            slaveId = ((data[1] << 8) | data[0])

                masterid=slaveId

                    return
                else:
                    masterid=slaveId

            RID = data[3]

            if is_in_ranges(RID):
                #uint32类型
                num = uint8s_to_uint32(data[4], data[5], data[6], data[7])

    # Extract packets from the serial data
    def __extract_packets(self, data):          
        frames = []
        header = 0xAA
        tail = 0x55
        frame_length = 16
        i = 0
        remainder_pos = 0

        while i <= len(data) - frame_length:
            if data[i] == header and data[i + frame_length - 1] == tail:
                frame = data[i:i + frame_length]
                frames.append(frame)
                i += frame_length
                remainder_pos = i
            else:
                i += 1
        self.data_save = data[remainder_pos:]
        return frames


def LIMIT_MIN_MAX(x, min_val, max_val):
    return max(min_val, min(x, max_val))


def float_to_uint(x: float, x_min: float, x_max: float, bits):
    x = LIMIT_MIN_MAX(x, x_min, x_max)
    span = x_max - x_min
    data_norm = (x - x_min) / span
    return np.uint16(data_norm * ((1 << bits) - 1))


def uint_to_float(x: np.uint16, min: float, max: float, bits):
    span = max - min
    data_norm = float(x) / ((1 << bits) - 1)
    temp = data_norm * span + min
    return np.float32(temp)


def float_to_uint8s(value):
    # Pack the float into 4 bytes
    packed = pack('f', value)
    # Unpack the bytes into four uint8 values
    return unpack('4B', packed)


def data_to_uint8s(value):
    # Check if the value is within the range of uint32
    if isinstance(value, int) and (0 <= value <= 0xFFFFFFFF):
        # Pack the uint32 into 4 bytes
        packed = pack('I', value)
    else:
        raise ValueError("Value must be an integer within the range of uint32")

    # Unpack the bytes into four uint8 values
    return unpack('4B', packed)


def is_in_ranges(number):
    """
    check if the number is in the range of uint32
    :param number:
    :return:
    """
    if (7 <= number <= 10) or (13 <= number <= 16) or (35 <= number <= 36):
        return True
    return False


def uint8s_to_uint32(byte1, byte2, byte3, byte4):
    # Pack the four uint8 values into a single uint32 value in little-endian order
    packed = pack('<4B', byte1, byte2, byte3, byte4)
    # Unpack the packed bytes into a uint32 value
    return unpack('<I', packed)[0]


def uint8s_to_float(byte1, byte2, byte3, byte4):
    # Pack the four uint8 values into a single float value in little-endian order
    packed = pack('<4B', byte1, byte2, byte3, byte4)
    # Unpack the packed bytes into a float value
    return unpack('<f', packed)[0]

        self.stat_time = []
        for motor in self.motors:

    def move_regressor_sync(self, regs, search_range, search_step, goal_positions, kps, kds):
        TORQUE_SCALER=30
        if len(self.stat_data) == 0:
            return self.move_towards_sync(goal_positions, kps, kds)
        for motor, reg, goal_position, kp, kd, stat in zip(

            pos = motor.getPosition()
            vel = motor.getVelocity()
            delta = goal_position - pos

            _goal_pos, _goal_tau, _pos, _vel, _tau = stat

                          [pos, vel, motor.getTorque(), goal_position, goal_tau]])
            x /= np.array([[np.pi, 10, TORQUE_SCALER, np.pi, TORQUE_SCALER]])
            xs = []
            for tau in np.linspace(goal_tau/TORQUE_SCALER - search_range,
                                   goal_tau/TORQUE_SCALER + search_range,
                                   num=search_step):

            tau = TORQUE_SCALER * xs[np.argmin(diff ** 2)][4]
            goal_tau = tau
            motor.goal_position = goal_position
            motor.goal_tau = goal_tau
            self.control.controlMIT(motor, 0, 0, 0, 0, goal_tau)
            sleep(0.00003)

damiao_motor.py
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

import time
import math
import numpy as np
from damiao_motor import Motor, MotorControl, DM_Motor_Type, Control_Type

# Configuration parameters
NUM_MOTORS = 1  # Number of motors to control
CAN_INTERFACE = "can0"  # CAN interface name
CAN_BITRATE = 1000000  # CAN bus baud rate
MOTOR_TYPE = DM_Motor_Type.DM4310  # Motor model

# Sine wave parameters
FREQUENCY = 0.1  # Frequency (Hz)
AMPLITUDE = 6  # Amplitude (rad)
DURATION = 60.0  # Operation duration (s)

def main():
    # Create motor controller object
    control = MotorControl(CAN_INTERFACE, bitrate=CAN_BITRATE)

    # Create and add motors
    motors = []
    for i in range(NUM_MOTORS):
        motor = Motor(MOTOR_TYPE, i + 1, i + 0X10)  # CAN IDs start from 1
        control.addMotor(motor)
        motors.append(motor)
        control.enable(motor)
        print(f"Motor {i + 1} enabled")

    try:
        start_time = time.time()
        while time.time() - start_time < DURATION:
            current_time = time.time() - start_time

            # Calculate sine wave position
            position = AMPLITUDE * math.sin(2 * math.pi * FREQUENCY * current_time)

            # Control all motors
            for motor in motors:
                control.controlMIT(
                    motor,
                    kp=10.0,  # Position gain
                    kd=1.0,   # Velocity gain
                    q=position,  # Target position
                    dq=0.0,   # Target velocity
                    tau=0.0   # Feedforward torque
                )

            # Control frequency
            time.sleep(0.001)  # 1kHz control frequency

    except KeyboardInterrupt:
        print("\nProgram interrupted by user")
    finally:
        # Disable all motors
        for motor in motors:
            control.disable(motor)
            print(f"Motor {motor.SlaveID} disabled")

if __name__ == "__main__":
    main()
