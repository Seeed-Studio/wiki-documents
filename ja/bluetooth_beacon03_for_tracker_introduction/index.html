BC03 屋内 Bluetooth Beacon の紹介

SenseCAP BC03 屋内 Bluetooth Beacon は、一定間隔で Bluetooth 信号を送信する小型のワイヤレスデバイスです。これらの信号は、SenseCAP T1000 Tracker、SenseCAP T2000 Tracker のような Bluetooth 対応デバイスによって検出され、ビーコンとの距離を推定できます。これにより、屋内測位、アセットトラッキング、その他のアプリケーション向けの位置情報ベースのソリューションを構築し、近接検知およびメートルレベルの屋内測位を実現します。

バージョン比較

Bluetooth 屋内測位システム​

GPS は屋外では有効ですが、屋内では性能に制限があります。屋内環境に BC03 Bluetooth ビーコンを配置することで、SenseCAP トラッカーはビーコン信号をスキャンし、RSSI 値に基づいて距離を推定できます。測位アルゴリズムと組み合わせることで、**メートルレベルの屋内測位精度（約 2～3 メートル）**を実現します。

代表的な適用シナリオは次のとおりです：

  • アセットトラッキング
  • 人員位置情報管理
  • 経路分析
  • 屋内ナビゲーション

このソリューションは、クラウドプラットフォーム、モバイルアプリケーション、ミニプログラムに統合することができます。

私たちは、SenseCAP BLE Beacons と SenseCAP LoRaWAN Trackers とシームレスに連携するよう設計された、オープンソースの Bluetooth 屋内測位システムを提供しています。 このソリューションは完全にオープンソースでカスタマイズ可能であり、ユーザーは GitHub リポジトリに基づいて独自のバックエンドサービスを構築、変更、統合することができます。

ヒント

詳細については、Indoor Positioning System を確認してください。

特長​

  • Bluetooth® LE 5.0
  • 超低消費電力：交換可能な Li/SOCl2 電池、5 年以上の電池寿命（0 dBm / 500 ms、デフォルト設定）
  • 長距離伝送：見通し環境で最大 130 m
  • 簡単な設置：絶縁フィルムを引き抜くだけで貼り付けて設置でき、施工コストを削減します。
  • UV 保護：UV 滅菌ランプなどのシナリオに適しており、外観を損ないません。
  • 柔軟な設定：アドバタイジング間隔と送信電力を設定可能
  • 高い互換性：iOS 7.0+ および Android 4.3+ と互換
  • オプションの加速度センサ対応：動きや振動検知用の PCBA フットプリントを予約
備考

BC03 は高利得全方向性 BLE アンテナ、低消費電力、およびユーザーインタラクションを備えています：

  • 強化されたビーコン送信機能 BLE アドバタイジングの安定性と RSSI の一貫性を最適化し、複雑な環境での屋内測位精度と堅牢性を向上させます。
  • アンテナ設計 優れた放射効率と指向性の一貫性を持つオンボードアンテナにより、設置方向を厳密に調整することなく、より長い通信距離とより安定した通信を実現します。
  • より長いバッテリー寿命 低消費電力設計をさらに最適化しました。同一設定（0 dBm / 500 ms）のもとで、BC03 は大規模かつ長期的な展開を実現します。
  • LED ステータスの追加 青色 LED により、起動時および動作中の直感的なデバイスステータスフィードバックを提供し、デバイスの起動およびアップグレードステータスを表示します。
