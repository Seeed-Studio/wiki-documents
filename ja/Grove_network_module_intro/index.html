Groveネットワークモジュールガイド

Groveネットワークモジュールは、Seeed Studioによって導入されたモジュール型電子部品であり、Groveシリーズの一部を構成しています。Groveシリーズのモジュールはプロトタイピングプロセスを簡素化するよう設計されており、電子プロジェクトの構築をより直感的かつ迅速にします。ネットワークモジュールは主にネットワーク機能を提供し、有線または無線手段を通じてデバイスをネットワークに接続することを可能にします。

全体として、Groveネットワークモジュールは接続と設定プロセスを簡素化することで電子プロジェクト開発の障壁を大幅に低下させ、機能の実装とアプリケーションの革新に集中できるようにします。

特徴​

  • モジュール設計: Groveモジュールは標準化されたインターフェース（通常は4ピンコネクタ）を介して接続され、ArduinoやRaspberry Piなどのさまざまなメインコントロールボードとの統合が便利です。

  • プラグアンドプレイ: ほとんどのGroveモジュールには詳細なドキュメントとサンプルコードが付属しており、ユーザーが迅速に開発を開始できるようになっています。

  • 多様性: Groveシリーズにはさまざまなセンサー、アクチュエータ、通信モジュールが含まれており、複数のアプリケーションシナリオに適しています。

Groveネットワークモジュールの種類​

Groveネットワークモジュールには、IoTプロジェクト、ワイヤレスセンサーネットワーク、スマートホームなどのさまざまなシナリオに適用できるさまざまな種類があります。

LoRa®​

Grove Wio-E5​

Grove Wio-E5は、EU868およびUS915周波数でLoRa®およびLoRaWAN®プロトコルをサポートするワイヤレスRFモジュールです。簡単なプラグアンドプレイ統合を可能にするオンボードGroveコネクタを備えており、開発ボードに超長距離伝送の強力な機能を提供します。

Bluetooth​

Grove - BLE (デュアルモデル) v1.0​

Grove - BLE (デュアルモデル) v1.0はCSRデュアルモードBluetoothチップを使用しています。このチップはARMアーキテクチャに基づいており、ATコマンドをサポートしています。ユーザーはシリアルボーレート、機器名、ペアリングパスワードに基づいて柔軟に開発できます。

Grove - シリアルBluetooth v3.0​

Grove - シリアルBluetoothは、既存のGrove Base Shieldと互換性があり、透明なワイヤレスシリアル接続のセットアップを設計した使いやすいモジュールです。このシリアルポートBluetoothモジュールは完全なBluetooth V2.0+EDR（Enhanced Data Rate）2Mbps変調を備えた2.4GHz無線トランシーバーとベースバンドを搭載しています。これにより、全体的な設計/開発サイクルが簡素化されることを期待しています。

Grove - BLE v1​

Grove - BLE v1（Grove - Bluetooth Low Energy v1）は、TI CC2540チップに基づいた低エネルギーBluetoothモジュール--HM-11を使用しています。このモジュールはATコマンドをサポートしています。Grove製品として、Base Shieldを介してArduinoボードと簡単に使用できます。

Wi-Fi​

Grove - UART Wifi V2​

Grove - UART Wifi V2は、広く普及しているESP8266 IoT SoCを搭載したシリアルトランシーバーモジュールです。統合されたTCP/IPプロトコルスタックにより、このモジュールはマイクロコントローラーがわずかなコードでWiFiネットワークとやり取りできるようにします。ホームオートメーション、ネットワークカメラ、ウェアラブル電子機器などの用途に使用できます。

NFC​

Grove - NFC (ST25DV64)​

Grove - NFC (ST25DV64)は、STMicroelectronicsの高度なST25DV64Kチップを基にした革新的で多用途なNFC/RFIDタグボードです。メーカー、DIY愛好家、NFC技術の実験に興味がある方々向けに設計されており、プロジェクトにNFC機能を追加するためのシンプルでコスト効率の高いソリューションを提供します。

Grove - NFC(PN532)​

近距離無線通信（NFC）は、短距離無線技術のセットです。アクセス制御システムやモバイル決済システムなどの日常的なアプリケーションの背後にある技術です。Grove NFCはI2CまたはUART通信プロトコルを使用するよう設計されており、デフォルトモードはUARTです。

Grove - NFCタグ​

Grove - NFC Tagは、高度に統合された近距離無線通信タグモジュールです。このモジュールはI2Cインターフェースを備えています。Grove - NFC Tagは独立したPCBアンテナを備えており、使用するエンクロージャから簡単に伸ばすことができるため、プロジェクトの外観デザインにより多くの余地を残します。

GPS​

Grove - GPS (SIM28)​

このGrove - GPSモジュールは、SIM28（旧バージョンはu-blox 6）とシリアル通信構成を備えたコスト効率の高いフィールドプログラム可能なガジェットです。個人用ナビゲーションプロジェクトや位置情報サービスに最適な選択肢と考えられます。

Grove - GPS (Air530)​

Grove - GPS (Air530)は、高性能で高度に統合されたマルチモード衛星測位およびナビゲーションモジュールです。GPS / Beidou / Glonass / Galileo / QZSS / SBASをサポートしており、車載ナビゲーション、スマートウェア、ドローンなどのGNSS測位アプリケーションに適しています。

RF​

Grove - 125KHz RFID リーダー​

このGrove-125KHz RFID Readerは、uem4100 RFIDカード情報を読み取るためのモジュールで、UartとWiegandの2つの出力形式を備えています。最大7cmの感知距離で高感度を持っています。このモジュールには電子ブリックバージョンもあります。IoTプロジェクトやアクセス制御システムのようなプロジェクトに役立ちます。

Grove - 315MHz RF キット​

このキットは、315MHzの周波数で一方向の無線通信を行うために使用され、送信モジュールと受信モジュールが含まれています。このキットのTwig構成により、屋内で約40メートル、屋外で約100メートルの送信距離が可能です。315MHzの周波数は、米国でライセンスなしで使用するのに適しています。

Grove - シリアル RF Pro​

Grove-Serial RF Proは、低コストで高性能な透明FSKトランシーバーです。ユーザーがUARTボーレート、周波数、出力電力、データレート、周波数偏移、受信帯域幅などのパラメータを柔軟に設定することができます。これは、無線データ伝送製品を設計するための理想的な選択肢であり、無線データ伝送分野で広く使用することができます。

その他の標準プロトコル​

Grove - DMX512​

Grove – DMX512は、GroveインターフェースからDMX512インターフェース（業界標準EIA-485インターフェース）へのアダプターです。Arduinoでステージ照明やDMX512コンソールを簡単に制御することができます。

Grove- I2C ADC​

Grove - I2C ADCは、ADC121C021を基にした12ビット精度のADCモジュールです。一定の基準電圧を提供することで、アナログセンサーから収集した値の精度を向上させることができます。

Grove - プロトシールド​

このGroveは、Groveシステムのプロトタイプに独自の回路やコンポーネントを追加することを可能にします。Groveコネクターケーブルの4本のライン（S0、S1、VCC、GND）すべてにアクセスできます。また、通常開ボタン用の予約スペースもあります。

Grove - RJ45 アダプター​

Grove-RJ45 Adapterは、標準的なGroveコネクターをRJ45コネクターに変換するモジュールです。2つのRJ45アダプターとケーブルを使用することで、ArduinoとGroveモジュール間の通信を実現できます。これにより、距離の問題でArduinoとGroveが接続しにくいという問題を解決します。
