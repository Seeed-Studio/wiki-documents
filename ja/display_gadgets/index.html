はじめに​

XIAO Display Gadgets シリーズは、Seeed Studio XIAO メインコントローラと小型カラー LCD を組み合わせた、コンパクトな拡張ボードファミリです。画面サイズは 0.96インチ、1.14インチ、1.47インチの3種類、XIAO コントローラは XIAO ESP32-S3 Plus と XIAO nRF52840 Plus の2種類があり、ポケットサイズの 80×160 ディスプレイから、MicroSD ストレージを備えた 172×320 静電容量式タッチディスプレイまでラインナップされています。

選び方​

2つのステップでモデルを選びます。まずコントローラを選び、その後に画面サイズを選択します。

ステップ 1: コントローラを選ぶ​

すべての画面サイズはどちらのコントローラでも利用でき、ディスプレイハードウェア — 画面、タッチ、MicroSD、ボタン、オンボードセンサ — は2つのバリアント間で同一です。唯一の違いは、オンボードの XIAO です。

XIAO ESP32-S3 PlusXIAO nRF52840 Plus
無線2.4 GHz Wi-Fi + BLE 5.0BLE 5.4
メモリ8 MB PSRAM + 16 MB Flash256 KB RAM + 1 MB internal Flash + 2 MB onboard Flash
最適な用途Wi-Fi 接続 IoT デバイスやデータダッシュボードバッテリー駆動で BLE を重視したウェアラブルやセンサノード
  • ESP32-S3 Plus を選択：Wi-Fi 接続やより多くのメモリが必要な場合 — 例えば、センサデータをクラウドやリモートダッシュボードへ送信する場合、またはワイヤレス IoT プロトタイプなどに適しています。
  • nRF52840 Plus を選択：バッテリー寿命が重要な低消費電力 BLE 設計の場合 — 例えばスマートバッジ、BLE ステータスディスプレイ、長時間動作するウェアラブルセンサなどに適しています。

ステップ 2: 画面サイズを選ぶ​

コントローラを決めたら、必要な機能に基づいて画面サイズを選択します：

  • 1.47" — 静電容量式タッチスクリーンと MicroSD ストレージを備えた唯一のサイズです。タッチ操作の HMI、ポータブルフォトフレーム、SD オーディオ録音、ローカルでのメディアおよびデータロギングに適しています。
  • 1.14" — 3つのユーザボタンと Grove I2C コネクタを備えた中型スクリーンです。センサディスプレイ、Grove プロジェクト、コンパクトさと拡張性のバランスを取りたい物理コントローラに適しています。
  • 0.96" — 最小のフォームファクタです。スマートバッジやキーチェーンガジェットなど、ウェアラブルやスペースに制約のある設計に適しています。

共通の特長​

6つすべてのモデルは、同じオンボードハードウェアを共有しています：

  • カラー IPS TFT LCD（SPI） — 画面サイズに応じて 80×160、135×240、または 172×320
  • PDM デジタルマイク
  • 6軸 IMU（LSM6DS3、3軸加速度センサ + 3軸ジャイロスコープ）
  • ユーザボタン — モデルに応じて 2 個または 3 個
  • 3.7 V LiPo バッテリー用 2ピン JST コネクタ
  • バッテリー電圧検出（nRF52840 モデルはさらに充電状態も検出）

すべてのモデルは、Seeed の Seeed_GFX2 グラフィックスライブラリを使用して Arduino IDE でプログラムされます。
