用語集、ドキュメントマップ、ライセンス

用語集​

プラットフォームとハードウェア​

用語意味
RV1126BNPU と ISP35 を搭載した Rockchip の IPC 向け SoC。reCamera Pro のメインチップ。RK_CHIP=rv1126b, RK_ARCH=arm64
RV1126BP一部の EVB ボード構成で使用される RV1126B パッケージ／派生バリアント
RK801reCamera Pro で使用される PMIC
RK817オーディオコーデック内蔵 PMIC（CONFIG_SND_SOC_RK817=y）
ES7202マイクアレイキャプチャ用の Everest マルチチャネル ADC
ISP35RV1126B の ISP バージョン。関連する IQ ファイルは iqfiles/isp35/ 配下にある
eMMCオンボードストレージ（RK_BOOT_MEDIUM=emmc）
MaskromSoC ROM に内蔵されたダウンロードモード。フラッシュ書き込みのエントリポイント（USB VID 2207）
loader / idblockDDR 初期化と第 1 段階ブートローダー。出力には idblock.img と download.bin が含まれる
board IDADC の抵抗分圧レベルによって検出されるベースボード／拡張ボードのバリアント。結果は /run/board_id.env に書き込まれる
DTBODevice Tree Blob Overlay。1 つのファームウェアイメージで複数のハードウェアバリアントをサポートするために、実行時に使用される

SDK とビルドシステム​

用語意味
BSPBoard Support Package。U-Boot、カーネル、rootfs、ドライバを含むボードレベルのサポート
BoardConfigproject/cfg/<series>/BoardConfig-*.mk。ビルド用のボードパラメータ一式
lunchBoardConfig を選択する操作。Android ビルドシステム由来の用語。.BoardConfig.mk シンボリックリンクを生成する
sysdrvU-Boot／カーネル／MCU ソースを含むシステムドライバコンポーネント SDK。make で単独ビルド可能
mediampp / rockit / rkaiq / rga / iva などを含むマルチメディアコンポーネント SDK。make で単独ビルド可能
appproject/app/ 配下のユーザ空間アプリケーション
fragmentベース defconfig の上に順番に適用される、カーネル／U-Boot の増分 defconfig
overlayパッケージング時に rootfs 上にコピーされるファイル群のディレクトリ。有効なエントリは RK_POST_OVERLAY に列挙される
IQ filerkaiq のセンサチューニングパラメータ（JSON）を含む Image Quality ファイル
rootfs3 G パーティション上の、Buildroot で生成された ext4 ルートファイルシステム
oem/oem ディレクトリ。このボードでは RK_BUILD_APP_TO_OEM_PARTITION=n のため、別パーティションではなく rootfs 内の通常ディレクトリとなる
userdata/userdata にマウントされる書き込み可能パーティション。設定やユーザデータを保存し、デフォルトの HOME となる
miscリカバリ／ファクトリリセットフラグを含む小さなパーティション
RK_APP_TYPEリファレンスアプリケーションタイプ。このボードでは RKIPC_RV1126B_RECAMERA2 を使用
allsaveall + save。./build.sh を引数なしで実行したときのデフォルト動作
RK_APP_xxxアプリケーションをビルドするかどうかを制御するボード設定スイッチ
MAROC_*Makefile.param 内のマクロ群。MAROC_COPY_PKG_TO_APP_OUTPUT、MAROC_STRIP_DEBUG_SYMBOL、MAROC_PKG_RELEASE などを含む

マルチメディア（rockit / MPI）​

用語意味
MPIMedia Process Interface。rockit 用の統一プログラミングインターフェース
rockitRockchip の MPI ランタイム実装。-lrockit とリンクする
MPPMedia Process Platform。より低レベルのコーデックライブラリ群。-lrockchip_mpp とリンクする
VIVideo Input。ISP を介してセンサからフレームをキャプチャする
VPSSVideo Process Sub System。マルチチャネルのスケーリング／クロップ／フォーマット変換
VENC / VDECビデオのエンコード／デコード
VOディスプレイへの Video Output
RGNOSD オーバーレイやウォーターマーク用のリージョンモジュール
AI / AOAudio In / Audio Out
AENC / ADECオーディオのエンコード／デコード
AVS複数カメラのサラウンドビュー合成を行う Around View System
IVS動体検知などの解析を行う Intelligent Video Surveillance
TDE2D アクセラレーション用の Two Dimensional Engine
RGAラスタグラフィックアクセラレーション。スケーリング、NV12↔RGB 変換、回転を行う 2D アクセラレータ
MBMedia Buffer／バッファプール
BindRK_MPI_SYS_Bind() により 2 つのモジュール間のチャネルを接続し、データを自動的にフローさせる
EIS / DIS電子式／デジタル式の手ぶれ補正
ePTZ電子的パン・チルト・ズーム
SVCScalable Video Coding
AOVAlways-On Vision。低消費電力の常時オンビジョン
FEC魚眼／歪み補正ハードウェア（CONFIG_VIDEO_ROCKCHIP_FEC=y）
IRFPA赤外線焦点面アレイ（サーマルイメージング）
rkaiq3A とチューニング用の Rockchip AI ISP エンジン。-lrkaiq とリンクする
uAPI / uAPI2rkaiq の 2 世代のユーザ空間インターフェース。新規コードは uAPI2（rk_aiq_user_api2_*.h）を使用すること
AINRAI ノイズリダクション。関連する IQ ファイルは iqfiles/isp35/ainr/ 配下にある
AI-ISPNPU を使用して ISP 出力を強化する機能。このボードでは無効（RK_AIISP_MODEL=NONE）

AI / NPU​

用語意味
NPURV1126B に統合された Neural Processing Unit
RKNNRockchip のニューラルネットワークモデル形式とランタイム（.rknn + librknnrt.so）
RKNN-Toolkit2x86_64／Python 向けの PC 側モデル変換ツール。SDK には含まれず、別途インストールが必要。内部ベースライン：2.3.2
rknn-toolkit-lite2デバイス向けの Python 推論ラッパー。検証用途にのみ適しており、本番アプリケーションでは C API を使用する
RKLLMRockchip の大規模言語モデルランタイム（.rkllm + librkllmrt.so）
rkllm-toolkitmedia/rknn-llm-mk/rknn-llm/rkllm-toolkit/ 配下にある PC 側 LLM 変換ツール
ROCKIVARockchip のビジョンアルゴリズム群（人物／顔／ペット検出など）をパッケージ化したもの。-lrockiva とリンクする
RKAILLM と VLM のワークフローをカバーする、project/app/rkai/ 配下の Rockchip AI ラッパー
VLMVision-Language Model。画像とテキストのマルチモーダルモデル
TTFTTime To First Token。RKLLM のベンチマーク指標
RKNN_NPU_CORE_xNPU コア割り当てマスク（AUTO / 0 / 0_1 / 0_1_2）
INT8 quantization / calibration set量子化には代表的な画像リストを使用する。キャリブレーションセットは検証セットと分離しておくこと

ネットワークとストリーミング​

用語意味
rkipcRockchip の IPC リファレンスアプリケーション。reCamera Pro のメインアプリ（recamera_ipc）はこれをベースとしている
go2rtc内部 RTSP を WebRTC／HLS などに変換するオープンソースのストリーミングゲートウェイ。overlay 内のビルド済みバイナリとして提供される
RTSPReal-Time Streaming Protocol。内部ソースは 127.0.0.1:5554。外部ポート :554 は必要に応じて有効化される
WebRTCブラウザベースのリアルタイム音声／映像。go2rtc は :8555 をリッスンする
ONVIFrecamera_onvif によって実装される、ネットワークデバイス相互運用標準
ttydポート 7681 上のウェブページ経由でターミナルを公開する
main / sub streamlive/0 および live/1 に対応する go2rtc のストリーム名

reCamera サービス​

用語意味
gmgrGPIO Manager。ポート 8080 と /dev/shm/gmgr.sock 上で動作する Rust 製 GPIO HTTP／WebSocket サービス
skt2wsrkipc-record-events を転送する Socket-to-WebSocket ブリッジ
tmirTTY Mirror。シリアルポート ttyS4 のトラフィックをソケット／WebSocket に多重化する
rcisdイベントキューイングとファイル転送を行う reCamera Intellisense デーモン
RkLunch.sh/oem/usr/bin/ 配下にある、システム全体のアプリケーション起動エントリポイント
vigilrecamera_ipc/common/vigil* 配下のモジュール。protobuf と libblkid に依存する
VQEVoice Quality Enhancement。音声フロントエンドアルゴリズム（AEC / ANS / AGC）
AECAcoustic Echo Cancellation。スピーカのリファレンス信号（asound.conf の Ch4）を必要とする
dsnoop1 つのハードウェアデバイスを複数プロセスで読み取れるようにする ALSA の共有キャプチャプラグイン
KWS / ASRKeyword Spotting / Automatic Speech Recognition。対応する仮想デバイスは ai_kws / ai_asr
