ファクトリーファームウェア コマンドリファレンス

記号の表記規則​

記号意味例
[ ]省略可能なパラメータ。省略時はデフォルト値が適用されます[-p <port>]
< >ユーザーが指定しなければならない具体的な値-g <gpio>
|列挙された値のいずれかを選択<0|1>
角括弧のない単語必須ping <host>
cmd>ファームウェアのプロンプト。入力しないでくださいcmd> help

値は常に -flag value の形式で記述します。例えば gpio_set -g 4 -l 1 のようになります。ファームウェアがロングフォームも登録している場合は、パラメータ表でショートフォームの隣にロングフォームを併記します。

General​

1. help​

登録されているすべてのコマンドを 1 行説明付きで一覧表示します。

このコマンドにはパラメータはありません。

例：

help

LoRa / RF​

これら 7 つのコマンドは、オンボードの LR2021 トランシーバを 2 つの変調方式で駆動します。LoRa は長距離向け、FLRC は高速向けです。すべての送信コマンドは、対応するコネクタにアンテナが必要です。サブ GHz 搬送周波数には SUB-1G、2400 ～ 2500 MHz 帯には LR-2.4G を使用します。2 枚のボードでリンクテストを行う場合は、両側で同一の無線パラメータを設定する必要があります。

注意: lora_rx、flrc_rx、lora_tx -n 0、flrc_tx -c 0 は、Ctrl+C を押すまで動作し続けます。

1. lora_tx​

lora_tx [-f <freq_hz>] [-s <5-12>] [-b <0-9>] [-c <1-7>] [-p <dbm>] [--crc <0|1>] [--hdr <0|1>] [--iq <0|1>] [--net <0|1>] [-i <interval_ms>] [-d <text>] [-n <count>] [-hp <n>] [-dc <n>] [-lf <n>]

設定した周波数、スペクトラム拡散率、出力で LoRa パケットを送信します。

項目説明データ
-f <freq_hz>送信周波数150000000 ~ 2500000000 Hz。デフォルト: 868000000
-s <5-12>スプレッディングファクタ5 ~ 12。値が大きいほど低速で遠くまで届きます。デフォルト: 7
-b <0-9>帯域幅インデックス0=31k、1=41k、2=62k、3=125k（デフォルト）、4=200k、5=250k、6=400k、7=500k、8=800k、9=1000k
-c <1-7>符号化率1 ~ 7。1=4/5 が最速、4=4/8 が最も堅牢。デフォルト: 1
-p <dbm>送信電力サブ GHz -10 ~ +22 dBm、2.4 GHz -17 ~ +12 dBm。デフォルト: 10
--crc <0|1>CRC チェック0=オフ、1=オン。デフォルト: 1
--hdr <0|1>ヘッダ種別0=インプリシット、1=エクスプリシット。デフォルト: 1
--iq <0|1>IQ モード0=標準、1=反転。デフォルト: 0
--net <0|1>ネットワーク種別とシンクワード0=プライベート（シンクワード 0x12）、1=パブリック（シンクワード 0x34）。デフォルト: 1
-i <interval_ms>パケット間隔ミリ秒。デフォルト: 200。0=連続送信
-d <text>ペイロード文字列デフォルト: hello
-n <count>パケット数0= Ctrl+C まで送信。デフォルト: 10
-hp <n>PA ハーフパワーレジスタデバッグ専用。通常使用では未指定のままにします
-dc <n>PA デューティサイクルレジスタデバッグ専用。通常使用では未指定のままにします
-lf <n>PA 低周波スライスレジスタデバッグ専用。通常使用では未指定のままにします

例：

lora_tx -f 868000000 -s 7 -b 3 -p 14 -d hello -n 10
注記

まずアンテナを取り付け、2 枚目のボードで lora_rx を起動し、-f、-s、-b、-c、--hdr、--crc、--iq、--net を同じ値に設定してください。範囲外の値を指定すると out of bounds 警告が表示され、コマンドはフォールバックします。-f はデフォルト周波数、-s は 7、-b は 3、-c は 1 に戻ります。-p はバンドの上限にクランプされます。数値以外の -f、負の -i または -n を指定すると、コマンドは中止され、何も送信されません。

2. lora_rx​

lora_rx [-f <freq_hz>] [-s <5-12>] [-b <0-9>] [-c <1-7>] [--crc <0|1>] [--hdr <0|1>] [--plen <0-255>] [--iq <0|1>] [--net <0|1>]

LoRa パケットを連続受信し、その数をカウントします。

項目説明データ
-f <freq_hz>受信周波数150000000 ~ 2500000000 Hz。デフォルト: 868000000
-s <5-12>スプレッディングファクタ5 ~ 12。デフォルト: 7
-b <0-9>帯域幅インデックス0=31k、3=125k（デフォルト）、9=1000k
-c <1-7>符号化率1 ~ 7。デフォルト: 1
--crc <0|1>CRC チェック0=オフ、1=オン。デフォルト: 1
--hdr <0|1>ヘッダ種別0=インプリシット、1=エクスプリシット。デフォルト: 1
--plen <0-255>受信側が想定するペイロード長バイト数。エクスプリシットモードでは 0=任意長、インプリシットモードで省略時は 5 とみなします。デフォルト: 0
--iq <0|1>IQ モード0=標準、1=反転。デフォルト: 0
--net <0|1>ネットワーク種別とシンクワード0=プライベート（0x12）、1=パブリック（0x34）。デフォルト: 1

例：

lora_rx -f 868000000 -s 7 -b 3
注記

このコマンドは Ctrl+C までコンソールをブロックし、その時点で rx_done、rx_hdr_err、rx_crc_err を表示します。両方のボードは同じ --hdr 値を使用する必要があります。一方がインプリシット、もう一方がエクスプリシットでは受信できません。インプリシットモードでは、送信側のペイロード長に合わせて --plen を設定してください。長くしすぎると末尾にゴミが付き、短すぎると末尾が切り捨てられます。インプリシットモードで --crc 1 を指定すると、テストでは CRC エラーが発生したため、--hdr 0 と --crc 0 を組み合わせて使用してください。近距離で hdr err が長く続く場合は、パケットが連続して到着していることを意味します。送信側の -i を 100 ～ 200 に上げ、1 パケットの空中伝送時間より長く保ってください。

3. lora_cw​

lora_cw [-f <freq_hz>] [-p <dbm>]

RF 電力測定用に、変調のない連続波を送信します。

項目説明データ
-f <freq_hz>キャリア周波数150000000 ~ 2500000000 Hz。デフォルト: 868000000。範囲外または数値以外の値はコマンドを中止します
-p <dbm>送信電力サブ GHz -10 ~ +22 dBm、2.4 GHz -17 ~ +12 dBm。デフォルト: 10。バンド上限にクランプされます

例：

lora_cw -f 868000000 -p 10
注記

キャリアは lora_cw_stop を入力するまで継続します。テスト中に電力や周波数を変更したい場合は、新しい値で再度 lora_cw を実行してください。設定は自動的に再起動されます。

4. lora_cw_pa​

lora_cw_pa [-f <freq_hz>] [-p <dbm>] [-h <n>] [-d <0-31>] [-l <0-15>]

PA レジスタを直接制御して連続波を送信します。

項目説明データ
-f <freq_hz>キャリア周波数150000000 ~ 2500000000 Hz。デフォルト: 868000000
-p <dbm>送信電力サブ GHz -10 ~ +22 dBm、2.4 GHz -17 ~ +12 dBm。デフォルト: 10
-h <n>PA ハーフパワー値0.5 dB ステップ。サブ GHz -19 ~ 44、2.4 GHz -39 ~ 24
-d <0-31>PA デューティサイクル0 ~ 31
-l <0-15>PA 低周波スライス数0 ~ 15

例：

lora_cw_pa -f 868000000 -h 22 -d 0 -l 0
注記

-h、-d、-l のいずれか 1 つでも指定すると、コマンドは直接パラメータモードに切り替わり、パワーテーブルを上書きします。範囲外の値は out of bounds 警告とともにバンド上限にクランプされます。キャリアの停止には lora_cw_stop を使用してください。

5. lora_cw_stop​

lora_cw_stop

lora_cw または lora_cw_pa で開始した連続波を停止します。

このコマンドにはパラメータはありません。

例：

lora_cw_stop

6. flrc_tx​

flrc_tx [-f <freq_hz>] [-p <dbm>] [-b <0-7>] [-l <1-255>] [-c <count>]

インクリメントするペイロードを持つ FLRC パケットを、1 秒に 1 パケット送信します。

項目説明データ
-f <freq_hz>送信周波数415000000 ~ 940000000 Hz。デフォルト: 915000000。範囲外はデフォルトにフォールバック
-p <dbm>送信電力-10 ~ +22 dBm。デフォルト: 22。上限にクランプ
-b <0-7>レートと帯域幅の組み合わせ0=2.6 Mbps（最速）から 7=0.26 Mbps まで。デフォルト: 0。範囲外は 7 にフォールバック
-l <1-255>パケット長バイト数。デフォルト: 200。範囲外はデフォルトにフォールバック
-c <count>パケット数デフォルト: 100。0= Ctrl+C まで送信。500 を超える値は 500 に切り詰め

例：

flrc_tx -f 868000000 -p 14 -l 200 -c 100
注記

1 秒ごとに 1 パケット送信されるため、1 分間の実行で約 60 パケット送信されます。-c 0 を指定すると、Ctrl+C まで停止せずに送信し続けます。

7. flrc_rx​

flrc_rx [-f <freq_hz>] [-b <0-7>]

FLRC パケットを受信し、正常パケット数、ヘッダエラー数、CRC エラー数をカウントします。

項目説明データ
-f <freq_hz>受信周波数415000000 ~ 940000000 Hz。デフォルト: 915000000。範囲外はデフォルトにフォールバック
-b <0-7>レートと帯域幅の組み合わせ0 ~ 7。デフォルト: 0。範囲外は 7 にフォールバック

例：

flrc_rx -f 868000000 -b 0
注記

Ctrl+C で受信を停止し、カウンタを表示します。

BLE​

Bluetooth は起動時には開始されません。最初の ble -a 1 で BLE スタックを初期化し、アドバタイズを開始します。ble -a 0 はアドバタイズを停止し、スタックをアンロードしてメモリを解放します。デバイス名は wio-lr2021- で始まり、アドバタイズは接続を受け付けます。

1. ble​

ble -a <0|1>

Bluetooth アドバタイズをオンまたはオフにします。

項目説明データ
-a <0|1>アドバタイズスイッチ1=アドバタイズ開始（初回はスタックを初期化）、0=アドバタイズ停止およびスタック解放。必須

例：

ble -a 1
注記

スマートフォンの nRF Connect から wio-lr2021- を検索します。リストに表示されればデバイスは正常です。接続後、アプリはデバイスにコマンドを送信し、デバイスが出力するログ行を読み取ることができます。

2. ble_status​

ble_status

デバイス名、MAC アドレス、送信電力、アドバタイズパラメータ、および接続状態を表示します。

このコマンドはパラメータを取りません。

例:

ble_status
注記

Bluetooth が初期化されていない場合、このコマンドは最初に ble -a 1 を実行するように促します。

Wi-Fi & ネットワーク​

Wi-Fi は起動時に自動で初期化および開始されるため、これらのコマンドで手動の wifi init は不要です。ほとんどのコマンドは Espressif の Wi-Fi テストコンポーネントをラップしており、多くのオプションを持ちます。以下のパラメータ表には、文書化されているものを示します。ルーターへの接続には、ユーザー自身の 2.4 GHz アクセスポイントとそのパスワードが必要です。

1. wifi​

wifi <status|stop|start|restart|init|deinit>

Wi-Fi の状態を問い合わせる、または無線を開始・停止・再初期化します。

項目説明データ
status初期化状態と接続情報を表示最も一般的な問い合わせ
stop, start無線を停止または開始、ドライバは保持電力試験および干渉除去
restartフル再起動：stop, deinit, init, startdeinit 後の復旧
init, deinitドライバを初期化またはアンロード研究開発でのデバッグ専用

例:

wifi status
注記

すでに初期化済みのシステムで wifi init を実行すると、WiFi already initialise. という 1 行の警告を出してスキップされます。wifi deinit は無線がまだ動作中であれば先に停止し、wifi status は initialized と started を別々に表示します。

2. wifi_count​

wifi_count [query|clear]

Wi-Fi の送受信パケットカウンタを表示またはリセットします。

項目説明データ
queryカウンタを表示引数がない場合のデフォルト
clear両方のカウンタをゼロにリセット—

例:

wifi_count

3. wifi_mode​

wifi_mode <sta|ap|apsta>

デバイスの Wi-Fi ロールを設定します。

項目説明データ
staスマートフォンなど、別のホットスポットに参加—
apホットスポットとして動作—
apsta両方のロールを同時に使用—

例:

wifi_mode sta

4. wifi_protocol​

wifi_protocol [protocol] [-i <ap|sta>]

802.11 プロトコルの組み合わせを問い合わせまたは設定します。

項目説明データ
<protocol>プロトコルの組み合わせb, b/g, b/g/n; デフォルト：現在値を問い合わせ
-i <ap|sta>設定を適用するインターフェースap または sta; デフォルト：sta

例:

wifi_protocol b/g/n

5. wifi_bandwidth​

wifi_bandwidth [20|40] [-i <ap|sta>]

チャネル帯域幅を問い合わせまたは設定します。

項目説明データ
<20|40>MHz 単位のチャネル帯域幅20 または 40; デフォルト：現在値を問い合わせ
-i <ap|sta>設定を適用するインターフェースap または sta; デフォルト：sta

例:

wifi_bandwidth 20

6. wifi_ps​

wifi_ps <0|1|2>

Wi-Fi の省電力レベルを設定します。

項目説明データ
0省電力なし、最高性能必須
1中程度の省電力—
2最大の省電力—

例:

wifi_ps 0

7. wifi_country​

wifi_country [code] [-s <start_channel>] [-n <channel_count>] [-p <auto|manual>]

国コードと使用可能なチャネル範囲を問い合わせまたは設定します。

項目説明データ
<code>2 文字の国コード例：US; デフォルト：現在値を問い合わせ
-s <start_channel>許可された範囲の最初のチャネルチャネル番号; デフォルト：未設定
-n <channel_count>範囲内のチャネル数個数; デフォルト：未設定
-p <auto|manual>チャネルプランの選択auto または manual; デフォルト：未設定

例:

wifi_country US

8. ap_set​

ap_set <ssid> [pass] [-a <authmode>] [-n <channel>] [-m <max_conn>]

デバイスを Wi-Fi ホットスポットとして動作させ、スマートフォンや PC が接続できるようにします。

項目説明データ
<ssid>ホットスポット名必須
<pass>ホットスポットのパスワード8 文字以上; 任意
-a <authmode>セキュリティモードopen, wep, wpa2; 認識されない名前は報告され、ホットスポットは open にフォールバック; デフォルト：未設定
-n <channel>ホットスポットのチャネルチャネル番号; デフォルト：未設定
-m <max_conn>同時接続クライアントの最大数デフォルト：2

例:

ap_set MyTestAP 12345678

エイリアス: ap（ap_set と同じ）。

注記

共有ネットワーク上でホットスポットを有効にしたままにする前にパスワードを変更し、テストが終わったら停止してください。

9. ap_query​

ap_query

現在のホットスポット設定と、接続されているクライアント数を表示します。

IO エクスパンダ​

GPIO 番号は ESP32-S3 の GPIO 番号です。ピン機能は Wio-LR2021 Dev Kit Pin Map に一覧があります。IO エクスパンダは I²C アドレス 0x21 の PCA9535 です。0 ～ 15 の 16 本のピンを公開しており、そのうち 4 本がカメラ、オーディオ、OLED、Grove の電源レールを切り替えます。

注記

どのペリフェラルにも割り当てられていないピンは、電源投入後はフローティング入力のまま（プル抵抗オフ）なので、生の gpio_get はノイズを読み取ります。まず gpio_config を実行してください：入力には -m 0（任意でプル指定）、プッシュプル出力には -m 1、オープンドレイン出力には -m 2 を指定します。

1. gpio_set​

GPIO を High または Low に駆動します。

項目説明データ
-g <gpio>GPIO 番号必須
-l <0|1>出力レベル1=High（約 3.3 V）、0=Low（0 V）; 必須

例:

gpio_set -g 4 -l 1
注記

ピンを駆動する前に gpio_config -m 1 で方向を設定し、マルチメータまたは別の GPIO へのループバックワイヤでレベルを確認してください。

-g <gpio>GPIO 番号必須
-m <0|1|2>方向0=入力、1=出力、2=オープンドレイン出力; 必須
-p <0|1|2|3>プル抵抗0=フローティング（デフォルト）、1=プルアップ、2=プルダウン、3=両方有効

項目説明データ

カメラはMedia HAT上の2 MP GC2145で、工場出荷時ファームウェアはRGB565として読み取り、JPEGフレームをストリーミングします。camera_http_start は、ホットスポット、カメラ、Webサーバを1つのコマンドで起動する、最も短いエンドツーエンドチェックです。

フラッシュの耐久性テストと速度テストは、専用の flashtest パーティション内でのみ動作するため、ファームウェアイメージやユーザーデータには一切触れません。flash_endurance はバックグラウンドタスクとして動作し、コンソールを使用可能なまま書き込みを続けます。

例：

flash_info
注記

リターンコード 0 は合格を意味します。境界書き込みチェックは、容量を過大に表記したフラッシュチップを検出します。

解析できない値はコマンドを中止し、英語のエラー行を出力します。範囲外の値は通常 out of bounds をログに出し、文書化されたデフォルトにフォールバックします。文言はコマンドごとに異なるため、文をパターンマッチするのではなく、指摘された値を修正してコマンドを再実行してください。
