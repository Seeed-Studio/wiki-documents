Ripple を使い始める

Ripple とは？​

Ripple UI は L2 Pro 用のタッチスクリーンファームウェアです。連絡先の追加、メッセージの送受信、地図の表示、GPS トラックの記録を、これらの操作に電話を使うことなく、デバイス上で直接行うことができます。

Ripple と MeshCore の関係​

MeshCore はメッシュ通信を処理します。Ripple UI を使うことで、L2 Pro のタッチスクリーンから直接 MeshCore を利用できます。

NamePurpose
MeshCoreLoRa メッシュ通信
Ripple UI firmware単体で動作するタッチスクリーン操作
MeshCore Companion firmwareスマートフォンや他のクライアントを介した操作

Ripple UI を直接書き込みます。事前に Companion をインストールする必要はありません。

注記

更新されたファームウェアは MeshCore プロファイルを使用し、New Network 画面で Ripple を選択することはできなくなりました。

Ripple は誰のためのもの？​

  • 電話を常時接続せずに、デバイス上で直接チャットしたいユーザー。

  • オフライン地図と、自分のルートの記録を必要とするアウトドアユーザー。

  • 異なる MeshCore ネットワークプロファイルを切り替えて使いたいユーザー。

  • MeshCore リピーター、Room Server、センサーノードを管理する必要がある上級ユーザー。一部の管理機能には有料のアンロックコードが必要です。

機能​

  • スタンドアロンメッセージング： タッチスクリーンからダイレクトメッセージやグループメッセージを送信できます。

  • 複数のネットワークプロファイル： 無線設定、ID、連絡先、各種設定をプロファイルごとに分けて保持できます。

  • カスタマイズ可能なホーム画面： 連絡先、チャンネル、設定へのショートカットを追加できます。

  • 地図： microSD から地図を読み込み、ドラッグでパンし、ボタンをタップしてズームできます。

  • GPS トラック： 位置とタイムスタンプを記録し、地図上で自分のルートを表示できます。

  • スクリーンショット： 画面左上を長押しして、現在の表示をキャプチャします。

  • リモート管理： 対象ノードの認可を得て、ノード管理機能をアンロックできます。

ファームウェアを書き込む​

お使いのデバイスに、ここで説明するバージョンの Ripple UI がすでに入っている場合は、初回セットアップ までスキップしてください。

2 種類のファームウェアバリアントがあります：

  • Ripple GUI: data on SD card (-SD)： 設定とデータを microSD カードに保存します。使用前に、32 GB 以下の FAT32 形式のカードを挿入してください。

  • Ripple GUI (Internal)： 設定とデータをデバイスの内部フラッシュに保存します。

ステップ 1：Web フラッシャーを開く

Wio Tracker L2 Web Flasher にアクセスし、L2 用の Ripple UI ファームウェアとストレージバリアントを選択します。Chrome や Edge など、シリアルアクセスをサポートするデスクトップブラウザを使用してください。

Seeed Studio Wio Tracker L2 Pro を選択し、Ripple GUI バリアントを選んでから、ファームウェアバージョンを選択します。下のスクリーンショットでは v12.3 を示しています。

ステップ 2：手動でダウンロードモードに入る

USB データケーブルを接続しながら U/B ボタンを押し続け、その後 RST を押してファームウェアダウンロードモードに入ります。

ステップ 3：ポートを選択して書き込む

Flash! をクリックし、シリアルポートダイアログでデバイスを選択して接続します。画面の指示に従って書き込みを完了してください。

警告

上記の Erase device オプションは、アンロック状態を含め、内部フラッシュ内のデータと設定を消去します。消去する前に、重要なデータをバックアップし、Unlock Code を控えておいてください。

ステップ 4：再起動

書き込みが完了したら、RST を押して Ripple UI を起動します。

ヒント

Flash をクリックしても先に進めない場合は、デバイスがダウンロードモードになっているか確認してください。また、USB データケーブル、ブラウザのシリアル権限、他のアプリケーションがポートを使用していないかも確認してください。

初回セットアップ​

初回起動時に表示されるタッチスクリーンとボタンのチュートリアルに従ってください。

ハードウェアボタン​

Ripple UI はタッチスクリーン入力と 2 つのハードウェアボタンを組み合わせて使用します：

  • 画面オン/オフ（上部ボタン）： 押すと画面を点灯または消灯します。画面をオフにしても、デバイスの電源は切れません。
  • ENTER（側面の U/B ボタン）： 押すと選択の確定、変更の保存、プロンプトが表示されたときの入力の送信を行います。

ネットワークプロファイルを作成する​

  1. 初回起動時に表示されるタッチスクリーンと Select ボタンのチュートリアルを完了します。

  2. お住まいの地域に適した無線プリセットを選択するか、ローカルネットワークで使用されている周波数、拡散率（SF）、その他のパラメータを入力します。

  3. プロファイル名を、スペースを含まない英数字で設定します。

  4. プロファイルを保存します。求められた場合は、設定を反映するためにデバイスを再起動します。

2 台でテストする場合は、両方のデバイスで同じ無線設定を使用してください。同じプリセットを選ぶのが最も簡単です。カスタム設定を使う場合は、周波数と SF だけでなく、帯域幅、符号化率などのパラメータも一致しているか確認してください。

自分の名前を設定する​

  1. 左側の L をタップし、現在のネットワークプロファイルを開いて Identity を選択します。

  2. デフォルト名を、micha や michb など認識しやすい名前に変更します。名前は最大 31 文字まで使用できます。

インターフェースを見てみる​

画面左側の G、L、M をタップして、3 つのホームページを切り替えます。

  • G: Grid
  • L: List
  • M: Map
  • Extra

G は 3 × 4 グリッドのカスタマイズ可能なホーム画面です。

  • 空のセルを長押しして、連絡先、グループチャンネル、設定へのショートカットを追加します。

  • 既存のショートカットを長押しして削除します。

L には、ネットワークプロファイル、連絡先、グループチャンネル、Discover が一覧表示されます。このページから連絡先の追加、Identity の編集、会話の開始ができます。

スクリーンショットにはテスト時に使用した名前が表示されています。実際のリストは、あなたのプロファイルと連絡先によって異なります。

M では、地図、位置情報、読み込まれた GPS トラックが表示されます。

  • 画面をドラッグしてパンします。

  • + または − をタップしてズームします。ピンチイン・ピンチアウトによるズームには対応していません。

  • 位置追従ボタンをタップすると、地図が自分の位置を中心に表示し続けます。ボタンが有効なときはオレンジ色になり、画面はオンのままになります。

左下のホーム画面メニューを開き、Extra にアクセスすると、デバイス設定やツールを利用できます。

  • Display： フォントサイズ、テーマ、アニメーション、アクセントカラーを調整します。

  • Wi-Fi： 接続と地図ダウンロードを設定します。地図のダウンロードにはアンロックコードが必要です。

  • Networks： ネットワークプロファイルを作成および管理します。

  • GPS Config： GPS 通信設定を構成します。通常はデフォルト設定で L2 Pro で問題なく動作します。

  • Timezone： ローカルの UTC オフセットを設定します。

  • SX1262： LoRa 無線の初期化状態を確認します。code=0 は成功を意味します。

タイトルバーとシステムメニュー​

AreaFunction

スクリーンショットを撮る​

画面左上を長押し して、現在の表示をキャプチャします。スクリーンショットは、設定の共有や問題報告に利用できます。

キャプチャされたスクリーンショットは、日時を含むファイル名の BMP ファイルとして保存されます（下図参照）。

最初のメッセージを送る​

デバイスを検出可能にする​

  1. 両方のデバイスで、同じ MeshCore 無線設定を構成します。

  2. 各デバイスに異なる Identity 名を設定します。

  3. Advert を On に設定して、Identity のアドバタイズを許可します。

  4. L ページから Discover を開き、近くのノードが表示されるのを待ちます。

Identity アドバタイズをすぐに送信するには、Discover メニューを開きます：

OptionFunction
Send ID Local近くのデバイスにゼロホップの Identity アドバタイズを送信します
Send ID Broadcastメッシュ全体に自分の Identity をブロードキャストします
Scan Local検出応答をサポートする近くのノードからの応答を要求します。リピーターの検出によく使用されます

Scan Local はすべてのデバイスを一覧表示するわけではありません。ノードは電波の届く範囲内にあり、応答するように設定されている必要があります。

連絡先を追加する​

  1. Discover で対象ノードを選択します。

  2. 右上のメニューを開き、Add to Contacts を選択します。

  3. L に戻り、連絡先が一覧に表示されていることを確認します。

  4. もう一方のデバイスでも同じ操作を行います。

ダイレクトメッセージを送信する​

  1. 連絡先を開きます。

  2. 入力フィールドをタップしてメッセージを入力します。

  3. ENTER を押して送信し、応答を待ちます。

  4. もう一方のデバイスで会話を開き、返信します。

ダイレクトメッセージは、受信側からの確認応答（ACK）を待ちます。送信に失敗した場合は、無線設定と距離を確認してから再試行してください。以前の経路が使用できなくなっている場合は、新しい経路を見つけるために Path で Flood (reset) を選択します。

マップと GPS トラック​

オフラインマップを準備する​

  1. 32 GB 以下の FAT32 形式の microSD カードを準備します。

  2. カード上に次のフォルダ構造を使ってラスターマップタイルを保存します：


/tiles/{zoom}/{x}/{y}.png

  1. カードを挿入し、デバイスを起動して M を開きます。SD カードがマウントまたはアンマウントされた場合は、デバイスの再起動が必要です。

  2. タイルが存在するエリアまでパンし、利用可能なズームレベルを選択します。

zoom はズームレベル、x と y はタイル座標です。ロックされたデバイスは ズームレベル 1～9 のみを描画します。より詳細なズームレベルにはアンロックコードが必要です。

Wi-Fi 経由でマップをダウンロードする（アンロックが必要）​

  1. 以下の手順に従ってデバイスをアンロックします。

  2. ホーム画面のシステムメニューから Wi-Fi を開きます。

  3. ネットワーク名とパスワードを入力し、マップのダウンロードを有効にします。

  4. ENTER を押して保存し、表示されたら再起動します。

  5. Wi-Fi メニューにオレンジ色の接続インジケータが表示されていることを確認します。

  6. マップを開き、必要なエリアまでパンまたはズームします。タイルはオンデマンドでダウンロードされ、SD カードにキャッシュされます。

広告で使用される位置情報を設定する​

Advert Location 設定使用される位置情報
GPSデバイスの GPS によって取得された位置
Manualマップ上で Advert Loc によって選択された固定位置

マップ上で選択したポイントを使用するには、まず Advert Location を Manual に設定します。GPS モードでは、広告は引き続き GPS 位置を使用します。

プレミアム機能をアンロックする​

アンロックコードを購入する前に、基本的なメッセージングを試すことができます。詳細なマップ、Wi-Fi マップダウンロード、より長いトラック、または高度な管理機能が必要になったら、デバイスをアンロックしてください。

デバイスのシリアル番号を確認する​

デバイスのメニューで Unlock を探して開きます。その画面に表示される Serial number を記録します。MAC アドレスの末尾数文字や Pair Device PIN ではなく、この完全なシリアル番号を購入時に使用してください。

アンロックコードを取得する​

Scott の Ripple Ultra Unlock Code ページを開き、購入手順に従って、デバイスに表示されているシリアル番号を入力します。ライセンスはデバイスごとに発行されます。1 つのライセンスにつき、1 台分のシリアル番号のみ入力してください。

デバイスに該当するアンロックコードが付属している場合は、次のステップに進んでください。

デバイスにコードを入力する​

  1. シリアル番号に対応する Unlock Code を受け取ったら、再度 Unlock を開きます。

  2. コード全体を入力して送信します。

  3. 有効化に成功すると、Unlock オプションは表示されなくなります。

  4. 使用したいプレミアム機能を開き、利用可能になっていることを確認します。

コードは、そのデバイスのシリアル番号と一緒に保管してください。テストでは、erase_flash でフラッシュを消去してファームウェアを再インストールしたところ、デバイスのアンロックコードを再入力する必要がありました。

プレミアム機能​

  • 自動テレメトリ： 直接パスで会話を開いたときにテレメトリを要求します。相手ノードが GPS テレメトリを許可している場合、位置、方向、距離を表示します。

  • Room 管理 CLI： 管理者パスワードを使って Room Server のコマンドラインにアクセスします。

  • リピータ管理： リピータの状態を確認し、ノードをリモート管理します。

  • センサー管理： センサーコマンド、テレメトリ、および権限管理にアクセスします。

  • より詳細なマップズーム： ズームレベル 9 より上のマップタイルを表示します。

  • Wi-Fi ダウンロード： マップタイルをオンデマンドでダウンロードし、SD カードにキャッシュします。

  • より長い GPS トラック： ロックされたデバイスで許可されている 64 GPS ポイントを超えて記録します。

上級者向けの使い方​

ネットワークプロファイルを作成・切り替えする​

  1. ホーム画面のシステムメニューを開き、Networks を選択します。

  2. New Network を選択し、無線設定を構成してプロファイルに名前を付けます。

  3. 保存し、表示されたら再起動します。

  4. タイトルバーの左側をタップし、Switch To でプロファイルを選択します。

各プロファイルは、それぞれ独自の ID、連絡先、設定を持ちます。別のプロファイルに属する連絡先を開くと、プロファイルの切り替えを促されることがあります。このプロンプトは、相手ノードが現在どのネットワークを使用しているかをデバイスが検出したことを意味するものではありません。

FAQ​

SX1262 ステータスコード​

この画面には、LoRa 無線の初期化から返される RadioLib のリターンコードが表示されます。0 は初期化が成功したことを意味します。この画面は無線の診断を目的としています。

他のデバイスを検出できない​

  • 両方のデバイスが、無線設定が一致する互換性のある MeshCore プロファイルを使用していることを確認します。

  • 相手側のデバイスで Advert を有効にするか、Send ID Local を送信してもらいます。

  • まずは見通しの良い場所で短距離テストから始めてください。

  • Scan Local は、検出要求に応答するノードのみを一覧表示します。すべてのデバイスからの ID 広告を代替するものではありません。

マップが真っ白なのはなぜですか​

SD カードのフォーマット、タイルパス、および表示されているエリアにタイルが存在するかを確認してください。ロックされたデバイスでは、ズームレベルが 1～9 の範囲内であることも確認します。有効な GPS 位置があることは、マップタイルがダウンロードされていることを意味しません。
