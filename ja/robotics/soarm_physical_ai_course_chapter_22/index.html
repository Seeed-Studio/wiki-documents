22. SenseCraft Robotics のノーコード VLA

ノーコード VLA パス：SenseCraft Robotics でアームの接続とキャリブレーション、テレオペレーションの確認、カメラのバインド、データの収集と洗浄、クラウド / ローカル訓練、推論まで — 端末も訓練 GPU も不要です。

準備接続収集運用
この章の対象すべての人 — 特に訓練 GPU のない読者へ。第 11 章と同じタスク（A でつかみ B へ置く）、同じ理論 — Python は不要です。6 ステップのガイド付きワークフローが端末を置き換えます。
ヒント

SenseCraft Robotics は SO-ARM101（および reBot シリーズ）向けの Seeed のノーコードプラットフォームです。ガイド付き UI でアームの接続、キャリブレーション、教示データの収集、訓練、推論まで行えます — Python 環境も端末も不要。本章はステージ 3〜4 で行ったすべての GUI 対応版です。

22.1 準備​

準備

22.1 準備

ハードウェア​

項目リーダーフォロワー
アーム組み立て済み黒リーダー ×1組み立て済み白フォロワー ×1
LeRobot サーボ制御ボード×1×1
電源ケーブル5V ×1Pro：12V ×1、スタンダード：5V
データケーブルUSB-C ×1USB-C ×1
固定クランプ×2×2

共通品：フレキシブルグリッパ部品、32 × 32 mm USB カメラ 2 台（キットに 1 台付属、もう 1 台は別途 — 訓練データには 2 視点が必要です）、ドライバー、マウスパッド。

アームは組み立て・固定・給電・USB 接続済みである必要があります。未完了の場合は 第 6 章 へ戻ってください。

PC とソフトウェア​

  • Windows または macOS。ローカル訓練には互換 GPU が必要；
  • ダウンロード・ログイン・クラウド訓練・推論のための安定したネットワーク；
  • SenseCraft Robotics をインストールし、SenseCraft アカウントでログイン済みであること。

シーンと安全​

  • テーブルに 2 つの固定位置をマーク：A 点は物体の開始位置、B 点は目的地；
  • 掴みやすい適度なサイズの物体（赤いブロックや柔らかい物）を準備；
  • A 点・B 点・両アーム・物体がカメラ映像に見え、遮蔽されていないことを確認；
  • 作業領域から人・雑物・ケーブル・壊れやすい物を撤去。リーダーをフォロワーから離し、フォロワーのカメラ視野外に置く。
注記

インターフェース名・ボタン位置・訓練バックエンドは SenseCraft Robotics のバージョンにより変わる可能性があります。シリアルポートやデータセット名は例です — 常に現在の PC が検出したデバイスを使用してください。

22.2 アームの接続​

接続

22.2 アームの接続

警告

安全上の注意：アームの取り付け・接続・取り外しの前に電源を切ってください。通電前に、アームが固定され、ケーブルが正しく、作業領域が空であることを確認。通電中の電源インターフェース抜き差しは厳禁です。

アーム本体の取り付け。 リーダーとフォロワーを安定したテーブルに置き、各アームをクランプ 2 個で固定。アーム間に安全距離を確保。電源オフの状態で各関節を手でゆっくり回し、衝突や引っかかりなく滑らかに動くことを確認。

制御ボードの取り付け。 各アームに 1 枚の LeRobot サーボ制御ボードを取り付け：ベースのスロットに合わせ、コネクタの向きを確認して確実に装着。すべてのサーボケーブルが奥まで挿さっているか、鋭く折れたり挟まれたりしていないかを確認。

データケーブルの接続。 リーダー → USB-C → PC。フォロワー → USB-C → PC。シリアル識別を容易にするため、アーム側を先に接続し、PC 側は 22.3 のバインド手順で 1 本ずつ挿します。

電源インターフェースの取り付けと通電。 アダプターを AC から外した状態で：各 DC ケーブルを挿入しロックリングを右回しで締める。Pro = リーダー 5V / フォロワー 12V、スタンダード = 両方 5V — 電圧を混在させない。ケーブルを関節の可動範囲から遠ざける。その後電源を接続し、制御ボードのインジケータを確認し、USB-C（データ）と DC（電源）の両方が接続済みであることを確認。

22.3 アプリでのデバイス設定​

デバイス設定

22.3 アプリでのデバイス設定

ログイン後、プロジェクト → 新規プロジェクトを開き、名前と説明を入力して作成。プロジェクト概要はデバイス設定・アクション再生・データセット・訓練・モデル・運用への入口を提供します。「未設定」または「未接続」と表示されたらデバイス設定へ移動をクリック。

デバイスモデルの選択​

デバイスペアリングで SO-ARM101 + SO-ARM101 を選択し、次へでシリアルポートをバインドします。

USB シリアルポートのバインド​

  1. 初回スキャン：両アームの USB ケーブルを抜き、再スキャンをクリック、表示されたポートを記録；
  2. リーダーのバインド：リーダーを接続し、再スキャン、新しく現れたポートをリーダーに割り当て；
  3. フォロワーのバインド：フォロワーを接続し、再スキャン、新しいポートをフォロワーに割り当て；
  4. 両方が接続済みと表示され → 次へ。

ヒント

シリアルポートのトラブル対処：各スキャン後は新しく現れたポートだけをバインド — COM 番号だけでデバイスを判断しない。ポートが表示されない場合は USB を挿し直して再スキャン。1 つしか表示されない場合は、もう一方のケーブルとアームの電源を確認。

アームキャリブレーションの検証​

画面例の中間姿勢へリーダーとフォロワーを動かし、作業領域を清空します。2 つのモード：

  • 自動キャリブレーション — システムが各関節の可動域を自動で識別します。すべての関節に確実な物理ストッパーが必要。負荷を外し、両アームをほぼ垂直に揃え、確認チェックボックスにチェックを入れ、キャリブレーション開始を押して完了を待ちます；
  • 手動キャリブレーション — ストッパーが不確かな関節や、段階的に確認したい場合：リーダーを通電したまま各関節を可動域の中央へ動かし、キャリブレーション開始を押し、画面の指示に従って両アームの関節の中位と可動域を順に確認します。

キャリブレーション中はテレオペレーションやデータ収集を行わないでください。姿勢が異常・関節が引っかかる・キャリブレーションが失敗する場合は、直ちに停止し、アームと作業領域を確認して再試行してください。

テレオペレーションの検証​

  1. テレオペレーション開始をクリック；
  2. リーダーを少し動かす — フォロワーが同期的に、同じ方向へ、滑らかに追従する必要があります；
  3. テレオペレーション終了を押し、テレオペレーション正常を確認（または異常、再キャリブレーションへ戻る）を選択。

ヒント

重力補償（任意）：アームには自重があり、手でフォロワーを調整するのは労力が必要です。重力補償は重量の一部を相殺して調整を楽にします — 調整後、テレオペレーション検証の前にオフにしてください。これは手動移動の補助であり、フォロワーがリーダーに追従する機能ではありません。

カメラのバインド​

2 台のカメラ・2 視点が必要です。一般的なレイアウト（第 12 章で同じ選択を検討）：グリッパ視点（俯瞰 + グリッパカメラ、接触を見る精密作業向け）または側面補助（俯瞰 + 側面、把持・搬送・配置向け — 本コースが採用）。

  1. 両カメラを接続し、再スキャンをクリック；
  2. ストリームを前面カメラと側面カメラに割り当て；
  3. 両プレビューを確認：アーム・物体・目標位置がはっきり見える → 次へ。

22.4 アクション再生（任意のウォームアップ）​

再生

22.4 アクション再生（任意のウォームアップ）

アクション再生はリーダー教示でアーム動作を記録し、アクションリストに保存して再生します — データセットに本格着手する前の動作確認に便利です：

機能操作目的
アクションの記録+ をクリック → リーダーで教示 → 記録停止把持・移動・配置の動作を記録
アクションの再生再生をクリック連続性・方向・グリッパ開閉の正しさを確認

22.5 データセット：設定・収集・洗浄​

データセット

22.5 データセット：設定・収集・洗浄

第 11 章の計画と同じく、小バッチ・複数セッション方式を推奨します：1 バッチ約 10 エピソード。2〜3 バッチ後に最初の訓練用に有効な 20〜30 本を残し、複雑な変種は後から追加します。

データ収集タスクの設定​

データセット → データ収集を開き、タスク情報を入力：

フィールド例ガイダンス
データセット名SO-ARM101 pick-and-place A-to-B-01「デバイス + タスク + バッチ」の命名
タスク記述Move the object from the left to the right目標を明確に。統合時は記述が完全一致必須
エピソード数101 エピソードが 1 回の完全なタスク
1 エピソードの長さ20〜30 秒完全な動作をカバー
休憩時間5 秒アームとシーンのリセット

タスクエピソードの記録​

各エピソードは「A 点で把持 → 運搬 → B 点でリリース」の完全な流れを記録します。手順は一貫させ、より強い汎化が必要になった場合にのみ小さな位置・角度の変化を加えます。

  1. 物体を A 点に置き、初期姿勢を確認、記録開始をクリック；
  2. リーダーでタスクを実行し、アームを初期姿勢へ戻す；
  3. 残り時間を待つか、➡（またはスペース）で早期終了；
  4. 休憩中に物体を A 点へ戻し、次のエピソードの準備。

注記

重要：

  • カメラを固定。アーム・グリッパ・物体・A/B 点が両視界に常に見えていること；
  • 重要な動作が遮られたり画面外に出ないように；
  • 失敗・物体落下・動画のカクつき・カメラ遮蔽時は — 再記録をクリックするか Esc で停止；
  • まずバッチを完走し、後から異常エピソードを検査・削除しても構いません；
  • 制御不能や衝突のリスクがあれば直ちに停止。

検査・削除・統合​

操作方法
エピソードの検査エピソードを選択し、動画 / アクション再生を再生。タスク完了度とグリッパ動作を確認
異常エピソードの削除一括エピソード削除 → 選択 → 確認 → 削除コピーを生成（元データセットは上書きされない）
データセットの統合統合 → データセット選択 → 新名称入力（タスク記述・デバイス構成・カメラ構成が一致している必要あり）

22.6 訓練​

訓練

22.6 訓練

訓練は教示データからアクションモデルを生成します — 第 15 章の GUI 版です。

パラメータ選択肢 / 値詳細
訓練ハードウェアクラウド · GPU 自動選択クラウドサーバー。対応するクレジットを消費
ローカル · 無料現在の PC。互換性のあるローカル GPU が必要
訓練データセット対象データセットを選択22.5 で洗浄したデータセット
ポリシーACT現在のデフォルトのアクション制御ポリシー
訓練ステップ数10000初期値。結果に応じて調整

推奨ステップ数とエピソード数（第 11 章の指針と一致）：

タスク難度タスク内容エピソード数ステップ数
初級固定 A 点から B 点約 2010,000〜15,000
中級ランダム位置での把持と配置約 5030,000〜40,000
上級複数ステップまたは長時間約 10080,000〜100,000

訓練時間は GPU 型番とステップ数によります — クラウドの 20,000 ステップは数分〜数十分、100,000 ステップは約 5 倍です。設定を確認して訓練開始をクリックし、現在の訓練タスクで進捗を確認します。

22.7 モデルと運用（推論）​

運用

22.7 モデルと運用（推論）

モデルで訓練結果を確認。タスクとデバイスの組合せが現在のプロジェクトと一致していることを確かめます。そして運用でモデルをアームにロードします：

  1. 現在のアームをサポートと表示されたモデルを選択；
  2. 推論方法を選択：クラウド推論またはローカル推論；
  3. 推論開始を押してタスクの実行を見守ります。

クラウド推論とローカル推論の比較：

比較項目クラウド推論ローカル推論
計算高性能クラウド GPUローカル CPU（現在のプラットフォームはローカル GPU 非対応）
性能の依存先ネットワーク品質ローカル CPU 性能
パラメータアクション数（デフォルト 120）：1 推論あたりの予測アクション数。チャンク閾値（デフォルト 0.9）：大きいほど慎重で停止しがち、小さいほど滑らかだが誤差が増しうる実行回数。1 回あたりの制限時間（タイムアウトで自動終了）
データ出力推論検証のみ実行終了後に推論データセットを自動生成
コストプラットフォーム規則に従いクレジット消費通常無料。CPU 性能の制約あり

注記

運用前に、アームが正しく接続され作業領域が安全であることを確認。運用中はアームを切断・分解しないでください。結果が満足できない場合はデータセットへ戻る — 異常エピソードを削除し、有効なデータを追加し、再訓練。それが第 16 章のイテレーションループをもう一度回すことです。

22.8 コースの結び​

結び

22.8 コースの結び

ここまで、あなたは SO-ARM を箱から開けて訓練・展開まで — しかも 2 つの道で — 連れてきました：

  • コードの道（ステージ 2〜3）：組み立て、キャリブレーション、テレオペレーション、録画、ACT 訓練、評価、イテレーション；
  • VLA の道（ステージ 4）：自分の GPU パイプラインで GR00T を微調整するか、SenseCraft Robotics で完全ノーコードで走るか。

次の行き先：

  • 飛ばした場合は第 17 章の双腕を補完；
  • ロボティクス Wiki でより広い SO-ARM エコシステムへ：Jetson Thor 上の GR00T、AmazingHand、Isaac Lab 強化学習、LeIsaac シミュレーション；
  • あなた自身のタスク — コース全体はそのための足場にすぎません。

このコースが役に立ったら、GitHub の SO-ARM100 と Seeed-Projects/lerobot に Star を頂き、コース紹介のコミュニティで作品を披露してください。
