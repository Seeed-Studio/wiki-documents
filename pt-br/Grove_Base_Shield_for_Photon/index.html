  1. Agora você pode copiar o código a seguir para o Web IDE e fazer o flash para o Photon clicando em um ícone parecido com um raio (o primeiro ícone na coluna da esquerda).
nota

Copie o código apenas para a aba chamada filename.ino.

/*
   Buzzing
   Use digital pin D4
   This example code is in the public domain.
   by xiaohe
  */
int led1 = D4; //set D4 as output

void setup() {
    pinMode(led1, OUTPUT);
}

void loop() {
    // enable buzzing
    digitalWrite(led1, HIGH);

    // We'll leave it on for 1 second...
    delay(1000);

    // Then we'll turn it off...
    digitalWrite(led1, LOW);

    // Wait 1 second...
    delay(1000);

    // And it will repeat!
}
