Introdução

Adquira Agora 🖱️

O SenseCAP M2 Multi-Platform LoRaWAN Gateway é um gateway LoRaWAN® padrão que suporta conexão a diferentes servidores de rede. Ele suporta planos de frequência LoRaWAN® globais de 865 MHz a 923 MHz e pode ser utilizado em múltiplas aplicações LoRaWAN®, como edifícios inteligentes, sistemas de monitoramento ambiental, agricultura de precisão, etc. Possui ampla cobertura e forte capacidade de saída de sinal, entre outros recursos, tornando‑o o gateway perfeito para construir uma rede LoRaWAN®.

Observação
  • O SenseCAP M2 Multi-Platform LoRaWAN® Gateway não oferece suporte à rede Helium. Ele não pode ser conectado ao SenseCAP Hotspot APP e ao SenseCAP Dashboard.
  • Entre em contato com a Equipe SenseCAP MX no canal oficial SenseCAP MX Community Discord para suporte técnico.

Principais Recursos​

  • Suporta múltiplos servidores de rede LoRaWAN®: Compatível com vários LNS como AWS, TTN, ChirpStack, etc., utilizando o modo Packet Forwarder / Basics™ Station.
  • Servidor de rede LoRaWAN integrado: Fornece uma solução rápida e confiável para lançar uma rede LoRaWAN.
  • Suporte a Power-over-Ethernet (PoE): Para usuários que precisam alimentar o gateway pela Ethernet em vez de um cabo de alimentação adicional, o recurso PoE também foi adicionado a este dispositivo, tornando sua implantação mais confiável e rápida.
  • Ampla cobertura e sinal forte: Fornece até 10 km de cobertura LoRaWAN® e sinal forte, permitindo aos usuários enviar dados a distâncias extremamente longas com baixas taxas de dados.
  • Desempenho excelente e estável: O gateway é alimentado pela solução de hardware madura MT7628 e pelo chip baseband Long Range Semtech SX1302. Ele suporta conexão à internet via celular (opcional), Wi‑Fi e Ethernet.
  • Ferramentas de gerenciamento profissionais e serviços em nuvem: Os usuários podem configurar facilmente o gateway em algumas etapas simples por meio da interface web. O SenseCAP Portal e o SenseCAP Local Console também foram desenvolvidos para que os usuários monitorem e gerenciem o gateway de forma eficiente e simples.

Descrição​

O SenseCAP M2 Multi-Platform LoRaWAN® Gateway é um gateway LoRaWAN® padrão que suporta conexão a diferentes servidores de rede.

Como um gateway LoRaWAN®, ele é capaz de fornecer quilômetros de cobertura de rede sem fio e capacidade de transmissão de dados para seus dispositivos LoRaWAN®.

O SenseCAP M2 Multi-Platform LoRaWAN® Gateway suporta múltiplas aplicações como agricultura inteligente, cidade inteligente ou qualquer projeto inteligente que exija densificação de rede, proporcionando ao mesmo tempo uma cobertura superior exclusiva e excelência operacional.

O gateway pode ser configurado facilmente, pronto para uso. Os usuários podem vincular e gerenciar o dispositivo através do SenseCAP Mate APP e do SenseCAP Portal em 4 etapas. Depois disso, os usuários podem começar a configurar os sensores da mesma maneira para criar soluções de rede LoRaWAN®.

  1. Escanear o código QR para vincular o dispositivo
  2. Conectar o gateway à internet e ligá‑lo
  3. Verificar o status do gateway na plataforma SenseCAP
  4. Conectar os sensores à rede e enviar dados para a nuvem

Arquitetura​

O SenseCAP M2 Multi-Platform LoRaWAN® Gateway pode ser configurado de 2 maneiras:

  1. Acesso via Wi‑Fi/Ethernet ao SenseCAP Local Console
  2. Acessar o SenseCAP Local Console remotamente via SenseCAP Portal

Além disso, se você quiser implantar o SenseCAP M2 Multi-Platform LoRaWAN® Gateway em ambientes externos, talvez seja necessário aplicar acessórios de gabinete para atender aos requisitos de implantação externa. Confira o SenseCAP Outdoor Enclosure com alta robustez para implantação rápida
