Visão geral do SenseCraft App

SenseCraft App é um aplicativo móvel para visualização de dados e gerenciamento de dispositivos.

Destaques do App​

  • Economize tempo - oferece uma experiência de escanear e usar para permitir que os usuários concluam toda a configuração em 4 etapas
  • Funciona para pessoas com pouca ou nenhuma experiência técnica começarem facilmente com dados de sensores
  • Adquira e visualize dados em interfaces de usuário limpas
  • Defina intervalos de tempo: melhore a eficiência da bateria
  • Defina valores de limite: foque nos dados para os quais você precisa tomar uma ação - em breve
  • Envie alarmes se os dados estiverem fora da faixa segura - em breve

Download​

SenseCraft App está disponível nas versões para iOS e Android.

Baixe o aplicativo SenseCraft na Central de Downloads oficial da SenseCraft.

Conta​

SenseCraft oferece suporte à configuração de dispositivos e ao gerenciamento remoto. Para usar a SenseCraft Data Platform (anteriormente SenseCAP Portal) e outras funções, registre uma conta.

Note

Selecione Global como Server Location. Você também pode criar uma conta por meio da SenseCraft Data Platform.

Dispositivo​

  • Na página de dispositivos, você pode adicionar novos dispositivos clicando no + no canto superior direito.

  • Clique no dispositivo desejado para visualizar os dados.

  • Clique no ícone de sino no canto superior direito para entrar no centro de mensagens.

MALL​

Evento​

Adicione Eventos para receber notificações.

  1. Clique no ícone Adicionar ou no botão Add Event para criar um alerta de Evento, na página Add Event em Conditions adicione opções de condição e clique no botão Add para selecionar um dispositivo.
  1. Selecione o dispositivo, selecione o tipo de medição, defina as condições de alarme, selecione condições como maior que ou menor que, arraste a barra de progresso para definir o valor e clique em próximo passo.
  1. Na página Add Event, em Back to normal actions quando o dispositivo voltar ao normal, selecione se deseja enviar uma notificação, clique em Save, insira o nome do Evento, clique em Submit para adicionar um alarme de Evento com sucesso e retornar à lista de Eventos.
  1. Na página do dispositivo, clique em Message Center para visualizar as mensagens de alarme, exibindo Device warning para mensagens de alarme acionadas pelo dispositivo e System notification para mensagens do sistema.
  1. Clique na mensagem de alarme, o dispositivo aciona o item de condição, envia a mensagem de alarme, clique para ver os detalhes do alarme. Ao retornar à lista de alarmes, o status muda para lido; clique no botão de edição para selecionar a mensagem, você pode marcar como lida, excluir e realizar outras operações.
  1. Alterne para mensagens do sistema e clique para ver os detalhes das mensagens enviadas pelo sistema.

Configuração via Bluetooth​

Selecione o produto correspondente para vinculação rápida.

Template​

O SenseCraft app fornece um conjunto de funções de template, incluindo Add New Template, Import Template, Download Template e Apply Preset Template, para simplificar e acelerar a configuração de dispositivos. Essas funções ajudam os usuários a reduzir o tempo de configuração e a otimizar a implantação em instalações em grande escala.

Add New Template​

Há duas maneiras de adicionar um novo template.

Method 1

  1. Vá para User → Device Bluetooth Configuration.
  2. Toque no botão Template no canto superior direito.
  3. Toque no ícone + → Add New Template.
  4. Selecione o tipo de dispositivo.
  5. Configure os parâmetros do template de acordo com suas necessidades.
  6. Toque em Confirm para salvar o template.
  7. Retorne à página Template, você verá Save successful.

Method 2

  1. Entre no modo de Configuração via Bluetooth e selecione Advanced Configuration.
  2. Vá para a página Setting.
  3. Toque no ícone Template no canto superior direito.
  4. Ajuste os parâmetros do template conforme necessário.
  5. Selecione Save as Template.
  6. Insira um nome para o Template.
  7. Toque em Confirm para salvar.

Download Template​

  1. Navegue até a página Template e selecione o template que você deseja baixar.
  2. Toque no menu de três pontos no canto superior direito.
  3. Selecione Download Template.
  4. Salve o arquivo no armazenamento do seu dispositivo móvel.

Import Template​

  1. Vá para User → Device Bluetooth Configuration.
  2. Toque em Template no canto superior direito.
  3. Na página Template, toque no ícone +.
  4. Selecione Import Template.
  5. Toque no ícone file.
  6. No gerenciador de arquivos do sistema, selecione o arquivo de configuração com a extensão “.seeed”.

Apply Preset Template​

  1. Entre no modo de Configuração via Bluetooth do dispositivo e selecione Advanced Configuration.
  2. Abra a página Settings e toque no ícone Template no canto superior direito.
  3. Selecione Choose Template.
  4. Na página Preset Template, selecione o template desejado.
  5. Retorne à página Settings e toque em Send para aplicar a configuração.
