Seeed Studio SOM STM32MP157C

SOM - STM32MP157C é o SOM baseado no STM32MP157C. O STM32MP157C é um processador dual-core Arm-Cortex-A7 operando a 650 MHz. O processador também é integrado com o coprocessador Arm Cortex-M4, e o Arm Cortex-M4 integra FPU e MPU. O Cortex-A7 lida principalmente com tarefas em nível de sistema operacional, enquanto o Cortex-M lida com tarefas em nível de MCU. Ele pode atingir o estado ideal a qualquer momento, tornando-o adequado para vários cenários de aplicação.

Recursos​

  • Processador dual-core Arm-Cortex-A7 com Cortex-M4 integrado
  • Hardware/SDK/API/BSP/OS de código aberto
  • ODYSSEY – STM32MP157C SoM
  • eMMC de 4 GB, interfaces ricas para desenvolvimento

Aplicações​

  • Industrial (gateways CAN-Ethernet etc.)
  • Eletrodomésticos (geladeiras, micro-ondas etc.)
  • Médico (registradores de dados etc.)
  • Wearables de alto padrão (dispositivo de VR etc.)
  • Dispositivos de Casa Inteligente

Especificações​

ItemValor
MPU(STM32MP157C)1 x processador dual-core Arm Cortex-A7 de 32 bits
1 x Arm Cortex-M4 de 32 bits com FPU/MPU
PMU1 x ST PMIC STPMIC1A
RAM1 x 512MB DDR3 RAM
Flash1 x 4GB EMMC
Interface Periférica3 x conectores board-to-board de 70 pinos
Dimensão38mm x 38mm

Hardware​

Aqui estão os detalhes de hardware do Seeed SoM - STM32MP157C:

  • 1.STM32MP157C: Chip de controle principal da placa de desenvolvimento (processador de arquitetura dupla: Arm® Cortex®-A7 e Cortex®-M4)

  • 2.MT41K256M16TW-107:P: Chip de memória RAM 512M16bit

  • 3.STPMIC1APQR: Chip de gerenciamento de energia

  • 4.EMMC04G-M627: Memória 4GeMMC

  • 5.LED: Quando a alimentação for bem-sucedida, o PWR acenderá. Quando o sistema estiver funcionando normalmente, o USER continuará piscando.
