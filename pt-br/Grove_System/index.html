O que é o Ecossistema Grove? ​

Grove é um sistema de prototipagem modular com conectores padronizados. Em comparação com sistemas que usam jumpers ou solda, a abordagem modular de blocos de montagem do Grove torna fácil montar eletrônicos reais. O sistema Grove consiste em uma unidade base e vários módulos com conectores padronizados. Eles eram originalmente chamados de "stems" e "twigs", mas esses nomes foram descontinuados.

A unidade Base, geralmente um microprocessador, permite a conexão fácil de qualquer entrada ou saída a partir dos módulos Grove. Cada módulo Grove normalmente atende a uma única função, como um botão simples ou um sensor de frequência cardíaca mais complexo. Você não precisa de uma unidade Base para se conectar a outros módulos Grove. Você pode usar um cabo (Conversor Grove para Pin Header) para ir dos pinos no Raspberry Pi ou Arduino até os conectores Grove.

O que há no Ecossistema Grove? ​

O ecossistema Grove oferece uma abordagem conveniente e fácil de usar para prototipar e construir sistemas eletrônicos. Sua natureza modular, conectores padronizados e ampla variedade de módulos tornam fácil para iniciantes e makers experientes montar e experimentar com eletrônicos reais rapidamente.

Sensores Grove ​

O ecossistema Grove oferece uma ampla variedade de sensores que podem ser facilmente integrados aos seus projetos de eletrônica. Esses sensores são projetados para atender a funções específicas e podem fornecer vários tipos de dados de entrada.

Módulos de Rede Grove​

O sistema Grove também inclui módulos de rede que permitem comunicação e conectividade em seus projetos. Esses módulos permitem conectar sua eletrônica a diferentes redes, como Wi-Fi, Bluetooth, LoRa, NFC ou outros protocolos padrão.

Com os módulos de rede Grove, você pode adicionar facilmente recursos sem fio aos seus projetos, permitindo transmissão de dados, controle remoto ou interação com outros dispositivos e com a internet.

Acessórios Grove ​

Além de sensores e módulos de rede, o ecossistema Grove oferece uma variedade de acessórios que complementam e aprimoram seus projetos de eletrônica. Esses acessórios incluem componentes como displays LCD, matrizes de LED, drivers de motor, módulos de relé e muito mais.

Grove - Cabo Ramificado para Servo​

O Grove Branch Cable para Servos é usado para conectar um ou dois servos a um projeto, com alimentação e terra compartilhados entre os conectores e sinais PWM individuais para cada servo conectado aos pinos com capacidade PWM do Arduino. O conector com chave de quatro pinos do cabo é normalmente conectado a um soquete digital do Grove Shield, e a cor do fio (amarelo ou branco) indica o pino digital correspondente para a entrada do servo.

Interface dos módulos Grove​

Você pode notar que os cabos Grove vêm em 4 cores diferentes.

  • Pino 1 - Amarelo (por exemplo, SCL nos conectores Grove I2C)
  • Pino 2 - Branco (por exemplo, SDA nos conectores Grove I2C)
  • Pino 3 - Vermelho - VCC em todos os conectores Grove
  • Pino 4 - Preto - GND em todos os conectores Grove

Existem principalmente 4 tipos de interface de módulos Grove.

Grove Digital​

Um conector Grove Digital consiste nas quatro linhas padrão que entram no conector Grove. As duas linhas de sinal são genericamente chamadas de D0 e D1. A maioria dos módulos usa apenas D0, mas alguns (como o display Grove LED Bar) usam ambas. Frequentemente as unidades base terão o primeiro conector chamado D0 e o segundo chamado D1, e eles serão ligados como D0/D1 e depois D1/D2, etc.

Exemplos de módulos Grove Digitais são: módulos de chave, o módulo de ventilador e o módulo de LED. Na Figura 8, você pode ver como o conector Grove aparece no esquema para o módulo Grove LED. Eles podem variar de simples a muito complexos.

Grove Analógico​

Um conector Grove Analógico consiste nas quatro linhas padrão que entram no conector Grove. As duas linhas de sinal são genericamente chamadas de A0 e A1. A maioria dos módulos usa apenas A0. Frequentemente as unidades base terão o primeiro conector chamado A0 e o segundo chamado A1, e eles serão ligados como A0/A1 e depois A1/A2, etc.

pinoFunçãoObservação
pino1AnEntrada analógica primária
pino2An+1Entrada analógica secundária
pino3VCCAlimentação para módulo Grove, 5V/3,3V
pino4GNDTerra

Grove UART​

O módulo Grove UART é uma versão especializada de um módulo Grove Digital. Ele usa tanto o pino 1 quanto o pino 2 para entrada e transmissão serial. O conector Grove UART é rotulado do ponto de vista da unidade base. Em outras palavras, o pino 1 é a linha RX (que a unidade base usa para receber dados, então é uma entrada), enquanto o pino 2 é a linha TX (que a unidade base usa para transmitir dados para o módulo Grove).

pinoFunçãoObservação
pino1RXRecepção serial
pino2TXTransmissão serial
pino3VCCAlimentação para módulo Grove, 5V/3,3V
pino4GNDTerra

Grove I2C​

Leitores antigos deste blog sabem que nossos dispositivos favoritos são sensores I2C. Existem muitos tipos de sensores Grove I2C disponíveis. A maioria são dispositivos de 5V/3,3V, mas há alguns que são apenas 3,3V ou 5,0V. Você precisa verificar as especificações.

O conector Grove I2C tem o layout padrão. O pino 1 é o sinal SCL e o pino 2 é o sinal SDA. A alimentação e o terra são os mesmos que nos outros conectores. Esta é outra versão especial do conector digital Grove. Na verdade, frequentemente o barramento I2C em um controlador (como o ESP8266, Raspberry Pi e o Arduino) usa apenas pinos de E/S digitais para implementar o barramento I2C. Os pinos no Raspberry Pi e no Arduino são especiais, com suporte de hardware para o barramento I2C.

pinoFunçãoObservação
pino1SCLClock I2C
pino2SDADados I2C
pino3VCCAlimentação para módulo Grove, 5V/3,3V
pino4GNDTerra
