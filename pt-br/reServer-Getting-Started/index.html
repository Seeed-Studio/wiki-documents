Primeiros Passos com reServer X86

reServer, como um produto marco da família reThings, é extremamente compacto e poderoso. Este pequeno servidor inteligente é capaz de trabalhar de forma fácil e eficiente da borda até a nuvem.

O reServer é baseado em uma placa ODYSSEY X86 v2 e é alimentado pelo mais recente processador Intel® Core™ de 11ª Geração e Intel® UHD Graphics ou Intel® Iris Xe Graphics, o que oferece alto desempenho de CPU e IA para várias aplicações. Ele possui duas portas Ethernet de alta velocidade de 2,5 Gigabit e suporta conectividade híbrida incluindo 5G, LoRa, BLE e WiFi. Ao mesmo tempo, o reServer tem um design compacto para funcionar com eficiência em praticamente qualquer cenário. A estrutura limpa do reServer também torna simples o acesso aos discos rígidos, memória e slots PCIe, o que permite fácil instalação, atualização e manutenção.

Com dois conectores de dados SATA III 6,0Gbps, o reServer é capaz de equipar até dois discos rígidos SATA internos de 3,5"/2,5" para obter mais armazenamento. Ele também possui conectores M.2 para conectar a vários SSDs para velocidades de leitura e gravação mais rápidas.

Recursos​

  • Design compacto para um servidor com uma dimensão total de 132mm x124mm x233mm
  • Alimentado pelo mais recente processador Intel® Core™ de 11ª Geração e Intel® UHD Graphics ou Intel® Iris Xe Graphics.
  • Periféricos ricos incluindo portas Ethernet duplas® de 2,5 Gigabit, porta USB 3.2 Type-A, porta USB 2.0 Type-A, porta HDMI e porta DP
  • Suporta conectividade híbrida incluindo 5G, LoRa, BLE e WiFi (5G e LoRa precisam de módulos adicionais)
  • Dois conectores de dados SATA III 6,0 Gbps para discos rígidos SATA de 3,5"/2,5" com espaço suficiente dentro do gabinete para armazenar ambos
  • M.2 B-Key/ M-Key/ E-Key para expansibilidade como SSD, módulos 4G/5G, WiFi 6
  • Ventoinha de resfriamento silenciosa com um grande dissipador de calor VC para excelente dissipação de calor
  • Fácil de instalar, atualizar e manter com fácil acesso aos componentes internos após a abertura do gabinete
  • Windows 10 Enterprise (não ativado) pré-instalado, também suporta outros sistemas operacionais Windows e Linux

Início Rápido com reServer​

Se você quiser começar a usar o reServer da forma mais rápida e fácil, pode seguir o guia abaixo.

Hardware Necessário​

Você precisa preparar o seguinte hardware antes de começar a usar o reServer。

  • reServer
  • Adaptador de Energia (fornecido)
  • Monitor externo
  • Cabo HDMI/DP
  • Teclado e Mouse

Instalação de Hardware​

Nesta parte, vamos apresentar como instalar ou substituir alguns hardwares dentro do reServer. Se isso não for necessário para você, por favor, pule esta parte. Você pode seguir o Manual de Montagem anexado ao final desta página para acessar a placa principal do reServer antes de ler esta parte.

Instalação de DDR4​

Você pode adicionar um novo DDR4 para expandir a memória. Os slots SO-DIMM de canal duplo suportam DDR4-3200MT/s até 64GB no total.

Instalação de SSD​

O M.2 M-Key 2242/2280(PCIe 3.0 x4) permite que você adicione SSD.

Instalação do Módulo WiFi​

Você pode seguir as etapas abaixo para adicionar o Módulo WiFi.

  • Passo 1. Remova o SSD do slot M.2 M-Key.

  • Passo 2. Retire o cabo da antena WiFi e remova o Módulo WiFi pré-instalado do M.2 E-Key.

  • Passo 3. Instale o novo Módulo WiFi e reconecte o cabo da antena WiFi a ele.

  • Passo 4. Instale o SSD novamente no M.2 M-Key.

Nota: o reServer é enviado com duas antenas WiFi 2.4/5GHz, você pode conectar a antena ao adaptador que se conecta ao cabo de antena do módulo WiFi dentro do reServer para obter uma melhor conectividade WiFi.

Instalação do Módulo 4G/5G/LoRaWAN​

O reServer suporta a instalação de Módulo 4G/5G/LoRaWAN no M.2 B-Key 2242/2252/2280(PCIe 3.0 x2; USB2.0 x1). (O Módulo 4G/5G/LoRaWAN não está incluído no reServer) Sinta-se à vontade para seguir as etapas para adicionar o Módulo 4G/5G/LoRaWAN.

  • Passo 1. Instale o Módulo 4G/5G/LoRaWAN no M.2 B-Key.

  • Passo 2. Conecte o cabo da antena ao Módulo.

Nota: Você deve inserir um cartão SIM padrão no slot de cartão micro SIM para habilitar 5G/4G.

Instalação de HDD​

O reServer suporta a instalação de dois discos rígidos internos de 3,5"/2,5" para obter mais armazenamento. (Os HDDs não estão incluídos no reServer) Por favor, siga as etapas para instalar os HDDs.

  • Passo 1. Remova os parafusos e puxe os suportes

  • Passo 2. Prenda os HDDs aos suportes com parafusos

  • Passo 3. Empurre os suportes dos HDDs para baixo para conectar os HDDs às portas SATA.

  • Passo 4. Prenda os suportes dos HDDs com parafusos

Conexão de Energia​

Existem dois métodos para alimentar o reServer, e o segundo é apenas para versões de Alto Desempenho.

Método 1. Basta conectar o adaptador de energia AC-DC(incluído na caixa do produto) com o cabo de alimentação AC(Fora da caixa do produto, mas ainda na embalagem), depois conectá-lo ao conector DC 12V do reServer.

Método 2. Conecte o cabo de carregamento USB Type-C(Não incluído no reServer) à porta Thunderbolt 4 USB Type-C(Esta porta está disponível apenas nas versões de Alto Desempenho)

Instalação do Sistema Operacional​

Para todas as versões do reServer, o Windows 10 Enterprise (não ativado) já vem pré-instalado; você pode simplesmente inicializá-lo e ativar o sistema operacional. No entanto, o reServer também é compatível com outros sistemas operacionais Windows e, também, com sistemas operacionais Linux, portanto você pode substituir o sistema pré-instalado pelo que desejar.
