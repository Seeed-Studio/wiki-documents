Rede de Sensores

Este tópico apresenta a documentação de produtos da Seeed Studio sobre o primeiro passo da digitalização de dados do mundo físico, ou seja, a implantação de infraestruturas de informação em uma estrutura dinâmica de sensoriamento, para lançar as bases para o monitoramento da sociedade e a compreensão dos ambientes físicos e naturais.

Você pode explorar esta página em duas grandes partes.

IoT Industrial - Especializado​

Lançamos sensores de grau industrial com conectividade de longo alcance e inteligência, gerando dados digitalizados do mundo físico com precisão em nível instrumental. Nesta parte, você pode encontrar:
  • Sensores e sondas para diversos tipos de detecção de dados ambientais de nível industrial
  • Sensores baseados em IA para cenários inteligentes prontos para implantação
  • Registrador de Dados para monitoramento remoto de dados ambientais
  • Gateway para transmissão de dados de longo alcance, alta segurança, ambientes internos e externos
  • Outras infraestruturas de rede para transmissão de dados, como roteadores.
