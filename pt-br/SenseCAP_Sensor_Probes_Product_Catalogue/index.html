Sobre o SenseCAP​

Entre os primeiros lançamentos da série de produtos IIoT da Seeed, o SenseCAP é focado em aplicações de detecção ambiental sem fio: agricultura inteligente, agricultura de precisão e cidades inteligentes, entre outras. Ele é composto por produtos de hardware (sensores, registradores de dados & gateways, etc.), serviços de software (SenseCAP Mate App, SenseCAP Web Portal, dashboard aberto) e API para gerenciamento de dispositivos & dados.

Sobre as sondas de sensores​

Nossa linha de sondas de sensores industriais SenseCAP é projetada para suportar ambientes hostis, como vibração e exposição a produtos químicos e gases, o que é comum em aplicações industriais, e nossa linha industrial de sensores é equipada com sérias classificações de IP de IP66 a IP68 para garantir que os produtos tenham um bom desempenho em seus respectivos ambientes severos. As sondas de sensores SenseCAP também apresentam conexões de processo para garantir um encaixe seguro no meio sendo medido, juntamente com transmissores de dados de sensores que convertem o sinal para se adequar a sistemas de instrumentação industrial. Alguns dos Sensores Industriais MODBUS RS485 vêm em duas versões. A principal diferença é o conector do cabo. Escolha a versão que melhor se adapta às suas necessidades: （1） A versão com fios de ligação é recomendada para uso com o SenseCAP LoRaWAN® Data Logger para conectar à rede LoRaWAN®, aproveitando os benefícios de comunicação de baixo consumo e longo alcance. （2）A versão com conector de aviação já pré-configurou o SenseCAP Sensor Hub 4G Data Logger com experiência plug-and-play para coletar vários dados de sensores via 3G/4G LTE.

[1] O tempo de preparação necessário para que o sensor seja ligado e esteja pronto para ler valores medidos por meio de instruções Modbus deve ser observado quando o sensor for ligado e desligado a cada leitura.

[2] O tempo de aquecimento = (valor do registrador 0x0021 + 3); ler o registrador 0x0000 antes do tempo de aquecimento resultará em 0, e a leitura será atualizada a cada segundo após o tempo de aquecimento; o sensor tem um tempo T90 de 300 segundos e um tempo T60 de 120 segundos.

[3] O intervalo de atualização dos dados de medição; após o tempo de aquecimento na energização, se continuamente alimentado, o sensor atualiza periodicamente a leitura nesse intervalo.

[4] Frequência de consulta do mestre Modbus.

[5] O tempo necessário para o sensor responder após receber a instrução de leitura, depois que o registrador de atraso de resposta 0x0020 for definido como 0.
