Panel Solar 3W 138*160

Este es un panel solar personalizado, que se conecta directamente con muchas de nuestras placas de desarrollo y tiene una alta eficiencia del 16%. La unidad tiene un recubrimiento epoxi transparente con respaldo de tablero duro. ¡Sellado robusto para aplicaciones exteriores!

Especificaciones​

  • Tamaño PCB : 1381601.5 mm
  • Monolítico : 10.93*156 mm
  • Eficiencia : 16%
  • Voltaje:5.5V;
  • Corriente:540mA
  • Potencia:3W
  • Conector: 2.0mm JST
  • Tipo:156 Dos líneas;
  • Material PCB : toda fibra de vidrio
  • Requisitos PCB : positivo
  • Requisitos de calidad :
    • planitud menor a 0.1mm
    • limpio, no permite tener rayones
    • fenómeno de desprendimiento de pintura, tal como un agujero no permite tener desviación
  • Nota : tolerancia Positiva y negativa 0.1mm
  • Nombre: laminado PET (138*160)
  • Disposición:1*11(serie)SIN espaciado pegado artical negro
