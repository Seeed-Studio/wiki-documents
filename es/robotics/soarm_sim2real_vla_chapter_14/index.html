Módulo 4 · Capítulo 14 · Deploy on Jetson

14. Preparar tu Jetson

Prepara la plataforma Jetson para el despliegue de GR00T N1.7 con TensorRT: elige el objetivo, flashea JetPack 7.2 y verifica la placa antes de conectar el robot.

ObjetivosPC anfitriónForce recoveryFlashearVerificar

14.1 Objetivos soportados​

Orin o Thor

14.1 Objetivos soportados

Los objetivos validados para el pipeline SO-ARM101 son:

ObjetivoRuta de software validadaEntorno usado después
Jetson AGX OrinJetPack 7.2 / L4T R39.2.venv-jp72 con scripts/deployment/orin_jp72/run_full_trt.sh
Jetson AGX ThorJetPack 7.2 / L4T R39.2.venv con scripts/activate_thor.sh
Los motores son específicos del objetivo

Los motores TensorRT dependen de la arquitectura de GPU. Orin y Thor pueden compartir el mismo checkpoint y dataset compatibles, pero cada objetivo debe construir su propio paquete de motores (capítulo 18).

14.2 Preparar el ordenador anfitrión​

Anfitrión Ubuntu

14.2 Preparar el ordenador anfitrión

Prepara un anfitrión Ubuntu con:

  • al menos 25 GB libres para SDK Manager y los paquetes de JetPack;
  • un cable de datos USB Type-C fiable;
  • una conexión de red estable;
  • acceso de administrador.

Instala NVIDIA SDK Manager desde la página oficial: https://developer.nvidia.com/sdk-manager.

14.3 Entrar en modo force recovery​

Danza de botones

14.3 Entrar en modo force recovery

Jetson AGX Thor Developer Kit​

  1. Apaga el Jetson.
  2. Conecta su puerto USB Type-C de recuperación al anfitrión.
  3. Mantén pulsado el botón Force Recovery.
  4. Pulsa y suelta Reset sin soltar Force Recovery.
  5. Suelta Force Recovery.
  6. Confirma que SDK Manager detecta el objetivo.
MarcaBotón
11Encendido
12Force Recovery
13Reset

Jetson AGX Orin Developer Kit​

El kit Orin debe estar encendido antes de este procedimiento; usa el botón 2 (Force Recovery) y el 3 (Reset):

  1. Conecta el puerto USB Type-C 10 — junto al header de 40 pines — al anfitrión Ubuntu.
  2. Conecta la alimentación y asegúrate de que el kit está encendido.
  3. Mantén pulsado el botón 2 (Force Recovery).
  4. Sin soltar Force Recovery, mantén pulsado el botón 3 (Reset).
  5. Suelta ambos botones.
  6. Confirma que SDK Manager detecta el objetivo Orin.
MarcaBotón o puerto
1Botón de encendido
2Botón Force Recovery
3Botón Reset
10Puerto USB Type-C de flasheo

Alternativa: recovery con el equipo apagado​

  1. Asegúrate de que el kit está apagado.
  2. Mantén pulsado el botón 2 (Force Recovery).
  3. Conecta la alimentación. Si el LED de encendido no se ilumina, pulsa y suelta el botón 1 (Encendido).
  4. Suelta Force Recovery.
  5. Confirma la detección en SDK Manager.

Referencia: Guía de usuario del Jetson AGX Orin — Force Recovery Mode.

14.4 Instalar JetPack​

SDK Manager

14.4 Instalar JetPack

En SDK Manager:

  1. Selecciona Jetson AGX Thor / Jetson AGX Orin como hardware destino.
  2. Selecciona JetPack 7.2.
  3. Usa Direct Flash salvo que tu despliegue requiera un flujo ISO.
  4. Completa la instalación del objetivo y la configuración inicial de Ubuntu.

Sigue el asistente hasta Installation completed successfully antes de desconectar el cable de recuperación.

14.5 Verificar el Jetson​

En el dispositivo

14.5 Verificar el Jetson

Ejecuta estos comandos en el destino:

tr -d '\0' < /proc/device-tree/model
cat /etc/nv_tegra_release
df -h /
free -h

Confirma que:

  • el modelo detectado coincide con el objetivo Orin o Thor previsto;
  • el sistema informa del release JetPack/L4T esperado;
  • el NVMe o el sistema de archivos raíz tiene espacio para el checkpoint, el backbone, los ONNX y los motores TensorRT;
  • el sistema arranca con normalidad tras un reinicio.

Reserva unos 45–50 GB para un flujo TensorRT local completo.
