Primeros Pasos con reServer J2032

reServer J2032 es el nuevo y potente dispositivo de computación Edge AI que orgullosamente introducimos a nuestra familia reThings, adopta el elegante diseño de carcasa con factor de forma reServer que empaqueta la unidad potente en una forma extremadamente compacta. Este pequeño servidor inteligente no solo es capaz de trabajar fácil y eficientemente desde el borde hasta la nube, sino que también añade poder de procesamiento de IA a la fórmula.

reServer J2032 está equipado con el módulo Nvidia Jetson™ Xavier NX 16GB de vanguardia (Módulo Jetson™ Xavier NX 8GB opcional) que puede entregar hasta 21 TOPS para procesar tareas comunes de IA, la cantidad extensa de RAM GPU permite el procesamiento paralelo de múltiples redes neuronales. Tiene puertos Ethernet duales que consisten en un puerto Ethernet de alta velocidad de 2.5 Gigabit y uno de 1 Gigabit y también soporta conectividad híbrida incluyendo 5G, LoRa® y BLE. reServer 2032 también teniendo conectores de datos SATA III 6.0Gbps duales, es capaz de equipar hasta dos discos duros internos SATA de 3.5"/2.5" para adquirir más almacenamiento.

Mientras tanto, reServer es de diseño compacto para trabajar eficientemente en casi cualquier escenario de servidor. La estructura ordenada de reServer también hace que sea simple acceder a los discos duros, y las ranuras extensas de extensión de módulos de comunicación que permiten instalación, actualizaciones y mantenimiento fáciles.

Teniendo conectores de datos SATA III 6.0Gbps duales, reServer es capaz de equipar hasta dos discos duros internos SATA de 3.5"/2.5" para adquirir más almacenamiento.

Características​

  • Diseño compacto para un servidor de escritorio con una dimensión general de 132mm x124mm x233mm
  • Alimentado por el Módulo Nvidia Jetson™ Xavier NX 16Gb.
  • Periféricos ricos incluyendo puerto LAN dual(1 x puerto de 2.5Gigabit y 1 x puerto de 1 Gigabit), 2 x USB 3.2 gen 2 Tipo-A, puerto HDMI y puerto DP, 1 x M.2 Key B, 1 x puerto Mini-PCIe.
  • Soporta conectividad híbrida incluyendo 5G, LoRa® y BLE (5G y LoRa® necesitan módulos adicionales)
  • Conectores de datos SATA III 6.0 Gbps duales para discos duros SATA de 3.5"/2.5" con suficiente espacio dentro de la carcasa para almacenar ambos
  • M.2 B-Key para expandibilidad como módulos 4G/5G.
  • Puerto Mini-PCIe para expandibilidad como módulos 4G/5G y módulo LoRaWAN® (WM1302-USB-XXXX)
  • Ventilador de enfriamiento silencioso con un gran disipador de calor VC para excelente disipación de calor
  • Fácil de instalar, actualizar y mantener con facilidad de acceso a los componentes internos después de abrir la carcasa
  • Pre-instalado con NVIDIA Jetpack 4.6.1 (Jetson™ Linux R32.7.1)

LoRaWAN® es una marca usada bajo licencia de LoRa Alliance®. La Marca LoRa® es una marca comercial de Semtech Corporation o sus subsidiarias.## Especificaciones

Inicio Rápido con Ensamblaje de Periféricos y Módulos de reServer​

!!! Note: reServer J2032 vendrá con Jetpack 4.6.1 preinstalado en la EMMC del módulo Jetson Xavier NX, lo que significa que podrías comenzar directamente a desarrollar tu propia aplicación con él.

Hardware Requerido​

Necesitas preparar el siguiente hardware antes de comenzar con reServer.

  • reServer
  • Adaptador de Corriente (incluido)
  • Monitor externo
  • Cable HDMI/DP
  • Teclado y Ratón

Ensamblaje de Periféricos y Módulos​

Para esta parte, introduciremos cómo instalar o reemplazar algunos hardware/módulos compatibles dentro de reServer. por favor omite esto si los siguientes pasos no se aplican a tu caso de uso. Podrías seguir el Manual de Guía de Ensamblaje adjunto al final de esta página para acceder a la placa principal de reServer antes de leer esta parte.

Instalación del Módulo LoRaWAN® en Puerto Mini-PCIe​

!!! Note: La siguiente guía de configuración para instalar el Módulo LoRaWAN® en el puerto Mini-PCIe solo ha sido probada con los siguientes módulos WM1302-USB-US915 o WM1302-USB-868. el Módulo LoRaWAN® no está incluido.

  • Paso 1. Localiza la ranura Mini-PCIe en la parte posterior de la placa portadora e instala el Módulo LoRaWAN®.

  • Paso 2. Conecta el cable de antena y localiza la ranura de montaje de antena en la parte posterior de la carcasa del reServer J2032 que debería tener un inserto de goma bloqueando el agujero.

!!! Note: reServer J2032 no se envía con Adaptadores de Antena y Antena.

  • Paso 3. modifica reServer J2032 para ser usado con el módulo LoRaWAN® escribiendo el siguiente comando en la Terminal:
sudo -i
cd /sys/class/gpio/
echo 268 > export; echo out > gpio268/direction; echo 1 > gpio268/value
echo 495 > export; echo out > gpio495/direction; echo 0 > gpio495/value

  • Paso 4. verifica si el módulo LoRaWAN® está conectado correctamente, abre Terminal y escribe el siguiente comando:

!!! Note: Los siguientes pasos para habilitar el módulo LoRaWAN® solo han sido probados y aplicados en el Jetpack 4.6.1 predeterminado de fábrica

ls /dev/ttyACM*

Deberías ver la siguiente salida como se muestra a continuación:

O

lsusb -t

Deberías ver la siguiente salida como se muestra a continuación:

  • Paso 5. Para usar el Módulo LoRaWAN® por favor descarga el código fuente:

Ahora instalemos git y descarguemos sx1302_hal(biblioteca y programas para SX1302 LoRa® Gateway) desde github:

sudo apt update
sudo apt install -y git
git clone https://github.com/Lora-net/sx1302_hal

Muévete a la carpeta sx1302_hal y construye el programa:

cd ~/sx1302_hal
make

Comienza a ejecutar la aplicación de gateway LoRaWAN®, aquí tienes un ejemplo usando el módulo WM1302-USB-868, donde se ha elegido el archivo de configuración global_conf.json.sx1250.EU868.USB:

cd packet_forwarder/
sudo ./lora_pkt_fwd -c global_conf.json.sx1250.EU868.USB

Deberías ver una salida similar a esta:

Instalación del Módulo 4G/5G Mini-PCIe​

!!! Nota: El módulo 4G QC25-EUX se utiliza con la siguiente guía de configuración y el módulo no está incluido.

  • Paso 1. Localiza la ranura Mini-PCIe en la parte posterior de la placa portadora e instala el Módulo LoRaWAN®.

!!! Nota: Necesitas insertar una tarjeta SIM estándar en la ranura de tarjeta SIM del reServer J2032 para habilitar la red 4G/5G. Si observas detenidamente, la Bandeja de tarjeta SIM tiene dos capas, el puerto Mini-PCIe está utilizando la Ranura SIM 2 como se indica en la imagen a continuación.

  • Paso 2. Conecta el cable de la antena y localiza la ranura de montaje de la antena en la parte posterior de la carcasa del reServer J2032 que debería tener un inserto de goma bloqueando el orificio.

!!! Nota: El reServer J2032 no se envía con Adaptadores de Antena y Antena.

  • Paso 3. modifica el reServer J2032 para ser usado con el módulo 4G QC25-EUX escribiendo el siguiente comando en la Terminal:
sudo -i
cd /sys/class/gpio/
echo 436 > export; echo in > gpio436/direction;
export; echo in > gpio268/direction;
export; echo out > gpio393/direction; echo 1 > gpio393/value
echo 495 > export; echo out > gpio495/direction;
echo 1 > gpio495/value
echo 0 > gpio495/value
  • Paso 4. verifica si el módulo 4G QC25-EUX está conectado correctamente encendiendo y arrancando el sistema, luego abre Terminal y escribe el siguiente comando:

!!! Note: Los siguientes pasos para habilitar el módulo 4G QC25-EUX solo han sido probados y aplicados en la Versión de Jetpack OS por Defecto de Fábrica 4.6.1

lsusb -t

Deberías ver la siguiente salida como se muestra a continuación:

  • Paso 5. Habilita el módulo 4G QC25-EUX para conectarse a la red 4G, por favor abre Terminal y escribe:

Abre el monitor serie minicom con el módulo 4G conectado

sudo apt install -y minicom
sudo minicom -D /dev/ttyUSB2 -b 115200m1

una vez que se abra la conexión serie, escriba AT y presione 'Enter', y debería ver OK.

En la misma ventana serie de minicom, por favor escriba:

AT+QCFG="usbnet"

Devolverá algo como +QCFG: "usbnet",0, pero necesitamos que esté configurado en 1 (modo ECM), así que ingresa el siguiente comando:

AT+QCFG="usbnet",1

Luego ingresa el siguiente comando para forzar el reinicio del módem:

AT+CFUN=1,1

Luego podrías reiniciar o esperar un momento para que el módulo obtenga internet de tu operador de tarjeta SIM.

Ahora si escribes ifconfig en Terminal deberías ver una salida similar a la imagen mostrada abajo donde tienes asignada una dirección IP de tu operador móvil de tarjeta SIM:

Instalación del Puerto M.2 B-key del Módulo 4G/5G​

!!! Note: El M.2 B-Key en reServer J2032 soporta formato 3042/3052(USB3.2 GEN2) compatible con Módulo Inalámbrico 4G/5G (El Módulo 4G/5G no está incluido en reServer). El módulo 5G SIM8202G-M2 se usa en los siguientes pasos.

  • Paso 1. Instalar el Módulo SIM8202G-M2 al M.2 B-Key.

  • Paso 2. Conectar el cable de antena al Módulo.

!!! Note: reServer J2032 no se envía con Adaptadores de Antena y Antena, Para usar el Módulo 5G SIM8202G-M2 para conectar a la red necesitas tener Antenas conectadas al módulo.

  • Paso 3. Modificar reServer J2032 para ser usado con el módulo 5G SIM8202G-M2 en el puerto M.2 B-Key escribiendo el siguiente comando en la Terminal:
sudo -i
cd /sys/class/gpio/
echo 419 > export; echo out > gpio419/direction; echo 0 > gpio419/valueexport; echo in > gpio268/direction;
echo 417 > export; echo out > gpio417/direction; echo 1 > gpio417/value
echo 266 > export; echo out > gpio266/direction; echo 1 > gpio266/value
  • Paso 4. verifica si el módulo 5G SIM8202G-M2 está conectado correctamente encendiendo y arrancando el sistema, luego abre Terminal y escribe el siguiente comando:

!!! Note: Los siguientes pasos para habilitar el módulo 5G SIM8202G-M2 solo han sido probados y aplicados en la Versión de Jetpack OS por Defecto de Fábrica 4.6.1

lsusb -t

Deberías ver salidas similares a las que se muestran a continuación:

Paso 5. Habilitar el módulo 5G SIM8202G-M2 para conectarse a la red 5G

!!! Note: Necesitas insertar una tarjeta SIM estándar en la ranura para tarjeta SIM del reServer J2032 para habilitar la red 4G/5G. Si observas detenidamente, la Bandeja de tarjeta SIM tiene dos ranuras superior e inferior, el puerto M.2 B-key está utilizando la Ranura Inferior.

Abre el monitor serie minicom con el módulo 5G SIM8202G-M2 conectado

sudo apt install -y minicom
sudo minicom -D /dev/ttyUSB2 -b 115200m1

Una vez que se abra la conexión serie, escriba AT y presione 'Enter', debería ver OK en la siguiente línea.

Ahora, para poder conectarse a la red 4G/5G, siga el comando para instalar el controlador requerido para el módulo 5G SIM8202G-M2 para habilitar la conexión de red:

cd ~
wget https://files.seeedstudio.com/wiki/reServerJ2032/SIM8200.tar.gz
tar xvf SIM8200.tar.gz
sudo chmod 777 -R SIM8200/
cd SIM8200/
sudo ./install.sh
cd Goonline
make
sudo ./simcom-cm -i wwan0

Instalación de HDD​

reServer soporta la instalación de dos discos duros internos de 3.5"/2.5" para adquirir más almacenamiento. Por favor sigue los pasos para instalar los HDDs.

  • Paso 1. Retira los tornillos y extrae los soportes

  • Paso 2. Fija los HDDs a los soportes con tornillos

  • Paso 3. Empuja los soportes de HDD hacia abajo para conectar los HDDs con los puertos SATA.

  • Paso 4. Fija los soportes de HDD con tornillos

Interfaz de Hardware​

Para esta parte, introduciremos la conexión de interfaz de reServer.

Conexión de Alimentación​

Simplemente conecta el adaptador de alimentación AC-DC (incluido en la caja del producto) con el cable de alimentación AC (fuera de la caja del producto pero aún en el paquete), luego conéctalo al conector DC de 12V de reServer.

Puerto USB 3.1 Dual​

Puedes conectar dispositivos USB como teclado y ratón a través del puerto USB 3.1 dual.

Conexión de Pantalla​

Hay dos métodos para que reServer se conecte a una pantalla.

Método 1. Puerto HDMI Método 2. Puerto DP

Conexión Ethernet​

reServer J2032 viene con dos puertos ethernet cuyas velocidades de conexión son 1000BASE-T y 2.5GBASE-T respectivamente,
