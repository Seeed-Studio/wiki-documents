Glosario, mapa de documentación y licencias

Glosario​

Plataforma y hardware​

TérminoSignificado
RV1126BSoC Rockchip enfocado a IPC con un NPU e ISP35. Chip principal en reCamera Pro; RK_CHIP=rv1126b, RK_ARCH=arm64
RV1126BPVariante de encapsulado / derivada de RV1126B usada por algunas configuraciones de placa EVB
RK801PMIC usado por reCamera Pro
RK817PMIC con códec de audio integrado (CONFIG_SND_SOC_RK817=y)
ES7202ADC multicanal Everest para captura con matriz de micrófonos
ISP35Versión ISP de RV1126B; los archivos IQ relacionados están bajo iqfiles/isp35/
eMMCAlmacenamiento integrado (RK_BOOT_MEDIUM=emmc)
MaskromModo de descarga incorporado en la ROM del SoC; punto de entrada para flasheo (USB VID 2207)
loader / idblockInicialización de DDR y primer gestor de arranque; las salidas incluyen idblock.img y download.bin
board IDVariante de placa base / placa de expansión detectada mediante niveles de divisor resistivo ADC; el resultado se escribe en /run/board_id.env
DTBODevice Tree Blob Overlay, usado en tiempo de ejecución para admitir múltiples variantes de hardware con una sola imagen de firmware

SDK y sistema de compilación​

TérminoSignificado
BSPBoard Support Package: soporte a nivel de placa incluyendo U-Boot, kernel, rootfs y controladores
BoardConfigproject/cfg/<series>/BoardConfig-*.mk; el conjunto completo de parámetros de placa para una compilación
lunchSeleccionar un BoardConfig; terminología del sistema de compilación de Android. Genera el enlace simbólico .BoardConfig.mk
sysdrvSDK del componente de controladores del sistema que contiene fuentes de U-Boot / kernel / MCU; se puede compilar de forma independiente con make
mediaSDK del componente multimedia que contiene mpp / rockit / rkaiq / rga / iva, etc.; se puede compilar de forma independiente con make
appAplicaciones en espacio de usuario bajo project/app/
fragmentDefconfig incremental de kernel / U-Boot aplicado en orden sobre el defconfig base
overlayDirectorio de archivos copiados sobre el rootfs durante el empaquetado; las entradas habilitadas se listan en RK_POST_OVERLAY
IQ fileArchivo de calidad de imagen que contiene parámetros de ajuste de sensor rkaiq (JSON)
rootfsSistema de archivos raíz ext4 generado por Buildroot en la partición de 3 G
oemDirectorio /oem. Esta placa establece RK_BUILD_APP_TO_OEM_PARTITION=n, por lo que es un directorio normal dentro de rootfs, no una partición separada
userdataPartición de escritura montada en /userdata; almacena configuración y datos de usuario y es el HOME predeterminado
miscPequeña partición que contiene flags de recuperación / restablecimiento de fábrica
RK_APP_TYPETipo de aplicación de referencia; esta placa usa RKIPC_RV1126B_RECAMERA2
allsaveall + save; comportamiento predeterminado cuando se ejecuta ./build.sh sin argumentos
RK_APP_xxxConmutador de configuración de placa que controla si se compila una aplicación
MAROC_*Familia de macros en Makefile.param, incluyendo MAROC_COPY_PKG_TO_APP_OUTPUT, MAROC_STRIP_DEBUG_SYMBOL y MAROC_PKG_RELEASE

Multimedia (rockit / MPI)​

TérminoSignificado
MPIMedia Process Interface, la interfaz de programación unificada para rockit
rockitImplementación en tiempo de ejecución de Rockchip MPI; enlazar con -lrockit
MPPMedia Process Platform, bibliotecas de códec de nivel inferior; enlazar con -lrockchip_mpp
VIEntrada de vídeo; captura fotogramas desde un sensor a través del ISP
VPSSVideo Process Sub System; escalado / recorte / conversión de formato multicanal
VENC / VDECCodificación / decodificación de vídeo
VOSalida de vídeo a una pantalla
RGNMódulo de región para superposiciones OSD y marcas de agua
AI / AOAudio In / Audio Out
AENC / ADECCodificación / decodificación de audio
AVSAround View System para unión de vista envolvente multicámara
IVSIntelligent Video Surveillance para analíticas como detección de movimiento
TDETwo Dimensional Engine para aceleración 2D
RGARaster Graphic Acceleration, un acelerador 2D para escalado, conversión NV12↔RGB y rotación
MBMedia Buffer / pool de búferes
BindRK_MPI_SYS_Bind() conecta canales de dos módulos para que los datos fluyan automáticamente
EIS / DISEstabilización de imagen electrónica / digital
ePTZPan-tilt-zoom electrónico
SVCScalable Video Coding
AOVAlways-On Vision, visión siempre activa de bajo consumo
FECHardware de corrección de ojo de pez / distorsión (CONFIG_VIDEO_ROCKCHIP_FEC=y)
IRFPAMatriz de plano focal infrarrojo (imagen térmica)
rkaiqMotor Rockchip AI ISP para 3A y ajuste; enlazar con -lrkaiq
uAPI / uAPI2Dos generaciones de interfaces de espacio de usuario de rkaiq; el código nuevo debe usar uAPI2 (rk_aiq_user_api2_*.h)
AINRReducción de ruido por IA; los archivos IQ relacionados están bajo iqfiles/isp35/ainr/
AI-ISPUsa el NPU para mejorar la salida del ISP; deshabilitado en esta placa (RK_AIISP_MODEL=NONE)

IA / NPU​

TérminoSignificado
NPUNeural Processing Unit integrada en RV1126B
RKNNFormato y runtime de modelos de red neuronal de Rockchip (.rknn + librknnrt.so)
RKNN-Toolkit2Herramienta de conversión de modelos en PC para x86_64 / Python; no incluida en el SDK y debe instalarse por separado. Línea base interna: 2.3.2
rknn-toolkit-lite2Wrapper de inferencia en Python para el dispositivo; adecuado solo para validación. Usa la API de C en aplicaciones de producción
RKLLMRuntime de modelos de lenguaje grande de Rockchip (.rkllm + librkllmrt.so)
rkllm-toolkitHerramienta de conversión LLM en PC bajo media/rknn-llm-mk/rknn-llm/rkllm-toolkit/
ROCKIVAAlgoritmos de visión empaquetados de Rockchip (detección de personas / caras / mascotas, etc.); enlazar con -lrockiva
RKAIWrapper de IA de Rockchip bajo project/app/rkai/, que cubre flujos de trabajo LLM y VLM
VLMVision-Language Model; modelo multimodal para imagen y texto
TTFTTime To First Token, una métrica de benchmark de RKLLM
RKNN_NPU_CORE_xMáscara de asignación de núcleos del NPU (AUTO / 0 / 0_1 / 0_1_2)
INT8 quantization / calibration setLa cuantización usa una lista de imágenes representativa; mantén el conjunto de calibración separado del conjunto de validación

TérminoSignificado

ONVIFEstándar de interoperabilidad de dispositivos de red implementado por recamera_onvif

main / sub streamNombres de flujo de go2rtc que corresponden a live/0 y live/1

El directorio docs/ contiene 90 archivos PDF: 52 en chino y 38 en inglés. El conjunto en chino es más completo, así que consúltalo primero.

Los documentos importantes disponibles solo en chino incluyen el ROCKIVA SDK, el conjunto completo de Wi-Fi / Bluetooth, la mayoría de las guías de ajuste y controladores ISP, EIS / DIS, System Suspend, RGB_MCU, SDMMC / SDIO / eMMC y algunos documentos de medios distintos de la calibración AVS. Para la documentación de clientes en el extranjero, traduce estos materiales o indica claramente que no se incluye una versión en inglés.
