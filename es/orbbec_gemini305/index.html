Cámara 3D Orbbec Gemini 305

La Orbbec Gemini 305 es una cámara de profundidad estéreo para visión robótica de corto alcance, incluyendo montaje en muñeca, reconocimiento de objetos y agarre. Esta página cubre la versión USB; la Gemini 305g tiene diferentes interfaces, requisitos de alimentación y dimensiones. Consulta la documentación de Orbbec para más detalles.

Características​

  • Detección de profundidad a corta distancia: Un rango de funcionamiento de 4–100 cm+ y un rango recomendado de 7–50 cm.
  • Visión estéreo: Las cámaras estéreo proporcionan datos de profundidad junto con imágenes en color.
  • Cuerpo compacto: La carcasa de 42 × 42 × 23 mm se adapta a instalaciones con limitaciones de espacio.
  • Sincronización y disparo: Admite sincronización multicámara y disparos por software y hardware.
  • Conexión USB: Una conexión USB Type-C suministra alimentación y datos; se recomienda USB 3.0.

Descripción general del hardware​

La cámara tiene dos lentes en la parte frontal y un puerto USB Type-C en el lateral. Antes de montarla en un brazo robótico o soporte, comprueba el campo de visión, el enrutamiento del cable y el espacio libre a lo largo de todo el movimiento previsto. Las ubicaciones de montaje y los planos de dimensiones están disponibles en la documentación de la Gemini 305.

Inicio rápido​

Preparar y conectar​

  1. Prepara una Gemini 305, un cable USB Type-C con capacidad de datos y un host que cumpla los requisitos de alimentación de la cámara. Se recomienda un puerto y cable USB 3.0 para mayor ancho de banda.
  2. Monta la cámara para tu aplicación y conéctala al host con el cable USB Type-C. Para un brazo en movimiento, deja suficiente holgura de cable y evita que el cable se tense o se pellizque.

Instalar Orbbec Viewer​

  1. Abre la página de lanzamientos de Orbbec SDK v2, selecciona una versión que admita la Gemini 305 y descarga el instalador o el paquete de Orbbec Viewer para el sistema operativo y la arquitectura de tu host. Los sistemas Jetson suelen usar Linux ARM64; elige el paquete x86-64 o Windows apropiado para un PC.
  2. Instala o extrae el paquete e inicia Orbbec Viewer como se describe en la página de lanzamientos. Los nombres de archivo y procedimientos pueden cambiar entre versiones; en Linux, configura los permisos USB según las instrucciones de tu versión.
nota

Gemini 305 usa Orbbec SDK v2; el SDK v1 no es compatible con este modelo. La interfaz de Viewer y las funciones disponibles dependen de la versión de software, el firmware y la configuración del dispositivo. Consulta la documentación del SDK v2 para la instalación y los permisos del dispositivo.

Previsualizar imágenes y nubes de puntos​

  1. Confirma que la Gemini 305 aparece en la lista de dispositivos de Orbbec Viewer y selecciónala.
  2. Habilita los flujos de Depth y Color, elige la resolución y la frecuencia de imagen ofrecidas por el dispositivo y comprueba que ambas ventanas de vista previa muestren imágenes.
  3. Coloca un objeto dentro del rango recomendado y observa la imagen de profundidad a medida que cambia su distancia. Habilita la nube de puntos para una vista previa 3D o revisa la configuración de alineación depth-to-color (D2C) al alinear imágenes de color y profundidad.
  4. Detén los flujos antes de desconectar la cámara. Para controles detallados, consulta la guía de Orbbec Viewer.

La Gemini 305 no tiene IMU integrada, por lo que el panel de IMU del ejemplo no indica una función de la Gemini 305. La interfaz y las opciones disponibles dependen del dispositivo y la versión de software.

Solución de problemas​

  • Dispositivo no listado: Vuelve a conectar el cable, confirma que admite datos y no solo alimentación, y comprueba la fuente de alimentación del host. En Linux, revisa también los permisos USB según las instrucciones del SDK v2.
  • Un flujo no se inicia o es inestable: Inicia profundidad o color por separado y prueba otras resoluciones y frecuencias de imagen admitidas por el dispositivo. Comprueba el puerto USB, el cable, el firmware y la compatibilidad del SDK.
  • Resultados de profundidad inesperados: Mueve el sujeto al rango recomendado, comprueba que las lentes no estén obstruidas y ajusta los parámetros de Viewer admitidos por el dispositivo para la escena.

ROS 2​

Para usar la cámara con ROS 2, sigue la guía de instalación de Orbbec SDK ROS 2 Wrapper v2 para configurar el espacio de trabajo y los permisos del dispositivo. Gemini 305 usa la rama v2-main. Después de instalar una versión que admita este modelo y de hacer source del espacio de trabajo, lanza el archivo proporcionado:

ros2 launch orbbec_camera gemini_301_series.launch.py

En otra terminal con el entorno de ROS 2 configurado, usa ros2 topic list para inspeccionar los tópicos disponibles. Los tópicos y parámetros dependen de la versión instalada y de la configuración de lanzamiento. Estos pasos se basan en la documentación oficial y no se han verificado con una Gemini 305 física para esta página.
