¿Qué es el Ecosistema Grove? ​

Grove es un sistema de creación de prototipos modular con conectores estandarizados. En comparación con los sistemas que usan jumpers o soldadura, el enfoque de bloques de construcción modulares de Grove hace que ensamblar electrónica real sea fácil. El sistema Grove consta de una unidad base y varios módulos con conectores estandarizados. Estos se llamaban originalmente "stems" y "twigs", pero esos nombres se han dejado de usar.

La unidad Base, generalmente un microprocesador, permite conectar fácilmente cualquier entrada o salida de los módulos Grove. Cada módulo Grove normalmente se centra en una sola función, como un botón sencillo o un sensor de frecuencia cardiaca más complejo. No necesitas una unidad Base para conectarte a otros módulos Grove. Puedes utilizar un cable (convertidor Grove a cabecera de pines) para ir desde los pines de la Raspberry Pi o Arduino hasta los conectores Grove.

¿Qué hay en el Ecosistema Grove? ​

El ecosistema Grove proporciona un enfoque práctico y fácil de usar para crear prototipos y construir sistemas electrónicos. Su naturaleza modular, los conectores estandarizados y la amplia gama de módulos hacen que tanto principiantes como creadores experimentados puedan ensamblar y experimentar rápidamente con electrónica real.

Sensores Grove ​

El ecosistema Grove ofrece una amplia gama de sensores que pueden integrarse fácilmente en tus proyectos de electrónica. Estos sensores están diseñados para abordar funciones específicas y pueden proporcionar diversos tipos de datos de entrada.

Módulos de red Grove​

El sistema Grove también incluye módulos de red que permiten la comunicación y la conectividad en tus proyectos. Estos módulos te permiten conectar tu electrónica a diferentes redes, como Wi‑Fi, Bluetooth, LoRa, NFC u otros protocolos estándar.

Con los módulos de red Grove, puedes añadir fácilmente capacidades inalámbricas a tus proyectos, habilitando transmisión de datos, control remoto o interacción con otros dispositivos e internet.

📖 Plataforma Wiki 🖱️ Comprar

Accesorios Grove ​

Además de sensores y módulos de red, el ecosistema Grove ofrece una variedad de accesorios que complementan y mejoran tus proyectos electrónicos. Estos accesorios incluyen componentes como pantallas LCD, matrices de LED, controladores de motor, módulos de relé y más.

Grove - Cable de rama​

Utiliza este cable para conectar dos módulos Grove I2C a un conector I2C Stem. Este cable es compatible con todos los módulos Grove I2C. Será muy útil cuando necesites conectar más de un dispositivo I2C a tu sistema Grove.

tip

Puedes verlo en la página de compra Bazaar. Hemos lanzado Grove - I2C Hub (6 Port) para esta función.

Grove - Cable de rama para Servo​

El Grove Branch Cable para servos se utiliza para conectar uno o dos servos a un proyecto, con la alimentación y la toma de tierra compartidas entre los conectores y señales PWM individuales para cada servo conectadas a los pines con capacidad PWM del Arduino. El conector ranurado de cuatro pines del cable suele conectarse a un zócalo digital del Grove Shield, y el color del cable (amarillo o blanco) indica el pin digital correspondiente para la entrada del servo.

tip

Puedes verlo en la página de compra Bazaar.

Interfaz de los módulos Grove​

Puede que notes que los cables Grove vienen en 4 colores diferentes.

  • Pin 1 - Amarillo (por ejemplo, SCL en conectores Grove I2C)
  • Pin 2 - Blanco (por ejemplo, SDA en conectores Grove I2C)
  • Pin 3 - Rojo - VCC en todos los conectores Grove
  • Pin 4 - Negro - GND en todos los conectores Grove

Principalmente hay 4 tipos de interfaz de módulos Grove.

Grove Digital​

Un conector Grove Digital consta de las cuatro líneas estándar que llegan al conector Grove. Las dos líneas de señal se llaman genéricamente D0 y D1. La mayoría de los módulos solo usan D0, pero algunos (como la pantalla Grove de barra de LED) usan ambas. A menudo, las unidades base tendrán el primer conector llamado D0 y el segundo llamado D1 y estarán cableados como D0/D1 y luego D1/D2, etc.

Ejemplos de módulos Grove Digital son: módulos de interruptor (Switch Modules), el módulo de ventilador (Fan Module) y el módulo LED (LED Module). En la Figura 8 puedes ver cómo se ve el conector Grove en el esquema del módulo Grove LED. Pueden ir de muy simples a muy complejos.

pinFunciónNota
pin1DnEntrada/Salida Digital primaria
pin2Dn+1Entrada/Salida Digital secundaria
pin3VCCAlimentación para el módulo Grove, 5V/3.3V
pin4GNDTierra

Grove Analógico​

Un conector Grove Analógico consta de las cuatro líneas estándar que llegan al conector Grove. Las dos líneas de señal se llaman genéricamente A0 y A1. La mayoría de los módulos solo usan A0. A menudo, las unidades base tendrán el primer conector llamado A0 y el segundo llamado A1 y estarán cableados como A0/A1 y luego A1/A2, etc.

pinFunciónNota
pin1AnEntrada analógica primaria
pin2An+1Entrada analógica secundaria
pin3VCCAlimentación para el módulo Grove, 5V/3.3V
pin4GNDTierra

Grove UART​

El módulo Grove UART es una versión especializada de un módulo Grove Digital. Usa tanto el Pin 1 como el Pin 2 para la entrada y transmisión serie. El conector Grove UART está etiquetado desde el punto de vista de la unidad base. En otras palabras, el Pin 1 es la línea RX (que la unidad base usa para recibir datos, por lo que es una entrada), mientras que el Pin 2 es la línea TX (que la unidad base usa para transmitir datos al módulo Grove).

pinFunciónNota
pin1RXRecepción serie
pin2TXTransmisión serie
pin3VCCAlimentación para el módulo Grove, 5V/3.3V
pin4GNDTierra

Grove I2C​

Los lectores de larga data de este blog saben que nuestros dispositivos favoritos son los sensores I2C. Hay muchos tipos de sensores Grove I2C disponibles. La mayoría son dispositivos de 5V/3.3V, pero hay unos pocos que son solo de 3.3V o 5.0V. Necesitas comprobar las especificaciones.

El conector Grove I2C tiene el diseño estándar. El Pin 1 es la señal SCL y el Pin 2 es la señal SDA. La alimentación y la tierra son iguales que en los otros conectores. Esta es otra versión especial del conector Grove Digital. De hecho, a menudo el bus I2C en un controlador (como el ESP8266, Raspberry Pi y el Arduino) simplemente usa pines de E/S digitales para implementar el bus I2C. Los pines en la Raspberry Pi y el Arduino son especiales, con soporte de hardware para el bus I2C.

pin1SCLReloj I2C
pin2SDADatos I2C
pin3VCCAlimentación para el módulo Grove, 5V/3.3V
pin4GNDTierra
