Introducción​

La serie XIAO Display Gadgets es una familia de placas de expansión compactas que combinan un controlador principal Seeed Studio XIAO con una pequeña pantalla LCD en color. Hay seis modelos disponibles en tres tamaños de pantalla — 0,96", 1,14" y 1,47" — y dos controladores XIAO — el XIAO ESP32-S3 Plus y el XIAO nRF52840 Plus — que abarcan desde una pantalla de 80×160 apta para el bolsillo hasta una pantalla táctil capacitiva de 172×320 con almacenamiento MicroSD.

Cómo elegir​

Elige un modelo en dos pasos: primero elige el controlador, luego elige el tamaño de pantalla.

Paso 1: Elige el controlador​

Cada tamaño de pantalla está disponible con cualquiera de los dos controladores, y el hardware de visualización — pantalla, táctil, MicroSD, botones y sensores integrados — es idéntico entre las dos variantes. La única diferencia es el XIAO a bordo.

XIAO ESP32-S3 PlusXIAO nRF52840 Plus
InalámbricoWi‑Fi de 2,4 GHz + BLE 5.0BLE 5.4
Memoria8 MB PSRAM + 16 MB Flash256 KB RAM + 1 MB Flash interna + 2 MB Flash integrada
Ideal paraDispositivos IoT conectados por Wi‑Fi y paneles de datosWearables y nodos de sensores alimentados por batería y centrados en BLE
  • Elige el ESP32-S3 Plus cuando necesites conectividad Wi‑Fi o más memoria — por ejemplo para enviar datos de sensores a la nube, a un panel remoto o a un prototipo IoT inalámbrico.
  • Elige el nRF52840 Plus para un diseño BLE de bajo consumo donde la duración de la batería sea importante — por ejemplo credenciales inteligentes, pantallas de estado BLE o sensores portables de larga duración.

Paso 2: Elige el tamaño de pantalla​

Una vez que hayas decidido el controlador, elige el tamaño de pantalla según las funciones que necesites:

  • 1.47" — el único tamaño con pantalla táctil capacitiva y almacenamiento MicroSD. Elígelo para interfaces HMI táctiles, marcos de fotos portátiles, grabación de audio en SD o registro local de medios y datos.
  • 1.14" — una pantalla de tamaño medio con tres botones de usuario y un conector Grove I2C. Elígela para pantallas de sensores, proyectos Grove o controladores físicos donde quieras un equilibrio entre compacidad y capacidad de expansión.
  • 0.96" — el factor de forma más pequeño. Elígela para wearables y diseños con limitaciones de espacio como credenciales inteligentes o gadgets tipo llavero.

Características compartidas​

Los seis modelos comparten el mismo hardware integrado:

  • Pantalla LCD TFT IPS en color (SPI): 80×160, 135×240 o 172×320 según el tamaño de pantalla
  • Micrófono digital PDM
  • IMU de 6 ejes (LSM6DS3, acelerómetro de 3 ejes + giroscopio de 3 ejes)
  • Botones de usuario: 2 o 3, según el modelo
  • Conector JST de 2 pines para una batería LiPo de 3,7 V
  • Detección de voltaje de batería (los modelos nRF52840 además detectan el estado de carga)

Todos los modelos se programan con el IDE de Arduino usando la biblioteca gráfica Seeed_GFX2 de Seeed.
