## システムログ

システムログエリアは、reCamera Pro の動作ログをリアルタイムで表示するために使用され、ユーザーがデバイスの現在の状態、サービスの動作状況を把握し、異常な問題のトラブルシューティングを行いやすくします。

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/20260708190224_6_2.png" />


ユーザーはこのエリアで次の操作を行うことができます：

- システムログ出力をリアルタイムで表示
- ログレベルまたはキーワードでログをフィルタリング
- 現在表示されているログ内容をクリア
- 問題解析や技術サポートのためにログファイルをダウンロード

この機能は、機器のデバッグ、サービス状態の確認、異常調査、および問題再現の記録に適用できます。

## ターミナルコンソール

ターミナルコンソールを使用すると、追加の SSH ツールを使用することなく、Web UI を介して reCamera Pro システムのターミナルに直接ログインできます。

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_2dvKqObUbo.png" />

ユーザーは次のデフォルトアカウントを使用してログインできます：

```bash
Username: root
Password: recamera
```
