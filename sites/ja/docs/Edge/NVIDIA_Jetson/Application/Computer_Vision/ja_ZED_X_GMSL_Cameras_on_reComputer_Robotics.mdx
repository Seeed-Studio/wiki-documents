### reComputer Robotics J50 Mini

#### 必要なもの

- GMSL 拡張ボード付き reComputer Robotics J50 Mini
- 対応する ZED X シリーズ GMSL2 カメラ
- 対応する GMSL2 Fakra/Mini-Fakra ケーブルまたはハーネス
- JetPack 6.2.x または JetPack 7.2
- インターネット接続、ディスプレイ、キーボード、ZED Studio 用のマウス

:::info
このガイドでは、Seeed プラットフォームドライバと ZED SDK のセットアップについて説明します。カメラモデルのサポートは、インストールされている ZED SDK のバージョンに依存する場合があります。JetPack/L4T リリースと互換性のある最新の ZED SDK を使用してください。
:::

#### 1. カメラを接続する

1. reComputer の電源を完全にシャットダウンします。
2. DC 電源入力を取り外します。
3. 対応するケーブルまたはハーネスを使用して、ZED X カメラを GMSL2 ポートに接続します。コネクタが奥までしっかり差し込まれ、ロックされていることを確認してください。
4. 電源を再接続し、デバイスを起動します。

:::warning
GMSL カメラをホットプラグしないでください。カメラまたは GMSL ハーネスを接続・取り外しする前には、必ず電源を切ってください。
:::

#### 2. ZED X GMSL サポートを有効化する

次のパスのうち **1 つ** を選択してください。クリーンなデプロイには最新 BSP のフラッシュを推奨しますが、既存システムを維持したい場合は DEB のインストールの方が高速です。

<Tabs groupId="j50-mini-zed-driver-method">
  <TabItem value="latest-bsp" label="オプション 1 · 最新 BSP をフラッシュ" default>

デバイスにすでにインストールされている BSP ビルド情報を確認します：

```bash
cat /etc/nv_tegra_release
```

`DATE` フィールドを探します。BSP のビルド日が **2026 年 9 月 24 日以降** の場合、ZED X GMSL サポートはすでに含まれているため、ZED SDK のインストールに進むことができます。

ビルドがそれより古い場合は、以下の手順に従って、日付が **2026 年 9 月 24 日** の最新 **JetPack 7.2 / L4T 39.2.0** イメージを書き込みます。2 つのモジュールバリアントでは異なるイメージを使用するため、J50 Mini に搭載されている Jetson モジュールに一致するタブを選択してください。

:::warning
フラッシュを行うと、ターゲットストレージは上書きされます。開始する前に、アプリケーションデータ、設定ファイル、認証情報をバックアップしてください。
:::

##### フォースリカバリモードに入る

1. J50 Mini の電源を切り、電源ケーブルを取り外します。
2. **REC** ボタンを押し続けます。

<div align="center">
  <img width="600" src="https://files.seeedstudio.com/wiki/recomputer-j501-mini/reset.png" alt="reComputer Robotics J50 Mini 上の REC ボタン" />
</div>

3. 電源ケーブルを接続し、その後 **REC** ボタンを離します。
4. 下図のフラッシュ用ポートを介して、USB Type-C データケーブルで J50 Mini を Ubuntu ホストに接続します。

<div align="center">
  <img width="600" src="https://files.seeedstudio.com/wiki/recomputer-j501-mini/flash-port.png" alt="reComputer Robotics J50 Mini 上の USB Type-C フラッシュポート" />
</div>

5. Ubuntu ホスト上で、リカバリモードを確認します：

```bash
lsusb
```

出力には、使用しているモジュールの USB ID が含まれている必要があります：

| Jetson モジュール | 期待される出力 |
| --- | --- |
| AGX Orin 64GB | `0955:7023 NVidia Corp.` |
| AGX Orin 32GB | `0955:7223 NVidia Corp.` |

<div align="center">
  <img width="800" src="https://files.seeedstudio.com/wiki/reComputer-Jetson/J501/lsusb.png" alt="lsusb によってフォースリカバリモードで検出された Jetson デバイス" />
</div>

##### イメージを展開してフラッシュする

選択したモジュール用のコマンドを実行します。ブラウザがファイルを別の場所に保存した場合は、`~/Downloads` を実際のダウンロードディレクトリに置き換えてください。

<Tabs groupId="j50-mini-flash-module">

```bash
cd mfi_recomputer-mini-agx-orin-64g-j501-7.2.0-39.2.0-2026-09-24
sudo ./tools/kernel_flash/l4t_initrd_flash.sh \
  --flash-only --massflash 1 --network usb0 --showlogs
```

  </TabItem>
  <TabItem value="agx-orin-32gb" label="AGX Orin 32GB">

#### 3. ZED SDK をインストールする

[Stereolabs ZED SDK ダウンロードページ](https://www.stereolabs.com/developers/release/) にアクセスし、`cat /etc/nv_tegra_release` で表示されたリリースに対応する NVIDIA Jetson インストーラを選択します：

| インストール済みシステム | ZED SDK ページで選択する項目 |
| --- | --- |
| JetPack 6.2.x / L4T 36.4.x | ZED SDK for JetPack 6.1 and 6.2 (L4T 36.4) |
| JetPack 7.2 / L4T 39.2 | ZED SDK for JetPack 7.2 (L4T 39.2) |

`zstd` をインストールし、ダウンロードしたインストーラに実行権限を付与して実行します。以下のプレースホルダは、実際にダウンロードしたファイル名に置き換えてください。

```bash
sudo apt update
sudo apt install -y zstd
cd ~/Downloads
chmod +x ZED_SDK_Tegra_L4T<release>_v<version>.zstd.run
./ZED_SDK_Tegra_L4T<release>_v<version>.zstd.run
```

インストーラの指示に従い、ZED ツールは選択されたままにしておきます。インストール完了後に再起動します：

```bash
sudo reboot
```

:::tip
ZED SDK インストーラ名に含まれる L4T バージョンは、reComputer 上の L4T リリースと一致している必要があります。SDK またはカメラ DEB のバージョンが一致しないと、カメラが検出されない原因になります。
:::

## トラブルシューティング

- **カメラが検出されない:** インストールされている L4T リリースと、DEB、BSP、ZED SDK がすべて一致していることを確認してください。その後、電源を切り、カメラケーブルを挿し直します。
- **APT がパッケージの不一致を報告する:** インストールを強制しないでください。`cat /etc/nv_tegra_release` によって表示される L4T バージョン用のパッケージをダウンロードします。
- **ZED Studio が起動しない:** グラフィカルデスクトップが動作していることを確認し、ターミナルから `/usr/local/zed/tools/ZED_Studio` を起動してエラー出力を確認します。
- **画像は表示されるが深度が利用できない:** ツールを含む完全な ZED SDK をインストールしていること、および選択したカメラモデルがその SDK リリースでサポートされていることを確認してください。
- **映像が断続的になる:** 電源を切り、再テストする前に Fakra/Mini-Fakra ケーブル、ロック位置、およびサポートされているケーブル長を確認してください。
