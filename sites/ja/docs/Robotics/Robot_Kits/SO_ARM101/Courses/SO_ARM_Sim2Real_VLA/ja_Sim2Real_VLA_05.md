このモジュールでは、コース全体を通して使う Physical AI のワークフローを
確認しました：

- **LeRobot** がソフトウェア基盤を提供します——データ収集・ポリシー学習・
  デプロイ・評価が 1 つのフレームワークで完結し、Hugging Face コミュニティ
  が支えます；
- **Sim-to-Real** は、シミュレーションが現代ロボット学習のスケーリング
  ツールである理由と、両者のギャップが中心課題である理由を説明します；
- **SO-ARM101** は今後の実験のハードウェア基盤です：人間の入力を読む
  リーダーと実行するフォロワー——NVIDIA の SO-101 Workshop と参照
  チェックポイントが対象とするエンボディメントそのものです。

全体ワークフローを理解したところで、次は物理システムを準備します。
