# Goto 補間プレイグラウンド

このコードは、Reachy Mini において頭部および／またはアンテナを目標ポーズへ動かすために利用できる、さまざまな補間方法を示します。linear、minjerk、ease_in_out、cartoon などの手法を試し、それぞれの方法が頭部とアンテナの動きにどのような影響を与えるかを観察できます。

完全なサンプルはこちらをご覧ください: [goto_interpolation_playground.py](https://github.com/pollen-robotics/reachy_mini/tree/develop/examples/goto_interpolation_playground.py)
