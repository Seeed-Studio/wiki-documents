# IMU

このサンプルでは、ワイヤレス版 Reachy Mini から IMU センサーデータ（加速度計、ジャイロスコープ、クォータニオン姿勢、温度）にアクセスする方法を示します。

注: IMU は Reachy Mini のワイヤレス版でのみ利用可能です。

完全なサンプルはこちらを参照してください: [imu_example.py](https://github.com/pollen-robotics/reachy_mini/tree/main/examples/imu_example.py)
