# Reachy Mini ロードマップ

## 最近の主なアップデート

* メディアスタックの統合と安定化、およびより一般的なデーモンの強化と改善に多くの作業を実施 — Wireless / Lite 間の機能差を埋め、体験を統一
* デスクトップアプリをよりユーザーフレンドリーかつ強力にするための取り組み。デバイス管理、アプリの発見、リモートコントロール機能を改善
* ビルダーが自分のアプリや行動を作成・共有できるようにするための Agent パスの改善：詳しくは [Vibe code with your agent](/ja/reachymini_vibe-code-with-your-agent) を参照してください！

## 今後の重点分野

* iOS と Android 向けの Reachy Mini モバイルアプリ。スマートフォンからロボットを操作し、外出先でもアプリストアにアクセス可能。コミュニティアプリをモバイルデバイスから直接実行し、シンプルなリンクとして共有できます！

* Reachy Mini アプリをライブで構築し、世界中と共有できる Vibe コーディングスペース！
