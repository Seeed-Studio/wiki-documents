# 3D エンクロージャ

このページでは、Wio Tracker L1 シリーズをベースにしたコミュニティ製 3D エンクロージャおよびデバイス設計プロジェクトをまとめています。

## L1

### マグネット式ワイヤレス充電器

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage1.png" alt="Magnetic Wireless Charger" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>出典：</strong> <a href="https://www.hackster.io/saheenpalayi/pocketmesh-bank-an-everyday-power-bank-meshtastic-node-20202b" target="_blank" rel="noopener noreferrer">PocketMesh Bank - an everyday power bank + Meshtastic node</a></p>

Wio Tracker L1 をコンパクトなマグネット式ワイヤレスモバイルバッテリーに統合し、スマートフォンの充電、ノードへの電源供給、アンテナ一体型でより携帯しやすいデザインを実現しています。

**製作者：** [Saheen Palayi](https://www.hackster.io/saheenpalayi)

**動画：** [PocketMesh Bank](https://www.youtube.com/watch?v=gsW4RvVaC_4)

**ダウンロード先：** [a360](https://a360.co/4nJFKRY)

### WioFold Communicator

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage2.png" alt="WioFold Communicator" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>出典：</strong> <a href="https://www.hackster.io/czipod/the-wio-tracker-l1-meshtastic-communicator-9465eb" target="_blank" rel="noopener noreferrer">The Wio Tracker L1 Meshtastic Communicator</a></p>

物理キーボードと交換可能な 18650 バッテリーを備えた、折りたたみ式の Wio Tracker L1 ベース Meshtastic 通信機です。

**製作者：** [Dávid Czipó](https://www.hackster.io/czipod)

### Ride Trace

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage3.png" alt="Ride Trace" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>出典：</strong> <a href="https://www.hackster.io/Milliam/lorider-the-meshatastic-0cffeb" target="_blank" rel="noopener noreferrer">LoRider- the Meshatastic</a></p>

Wio Tracker L1 をベースにしたコンパクトな自転車搭載 Meshtastic トラッカーで、GPS トラッキング、防犯アラート、フロントライト機能、そして日常走行で目立たない使用を目的として設計されています。

**製作者：** [Miriam Choi](https://www.hackster.io/Milliam)

### Wio Tracker L1 ゲートウェイ

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage4.png" alt="Wio Tracker L1 Gateway" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>出典：</strong> <a href="https://www.hackster.io/hendra/wio-tracker-l1-gateway-9421c2" target="_blank" rel="noopener noreferrer">Wio Tracker L1 Gateway</a></p>

Wio Tracker L1 をベースにしたハイブリッド Meshtastic ゲートウェイで、環境テレメトリを収集し、メッシュ全体に中継し、さらに MQTT を介してクラウドへブリッジしてリアルタイムのリモート監視を可能にします。

**製作者：** [Hendra Kusumah](https://www.hackster.io/hendra)

### 自立型 Meshtastic ノードファミリー

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage5.png" alt="A Self-Sustaining Meshtastic Node Family" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>出典：</strong> <a href="https://www.hackster.io/jrbanks777/seeedpod-ultimate-77168f" target="_blank" rel="noopener noreferrer">SEEEDpod Ultimate</a></p>

Wio Tracker L1 を中心に構築されたモジュラー型 Meshtastic ノードエコシステムで、オフグリッド展開、都市部での携帯性、自己完結型電源オプションによる日常のバックアップ用途を想定して設計されています。

**製作者：** [Jack](https://www.hackster.io/jrbanks777)

### デュアル Wio Tracker L1 ポータブルソーラーステーション

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage6.png" alt="Dual Wio Tracker L1 Portable Solar Station" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>出典：</strong> <a href="https://www.hackster.io/fernando-doutel/dual-wio-tracker-l1-portable-solar-station-e3fcc1" target="_blank" rel="noopener noreferrer">Dual Solar Charging Station for Wio Tracker L1</a></p>

2 台の Wio Tracker L1 ノードをどこでも充電できるよう設計された堅牢なポータブルソーラーステーションで、オフグリッド監視や緊急通信のために Grove センサー統合にも対応しています。

**製作者：** [Fernando Doutel](https://www.hackster.io/fernando-doutel)

## E-ink

### Meshy: Wio Tracker L1 E-ink 用タフな 3D プリントケース

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage7.png" alt="Meshy 3D-printed case for Wio Tracker L1 E-ink" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>出典：</strong> <a href="https://www.hackster.io/akashedamana/meshy-wio-tracker-l1-e-ink-3d-printed-case-affad1" target="_blank" rel="noopener noreferrer">meshy-wio-tracker-l1-e-ink-3d-printed-case-affad1</a></p>

これは Wio Tracker L1 E-ink 用の 3D プリント保護ケースで、屋外や日常携行での耐久性、携帯性、取り付けやすさを高めるために設計されています。パラメトリックデザインにより、さまざまなバッテリーサイズや取り付け構造に対応し、ベルト、バックパック、MOLLE ギアに装着できるクリップ式マウントも備えています。

**製作者：** [Akash](https://www.hackster.io/akashedamana)

**ダウンロード先：** [a360](https://a360.co/3KNHxqQ)

### MeshPack Pro L1

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage8.png" alt="MeshPack Pro L1" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>出典：</strong> <a href="https://www.hackster.io/alleycat/acos-meshpack-pro-l1-for-meshtastic-1ec031" target="_blank" rel="noopener noreferrer">[ACOS] MeshPack Pro L1 for Meshtastic</a></p>

Wio Tracker L1 用の堅牢でモジュラーな 3D プリントエンクロージャで、ボードをより耐久性が高くカスタマイズ可能なハンドヘルド Meshtastic デバイスへと変えることを目的に設計されています。

**製作者：** [Alley Cat](https://www.hackster.io/alleycat)

### ソーラーオフグリッドメッシュコミュニケーター

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage9.png" alt="Solar Off-Grid Mesh Communicator" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>出典：</strong> <a href="https://www.hackster.io/bastiaan-slee/meshtastic-20-25-cd4c1f" target="_blank" rel="noopener noreferrer">Meshtastic 20.25</a></p>

Wio Tracker L1 を中心に構築された自立型オフグリッド Meshtastic コミュニケーターで、ミニキーボード、E-ink ディスプレイ、バイブレーションアラート、背面ソーラー充電を組み合わせ、日常およびアウトドアでの携帯利用を想定しています。

**製作者：** [Bastiaan Slee](https://www.hackster.io/bastiaan-slee)
