# reComputer RK Module FAQ

このページでは、reComputer RK Module に関する検証済みの回答をまとめています。各回答には、対象となる製品バリアントとファームウェアモード、および最新の公式情報源と照合した最終確認日が記載されています。

## 始める前に

- 正確な製品バリアントと、そのベースとなっている SoC（RK3588 または RK3576）を確認してください。
- バージョン依存の手順を適用する前に、現在のファームウェアバージョンを確認してください。
- このページの回答は 2026-11-01 時点で検証されています。これ以降に閲覧している場合は、リンクされている公式情報源を改めて確認してください。

### reComputer RK3576 Module 用の機械図面、B2B ピン定義、KiCad フットプリントは入手できますか？ {#rk3576-module-open-resources}

**対象:** reComputer RK3576 Module およびその開発キット（キャリアボードおよびフットプリント設計向け）

**最終確認日:** 2026-11-01

現時点では入手できません。現在、reComputer RK3576 Module 向けに公開されている唯一のオープンリソースは、Bazaar 上の回路図のみです: https://files.seeedstudio.com/wiki/reComputer_RK/Documents/recomputer_rk3576_module/reComputer_RK3576_Module_v1.0_260821_sch.pdf 。

**補足:**

- デバイスのカスタマイズ版が必要な場合は、カスタマイズサービスについて Seeed チームまでお問い合わせください

**参考資料:**

- [reComputer RK3576 Module v1.0 Schematic](https://files.seeedstudio.com/wiki/reComputer_RK/Documents/recomputer_rk3576_module/reComputer_RK3576_Module_v1.0_260821_sch.pdf)
