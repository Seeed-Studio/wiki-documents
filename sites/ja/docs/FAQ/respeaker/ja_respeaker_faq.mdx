# reSpeaker FAQ センター

このセンターでは、reSpeaker ファミリ向けの、製品レベルで検証済みの回答をまとめています。すべての質問は各製品の FAQ ページに掲載され、最新の公式情報と照合されています。各回答に表示される **Last verified** 日付は、最後にレビューされた日時を示します。

## この FAQ センターの使い方

1. 製品名、SKU、エラーメッセージ、または機能に関するキーワードを検索ボックスに入力します。
2. どのキーワードを使えばよいか分からない場合は、まず製品を選び、次に **Connectivity** や **Firmware** などのドメインを選択します。
3. 結果をクリックすると、その製品の FAQ ページ内の該当する質問に直接ジャンプします。
4. 手順に従う前に、**Applies to**、ファームウェアモード、**Last verified** の各項目を確認してください。
5. 質問が解決しない場合は、テクニカルサポートに連絡する前に、製品モデル、SKU、ファームウェアバージョン、ホストシステム、および最小限の再現手順を用意してください。
