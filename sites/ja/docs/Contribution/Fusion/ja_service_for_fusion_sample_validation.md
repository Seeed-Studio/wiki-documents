サンプル検証は、製品設計が意図した要件を満たしているかどうかを確認する工程です。パイロット生産は、量産に向けて生産プロセス、組立手順、および試験方法を検証します。

本ガイドは、製品設計を完了し、サンプルの製作またはパイロット生産の開始を準備しているハードウェアチームを対象としています。各段階における検証の優先事項を説明します。製造範囲、検証活動、および生産体制は、設計の進捗状況と製造ニーズに基づき、各プロジェクトごとに確認されます。

## サンプル検証とパイロット生産の目的

製品が設計段階から製造段階へ進むにつれて、検証の焦点は変化します。エンジニアリングサンプルは、機能と設計の実現可能性を確認するのに役立ちます。後期のサンプルでは完成した設計を検証し、パイロット生産では検証範囲を生産プロセスまで拡大します。

以下の表は、『Open Manufacturing Whitepaper』で説明されている製造段階に基づいています。

| 段階 | 主な焦点 |
| --- | --- |
| エンジニアリング検証（EVT） | エンジニアリングサンプルを製作し、コア機能、性能、およびハードウェアとソフトウェアの連携を確認します。設計上の問題を特定し、対処します。 |
| 設計検証（DVT） | 機構適合、設計仕様、および適用される信頼性要件を含む、最終製品に近い設計を検証します。 |
| 生産検証（PVT） | パイロット生産を通じて、生産プロセス、組立手順、材料の一貫性、試験方法を確認し、生産上の問題を特定します。 |
| 量産（MP） | 確認された設計、プロセス、および品質要件に基づいて製造を行い、品質の一貫性と生産効率に継続的に注意を払います。 |

これらの段階は、製造プロジェクト全体にわたる検証の優先事項を示しています。個々のプロジェクトでは、このうちの一部のみを実施する場合もあり、段階と範囲はプロジェクトのニーズに応じて決定されます。

サンプル検証で得られた知見は、設計改善の指針となります。その後、パイロット生産で、部品が一貫して組み立てられるか、試験が現実的に実施できるか、材料とプロセスが要件を満たしているかなど、設計が生産環境でどのように機能するかを確認します。

## サンプル検証の優先事項

サンプル検証は、製品の設計要件に基づいて行われます。検証内容は、プロジェクトが回路基板、ファームウェア、機構部品、または完成品の組立のいずれを含むかによって異なります。

初期サンプルは、設計の実現可能性を確認するために、短納期PCB製造、CNC加工、または3Dプリントを用いて製作される場合があります。設計が最終化されるにつれて、検証範囲は最終寸法、材料、および部品同士の嵌合にも及びます。

| 検証分野 | 確認内容 |
| --- | --- |
| 機能と性能 | 製品が意図した機能を果たし、設計上の性能要件を満たしているかどうか。 |
| ハードウェアとソフトウェアの統合 | ファームウェアが関係する場合に、ハードウェア、ドライバ、およびソフトウェアが正しく連携して動作するかどうか。 |
| 機構適合と組立 | 基板、筐体、ケーブル、その他の部品が、寸法や組立方法を含め、設計どおりに組み合わさるかどうか。 |
| 材料および部品仕様 | サンプルに使用される材料および部品が、その段階の設計仕様を満たしているかどうか。 |

信頼性および安定性の確認は、製品の想定動作条件を反映したものです。これらは、その条件下で製品が設計要件を満たしているかどうかを確認します。試験内容と合否判定基準は、製品要件に合致している必要があります。

サンプル検証で見つかった問題は分析され、設計改善によって対処され、その後再度確認して解決されたことを検証します。

## パイロット生産の検証

パイロット生産では、設計が生産環境でどのように製造されるかを確認します。これは、材料の投入から組立と試験を経て、完成品の保管に至るまでのプロセスを対象とします。また、繰り返し生産した際の一貫性も確認します。

| 検証分野 | 確認内容 |
| --- | --- |
| 生産プロセスと組立手順 | 生産工程が計画どおりに連携しているか、作業方法が明確か、改善が必要な組立上の問題が特定されているかどうか。 |
| 材料および供給の一貫性 | 小ロットで供給される材料が仕様および品質要件を満たしているか、サプライヤから納入される部品に一貫性があるかどうか。 |
| 試験手順および治具 | 試験手順が実施可能か、治具が準備できているか、繰り返し試験に適した方法になっているかどうか。 |
| 品質検査 | 確認済みの基準に照らして、材料、組立、および機能試験結果を検査し、不良の原因を分析します。 |

標準作業手順書（SOP）は、各生産工程の実施方法を記録したもので、生産スタッフが従う指針となります。治具および試験手順は、組立と検査を支援します。これらの手順とツールは、パイロット生産での実際の使用を通じて検証されます。

パイロット生産では、設計、受入材料、プロセス、または試験方法に関する問題が明らかになる場合があります。そこで得られた知見は、量産前の準備状況レビューを支える材料となります。

## 量産準備と問題解決

量産前には、パイロット生産の結果を用いた準備状況レビューを行い、生産手順、品質要件、重要材料、および特定された問題の対応状況を評価します。ホワイトペーパーでは、主なレビュー項目として以下を挙げています。

| レビュー項目 | 確認内容 |
| --- | --- |
| 標準作業手順書 | 量産用の手順が確定しており、関連する生産工程を網羅していること。 |
| 品質検査仕様 | 検査要件が、材料、生産プロセス、および試験を対象としていること。 |
| 重要部品および材料サンプル | 重要部品および材料のサンプルが承認されていること。 |
| パイロット生産での問題 | パイロット生産レポートに記録された問題が対処され、クローズされていること。 |

作業手順および検査仕様は、製造チームの生産および検査業務の指針となります。顧客の設計ファイル、試験要件、および承認は、これらの生産準備の根拠となります。

量産に影響を与える重大な問題は、その段階を開始する前に解決する必要があります。改善内容を検証するために、追加のパイロット生産を行う必要が生じる場合もあります。

量産中は、製品品質、歩留まり、および効率が継続的に監視されます。実際の生産状況に基づき、プロセスおよび生産能力計画が改善されます。

## プロジェクト文書およびサービスリンク

サンプル製作およびパイロット生産に使用する材料情報、図面、組立文書、および試験文書は、該当する設計リビジョンと一致している必要があります。検証の結果、設計変更が行われた場合は、その後の生産に使用する文書も更新する必要があります。

以下のガイドでは、関連文書およびサービスの目的と内容について説明しています。

| ガイド | 内容 |
| --- | --- |
| [Seeed Fusion 製造文書作成ガイド](https://wiki.seeedstudio.com/ja/service_for_fusion_manufacturing_documents/) | PCB/PCBA、機構、パッケージング、ファームウェア、および試験文書の目的と、それらの相互関係。 |
| [Seeed Fusion PCBA 機能試験要件作成ガイド](https://wiki.seeedstudio.com/ja/service_for_fusion_pcba_functional_test/) | 試験対象、試験条件、作業手順、期待される結果、および合否判定基準。 |
| [Seeed Fusion ワンストップ製造・出荷ガイド](https://wiki.seeedstudio.com/ja/service_for_fusion_one_stop/) | 製造、カスタマイズ、保管、およびフルフィルメントサービスの範囲と、それらの連携方法。 |

PCB および PCBA のファイル形式、テンプレート、提出要件については、[Seeed Fusion PCB & PCBA サービスガイド](https://wiki.seeedstudio.com/ja/Service_for_Fusion_PCB/)を参照してください。

サンプル製作、小ロット生産、または完成品の製造について相談する場合は、[Fusion One-Stop Service ページ](https://www.seeedstudio.com/fusion-one-stop.html)をご覧いただくか、[fusion@seeed.io](mailto:fusion@seeed.io) までご連絡いただき、製造範囲とプロジェクト体制をご確認ください。

製造段階の背景については、[Open Manufacturing Whitepaper](https://files.seeedstudio.com/fusion/Open_Manufacturing_Whitepaper.pdf)を参照してください。
