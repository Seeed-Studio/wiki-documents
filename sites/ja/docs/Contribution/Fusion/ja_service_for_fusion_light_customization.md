Seeed Fusion は、標準的な Seeed ハードウェア製品に対して、ロゴ、パッケージ、ファームウェア、およびアクセサリのカスタマイズを提供します。これらのオプションにより、製品をお客様のブランド、アプリケーション、または展開要件に合わせて調整できます。

本ガイドでは、カスタマイズオプション、注文方法、サンプル承認、および費用について説明します。対応製品、利用可能なオプション、最新の価格およびリードタイムについては、サービスページおよび関連する製品ページを参照してください。

## カスタマイズオプション

| オプション | 内容 |
| --- | --- |
| ロゴカスタマイズ | スクリーン印刷やレーザー刻印などの方法で、お客様のブランディングを追加します。方法は製品および選択したカスタマイズオプションによって異なります。 |
| パッケージカスタマイズ | パッケージ箱、ラベル、スリーブ、マニュアル、および外箱情報をカスタマイズします。 |
| ファームウェアカスタマイズ | 出荷前に Seeed によってテストされたファームウェアをプリロードするか、製品がサポートする基本設定を調整します。 |
| アクセサリオプション | 製品で利用可能なオプションから、既存のテスト済みアクセサリを追加または削除します。 |

利用可能なオプションは製品によって異なります。[Light Customization サービスページ](https://www.seeedstudio.com/fusion_branding_firmware.html)にアクセスし、該当する製品ページを開いてオプションを確認してください。

掲載されていない製品、開発済みのファームウェア、またはオンラインオプションに含まれない要件については、[fusion@seeed.io](mailto:fusion@seeed.io) までお問い合わせください。

## 注文とサンプル承認

オンラインのライトカスタマイズ注文は、選択した製品のカスタマイズページから送信します。

| 手順 | 行うこと |
| --- | --- |
| 製品を選択 | Light Customization サービスページから、カスタマイズしたい Seeed 製品を選択します。 |
| カスタマイズオプションを選択 | 製品がサポートするロゴ、パッケージ、ファームウェア、またはアクセサリのオプションを確認して選択します。 |
| 数量と要件を入力 | ページで求められる数量およびカスタマイズの詳細を入力します。 |
| カスタマイズ用ファイルを提出 | 選択したオプションに必要なファイルをアップロードし、関連する注意事項を追記します。 |
| 注文内容を確認して支払い | 注文内容、料金、および適用される条件を確認し、支払いを完了します。 |

実物サンプルにより、色、ロゴの見え方、パッケージの外観と質感、ラベルの配置、および全体的な外観を確認できます。サンプル費用は別途請求されます。

サンプル承認後は、確定した要件に基づいて生産が行われます。具体的なサンプル手配および承認要件は、注文内容、適用条件、およびプロジェクト契約に従います。

## コスト内訳

ライトカスタマイズの費用には、一般的に標準製品、選択したオプションに対するノンリカーリングエンジニアリング費用、およびカスタマイズ作業費が含まれます。

| コスト | 説明 |
| --- | --- |
| 製品コスト | 選択した標準ハードウェア製品のコスト。 |
| ノンリカーリングエンジニアリング (NRE) 費用 | プロジェクト評価、セットアップ、治具製作、または生産準備などの作業に対する一回限りのエンジニアリング費用。 |
| 加工費 | カスタマイズ作業に対する料金で、数量に基づいて算出されます。 |

選択した各カスタマイズオプションには、それぞれ個別の料金が発生します。サンプル費用は別途計算されます。同一のカスタマイズ要件での再注文については、通常、追加の NRE 費用は発生しません。適用される料金はプロジェクト見積書に明記されます。

最新の価格、数量要件、支払い条件、およびリードタイムについては、該当するカスタマイズページおよび価格ポリシーを参照してください。

## サービスリンクとポリシー

ライトカスタマイズを依頼するには、[Light Customization サービスページ](https://www.seeedstudio.com/fusion_branding_firmware.html)にアクセスして該当する製品ページを開くか、[fusion@seeed.io](mailto:fusion@seeed.io) のチームまでご連絡ください。

以下の文書では、適用される条件、料金、および品質ポリシーについて説明しています。

| 文書 | 内容 |
| --- | --- |
| [Terms and Conditions for Online Custom Services](https://files.seeedstudio.com/fusion/odm/TermsAndConditionsForOnlineCustomServices.pdf) | オンラインカスタマイズ注文に適用される条件。 |
| [Pricing and Payment Policy for Custom Service](https://files.seeedstudio.com/fusion/odm/PricingAndPaymentPolicyForCustomService.pdf) | カスタマイズ料金および支払い要件。 |
| [Quality Policy for Custom Service](https://files.seeedstudio.com/fusion/odm/QualityPolicyforCustomService.pdf) | カスタマイズサービスに関する品質規定。 |

顧客と Seeed の間で別途契約が締結されている場合は、その契約が優先して適用されます。
