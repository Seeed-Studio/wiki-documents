製造ドキュメントは、製品の材料、図面、組立および検査要件を記述するものです。これらは見積もり、調達、生産、検査を支援します。本ガイドは、顧客設計に基づくプロジェクト向けです。一般的な製造ドキュメントの目的と、それらの相互関係について説明します。

必要なドキュメントは、プロジェクトに含まれる製造作業の内容によって異なります。すべてのプロジェクトで、以下に挙げるすべてのドキュメントが必要になるわけではありません。

| プロジェクトに含まれる作業 | 関連セクション |
| --- | --- |
| PCB 製造、部品調達、および実装 | PCB および PCBA ドキュメント |
| エンクロージャやその他の機構部品、または製品組立 | 機構部品および製品組立 |
| カスタムパッケージおよび印刷物 | パッケージングドキュメント |
| ファームウェア書き込みおよび機能検査 | ファームウェアおよび検査ドキュメント |
| 複数ファイル間の情報の突き合わせ | ドキュメントの整合性と版数情報 |

標準 Seeed 製品をベースにしたロゴ、パッケージ、その他の軽微なカスタマイズについては、[Seeed Fusion Light Customization Service Guide](https://wiki.seeedstudio.com/ja/service_for_fusion_light_customization/) を参照してください。[Light Customization service page](https://www.seeedstudio.com/fusion_branding_firmware.html) から該当製品ページを開き、選択したオプションに必要なドキュメントを確認してください。

## PCB および PCBA ドキュメント

PCB 製造ドキュメントは、基板のアートワークと製造要件を定義します。PCBA プロジェクトでは部品調達と実装も行うため、関連する部品情報および実装情報が必要です。

| ドキュメント | 目的 | 主な情報 |
| --- | --- | --- |
| Gerber およびドリルファイル | PCB 層構成、基板外形、および製造用のドリル情報を記述します。 | 銅箔、ソルダーレジスト、シルク、基板外形、ドリルデータ、および必要に応じた内層情報。 |
| PCB 製造仕様書 | 基板アートワーク以外の材料およびプロセス要件を定義します。 | 基板材料、スタックアップ、基板厚、銅箔厚、表面処理、ソルダーレジスト、および該当するインピーダンスや公差要件。 |
| 部品表 (BOM) | 購入および実装する部品を特定します。 | リファレンスデザインators、完全なメーカー品番または Seeed SKU、数量、および任意の部品リンク。 |
| 実装図 | 生産および検査担当者が部品の実装位置、向き、極性を把握できるようにします。 | リファレンスデザインators、部品位置、極性マーク、向き。両面実装の場合は両面を含めます。 |
| CPL / ピックアンドプレースファイル | 実装装置をプログラムするための SMT 部品実装データを提供します。 | リファレンスデザインators、X/Y 座標、回転角、実装面。 |
| 回路図 | 回路解析、デバッグ、トラブルシューティングを支援します。 | 回路接続、ドキュメントの版数、日付。 |

Gerber ファイルと BOM は、Fusion PCBA 見積もりおよびファイルレビューの基本ドキュメントです。実装図は実装および検査のためのビジュアルリファレンスを提供し、CPL ファイルは実装装置向けの位置データを提供します。提出要件は、実装方法およびプロジェクト内容に応じて確認されます。

ファイル形式、BOM テンプレートと書式ルール、図面の出力手順については、[Seeed Fusion PCB & PCBA Service Guide](https://wiki.seeedstudio.com/ja/Service_for_Fusion_PCB/) およびそこからリンクされているガイドを参照してください。

## 機構部品および製品組立

プロジェクトにエンクロージャやその他の機構部品が含まれる場合、ドキュメントは部品の寸法、材料、外観、および品質要件を記述します。製品組立については、部品同士の組み合わせ方法も説明します。

| ドキュメント | 目的および主な情報 |
| --- | --- |
| アプリケーション説明 | 製造チームが機構要件を理解できるよう、製品の用途および動作条件を記述します。 |
| 機構 BOM | 機構部品、材料情報、および数量を一覧にします。 |
| 3D 図面 | 部品形状および空間的な関係を示し、部品同士の嵌合を確認します。 |
| 2D 図面 | 部品寸法および対応する公差を規定します。 |
| CMF ドキュメント | 機構部品の色、材料、表面仕上げ要件を規定します。 |
| 品質要件 | 機構部品の検査および受入要件を定義します。 |
| 組立図または分解図 | 部品同士の組み立て方を示します。BOM と併用することで、完成品の組立全体を記述します。 |

例えば、エンクロージャ図面はエンクロージャそのものを記述します。組立図は、エンクロージャが基板、ケーブル、その他の部品とどのように組み合わさるかを示します。

## パッケージングドキュメント

カスタムパッケージを含むプロジェクトでは、ドキュメントはパッケージデザイン、材料、梱包方法、およびラベル要件を記述します。

| ドキュメント | 目的および主な情報 |
| --- | --- |
| パッケージデザインファイル | パッケージ箱およびその他のカスタムパッケージ資材のデザインと材料を規定します。 |
| 梱包手順書 | 製品の梱包方法およびカートンへの詰め方を説明します。 |
| 印刷物ファイル | クイックスタートガイドやマニュアルなどの印刷物のデザインおよび材料要件を提供します。 |
| 出荷用カートンおよびラベル要件 | カートンのデザイン、梱包要件、およびカートンラベル情報を規定します。 |

プロジェクトにパレット、乾燥剤、その他の特別なパッケージング要件が含まれる場合は、それらの詳細もパッケージングドキュメントに含めてください。

## ファームウェアおよび検査ドキュメント

製造プロジェクトにファームウェア書き込みや機能検査が含まれる場合、ドキュメントは書き込むファイル、作業手順、および検査結果の評価方法を説明します。

| ドキュメント | 目的および主な情報 |
| --- | --- |
| ファームウェアファイル | 書き込み対象のファイルと、そのバージョン、日付、対応するハードウェアリビジョンを提供します。 |
| 書き込み手順書 | プログラマの機種、接続方法、書き込みソフトウェア、および操作手順を規定します。 |
| 試験環境説明 | 試験に必要なハードウェア、オペレーティングシステム、試験ソフトウェア、および治具を特定します。 |
| 試験手順書 | 試験手順および操作手順を記述します。 |
| 期待結果および合否判定基準 | 各試験の期待される結果と、合否を判定するための条件を規定します。 |

試験用ファームウェアは生産中の確認をサポートします。出荷用ファームウェアは、出荷後に製品を動作させるために使用されます。これらが異なる場合、書き込み、試験、出荷前検査の過程で混同されないよう、それぞれのバージョンと目的をドキュメントで明確に区別する必要があります。

試験要件の作成に関する詳細なガイダンスについては、[Seeed Fusion Guide to Preparing PCBA Functional Test Requirements](https://wiki.seeedstudio.com/ja/service_for_fusion_pcba_functional_test/) を参照してください。

## ドキュメントの整合性と版数情報

同一プロジェクトの材料情報、図面、および組立データは整合している必要があります。PCB および PCBA プロジェクトについて、主な対応関係を以下に示します。

| 照合項目 | 確認内容 |
| --- | --- |
| 品番およびパッケージ | BOM の品番に対応する部品パッケージが、PCB フットプリントと一致していること。 |
| 数量およびリファレンスデザインators | BOM 上の部品数量が、対応するリファレンスデザインatorsの数と一致していること。数量は、基板単位かパネル単位かなど、全体を通して同じ基準であること。 |
| 実装図および CPL ファイル | リファレンスデザインators、実装面、位置、向きがファイル間で一致していること。極性は実装図上で明確に示されていること。 |

Gerber ファイル、BOM、実装図、および CPL ファイルは、すべて同じ設計リビジョンに対応している必要があります。回路図およびファームウェアファイルの版数および日付情報は、生産に使用されたドキュメントを特定し、トレーサビリティを確保するためのものです。ファームウェアファイルには、対応するハードウェアリビジョンも明記されており、ハードウェアとファームウェアを正しく対応付けることができます。

プロジェクト固有の提出要件については、該当するサービス注文ページを確認するか、[fusion@seeed.io](mailto:fusion@seeed.io) までお問い合わせください。
