SenseCaft クラウドサービスは、LoRaWAN IoT 省電力通信プロトコルを使用するハードウェアデバイスをベースにしています。LoRaWAN デバイスは、データ通信機能を有効にするために従量制の事前支払いが必要です。ユーザーは製品の利用ニーズに応じて、月単位または年単位で前払いできます。

:::note
課金はデバイスがプラットフォームにバインドされた後に開始されます。課金サイクル中にデバイスのバインドが解除されたり、デバイスの所属組織が変更された場合でも、課金は中断されず、デバイス単位で料金が発生します。
:::

:::tip note
サービスの購入は `Paypal` のみサポートされています。
:::

## サブスクリプション

### SenseCraft アプリでのサブスクリプション

`Device` ページに移動し、サービスを購入したいデバイスを選択します。
デバイスの詳細画面に入り、`Settings` インターフェースを開きます。`Communication Service` を選択してサービス購入モジュールにアクセスします。

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/fee_1.png" alt="pir" width={600} height="auto" /></p>

:::tip
APP では現在、単一デバイスの購入のみサポートしています。複数デバイス向けの一括サービス購入については、[SenseCAP Portal Subscription](https://wiki.seeedstudio.com/ja/sensecraft_cloud_fee/#sensecap-portal-services-subscription) を参照してください。
:::

### SenseCAP Portal でのサブスクリプション

[SenseCAP Portal](https://sensecap.seeed.cc) にログインします。

`Devices` —> `Sensor Node` ページに移動し、リスト左上の `Bulk Purchase services` ボタンをクリックします。購入する対象デバイスを選択します。

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/portal_fee_1.png" alt="pir" width={600} height="auto" /></p>
