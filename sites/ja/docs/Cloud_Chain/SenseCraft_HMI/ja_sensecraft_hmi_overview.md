# SenseCraft HMI 概要

## はじめに

[SenseCraft HMI](https://sensecraft.seeed.cc/hmi/?utm_source=seeedstudio_wiki&utm_medium=referral&utm_campaign=wiki_to_sensecraft&utm_content=sensecraft_hmi_home) は、Seeed Studio が提供する強力なクラウドベースのインターフェースデザインプラットフォームで、コーディング不要で画面搭載デバイス向けのプロフェッショナルなビジュアルインターフェースを作成できます。直感的なドラッグ＆ドロップエディタ、あらかじめ用意されたテンプレート、AI を活用したデザイン機能により、SenseCraft HMI を使えば、ハードウェアを美しい情報表示、ダッシュボード、デジタルサイネージ、コントロールパネルへと簡単に変換できます。

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/reterminal_e10xx/img/23.png" style={{width:1000, height:'auto'}}/></div>

### 主な特長

- **ノーコードインターフェースビルダー**：シンプルなドラッグ＆ドロップツールでプロフェッショナルな表示画面を作成

- **AI を活用したデザイン**：自然言語での説明からレイアウトや画像を自動生成

- **リアルタイムデータ連携**：天気、株価、GitHub、YouTube などに接続

- **複数の表示機能**：用途に応じて Gallery、Canvas、RSS、Web 機能を利用可能

- **すぐに使えるテンプレート**：一般的なアプリケーション向けにデザイン済みのレイアウトを用意

- **ワンクリックデプロイ**：作成したデザインを接続済みデバイスへ直接プッシュ

- **デバイスセンサー連携**：デバイスから取得した温度、湿度、バッテリー情報を自動表示

## 利用開始方法

SenseCraft HMI を使い始めるには：

1. **プラットフォームへアクセス**：[SenseCraft HMI](https://sensecraft.seeed.cc/hmi/?utm_source=seeedstudio_wiki&utm_medium=referral&utm_campaign=wiki_to_sensecraft&utm_content=sensecraft_hmi_home) にアクセスします

2. **アカウントを作成**：まだお持ちでない場合は、無料の SenseCraft アカウントに登録します

3. **デバイスを接続**：画面の指示に従って、対応デバイスをペアリングします

4. **機能を選択**：用途に応じて Gallery、Canvas、RSS、または Web 機能を選択します

5. **インターフェースをデザイン**：直感的なツールを使って表示画面を作成します

6. **デバイスへデプロイ**：ワンクリックで作成したデザインを接続済みデバイスへ送信します

## 機能ドキュメント

SenseCraft HMI には、さまざまな表示ニーズに対応した複数の専用機能が用意されています：

### [AI Generation Function](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-ai-generator/)

自然言語で希望する内容を説明するだけで、美しいレイアウトや画像を作成でき、デザインスキルは不要です。

### [Gallery Function](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-gallery/)

デバイスをデジタルフォトフレームとして活用し、カスタマイズ可能な画像表示、トランジション、ビジュアルエフェクトを実現します。

### [Canvas Function](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-canvas/)

静的要素とさまざまなソースからの動的データを組み合わせて、カスタムインターフェースやダッシュボードをデザインします。

### [RSS Function](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-rss/)

RSS フィードを利用して、ニュースサイト、ブログ、その他の情報ソースから自動更新されるコンテンツを表示します。

### [Web Function](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-web/)

Web コンテンツをデバイス上に直接表示でき、ダッシュボード、ドキュメント表示、監視システムなどに最適です。
