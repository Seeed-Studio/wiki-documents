Seeed Fusion 为标准 Seeed 硬件产品提供 Logo、包装、固件和配件定制服务。这些选项有助于让产品适配您的品牌、应用场景或部署需求。

本指南介绍定制选项、下单流程、样品确认以及费用构成。关于支持的产品、可用选项、当前价格和交期，请参考服务页面及相关产品页面。

## 定制选项

| 选项 | 包含内容 |
| --- | --- |
| Logo 定制 | 通过丝印、激光雕刻等方式添加您的品牌标识。具体方式取决于产品和所选定制选项。 |
| 包装定制 | 可定制包装盒、标签、套封、说明书以及外箱信息。 |
| 固件定制 | 在发货前预烧由 Seeed 测试过的固件，或调整产品所支持的基础设置。 |
| 配件选项 | 在产品可选范围内添加或移除现有、已测试的配件。 |

可用选项因产品而异。请访问 [Light Customization 服务页面](https://www.seeedstudio.com/fusion_branding_firmware.html)，进入相关产品页面查看其定制选项。

对于未列出的产品、自主开发的固件，或在线选项未涵盖的需求，请联系 [fusion@seeed.io](mailto:fusion@seeed.io) 进行评估。

## 下单与样品确认

在线轻定制订单通过所选产品的定制页面提交。

| 步骤 | 操作说明 |
| --- | --- |
| 选择产品 | 在 Light Customization 服务页面中选择您希望定制的 Seeed 产品。 |
| 选择定制选项 | 查看并选择该产品所支持的 Logo、包装、固件或配件定制选项。 |
| 填写数量和需求 | 在页面中填写数量及所需的定制细节。 |
| 提交定制文件 | 上传所选定制选项所需的文件，并补充相关备注信息。 |
| 核对订单并付款 | 检查订单详情、费用及适用条款，然后完成付款。 |

通过实物样品，您可以检查颜色、Logo 效果、包装的外观与手感、标签位置以及整体外观。样品费用单独计费。

样品确认后，量产将按照已确认的需求执行。具体的样品安排和确认要求以订单、适用条款及项目协议为准。

## 费用构成

轻定制费用通常包括标准产品费用、所选定制选项的一次性工程费用，以及定制加工费用。

| 费用项目 | 说明 |
| --- | --- |
| 产品费用 | 所选标准硬件产品的费用。 |
| 一次性工程（NRE）费用 | 项目评估、方案搭建、工装治具或生产准备等工作的单次工程费用。 |
| 加工费用 | 按数量计费的定制加工费用。 |

每个选定的定制选项都有对应的收费。样品费用单独计算。相同定制需求的重复下单通常不再收取额外的 NRE 费用。适用费用将在项目报价中明确说明。

关于当前价格、起订量要求、付款安排和交期，请参考相关定制页面及价格政策。

如需提交轻定制需求，请访问 [Light Customization 服务页面](https://www.seeedstudio.com/fusion_branding_firmware.html) 并打开相关产品页面，或通过 [fusion@seeed.io](mailto:fusion@seeed.io) 联系团队。

以下文档涵盖适用条款、收费及质量政策。

| 文档 | 涵盖内容 |

| [Terms and Conditions for Online Custom Services](https://files.seeedstudio.com/fusion/odm/TermsAndConditionsForOnlineCustomServices.pdf) | 适用于在线定制订单的条款。 |
| [Pricing and Payment Policy for Custom Service](https://files.seeedstudio.com/fusion/odm/PricingAndPaymentPolicyForCustomService.pdf) | 定制服务的收费及付款要求。 |
