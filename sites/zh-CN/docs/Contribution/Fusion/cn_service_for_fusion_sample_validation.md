样品验证用于检查产品设计是否满足其预期需求。试生产用于验证生产过程、装配工艺和测试方法，为量产做准备。

本指南适用于已经完成产品设计、正准备制作样品或开始试生产的硬件团队。文中说明了各阶段的验证重点。每个项目的制造范围、验证活动和生产安排会根据设计进度和制造需求进行确认。

## 样品验证与试生产的目的

随着产品从设计阶段进入制造阶段，验证的重点也会发生变化。工程样品用于检查功能和设计可行性。后续样品用于验证完整设计，而试生产则将验证范围扩展到生产过程。

下表基于《开放制造白皮书》（*Open Manufacturing Whitepaper*）中描述的制造阶段。

| 阶段 | 主要关注点 |
| --- | --- |
| 工程验证（EVT） | 制作工程样品并检查核心功能、性能，以及软硬件协同工作情况。识别并解决设计问题。 |
| 设计验证（DVT） | 验证接近最终版本的产品设计，包括结构配合、设计规格以及适用的可靠性要求。 |
| 生产验证（PVT） | 通过试生产检查生产过程、装配工艺、物料一致性和测试方法，并识别生产问题。 |
| 量产（MP） | 按照确认的设计、工艺和质量要求进行生产，并持续关注质量一致性和生产效率。 |

这些阶段描述了一个制造项目中不同阶段的验证重点。具体项目可能只涉及其中部分工作，阶段划分和范围会根据项目需求确定。

样品验证的发现将指导设计改进。随后通过试生产检查设计在生产环境中的表现，包括零件是否可以稳定装配、测试是否便于执行，以及物料和工艺是否满足要求。

## 样品验证重点

样品验证以产品的设计要求为基础。检查内容取决于项目是否涉及电路板、固件、结构件或完整产品装配。

早期样品可以通过快速 PCB 制作、CNC 加工或 3D 打印完成，用于检查设计可行性。随着设计定型，验证范围还会覆盖最终尺寸、材料以及零件之间的配合情况。

| 验证领域 | 检查内容 |
| --- | --- |
| 功能与性能 | 产品是否实现预期功能并满足设计性能要求。 |
| 硬件与软件集成 | 在涉及固件的情况下，硬件、驱动和软件是否能够正确协同工作。 |
| 结构配合与装配 | 电路板、外壳、线缆及其他部件是否按设计要求配合，包括尺寸和装配方式。 |
| 材料和零件规格 | 样品中使用的材料和零件是否满足该阶段的设计规格。 |

可靠性和稳定性检查应反映产品的预期工作条件，用于确认产品在这些条件下是否满足设计要求。测试项目和验收标准需要与产品需求相匹配。

样品验证中发现的问题需要进行分析，通过设计改进加以解决，并再次检查以确认问题已被消除。

## 试生产验证

试生产用于检查设计在生产环境中的制造情况。其范围涵盖从物料投入生产、装配和测试到成品入库的全过程，同时检查多次生产批次之间的一致性。

| 验证领域 | 检查内容 |
| --- | --- |
| 生产过程与装配工艺 | 生产步骤是否按计划衔接、操作方法是否清晰，以及需要改进的装配问题。 |
| 物料与供应一致性 | 小批量供应的物料是否满足规格和质量要求，以及供应商交付的零件是否一致。 |
| 测试流程与治具 | 测试步骤是否可执行、治具是否就绪，以及测试方法是否适合重复测试。 |
| 质量检验 | 按照确认的标准对物料、装配和功能测试结果进行检验，并分析不良原因。 |

标准作业指导书（SOP）记录了每个生产步骤的具体操作，供生产人员遵循。治具和测试流程则支持装配和检验工作。这些流程和工具会在试生产中通过实际使用进行验证。

试生产可能暴露出设计、来料、工艺或测试方法中的问题。这些发现将为量产前的准备评审提供依据。

## 量产准备与问题解决

在量产前，需要基于试生产结果进行一次准备评审，以评估生产流程、质量要求、关键物料以及已识别问题的处理状态。白皮书列出了以下主要评审项目。

| 评审项目 | 确认内容 |
| --- | --- |
| 标准作业指导书 | 量产用作业指导书已定稿，并覆盖相关生产步骤。 |
| 质量检验规范 | 检验要求覆盖物料、生产过程和测试。 |
| 关键元器件和材料样品 | 关键元器件和材料的样品已获批准。 |
| 试生产问题 | 试生产报告中记录的问题已得到处理并关闭。 |

作业指导书和检验规范为制造团队的生产和检验工作提供依据。客户的设计文件、测试要求和批准记录则为这些生产准备提供基础。

对量产有重大影响的问题需要在量产开始前解决。必要时可以安排进一步的试生产批次来验证改进效果。

在量产过程中，需要持续监控产品质量、良率和生产效率，并根据实际生产情况优化工艺和产能规划。
