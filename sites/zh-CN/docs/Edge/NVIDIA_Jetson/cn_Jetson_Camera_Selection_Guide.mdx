# Jetson 摄像头选型指南

为你的 Jetson 平台 reComputer 或 reServer 查找合适的摄像头。可对比两个型号，然后打开“Details”查看规格参数和可用的安装配置指南。

还没有 Jetson 设备？请先查看 [Jetson 产品选型指南](/cn/jetson-product-selection-guide/)。
