# Orin NX 16GB (J4012)
sha256sum mfi_recomputer-rugged-orin-nx-16g-j401-5.1-35.5.0-2026-04-01.tar.gz

# Orin Nano 8GB (J3011)
sha256sum mfi_recomputer-rugged-orin-nano-8g-j401-5.1-35.5.0-2026-04-01.tar.gz

- reComputer Rugged J4012 或 J3011

- 外接显示器和 HDMI 线缆
- 键盘和鼠标

  <div className="jetson-product-step-content">
    <h3>进入强制恢复模式</h3>
    <p className="jetson-product-step-label">步骤 3 · 连接 DEVICE 端口并验证 USB ID</p>

<img className="jetson-product-step-image" src="https://files.seeedstudio.com/wiki/rugged_J401/1.jpg" alt="用于为 reComputer Rugged J40 烧录的恢复按钮和 DEVICE 端口" />

1. 使用 USB Type-C 数据线将 **DEVICE** 端口与 Ubuntu 主机连接。
2. 按住 **REC** 按钮。
3. 在按住 **REC** 的同时，接通电源以启动设备。
4. 松开 **REC** 按钮。
5. 在 Ubuntu 主机上验证 Jetson 是否被检测到：

```bash
lsusb
```

按配置预期的输出：

| 产品 | Jetson 模组 | 预期 USB ID |
| --- | --- | --- |
| reComputer Rugged J4012 | Orin NX 16GB | `0955:7323 NVidia Corp` |
| reComputer Rugged J3011 | Orin Nano 8GB | `0955:7523 NVidia Corp` |

如果缺少预期的 ID，请重新连接 USB 线缆，尝试主机上的其他 USB 端口，并在继续之前重复恢复步骤。

  </div>
</section>

<section className="jetson-product-step-item">
  <span className="jetson-product-step-number">4</span>
  <div className="jetson-product-step-content">
    <h3>解压并烧录镜像</h3>
    <p className="jetson-product-step-label">步骤 4 · 在 Ubuntu 主机上运行批量烧录包</p>

切换到包含已下载镜像的目录，并为你的模组解压归档文件：

```bash
cd <path-to-image>
# Orin NX 16GB (J4012)
sudo tar xpf mfi_recomputer-rugged-orin-nx-16g-j401-5.1-35.5.0-2026-04-01.tar.gz

# Orin Nano 8GB (J3011): use this archive instead
# sudo tar xpf mfi_recomputer-rugged-orin-nano-8g-j401-5.1-35.5.0-2026-04-01.tar.gz
```

进入包含 `tools/kernel_flash/l4t_initrd_flash.sh` 的已解压 BSP 目录并开始烧录。将 `<extracted-bsp-directory>` 替换为该目录的实际名称：

```bash
cd <extracted-bsp-directory>
sudo ./tools/kernel_flash/l4t_initrd_flash.sh \
  --flash-only --massflash 1 --network usb0 --showlogs
```

等待终端提示烧录成功完成。然后断开 USB 线缆，对 reComputer 断电重启，连接显示器和输入设备，并完成 Ubuntu 的首次启动设置。
