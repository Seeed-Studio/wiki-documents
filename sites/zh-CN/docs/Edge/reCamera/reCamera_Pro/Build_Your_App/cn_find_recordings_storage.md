# 查找录制文件与存储

在配置事件录制触发器之后（参见 [配置事件录制](/cn/recamera_pro_record_settings/)），使用 Web UI 中的 **Recording Settings** 页面来查找文件并管理设备存储。

## 存储管理

在 **Storage Management** 中，你可以查看当前磁盘使用情况以及文件保存的位置。

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_65N6rhHetJ.png" />

在存储配置区域，你可以设置可用存储大小、配置配额，并选择是否覆盖旧文件，以确保始终保存最新的录制内容。

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_WZBl9MEr7Z.png" />
