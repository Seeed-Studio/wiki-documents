# reComputer RK 模组常见问题

本页面包含针对 reComputer RK 模组的已验证解答。每个解答都会说明适用的产品型号和固件模式，并给出最近一次根据当前官方资料完成验证的日期。

## 在开始之前

- 确认准确的产品型号以及其所基于的 SoC（RK3588 或 RK3576）。
- 在执行与版本相关的步骤前，检查当前固件版本。
- 本页答案最近一次验证时间为 2026-11-01；如果你在此之后阅读，请重新核对所链接的官方资料。
