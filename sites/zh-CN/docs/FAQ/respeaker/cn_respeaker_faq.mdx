# reSpeaker 常见问题中心

此中心汇总了 reSpeaker 系列产品级别的已验证解答。每个问题都会发布在对应产品的常见问题页面上，并与当前官方信息进行核对，每条答案中的 **Last verified** 日期表示其最近一次审核时间。

## 如何使用此常见问题中心

1. 在搜索框中输入产品名称、SKU、错误信息或功能关键词。
2. 不确定该用哪个关键词？先选择一个产品，然后选择一个领域，例如 **Connectivity** 或 **Firmware**。
3. 点击某条结果即可跳转到该产品常见问题页面上的对应问题。
4. 在按照步骤操作前，请先查看 **Applies to**、固件模式以及 **Last verified** 字段。
5. 如果问题仍未解决，请在联系技术支持前准备好产品型号、SKU、固件版本、主机系统以及最小可复现步骤。
