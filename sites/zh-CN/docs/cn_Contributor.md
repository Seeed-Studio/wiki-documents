# ✨ 贡献者计划 ✨

在 Seeed，我们非常重视由 Seeeders 组成的社区。[Seeed Studio Contributor Program](/cn/contributors) 是一个协作项目，旨在联合来自世界各地的朋友，共同构建创新解决方案。

<p style={{textAlign: 'center'}}><img src="http://files.seeedstudio.com/wiki/wiki-platform/contributor/contributors.png" alt="pir" width={800} height="auto" /></p>

## 你可以如何贡献并成为我们团队的一员？

作为一个开源平台，我们欢迎所有希望帮助我们改进 wiki 平台的个人参与贡献。

:::info

1. 我们在 GitHub 上准备了**一大批任务（如下所示）**，需要大家的帮助来增强我们的 wiki 平台，每个任务都附有详细的需求说明。
2. 完成后，贡献者可以通过 "Pull Request" 提交内容。
3. 审核通过后，我们的维护者团队会合并提交、记录贡献，并提供感谢礼品。

:::

### [GitHub 上的任务](https://github.com/orgs/Seeed-Studio/projects/6)

我们会根据任务难度等级（Tier 0/1/2/3）、预期完成时间（1/3/7/15 天）、实际提交时间以及内容质量，向贡献者表达感谢并提供不同档位的奖励。

![](http://files.seeedstudio.com/wiki/wiki-platform/contributor/github_assignment_2.png)

### [公开招募 - 每一小步都很重要！](https://wiki.seeedstudio.com/cn/contributors/)

我们也有一系列持续进行中的专题任务，例如：

- 使用我们的产品在特定领域中实现项目。
- 为某些产品设计不同风格的外壳。
- 与我们的工程师一起撰写教程。

![](http://files.seeedstudio.com/wiki/wiki-platform/contributor/open_call.png)

### [分享你的想法 - 实现它 - 获得奖励](https://wiki.seeedstudio.com/cn/contributors/)

我们非常欢迎更多想法！与主题相关的、与场景相关的、你的心愿……

![](http://files.seeedstudio.com/wiki/wiki-platform/contributor/submit.png)

1. 通过填写一个简单的表格来分享你的想法：你的姓名（邮箱）、你想做的项目，以及项目的简要描述。

<p style={{textAlign: 'center'}}><img src="http://files.seeedstudio.com/wiki/wiki-platform/contributor/wish.png" alt="pir" width={400} height="auto" /></p>

:::info
它们会立即显示——你只需刷新页面就能看到。
:::

2. 维护者会对这些想法进行评审：

<p style={{textAlign: 'center'}}><img src="http://files.seeedstudio.com/wiki/wiki-platform/contributor/submit_2.png" alt="pir" width={1000} height="auto" /></p>

3. 并将**被接受的想法**作为任务发布到 [GitHub 仓库](https://github.com/orgs/Seeed-Studio/projects/6/views/1) 上：

<p style={{textAlign: 'center'}}><img src="http://files.seeedstudio.com/wiki/wiki-platform/contributor/submit_3.png" alt="pir" width={400} height="auto" /></p>

:::info
你可以自己领取任务，也可以让其他人来实现它。你同样会获得奖励！
:::

## 我们能提供什么？

我们希望通过提供多种形式的奖励，向所有贡献者表达我们的感谢。
根据预估难度等级 ***(Tier 0/1/2/3)*** 和预估工作时间 ***(1/3/7/15 天)***，以及实际耗时和提交内容，我们会提供不同等级的奖励。

1. 我们会向贡献者提供 Seeed 产品和现金奖励，作为感谢的象征。
2. 对于加入我们 **"Ranger Program"**（即将公布）的贡献者，我们会提供更加令人兴奋的奖励，包括优先体验我们的原型产品。
3. 此外，所有贡献者及其贡献都会在我们的 wiki 平台上得到致谢与展示，以示感谢。

## 有哪些任务示例？

我们已经在 GitHub 上列出了一些任务。目前的任务类型包括：

1. 围绕 Seeed Studio 产品的各类应用与软件部署，从 MCU 开发板应用到工业级设备的软件部署。

2. 网页结构与内容的迭代更新，从简单的语法纠正到整页内容更新以及页面结构重构。

3. 关于“基于解决方案”的原型、可部署的解决方案，甚至是有趣的项目创意的任何额外想法！（数字自动化；去中心化数字化转型；可在野外部署的基础设施；碳中和；可持续发展目标（SDGs）；日常生活中被解决的问题；TinyML；等等。）我们非常重视创造力和创新，因此欢迎你大胆与我们分享你的想法！
