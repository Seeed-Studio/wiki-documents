本模块带你了解了贯穿整门课程的具身智能工作流：

- **LeRobot** 提供软件基座——数据采集、策略训练、部署与评估在一个框架里
  完成，背后是 Hugging Face 社区；
- **Sim-to-Real** 解释了为什么仿真是现代机器人学习的规模化工具，以及仿真与
  现实的差距为何是核心工程问题；
- **SO-ARM101** 是后续所有实验的硬件平台：一只读取人类输入的主臂和一只执行
  的从臂——正是 NVIDIA SO-101 Workshop 与参考 checkpoint 所针对的本体。

理解了整体工作流，接下来就该准备物理系统了。
