# reBot Arm B601-DM 的 Pinocchio 与 MeshCat 入门指南

## 环境依赖

在开始本教程之前，请确保您的系统满足以下环境要求：

| 项目 | 要求 |
|------|------|
| **发行商 ID** | Ubuntu |
| **描述** | Ubuntu 22.04.5 LTS |
| **版本** | 22.04 |
| **开发代号** | Jammy |
| **ROS2 版本** | Humble |

:::tip
本教程基于 Ubuntu 22.04 LTS 和 ROS2 Humble 版本进行编写，如使用其他版本可能需要适当调整。
:::
