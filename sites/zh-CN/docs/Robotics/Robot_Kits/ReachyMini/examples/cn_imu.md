# IMU

此示例演示如何从无线Reachy Mini访问IMU传感器数据（加速度计、陀螺仪、四元数方向和温度）。

注意：IMU仅在无线版Reachy Mini上可用。

请参阅完整示例：[imu_example.py](https://github.com/pollen-robotics/reachy_mini/tree/main/examples/imu_example.py)
