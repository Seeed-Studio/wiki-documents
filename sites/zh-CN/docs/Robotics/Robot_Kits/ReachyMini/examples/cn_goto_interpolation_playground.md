# Goto插值 playground

此代码演示了Reachy Mini中可用的不同插值方法，用于将头部和/或天线移动到目标姿态。它测试各种方法，如linear、minjerk、ease_in_out和cartoon，让您观察每种方法如何影响头部和天线的运动。

请参阅完整示例：[goto_interpolation_playground.py](https://github.com/pollen-robotics/reachy_mini/tree/main/examples/goto_interpolation_playground.py)
