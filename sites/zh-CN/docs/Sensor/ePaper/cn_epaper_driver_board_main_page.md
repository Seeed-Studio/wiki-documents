# ePaper 驱动板总览

## 介绍

ePaper Driver Board 系列专为多用途、低功耗的电子纸应用而设计。这些板卡支持多种电子纸显示屏——从通用的 24-pin 和 50-pin 屏幕，到诸如 10.3 英寸（高速刷新）和 13.3 英寸（Spectra™ 6）等专用大尺寸显示屏。每块板卡都具备核心功能，包括带电源开关的 JST 2.0mm 电池连接器、集成充电 IC、复位按钮以及三个用户可配置按钮。板卡由多种微控制器驱动（例如 XIAO ESP32-S3 Plus、XIAO nRF52840 Plus），部分型号还具备 NFC 功能，非常适合用于数字标牌、电子货架标签、便携式仪表板以及其他节能显示项目。

**EE02** 是一款高性能的电子墨水屏驱动板，专为 **13.3 英寸**电子纸显示屏设计。其搭载 ESP32-S3 芯片，支持 Wi-Fi 和 Bluetooth 连接，是无线显示应用的理想解决方案。

### 特性

- **强大的控制器**：基于 ESP32-S3 构建，提供强劲的处理能力和无线功能。
- **专为大屏设计**：专门针对 13.3 英寸电子墨水屏进行优化，具备高稳定性和高显示清晰度。
- **无线连接**：支持 Wi-Fi 和 Bluetooth 5.0（LE），可实现远程数据更新和云端集成。
- **低功耗**：以节能为设计目标，适用于电池供电应用。
- **易于集成**：兼容 SenseCraft HMI，可进行拖拽式界面设计和远程管理。
- **多样化接口**：包括用于供电/编程的 Type-C 接口以及标准电子墨水屏连接器。

由 **XIAO ESP32-S3 Plus** 提供算力的 ePaper 驱动板 EE03 支持 **10.3 单色电子纸显示屏**。它配备带电源开关的 JST 2.0 mm 电池连接器、内置充电 IC，并带有一个复位按钮和三个用户按钮。非常适合用于低功耗电子纸项目，如数码相框和信息公告板。

### 特性

- **内置 XIAO ESP32-S3 Plus：** 连接兼容的电子纸显示屏即可立即工作。
- **专用 10.3 英寸单色电子纸显示屏支持：** 专为 10.3 英寸高速刷新电子纸显示屏设计，确保快速部署和稳定运行。
- **支持高速刷新：** 集成 T-CON 时序控制，确保精确的高速驱动，同时板载 SHT40 提供实时温度感应以进行波形补偿。
- **带开关的 BAT 接口：** 提供简便的电池连接并集成开关，实现高效电源管理和节能。
- **用户友好按键：** 配备 1 个复位按钮和 3 个用户可编程按钮，为项目加速和自定义功能提供灵活性。
