## 环境准备

要使用 Arduino 为 reTerminal E 系列电子纸显示屏编程，您需要在 Arduino IDE 中配置 ESP32 支持。

:::tip
如果这是您第一次使用 Arduino，我们强烈建议您参考[Arduino 入门指南](https://wiki.seeedstudio.com/cn/Getting_Started_with_Arduino/)。
:::

### Arduino IDE 设置

**步骤 1.** 下载并安装 [Arduino IDE](https://www.arduino.cc/en/software)，然后启动 Arduino 应用程序。

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/seeed_logo/arduino.jpg" style={{width:800, height:'auto'}}/></div>

<div class="download_arduino_container" style={{textAlign: 'center'}}>
    <a class="download_arduino_item" href="https://www.arduino.cc/en/software">
      <strong><span><font color={'FFFFFF'} size={"4"}>下载 Arduino IDE</font></span></strong>
    </a>
</div><br />

**步骤 2.** 在 Arduino IDE 中添加 ESP32 开发板支持。

在 Arduino IDE 中，依次点击 **File > Preferences**，并在 “Additional Boards Manager URLs” 字段中添加以下 URL：

```url
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
```

**步骤 3.** 安装 ESP32 开发板包。

依次点击 **Tools > Board > Boards Manager**，搜索 “esp32”，并安装 Espressif Systems 提供的 ESP32 包。

**步骤 4.** 选择正确的开发板。

依次点击 **Tools > Board > ESP32 Arduino**，然后选择 **XIAO_ESP32S3**。

**步骤 5.** 使用 USB-C 线将 reTerminal E 系列电子纸显示屏连接到电脑。

**步骤 6.** 在 **Tools > Port** 中选择正确的端口。

### Lopaka 注册与使用

Lopaka 是一款专为嵌入式图形开发设计的图形编辑器。它可以让用户自定义创建自己的 UI 界面，内置多种字体资源，搭配 Arduino 或 ESP32 的 OLED、TFT 或 LCD 显示屏使用非常方便。Lopaka 能够自动生成可直接应用于草图的 C 代码，大幅提升开发效率。

**步骤 1.** [注册](https://lopaka.app/)

- **[前往 Lopaka](https://lopaka.app/)**

  您可以使用 Google 或 GitHub 账号进行注册。

**步骤 2.** 新建项目

点击 “NEW PROJECT” 创建一个新项目。随后会弹出一个窗口，您将看到如下界面。填写项目信息。
<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/reterminal_e10xx/img/create_project_3.png" style={{width:800, height:'auto'}}/></div>

- **Titile**：项目名称，我选择 hello
- **Platform**：您选择用于开发的平台，reTerminal E 系列使用 AdfruitGFX Color。
- **Screen**：屏幕尺寸的选择。点击 “Custom” 可自定义尺寸。reTerminal E 系列的屏幕尺寸为 800×480。
- **Background**：屏幕背景颜色，默认是黑色。为了获得更好的显示效果，我将其改为黄色。
然后点击 “SUBMIT” 创建项目。

**步骤 3.** 常用设置介绍

- **Layers**：图层名称，支持自定义命名。
- **Screens**：可以创建多个屏幕，帮助你存储不同的创意。
- **CODE**：生成的代码为 C 语言。
- **IMAGES**：Lopaka 的官方图像类型。
- **Code settings**：设置生成代码的选项。建议您将所有选项都勾选上。

**其他**

- **Toolbar**：这一排工具栏的功能依次为：选择、填充、字符串、矩形、圆形、直线和图像。

- **Shortcuts**：这里是一些快捷键提示。

### 为 reTerminal E1002 编程

全彩电子纸显示屏支持红、黑、黄、绿和白色，可以实现更加丰富的视觉界面。

**步骤 1.** 在 Seeed_GFX 库中打开彩色示例草图：**File > Examples > Seeed_GFX > ePaper > Colorful > HelloWorld**

**步骤 2.** 在与草图相同的文件夹中创建一个名为 `driver.h` 的新文件，创建方式与之前相同。

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/reterminal_e10xx/img/select2.jpg" style={{width:800, height:'auto'}}/></div>

**步骤 3.** 打开 [Seeed GFX Configuration Tool](https://seeed-studio.github.io/Seeed_GFX/)，并在设备列表中选择 **reTerminal E1002**。

**步骤 4.** 复制生成的配置代码并粘贴到 `driver.h` 文件中。代码应类似如下所示：

```cpp
#define BOARD_SCREEN_COMBO 521 // reTerminal E1002 (UC8179C)
```

:::tip

如果你正在使用 reTerminal E1001，那么你应该复制以下代码

```cpp
#define BOARD_SCREEN_COMBO 520 // reTerminal E1001 (UC8179)
```

:::

**步骤 5.** 修改流程

- 将 Lopaka 页面中的 CODE 代码复制到 Arduino 环境中。
- 将小写的 "epaper" 替换为 "tft"，使用 Ctrl + F 打开全局搜索，输入 "epaper"，然后点击 `Aa` 切换为不区分大小写搜索，接着输入 "tft"，并点击“全局替换”

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/reterminal_e10xx/img/hello_world_2.png" style={{width:800, height:'auto'}}/></div><br/>

reTerminal E1002 目前支持六种颜色。因此，你需要根据实际情况修改颜色。
<details>

<summary>颜色类别</summary>

```cpp
Here is the 6 colors you can display:
1.TFT_WHITE
2.TFT_BLACK
3.TFT_YELLOW
4.TFT_GREEN
5.TFT_BLUE
6.TFT_RED
```

</details>

- 将 `tft.fillScreen(TFT_WHITE)` 中的参数替换为 TFF_YELLOW
- 将 `tft.setTextColor(0x4D6A)` 中的 0x4D6A 替换为 TFT_GREEN。
- 修改 `setup` 函数，将 `tft.fillScreen(TFT_WHITE)` 和 `tft.update` 之间的内容替换为 `draw()`。

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/reterminal_e10xx/img/hello_world_3.png" style={{width:800, height:'auto'}}/></div>

<details>

<summary>代码</summary>

```cpp
/*This is a 6-color electronic ink screen, which can only display 6 colors. 
Any other colors will be mapped to similar ones.

Here is the 6 colors you can display:
1.TFT_WHITE
2.TFT_BLACK
3.TFT_YELLOW
4.TFT_GREEN
5.TFT_BLUE
6.TFT_RED
*/

#include "TFT_eSPI.h"

#ifdef EPAPER_ENABLE // Only compile this code if the EPAPER_ENABLE is defined in User_Setup.h
EPaper tft;
#endif


void draw(void) {

    // Layer 1
    tft.setTextColor(TFT_GREEN);
    tft.setTextSize(6);
    tft.setTextWrap(false);
    tft.setCursor(182, 203);
    tft.print("Hello World!");

}


void setup()
{
#ifdef EPAPER_ENABLE
    tft.begin();
    tft.fillScreen(TFT_YELLOW);

    draw();

    tft.update(); // update the display

#endif
}

void loop()
{
    // put your main code here, to run repeatedly:
}
```

</details>
