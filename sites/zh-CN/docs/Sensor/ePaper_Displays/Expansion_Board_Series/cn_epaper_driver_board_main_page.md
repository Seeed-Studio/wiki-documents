# ePaper 驱动板总览

## 介绍

ePaper 驱动板系列专为多用途、低功耗的 ePaper 应用而设计。这些板卡支持多种 ePaper 显示屏——从通用的 24-pin 和 50-pin 屏幕，到诸如 10.3 英寸（高速刷新）和 13.3 英寸（Spectra™ 6）等专用大尺寸显示屏。每块板卡都具备共同的核心功能，包括带电源开关的 JST 2.0mm 电池连接器、集成充电 IC、复位按键以及三个用户可配置按键。板载多种微控制器（如 XIAO ESP32-S3 Plus、XIAO nRF52840 Plus），部分型号还具备 NFC 功能，非常适合用于数字标牌、电子货架标签、便携式仪表盘以及其他节能显示项目。

**EE02** 是一款高性能的电子墨水屏驱动板，专为 **13.3 英寸**电子纸显示屏设计。其搭载 ESP32-S3 芯片，支持 Wi-Fi 和 Bluetooth 连接，是无线显示应用的理想解决方案。

### 特性

- **强大的控制器**：基于 ESP32-S3 构建，提供强劲的处理能力和无线功能。

- **多样化接口**：包含用于供电/编程的 Type-C 接口以及标准电子墨水屏连接器。
