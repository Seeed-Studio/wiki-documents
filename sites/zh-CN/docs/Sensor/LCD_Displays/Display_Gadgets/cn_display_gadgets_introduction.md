## 介绍

XIAO Display Gadgets 系列是一组紧凑型扩展板，将 Seeed Studio XIAO 主控制器与小尺寸彩色 LCD 相结合。该系列在三种屏幕尺寸——0.96"、1.14" 和 1.47"——以及两种 XIAO 控制器——XIAO ESP32-S3 Plus 和 XIAO nRF52840 Plus——之间提供六款型号，覆盖从口袋友好的 80×160 显示屏到带 MicroSD 存储的 172×320 电容触摸显示屏。

## 如何选择

分两步选择型号：先选择**控制器**，再选择**屏幕尺寸**。

### 步骤 1：选择控制器

每种屏幕尺寸都可以搭配任一控制器使用，并且显示硬件——屏幕、触摸、MicroSD、按键和板载传感器——在这两种版本之间完全相同。唯一的区别是板载的 XIAO。

<div class="table-center">
  <table align="center">
    <tr><th></th><th>XIAO ESP32-S3 Plus</th><th>XIAO nRF52840 Plus</th></tr>
    <tr><td>无线</td><td>2.4 GHz Wi-Fi + BLE 5.0</td><td>BLE 5.4</td></tr>
    <tr><td>内存</td><td>8 MB PSRAM + 16 MB Flash</td><td>256 KB RAM + 1 MB internal Flash + 2 MB onboard Flash</td></tr>
    <tr><td>最适合</td><td>需要 Wi-Fi 连接的 IoT 设备和数据仪表盘</td><td>电池供电、以 BLE 为主的可穿戴设备和传感器节点</td></tr>
  </table>
</div>

- **选择 ESP32-S3 Plus**，当你需要 Wi-Fi 连接或更多内存时——例如将传感器数据推送到云端、远程仪表盘，或无线 IoT 原型。
- **选择 nRF52840 Plus**，用于低功耗 BLE 设计且电池寿命很重要的场景——例如智能胸牌、BLE 状态显示屏，或长时间运行的可穿戴传感器。

### 步骤 2：选择屏幕尺寸

在确定控制器之后，根据你需要的特性选择屏幕尺寸：

- **1.47"**——唯一带电容式触摸屏和 MicroSD 存储的尺寸。适用于以触摸为主的人机界面、便携式相框、SD 音频录制，或本地媒体与数据记录。
- **1.14"**——中等尺寸屏幕，带有三个用户按键和一个 Grove I2C 接口。适用于传感器显示、Grove 项目，或在紧凑性与可扩展性之间需要平衡的物理控制器。
- **0.96"**——最小的外形尺寸。适用于可穿戴设备和空间受限的设计，例如智能胸牌或钥匙扣小工具。

## 共享特性

所有六款型号都共享相同的板载硬件：

- 彩色 IPS TFT LCD（SPI）——根据屏幕尺寸不同为 80×160、135×240 或 172×320
- PDM 数字麦克风
- 6 轴 IMU（LSM6DS3，3 轴加速度计 + 3 轴陀螺仪）
- 用户按键——2 或 3 个，取决于型号
- 适用于 3.7 V 锂聚合物电池的 2 针 JST 接口
- 电池电压检测（nRF52840 型号还可额外检测充电状态）

所有型号都使用 Arduino IDE 搭配 Seeed 的 **Seeed_GFX2** 图形库进行编程。
