**SenseCAP M4 Square** 是一款用于运行多种第三代互联网应用并帮助你构建去中心化网络的设备。它具备出色的硬件特性，可支持多种应用的扩展，同时通过 SenseCAP Hotspot App 提供简单友好的方式来部署 **CUMULUS FluxNode** 和其他 **第三代互联网应用**。

SenseCAP M4 Square 采用四核 Intel® Celeron® J4125 与 RP2040 协处理器运行，配备双 2.5GbE 接口和多种无线连接方式，支持 4K 输出，具备充足的存储能力和设备可扩展性。

**产品特性**
============

- **即插即用**：提供零命令行体验，使用户可以通过 4 个步骤完成 CUMULUS FluxNode 的部署。

- **支持多种应用**：从 dApp 中心部署 SenseCAP 提供的多种第三代互联网应用。云服务：提供一站式云服务，帮助用户购买、部署、管理和监控他们的设备。

- **高安全性**：内置 TPM2.0 加密处理器和 ECC608 加密芯片，高安全认证和可靠连接。

- **卓越性能**：由 Intel® Celeron® J4125 提供动力（频率：2.0 - 2.7GHz），具备 4 核心 4 线程。

- **低功耗**：10W 低功耗，每月 7.2 kWh，用电成本为每月 \$1.008（按全球平均电价 \$0.144/每 kWh 计算）。
