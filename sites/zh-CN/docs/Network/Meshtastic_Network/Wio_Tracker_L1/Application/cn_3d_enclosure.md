# 3D 外壳

本页面收录了基于 Wio Tracker L1 系列的社区 3D 外壳和设备设计项目。

## L1

### 磁吸无线充电器

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage1.png" alt="Magnetic Wireless Charger" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/saheenpalayi/pocketmesh-bank-an-everyday-power-bank-meshtastic-node-20202b" target="_blank" rel="noopener noreferrer">PocketMesh Bank - an everyday power bank + Meshtastic node</a></p>

它将 Wio Tracker L1 集成到一款紧凑的磁吸无线充电宝中，实现手机充电、节点供电，以及更便携的一体化天线设计。

**创作者：** [Saheen Palayi](https://www.hackster.io/saheenpalayi)

**视频：** [PocketMesh Bank](https://www.youtube.com/watch?v=gsW4RvVaC_4)

**下载地址：** [a360](https://a360.co/4nJFKRY)

### WioFold 通信器

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage2.png" alt="WioFold Communicator" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/czipod/the-wio-tracker-l1-meshtastic-communicator-9465eb" target="_blank" rel="noopener noreferrer">The Wio Tracker L1 Meshtastic Communicator</a></p>

一款基于 Wio Tracker L1 的可折叠 Meshtastic 通信器，配备实体键盘和可更换的 18650 电池。

**创作者：** [Dávid Czipó](https://www.hackster.io/czipod)

### Ride Trace

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage3.png" alt="Ride Trace" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/Milliam/lorider-the-meshatastic-0cffeb" target="_blank" rel="noopener noreferrer">LoRider- the Meshatastic</a></p>

一款基于 Wio Tracker L1 的紧凑型车载 Meshtastic 追踪器，用于 GPS 追踪、防盗告警、前灯功能，并在日常骑行中保持低调隐蔽。

**创作者：** [Miriam Choi](https://www.hackster.io/Milliam)

### Wio Tracker L1 网关

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage4.png" alt="Wio Tracker L1 Gateway" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/hendra/wio-tracker-l1-gateway-9421c2" target="_blank" rel="noopener noreferrer">Wio Tracker L1 Gateway</a></p>

一款基于 Wio Tracker L1 的混合 Meshtastic 网关，用于采集环境遥测数据，在网状网络中中继，并通过 MQTT 将其桥接到云端，实现实时远程监控。

**创作者：** [Hendra Kusumah](https://www.hackster.io/hendra)

### 自持式 Meshtastic 节点家族

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage5.png" alt="A Self-Sustaining Meshtastic Node Family" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/jrbanks777/seeedpod-ultimate-77168f" target="_blank" rel="noopener noreferrer">SEEEDpod Ultimate</a></p>

一个围绕 Wio Tracker L1 构建的模块化 Meshtastic 节点生态系统，面向离网部署、城市便携和日常备份使用，提供自持式供电选项。

**创作者：** [Jack](https://www.hackster.io/jrbanks777)

### 双 Wio Tracker L1 便携式太阳能站

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage6.png" alt="Dual Wio Tracker L1 Portable Solar Station" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/fernando-doutel/dual-wio-tracker-l1-portable-solar-station-e3fcc1" target="_blank" rel="noopener noreferrer">Dual Solar Charging Station for Wio Tracker L1</a></p>

一款坚固的便携式太阳能充电站，可在任意地点为两块 Wio Tracker L1 节点充电，并支持集成 Grove 传感器，用于离网监测和应急通信。

**创作者：** [Fernando Doutel](https://www.hackster.io/fernando-doutel)

## E-ink

### Meshy：适用于 Wio Tracker L1 E-ink 的坚固 3D 打印外壳

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage7.png" alt="Meshy 3D-printed case for Wio Tracker L1 E-ink" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/akashedamana/meshy-wio-tracker-l1-e-ink-3d-printed-case-affad1" target="_blank" rel="noopener noreferrer">meshy-wio-tracker-l1-e-ink-3d-printed-case-affad1</a></p>

这是一个为 Wio Tracker L1 E-ink 设计的 3D 打印保护外壳，用于提升其在户外和日常随身携带场景下的耐用性、便携性和安装便利性。其参数化设计支持不同电池尺寸和安装结构，并包含可夹在腰带、背包或 MOLLE 装备上的卡扣式支架。

**创作者：** [Akash](https://www.hackster.io/akashedamana)

**下载地址：** [a360](https://a360.co/3KNHxqQ)

### MeshPack Pro L1

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage8.png" alt="MeshPack Pro L1" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/alleycat/acos-meshpack-pro-l1-for-meshtastic-1ec031" target="_blank" rel="noopener noreferrer">[ACOS] MeshPack Pro L1 for Meshtastic</a></p>

一款为 Wio Tracker L1 设计的坚固、模块化 3D 打印外壳，可将开发板变成更耐用、可定制的手持 Meshtastic 设备。

**创作者：** [Alley Cat](https://www.hackster.io/alleycat)

### 太阳能离网 Mesh 通信器

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage9.png" alt="Solar Off-Grid Mesh Communicator" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/bastiaan-slee/meshtastic-20-25-cd4c1f" target="_blank" rel="noopener noreferrer">Meshtastic 20.25</a></p>

一款围绕 Wio Tracker L1 构建的自包含离网 Meshtastic 通信器，集成迷你键盘、E-ink 显示屏、震动提醒以及背部太阳能充电，适用于便携的日常和户外使用。

**创作者：** [Bastiaan Slee](https://www.hackster.io/bastiaan-slee)

### SkySense 飞行实验室

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage10.png" alt="SkySense Flying Lab" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>来源：</strong> <a href="https://www.hackster.io/pasquale887/skysense-the-perfect-flying-laboratory-bb39db" target="_blank" rel="noopener noreferrer">SkySense - The Perfect Flying Laboratory</a></p>
