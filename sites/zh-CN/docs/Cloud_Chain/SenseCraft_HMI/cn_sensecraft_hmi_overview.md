# SenseCraft HMI 概览

## 介绍

[SenseCraft HMI](https://sensecraft.seeed.cc/hmi/?utm_source=seeedstudio_wiki&utm_medium=referral&utm_campaign=wiki_to_sensecraft&utm_content=sensecraft_hmi_home) 是 Seeed Studio 功能强大的云端界面设计平台，可让你在无需编程的情况下，为基于屏幕的设备创建专业的可视化界面。借助直观的拖放式编辑器、预构建模板和 AI 驱动的设计能力，SenseCraft HMI 能轻松将你的硬件转变为精美的信息展示屏、仪表盘、数字标牌和控制面板。

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/reterminal_e10xx/img/23.png" style={{width:1000, height:'auto'}}/></div>

### 主要特性

- **零代码界面构建器**：使用简单的拖放工具创建专业显示界面

- **AI 驱动设计**：使用自然语言描述生成完整布局和图像

- **实时数据集成**：连接天气、股票、GitHub、YouTube 等多种数据源

- **多种显示功能**：提供 Gallery、Canvas、RSS 和 Web 功能以适配不同使用场景

- **即用型模板**：为常见应用预先设计好的布局

- **一键部署**：将设计直接推送到已连接设备

- **设备传感器集成**：自动显示设备的温度、湿度和电池数据

## 入门指南

开始使用 SenseCraft HMI：

1. **访问平台**：打开 [SenseCraft HMI](https://sensecraft.seeed.cc/hmi/?utm_source=seeedstudio_wiki&utm_medium=referral&utm_campaign=wiki_to_sensecraft&utm_content=sensecraft_hmi_home)

2. **创建账号**：如果你还没有账号，请注册一个免费的 SenseCraft 账号

3. **连接你的设备**：按照屏幕上的指引配对你的兼容设备

4. **选择功能**：根据需求从 Gallery、Canvas、RSS 或 Web 功能中进行选择

5. **设计你的界面**：使用直观的工具创建你的显示界面

6. **部署到设备**：一键将你的设计发送到已连接设备

## 功能文档

SenseCraft HMI 提供多种专用功能，每种功能都针对不同的显示需求而设计：

### [AI 生成功能](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-ai-generator/)

只需用自然语言描述你想要的效果，即可创建精美的布局和图像，无需任何设计技能。

### [Gallery 功能](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-gallery/)

将你的设备变成数字相框，支持可自定义的图像展示、切换效果和视觉特效。

### [Canvas 功能](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-canvas/)

设计自定义界面和仪表盘，将静态元素与来自多种数据源的动态数据相结合。

### [RSS 功能](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-rss/)

通过 RSS 源显示来自新闻媒体、博客和其他信息源的自动更新内容。

### [Web 功能](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-web/)

在设备上直接展示网页内容，非常适合用于仪表盘、文档或监控系统。
