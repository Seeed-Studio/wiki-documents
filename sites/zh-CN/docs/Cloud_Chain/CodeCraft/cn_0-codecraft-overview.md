# CodeCraft 用户指南

欢迎使用 CodeCraft。本指南将帮助你快速了解平台、完成账号准备，并开始使用 CodeCraft 进行零代码项目创作、社区项目复用与作品发布。

## 文档目录

### [1. 快速入门与账户支持](/codecraft/quick-start-and-support)

适合第一次使用 CodeCraft 的用户阅读。

本部分包含：

- 认识 CodeCraft
- 准备与登录
- 购买与激活 CodeCraft 会员
- 账单与用量管理
- 帮助与支持

### [2. 创作与平台功能](/codecraft/creation-and-platform)

适合想要正式开始制作项目的用户阅读。

本部分包含：

- 动手制作零代码项目
- 认识对话式工作台
- 选择硬件
- 描述项目需求
- 生成、烧录与调试
- 项目案例：番茄钟、The Terminal 番茄钟、ESP32S3 闪烁灯，以及 Beginner Kit 按键灯

### [3. 作品发布与社区分享](/codecraft/community-and-publishing)

适合已经完成项目，并希望浏览、复用或发布作品的用户阅读。

本部分包含：

- 应用广场能做什么
- 浏览和复用社区项目
- 发布前准备
- 发布新的应用
- 编辑应用内容
- 应用信息、文档、物料清单与预览发布
- 将作品分享到社区

### [4. 教育解决方案](/codecraft/codecraft-for-education)

适合想要将 CodeCraft 应用于教学、课程设计或开展科技教育培训的用户阅读。

本部分包含：

- 完整教育解决方案
- 师生管理与教学工作流支持
