### reComputer Robotics J50 Mini

#### What You Need

- reComputer Robotics J50 Mini with the GMSL extension board
- A supported ZED X-series GMSL2 camera
- A compatible GMSL2 Fakra/Mini-Fakra cable or harness
- JetPack 6.2.x or JetPack 7.2
- Internet access, a display, keyboard, and mouse for ZED Studio

:::info
This guide covers the Seeed platform driver and ZED SDK setup. Camera model support can depend on the installed ZED SDK version. Use the latest ZED SDK compatible with your JetPack/L4T release.
:::

#### 1. Connect the Camera

1. Shut down the reComputer completely.
2. Disconnect the DC power input.
3. Connect the ZED X camera to a GMSL2 port using the compatible cable or harness. Make sure the connector is fully seated and locked.
4. Reconnect power and boot the device.

:::warning
Do not hot-plug the GMSL camera. Always remove power before connecting or disconnecting the camera or GMSL harness.
:::

#### 2. Enable ZED X GMSL Support

Choose **one** of the following paths. Flashing the latest BSP is recommended for a clean deployment; installing the DEB is faster when you want to keep an existing system.

<Tabs groupId="j50-mini-zed-driver-method">
  <TabItem value="latest-bsp" label="Option 1 · Flash latest BSP" default>

Check the BSP build information already installed on the device:

```bash
cat /etc/nv_tegra_release
```

Look for the `DATE` field. If the BSP was built on **September 24, 2026 or later**, ZED X GMSL support is already included and you can continue to the ZED SDK installation.

If the build is older, flash the latest **JetPack 7.2 / L4T 39.2.0** image dated **September 24, 2026** by following the steps below. The two module variants use different images, so select the tab that matches the Jetson module installed in your J50 Mini.

:::warning
Flashing rewrites the target storage. Back up application data, configuration files, and credentials before you begin.
:::

1. Shut down the J50 Mini and disconnect its power.
2. Press and hold the **REC** button.

4. Connect the J50 Mini to the Ubuntu host with a USB Type-C data cable through the flashing port shown below.

#### 3. Install the ZED SDK

Go to the [Stereolabs ZED SDK download page](https://www.stereolabs.com/developers/release/) and select the NVIDIA Jetson installer that matches the release reported by `cat /etc/nv_tegra_release`:

| Installed system | Select on the ZED SDK page |
| --- | --- |
| JetPack 6.2.x / L4T 36.4.x | ZED SDK for JetPack 6.1 and 6.2 (L4T 36.4) |
| JetPack 7.2 / L4T 39.2 | ZED SDK for JetPack 7.2 (L4T 39.2) |

Install `zstd`, make the downloaded installer executable, and run it. Replace the placeholder below with the actual downloaded filename.

```bash
sudo apt update
sudo apt install -y zstd
cd ~/Downloads
chmod +x ZED_SDK_Tegra_L4T<release>_v<version>.zstd.run
./ZED_SDK_Tegra_L4T<release>_v<version>.zstd.run
```

Follow the installer prompts and keep the ZED tools selected. Reboot after the installation finishes:

```bash
sudo reboot
```

:::tip
The L4T version in the ZED SDK installer name must match the L4T release on the reComputer. A mismatched SDK or camera DEB can prevent the camera from being detected.
:::

#### 4. Validate with ZED Studio

Launch ZED Studio from a terminal:

```bash
ZED_Studio
```

You can also start it directly from the SDK installation directory:

```bash
/usr/local/zed/tools/ZED_Studio
```

ZED Studio should detect the connected camera. Open the live view and enable **Depth** to confirm that both the image stream and depth pipeline are working.

## Troubleshooting

- **Camera not detected:** Confirm that the DEB, BSP, and ZED SDK all match the installed L4T release. Then power off and reseat the camera cable.
- **APT reports a package mismatch:** Do not force the installation. Download the package for the L4T version shown by `cat /etc/nv_tegra_release`.
- **ZED Studio does not open:** Confirm that the graphical desktop is running and start `/usr/local/zed/tools/ZED_Studio` from a terminal to see the error output.
- **Image appears but depth is unavailable:** Confirm that you installed the complete ZED SDK with tools and that the selected camera model is supported by that SDK release.
- **Intermittent video:** Power down and verify the Fakra/Mini-Fakra cable, locking position, and supported cable length before testing again.
