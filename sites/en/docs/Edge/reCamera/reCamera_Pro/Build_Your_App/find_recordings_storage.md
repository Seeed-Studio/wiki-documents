# Find Recordings and Storage

After configuring event recording triggers (see [Configure Event Recording](/recamera_pro_record_settings/)), use the **Recording Settings** page in the Web UI to find your files and manage device storage.

## Storage Management

In **Storage Management** you can view the current disk usage and the location where files are saved.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_65N6rhHetJ.png" />

In the storage configuration area you can set the available storage size, configure quotas, and choose whether to overwrite old files so the latest recordings are always saved.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_WZBl9MEr7Z.png" />
