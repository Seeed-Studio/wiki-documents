In this interface, you can view the various hardware and software version information of recamera pro, as well as adjust the corresponding system settings.
## Basic Information
In this interface, you can view the basic hardware and software information of the device, as well as the usage of system resources.
<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_aWZqM1cZvA.png" />

## Time Settings
This interface allows you to set the system time on recamera pro.
<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_F3jLNlVu0W.png" />

## Network Settings
recamera pro is equipped with a WiFi module, and you can set the network status in this interface.
<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_GJspvgAFdl.png" />
After connecting to the network, you can click the exclamation mark to the right of the connected network to get more detailed device network information.
<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_vq4u1biblp.png" />

## Connection Settings
In this interface, you can configure how to connect to recamera pro, and you can adjust whether to enable SSH remote connection, HTTP settings, and serial port baud rate.
<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_ZH9JMcsCen.png" />

## System Settings
In this interface, you can check the device's firmware version, choose whether to update to new firmware, and restart the system, change the password, or restore factory settings.
### Export and Import Configuration
When you select "Export Configuration," the browser will automatically download a file containing various current settings, making it convenient to quickly import them into other recamera pro devices later.
<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_eBayhpwddh.png" />
To import configuration, you need to select a tar file for import, which has the same file extension as the exported configuration file. After importing, it will load automatically. Wait for the restart, and then the imported configuration information will be updated.
<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_4h4p6raYPF.png" />
