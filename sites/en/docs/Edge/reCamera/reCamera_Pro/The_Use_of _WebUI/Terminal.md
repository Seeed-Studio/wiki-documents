## System Log

The system log area is used to view the reCamera Pro's operation logs in real time, making it easier for users to understand the current status of the device, the service operation status, and troubleshoot abnormal issues.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/20260708190224_6_2.png" />


Users can perform the following operations in this area:

- View system log output in real time
- Filter logs by log level or keywords
- Clear the current log display content
- Download the log files for problem analysis or technical support.

This function is applicable to equipment debugging, service status confirmation, anomaly investigation, and problem reproduction recording.

## Terminal console

The terminal console allows users to log in directly to the reCamera Pro system terminal via the Web UI, without needing to use an additional SSH tool.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_2dvKqObUbo.png" />

Users can log in using the following default accounts:

```bash
Username: root
Password: recamera
```
