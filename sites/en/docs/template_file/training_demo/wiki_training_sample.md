# Wiki Training Sample

:::note
This is a brand-new page created to practice the **wiki editing workflow**:
edit &rarr; preview &rarr; build &rarr; commit &rarr; push.
:::

This page shows how to write a simple Wiki document following the official template.

## Getting Started

This demo page covers the mandatory rules:

1. The `slug` must be all **lowercase**.
2. The folder name uses an **underscore** (`_`) instead of a space.
3. The date format is **month/day/year** (e.g. `09/22/2026`).
