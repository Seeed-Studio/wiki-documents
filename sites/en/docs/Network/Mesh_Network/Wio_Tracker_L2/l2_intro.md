The Wio Tracker L2 Series is a highly extensible [Meshtastic®](https://meshtastic.org/) node featuring LoRa (862–930 MHz), the ESP32S3 for efficient processing, and an L76K GPS module for accurate location tracking. Designed for flexibility, it supports QSPI touch screen, E-Ink displays, TF Card, as well as solar panels and battery power, making it ideal for a wide range of IoT and off-grid applications.

## L2 Series Model

The Wio Tracker L2 Series includes Wio Tracker L2 for custom builds and Wio Tracker L2 Pro with an enclosure and built-in battery.

## Features

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/Wio_Tracker_L2/feature/01 (8).jpg" alt="pir" width={900} height="auto"/></p>

- **One Hardware, Endless Possibilities** Build your own interface, dashboard, game, map tool, or interactive experience—L2 Pro is ready for whatever you want to make.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/Wio_Tracker_L2/feature/100029766_2.webp" alt="pir" width={900} height="auto"/></p>

- **3.2'' High-Quality Touchscreen**: Featuring a 320×240 high-clarity display with switchable MUI and Base UI, it delivers smooth on-device interaction for messaging, mapping, and control—without a mobile phone.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/Wio_Tracker_L2/feature/01 (1).jpg" alt="pir" width={900} height="auto" /></p>

- **ESP32S3 Powered, Ready to Build On**: Powered by the dual-core ESP32-S3 with Wi-Fi and Bluetooth LE, L2 Pro provides a flexible platform for UI customization, feature development, and open-source applications.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/Wio_Tracker_L2/feature/01 (2).jpg" alt="pir" width={900} height="auto"/></p>

- **Offline Maps with GNSS Positioning**: Pre-download offline maps to a MicroSD card and view your real-time GNSS location directly on the device, even without cellular coverage or Internet access.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/Wio_Tracker_L2/feature/01 (4).jpg" alt="pir" width={900} height="auto"/></p>

- **3000mAh Long-Lasting Battery**: Supports extended daily use with reduced charging frequency; operates within -10°C to 55°C conditions.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/Wio_Tracker_L2/feature/01 (5).jpg" alt="pir" width={900} height="auto"/></p>

- **Easy to Carry, Flexible Placement**: A foldable antenna improves portability, and the 1/4" mounting interface supports flexible placement with compatible accessories.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/Wio_Tracker_L2/feature/01 (6).jpg" alt="pir" width={900} height="auto"/></p>

- **Prototype Faster with CodeCraft**

Describe your idea in a few words, and Seeed Studio’s CodeCraft AI coding assistant will generate a first draft of the code in minutes. Review it, flash it to your Wio Tracker L2, and test it on the board.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/Wio_Tracker_L2/feature/08.jpg" alt="pir" width={900} height="auto"/></p>
