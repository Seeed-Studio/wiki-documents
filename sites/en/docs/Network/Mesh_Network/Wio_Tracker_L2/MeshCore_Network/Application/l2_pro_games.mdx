The Wio Tracker L2 Pro has the core parts of a handheld game system. Its ESP32-S3 can render a scene in memory, send pixels to the touchscreen, read level data from microSD, and play sound through the built-in speaker. Community projects show how those parts work together, from a voxel engine to a platform with USB gamepad support.

## How the hardware runs a game {#hardware}

| Hardware | How a game can use it |
| --- | --- |
| Dual-core ESP32-S3, 16 MB flash, 8 MB PSRAM | Flash holds the firmware. External RAM gives the engine room for frame buffers and cached assets. WioCraft renders at 160 × 120 and doubles each dimension for the 320 × 240 display. That reduces the number of scene pixels the CPU has to draw per frame to one quarter. |
| 3.2-inch QSPI display and GT911 touch controller | The display receives finished pixels over QSPI. Touch coordinates can drive a virtual stick in a 3D game or select a unit directly on a strategy map. |
| microSD slot | A port can read levels, textures, and sound from the card as needed. Quake reads its converted PAK archive from microSD and caches recently used data in PSRAM. |
| ES8311 audio codec and built-in speaker | The engine mixes sound effects into a stream of samples. The ESP32-S3 sends the samples over I²S to the codec for playback through the speaker. |

For a port, start with the board initialization in Quake. It shows how the L2 brings up the display, touch controller, and audio hardware. [L2 hardware specifications and pinout](https://wiki.seeedstudio.com/meshtastic_wio_tracker_l2_intro/) · [Quake L2 board code](https://github.com/recrof/Quake-ESP32S3/blob/HEAD/QuakeESP32S3/main/esp_board_l2.c) · [WioCraft source](https://github.com/zxw19/WioCraft-L2)

## Gamepads and multiplayer links {#connectivity}

**USB gamepads.** With MeshPunk v0.5.0, the L2 acts as the USB host and supplies power to a compatible controller through USB-C. The gamepad driver reads the controller, and MeshPunk maps its buttons to game actions. A developer adding a game can use that mapping for movement and actions alongside the on-screen controls. [MeshPunk v0.5.0 L2 release notes](https://github.com/PhilMo6/meshpunk/releases/tag/v0.5.0)

**Wireless input.** A game can also use the ESP32-S3’s Bluetooth LE radio for input and leave the USB-C port free. The Quake port supports BLE keyboards, mice, and gamepads. Its maintainer lists 8BitDo controllers in BLE/Android mode as one example. Check the controller’s Bluetooth mode when choosing hardware for a port. [Quake input support](https://github.com/recrof/Quake-ESP32S3#hardware)

**Two-player USB link.** A wired game link gives the USB port a different job. One handheld acts as host and the other as a USB device. The game firmware on both ends must agree on the data to exchange, such as each player’s inputs for the next turn. MeshPunk documents this arrangement for its Game Boy emulator on two T-Decks. Developers can use it as a reference for an L2-to-L2 implementation. Operation with two L2 Pro units is unverified. [MeshPunk Game Boy link example](https://github.com/PhilMo6/meshpunk/blob/v0.5.0/README.md)

**Local Wi-Fi multiplayer.** Wi-Fi gives developers another way to exchange game data between handhelds. MeshPunk’s Doom app describes a shared Wi-Fi network for two to four players. Its documentation describes decks and leaves L2 Pro multiplayer compatibility unconfirmed. [Doom multiplayer notes](https://github.com/PhilMo6/meshpunk-apps/blob/main/apps/Doom/readme.lua)

## Firmware and recovery {#flash}

The release links above lead to the community firmware. Choose the build for **Wio Tracker L2** or **L2 Pro** and follow that project's instructions for its flash address and microSD layout. MeshDesk provides a PlatformIO source build. For MeshPunk v0.5.0, the L2 release includes a full image for installation from a computer and a separate `-launcher.bin` image for bmorcelli Launcher. [MeshPunk release files](https://github.com/PhilMo6/meshpunk/releases/tag/v0.5.0)

Installing game firmware replaces the current firmware. A full erase also removes settings and keys, so export the configuration and identity information you want to keep first. To return to mesh use, follow the guide for the firmware you previously used. [Restore Meshtastic](https://wiki.seeedstudio.com/get_started_with_meshtastic_wio_tracker_l2/#flash-firmware) · [Restore MeshCore Ripple](https://wiki.seeedstudio.com/get_started_with_ripple_l2_pro/#flash-firmware)
