The SenseCAP Portal provides data queries that filter queries or export the sensor data you need based on a variety of criteria.

## Table

- ① The device supports viewing two types of data: “Uplink Data” and “Threshold Data”. You can click to view each type.
- ② Filter criteria, according to EUI, frequency, group, status, and registration time filter node.
- ③ List of data showing EUI, device name, data type, measurements, collection and upload time, etc.
- ④ Click EUI to enter the device details page and view the basic information of the Sensor Node.

## Add / Manage Sub-accounts
You can register a new sub-account here and link it to your main account. After filling in the required information, you can set the permission type for the sub-account.

1. **Limited User**: Has no permissions. Cannot view the main account’s device data or add, edit, or delete devices.
2. **Observer**: Can view the devices linked to the main account and the uploaded data, but cannot add, edit, or delete devices.
3. **Administrator**: Can view, edit, and delete devices linked to the main account.
4. After filling in the information, click **Confirm** to complete the registration.
