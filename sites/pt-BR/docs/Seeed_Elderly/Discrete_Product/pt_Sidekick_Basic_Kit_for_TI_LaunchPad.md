O Seeedstudio Sidekick Basic Kit for TI LaunchPad™ é um ótimo ponto de partida para aprender eletrônica e construir circuitos básicos usando componentes discretos, uma protoboard e um LaunchPad. Usar o Energia pode simplificar bastante a criação de software, permitindo que mais foco seja colocado na prototipagem rápida e na modificação de circuitos para se adequarem às nossas ideias de projeto. Este é um excelente kit inicial para novos engenheiros eletrônicos e makers!
O Sidekick inclui componentes avulsos, fios e uma protoboard para complementar seu kit de desenvolvimento LaunchPad. O manual inclui 10 circuitos de exemplo diferentes, mas muitos outros são possíveis reunindo componentes adicionais ou usando criatividade. Este é um item indispensável para qualquer desenvolvedor de LaunchPad!

*   Baixe a pasta de códigos de exemplo [aqui](http://www.energia.nu/sidekickcode).
