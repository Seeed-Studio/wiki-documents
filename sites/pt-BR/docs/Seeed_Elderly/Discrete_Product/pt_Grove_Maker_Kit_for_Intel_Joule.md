Algumas semanas atrás publicamos o Grove Shield para Intel Joule. Desta vez, vamos apresentar o kit incrível que pode ajudar você a começar com o Intel Joule de forma fácil e rápida, o kit Grove Maker para Intel Joule.

O Joule é a placa mais incrível que a Intel lançou para projetos de IoT em 2016. Com o sistema Linux embarcado e hardware rico, o Intel Joule pode ser a melhor escolha para desenvolvedores aprimorarem seus projetos e colocarem o protótipo no mercado sem muito esforço.

O kit Grove Maker para Intel Joule é o melhor kit para construir protótipos rapidamente com base no Joule. O kit contém um Grove Bash Shield para Joule, com o qual você pode adicionar facilmente os 13 módulos Grove que selecionamos especificamente para o Joule. Se você tem o Intel Joule em mãos e planeja criar um protótipo rapidamente, não hesite em escolher o kit Grove Maker para Intel Joule.

## Apresentação das Partes

### [Grove Shield para Intel Joule](https://www.seeedstudio.com/Grove-Shield-for-Intel-Joule-p-2782.html)

![](https://files.seeedstudio.com/wiki/Grove_Maker_Kit_for_Intel_Joule/img/grove%20shield%20for%20intel%20joule.jpg)

O Grove Shield para Intel Joule é a chave para fazer a ponte entre o Intel Joule e a família de módulos Grove. Simplesmente conectando-o à sua placa Joule, você passa a ter 8 conectores Grove sólidos e fáceis de usar, que incluem interfaces como I2C, UART, E/S digitais e entradas analógicas imediatamente. Ele também mantém os cabeçalhos de pinos 2x20 caso você queira mais GPIOs para o projeto. Uma chave é integrada na placa para selecionar a tensão de trabalho em 5 V ou 3,3 V.
