IOIO é uma placa especialmente projetada para funcionar com o seu dispositivo Android. E este Grove - Base Shield para IOIO é uma placa de expansão para IOIO funcionar com os abundantes recursos Grove. Existem 6 soquetes Grove prontos na placa que cobrem funções como ADC e I2C. E desta forma, todos os módulos Grove ficam acessíveis para a placa IOIO. Quer fazer alguns projetos com IOIO e precisa de alguns sensores ou display? Este Grove - Base Shield para IOIO pode trazer essa praticidade para você.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/Grove-Base-Shield-for-IOIO-OTG-p-1613.html)

##  Interface

![](https://files.seeedstudio.com/wiki/Grove-Base_Shield_for_IOIO-OTG/img/Base_Shield_for_IOIO_Interface_Function.jpg)

**J1,J2:** podem ser usados para TWI.

**J3,J6,J7,J8:** podem ser usados como entradas e saídas, incluindo PWM, UART.
