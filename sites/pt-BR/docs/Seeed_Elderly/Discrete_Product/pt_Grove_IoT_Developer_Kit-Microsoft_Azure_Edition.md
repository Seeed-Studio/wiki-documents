Grove IoT Developer Kit – Microsoft Azure Edition contém um **módulo Intel® Edison**, uma **placa Intel® Edison para Arduino**, um **Grove Base Shield**, um conjunto de **sensores Grove** e **atuadores** com portas Grove integradas para prototipagem rápida. Basta conectar os módulos e você estará pronto para criar.

## Intel® Edison Para Arduino

![](https://files.seeedstudio.com/wiki/Grove_IoT_Developer_Kit-Microsoft_Azure_Edition/img/Intel_Edison_for_Arduino_Microsoft_Azure_Edition_1.jpg)

O módulo de computação Intel® Edison é projetado para makers experientes, empreendedores e algumas aplicações industriais de IoT; ele oferece facilidade de desenvolvimento para uma variedade de projetos de prototipagem ou empreendimentos comerciais quando o desempenho é importante. Com uma placa de expansão que se conecta a uma ampla gama de shields Arduino, o Intel® Edison para Arduino permite prototipagem rápida e fácil com hardware open source e um ambiente de desenvolvimento de software.

## Recursos

- Uma combinação do poderoso Intel® Edison e o rico Sistema Grove com muitos recursos

- Prototipagem rápida para projetos de IoT

- Suporta desenvolvimento com Arduino* e C/C++, seguido por Node.JS, Python, RTOS e suporte a Programação Visual em um futuro próximo

- Inclui uma estrutura de conectividade dispositivo-a-dispositivo e dispositivo-à-nuvem para possibilitar comunicação entre dispositivos e um serviço de análise de séries temporais, baseado em nuvem e multi-inquilino.

- Possui um conector para cartão SD, conector micro USB ou USB host padrão tipo A (via chave mecânica), Micro USB device, 6 entradas analógicas e 20 pinos de entrada/saída digitais, 1x UART, 1x I2C e 1x cabeçalho ICSP de 6 pinos (SPI) conector de alimentação com entrada DC de 7V-15V.

## Primeiros Passos com a Placa Intel® Edison

Antes de trabalharmos em quaisquer módulos Grove, vamos primeiro começar com a placa Intel® Edison; você pode seguir as instruções detalhadas no **[site oficial do Intel® Edison](https://software.intel.com/en-us/iot/library/edison-getting-started)** para:

### Etapa 1: Monte Sua Placa

Instale o módulo de computação, prenda os suportes e conecte seus cabos.

![](https://files.seeedstudio.com/wiki/Grove_IoT_Developer_Kit-Microsoft_Azure_Edition/img/Intel_edison_assemble.png)

### Etapa 3: Configure um Terminal Serial

Você precisará de uma [**conexão de terminal serial**](https://software.intel.com/en-us/get-started-edison-windows-step3) para sua placa para fazer o flash do firmware

### Etapa 4: Conecte Sua Placa à Internet

Como você pode construir um dispositivo IoT sem o "I"? Vamos [**conectar sua placa à rede WiFi**](https://software.intel.com/en-us/get-started-edison-windows-step4).

### Etapa 5: Teste com o Arduino IDE

Como já instalamos o ambiente de desenvolvimento, incluindo o Arduino IDE, na Etapa 2 (se não, você pode baixar o Arduino IDE mais recente **[aqui](https://www.arduino.cc/en/Main/Software)**.) agora, como seu primeiro exercício, vamos tentar [**piscar um LED na Placa Intel Edison com o Arduino IDE**](https://software.intel.com/en-us/get-started-arduino-blink).

## Executando o Exemplo

1. Abra o site: [Grove_Indoor_Environment_Demo](https://github.com/Seeed-Studio/Grove_Indoor_Environment_Demo) para baixar o projeto completo.

![](https://files.seeedstudio.com/wiki/Grove_IoT_Developer_Kit-Microsoft_Azure_Edition/img/Indoor_Kit_Github_Demo.png)

2. Clique em **Tools &gt; Serial Port** e selecione a porta COM # à qual o Intel Edison está conectado

![](https://files.seeedstudio.com/wiki/Grove_IoT_Developer_Kit-Microsoft_Azure_Edition/img/Import_Indoor_Kit_Demo.png)

3. Clique em Sketch&gt;Import Library…&gt;Add Library e importe a biblioteca baixada na **etapa 1**

4. Clique em **File&gt;Examples&gt; Grove_Indoor_Environment_Demo** e selecione o demo. Clique no ícone **upload**

![](https://files.seeedstudio.com/wiki/Grove_IoT_Developer_Kit-Microsoft_Azure_Edition/img/Upload_Indoor_Kit_Demo.png)

5. Abra o **Serial Monitor**, ele irá imprimir as informações dos sensores:

![](https://files.seeedstudio.com/wiki/Grove_IoT_Developer_Kit-Microsoft_Azure_Edition/img/Indoor_Kit_Serial_Monitor.png)

6. Gire o Encoder para verificar o valor do sensor no LCD.

![](https://files.seeedstudio.com/wiki/Grove_IoT_Developer_Kit-Microsoft_Azure_Edition/img/Indoor_Kit_Rotate_Encoder.png)

7. Em **"Send TextBox"**, você pode inserir o seguinte comando para operar os sensores e atuadores:

<table>
<tr>
<th>Exemplo</th>
<th>Descrição</th>
</tr>
<tr>
<td width="300px">_set temp&gt;40, relay=1_</td>
<td width="500px">se a temperatura for maior que 40℃, o relé abre.</td>
</tr>
<tr>
<td width="300px">_set temp&gt;40, sleep=1_</td>
<td width="500px">se a temperatura for &gt;40℃, nada é feito.</td>
</tr>
<tr>
<td width="300px">_set humi&gt;60, buzzer=1_</td>
<td width="500px">se a umidade for &gt;60%, o buzzer apita.</td>
</tr>
<tr>
<td width="300px">_set light&gt;600, servo=90_</td>
<td width="500px">se a intensidade de luz for &gt;600, o servo gira 90°.</td>
</tr>
<tr>
<td width="300px">_set uv&gt;80, relay=0_</td>
<td width="500px">se a intensidade de UV for &gt;80, o relé fecha.</td>
</tr>
<tr>
<td width="300px">_set pir=1, buzzer=1_</td>
<td width="500px">se pessoas forem detectadas, o buzzer apita.</td>
</tr>
<tr>
<td width="300px">_set ms&gt;40, relay=1_</td>
<td width="500px">se a umidade do solo for &gt;40, o relé abre.</td>
</tr>
<tr>
<td width="300px">_set ssid=name, psw=password_</td>
<td width="500px">define o SSID e a senha do WiFi. Você pode abrir um navegador da web e ir para o endereço IP exibido no Serial Monitor ou no LCD. A porta padrão é 88. A porta padrão é 88. Por exemplo: 192.168.1.101:88</td>
</tr>

Nota:

- O comando deve terminar com 'n', então **"NewLine"** (no Serial Monitor) deve ser selecionado.

- Um atuador só pode ser controlado por um sensor. Se o sensor A quiser controlar um atuador (que foi controlado pelo sensor B), o sensor B deve ser configurado para sleep.

![](https://files.seeedstudio.com/wiki/Grove_IoT_Developer_Kit-Microsoft_Azure_Edition/img/Indoor_Kit_command.png)

8. Conexão WiFi. Abra o Serial Monitor e defina seu ssid e password (como abaixo). Verifique o IP local no LCD ou no Serial Monitor. Em um dispositivo conectado na mesma rede, abra um navegador da web e vá para o endereço IP acima; você poderá ver o valor do sensor.

_**Nota: Ao visitar o servidor web, um número de porta (88) deve ser adicionado, por exemplo: 172.20.10.2:88.**_
