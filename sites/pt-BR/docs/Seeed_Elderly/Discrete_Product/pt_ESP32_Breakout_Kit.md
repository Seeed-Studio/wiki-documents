Este é o kit de breakout especialmente projetado para ESP32; ele contém uma placa de breakout e pinos de cabeçalho. As dimensões são 53mmx38mmx1.2mm. A placa de breakout com conectores fêmea com passo de 2,54mm permite que você conecte facilmente os pinos do ESP32 a ela. Também fornecemos 2 conectores Grove neste kit para enriquecer a expansibilidade do ESP32.


[![enter image description here](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/get_one_now.png)](https://www.seeedstudio.com/ESP32-Breakout-Kit-p-2783.html)

## Primeiros Passos

- Primeiro, você precisa adquirir o [ESP-32S Wifi Bluetooth Combo Module](https://www.seeedstudio.com/ESP-32S-Wifi-Bluetooth-Combo-Module-p-2706.html).
![enter image description here](https://files.seeedstudio.com/wiki/ESP32_Breakout_Kit/img/ESP32.jpg)
- Em segundo lugar, solde o módulo ESP32 no kit de breakout.
- O kit montado fornecerá uma solução sem fio de Wi-Fi e Bluetooth de desempenho ultra alto e consumo de energia ultrabaixo.
