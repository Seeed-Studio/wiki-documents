**MW2401TR11** é um módulo sensor de micro-ondas para detecção de movimento humano de **24GHz**, com alta integração e algoritmo inteligente avançado, equipado com um transceptor de alto desempenho. A antena não apenas possui boa diretividade, como também pode ajustar a área de cobertura por meio de configurações de software de acordo com diferentes cenários de aplicação, e filtrar interferências por meio de algoritmos inteligentes. Além disso, é capaz de identificar efetivamente movimentos sutis de objetos.

## Recursos

- Reconhece sensivelmente pequenos movimentos de pessoas
- O módulo de micro-ondas de **24Ghz** pode reconhecer de forma altamente eficaz o estado do objeto
- Suporta sinal original e saída de sinal digital de nível alto ou baixo
- Distância de detecção e sensibilidade são ajustáveis (Máximo: 20 metros)
- Antena em tamanho reduzido com função de detecção de ângulo de azimute de **170 °**
- Há porta I/O reservada e suporte à comunicação pela porta UART
- Padrões de teste de certificação FCC/CE/RS

## Software

- **passo 1. Baixe o** [arduino IDE](https://www.arduino.cc/en/main/software)
- **passo 2. configure o Seeeduino Cortex-MO+, por favor siga as** [instruções do Seeeduino Cortex-MO+](https://wiki.seeedstudio.com/pt-br/Seeeduino-Cortex-M0/)
- **passo 3. copie o código para o arduino IDE e então faça o upload.** [guia de upload de código](https://wiki.seeedstudio.com/pt-br/Upload_Code/)

```cpp
int MW_out = 2;   
// set pin 2 as OUT port
void setup() {
  Serial.begin(9600);
  Serial1.begin(115200);
  pinMode(MW_out, INPUT);
}

void loop() {
  Serial.println(analogRead(MW_out));
  delay(2000);
  if (Serial1.available()){
    //Serial.println("data be ready to present");
    uint8_t begin_code = Serial1.read();
    delay(10);
    uint8_t state_code = Serial1.read();
    delay(10);
    uint8_t gear_code = Serial1.read();
    delay(10);
    uint8_t delay_code = Serial1.read();
    delay(10);
    uint8_t check_code = Serial1.read();

    if(begin_code == 170){  //confirm the hearder alway present 0xaa
      check_code = begin_code + state_code + gear_code + delay_code;
      if(check_code == 175) Serial.println("object state:stop");
      if(check_code == 176) Serial.println("object state:closing_5");
      if(check_code == 177) Serial.println("object state:leaving");
      if(check_code == 172) Serial.println("object state:closing_1");
    }
    else Serial.println("no data recived");   
    }
    while(Serial1.read()>=0);    //clear buffer
}

```

- **passo 4. abra o Serial Monitor e você verá os dados sendo impressos**.

![](https://files.seeedstudio.com/wiki/MW2401TR11/img/monitor2.png)

**1018 e 1019 significam sinal de nível alto, 4 e 5 significam sinal de nível baixo; normalmente, se o sinal de nível baixo estiver presente, os dados de ação não serão apresentados.**
