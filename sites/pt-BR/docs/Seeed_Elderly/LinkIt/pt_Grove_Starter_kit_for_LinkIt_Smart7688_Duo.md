O kit inicial Grove para LinkIt Smart7688 Duo é um kit inicial que contém módulos funcionais fundamentais e essenciais, como codificador e display OLED. Este kit economizará muito em despesas e você poderá construir um modelo experimental para o seu produto. Todos os módulos são conectados com a interface Grove patenteada da Seeed. Com esse tipo de interface, você pode acelerar o seu processo de prototipagem. Além disso, um iniciante pode começar com aplicações básicas usando um guia passo a passo fornecido pela Seeed.

Sobre o LinkIt<sup>TM</sup> Smart 7688 Duo, o LinkIt<sup>TM</sup> Smart 7688 Duo (uma placa controladora compacta) é uma placa de desenvolvimento aberta, baseada na distribuição Linux OpenWrt, MT7688 e ATmega32u4. A placa é projetada especialmente para possibilitar a prototipagem de dispositivos IoT de Aplicações Ricas para casas inteligentes.

Uma demonstração simples
-------------

Você pode construir uma aplicação de IoT facilmente com os módulos Grove fornecidos neste kit. Agora usaremos alguns módulos Grove fornecidos para construir uma aplicação de IoT demonstrativa, que é usada para coletar dados de sensores na casa e controlar eletrodomésticos. Especificamente, esta aplicação demonstrativa alcança as seguintes funções:

-   Coletar dados sobre a intensidade de iluminação, temperatura e umidade ambiente e exibi-los na tela OLED; esses dados também podem ser acessados a partir de um servidor em nuvem.
-   Usar um relé para conectar uma luminária de mesa, com o qual você pode ligar e desligar a luminária com um controle ou ligar e desligar a luminária com um botão a partir do servidor em nuvem.

### Material necessário

-   Grove - Light Sensor
