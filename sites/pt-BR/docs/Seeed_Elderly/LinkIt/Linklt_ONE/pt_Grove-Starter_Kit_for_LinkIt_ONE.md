Visão geral do hardware
-----------------

![](https://files.seeedstudio.com/wiki/Grove-Starter_Kit_for_LinkIt_ONE/img/Grove_Starter_Kit_for_LinkIt_ONE_modules.jpg)

**Grove Touch Sensor**

Este "botão" pode detectar o toque dos seus dedos.

**Grove Sound Sensor**

Este é um sensor para avaliar a intensidade do som.

**Grove - Light Sensor v1.2**

Este é um sensor que detecta o nível de luz em situações do dia a dia

**Grove Servo**

Este é um atuador cuja posição pode ser controlada com precisão.

**Grove Dust Sensor**

Este sensor pode medir a qualidade do ar.

**Grove Temperature & Humidity Sensor Pro**

Ele tem desempenho mais completo e preciso do que a versão básica. A faixa de detecção deste sensor é de 5% RH - 99% RH, e -40°C - 80°C.

**Grove UV Sensor**

Este sensor é usado para detectar a intensidade da radiação ultravioleta (UV) incidente.

**Grove - Barometer Sensor (BMP280)**

Este sensor é usado para detectar a pressão atmosférica e a temperatura.

**Grove 3-Axis Digital Accelerometer (±16g)**

Este é um acelerômetro digital de alta resolução que fornece no máximo 3,9mg/LSB de resolução e ampla faixa de medição de ±16g.

**Grove Led Bar**

O Grove LED Bar é composto por um LED de 10 segmentos, que você pode usar como indicador.

**Grove Base Shield**

A Base Shield é uma interface entre o Arduino e os módulos Grove. Há 16 soquetes Grove na base shield, que podem ser divididos em três áreas funcionais diferentes: portas digitais (8), portas analógicas (4) e portas I2C (4).
