O Kit RePhone é um kit de telefone modular de código aberto que muda a maneira como colocamos nosso telefone em uso. Ele oferece uma nova forma de personalização de telefone e a solução mais fácil para desenvolvimento de dispositivos vestíveis/IoT.

Com o RePhone você pode criar seu próprio telefone em minutos usando os MÓDULOS finos, o SOFTWARE acessível e a CAPA DE TELEFONE personalizável. Você também pode hackear coisas ao seu redor, dando a objetos inanimados o poder da comunicação celular, tendo conversas com seus animais de estimação, plantas, brinquedos, capacetes de motocicleta, robôs ou drones por meio de conectividade celular.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/get_one_now.png)](https://www.seeedstudio.com/RePhone-Kit-Create-p-2552.html)

## Recursos

- Primeiro telefone modular e de código aberto do mundo
- Suporta Lua, Javascript, Arduino IDE e Eclipse IDE
- Vários módulos complementares ricos em recursos para extensão de funções
- Telefone DIY
- Dura cerca de 25 horas em espera (RePhone Kit Create)

## Família RePhone

O núcleo do RePhone é fornecido por Xadow GSM+BLE ou pelo RePhone Core 3G Module (em breve), além desses dois módulos principais há mais 8 módulos adicionais encadeáveis para estender os recursos e funcionalidades – Xadow 1,54’’ Touchscreen, Xadow Audio, Xadow GSM Breakout, Xadow LED 5x7, Xadow Basic Sensors, Xadow Duino, Xadow GPS v2 e Xadow NFC v2.

## Redefinir seu RePhone para os padrões

**Por favor, esteja ciente de que redefinir seu RePhone para os padrões excluirá todas as configurações e arquivos (imagens, músicas) no RePhone, esteja ciente disso antes de redefini-lo para os padrões.**

Para redefinir seu RePhone para os **PADRÕES:**

1. Siga as instruções na seção "[Update/Flash the Firmware](https://wiki.seeedstudio.com/pt-br/Arduino_IDE_for_RePhone_Kit/#AtualizarFlash-o-firmware)" para gravar o firmware
2. Baixe o arquivo [RePhone_Create_Kit_VXP](https://github.com/WayenWeng/RePhone_Create_Kit_VXP/)
3. Entre no [RePhone Mass Storage Mode](https://wiki.seeedstudio.com/pt-br/Xadow_GSMPlusBLE/#Modo-de-armazenamento-em-massa)
4. Copie tudo que estiver dentro do arquivo chamado "RePhone Create Kit VXP" para o armazenamento em massa de 5 MB do RePhone.
5. Reinicie seu RePhone e pronto. Como a redefinição apagou todos os arquivos, você terá que colocar também um arquivo mp3 no armazenamento em massa para ser usado como toque.
