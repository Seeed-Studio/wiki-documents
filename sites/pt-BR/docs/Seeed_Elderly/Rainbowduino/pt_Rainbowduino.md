A série Rainbowduino é uma placa controladora compatível com Arduino com driver LED multiplexado profissional. Ela pode acionar uma matriz de LEDs RGB 8x8 ou um cubo de LEDs RGB 4x4x4 em modo ânodo comum. A família Rainbowduino é a seguinte,

*   Rainbowduino v3.0: Rainbowduino v3.0 é gravada com o bootloader do Arduino e isso facilita a programação de sketches usando a IDE do Arduino. Diferente de outros drivers de LED, esta vem com um USB para UART (FT232RL) embutido para programar os sketches. Esta está sendo vendida atualmente.

*   Versões mais antigas:

    *   Rainbowduino plataforma de driver de LED - Atmega 168: Não disponível no momento.

    *   Rainbowduino plataforma de driver de LED - ATmega328: A placa Rainbowduino é uma placa controladora compatível com Arduino com capacidade profissional de acionamento de LEDs. Ela irá acionar uma matriz de LEDs RGB 8x8 (ânodo comum). Ela foi revisada para Rainbowduino v3.0.

*   Rainbow Cube kit - RGB 4*4*4 (Compatível com Rainbowduino): **<font color="Red">R</font><font color="Orange">a</font><font color="Yellow">i</font><font color="Green">n</font><font color="Blue">b</font><font color="Indigo">o</font><font color="Violet">w</font> ** **Cube Kit** é um cubo de LEDs **3D<font color="red"> R</font><font color="green">G</font><font color="blue">B</font>** útil para criar designs coloridos. O Cubo 3D é artisticamente confeccionado com sessenta e quatro LEDs **<font color="red">R</font><font color="green">G</font><font color="blue">B</font>** de 8 mm dispostos em uma configuração de 4 x 4 x 4. O **Rainbow Cube Kit** pode ser usado para criar muitos e belos efeitos visuais com um **Rainbowduino**. O **Rainbow Cube Kit** vem com um LDO 3,3 V / 1 Amp embutido, útil para alimentar o kit de forma independente. Um soquete compatível com XBee também é fornecido, que pode ser usado para conectar o Rainbowduino a um PC ou a um Arduino sem fio.

*   Rainbowduino Extension Board v0.9b: Rainbowduino Extension Shield é uma placa de derivação dos 192 canais de acionamento de LED separados do Rainbowduino. Os canais são divididos em três matrizes 8*8: vermelho, verde e azul para facilitar o controle; ela é projetada para simplificar projetos de LED personalizados baseados em Rainbowduino.

*   Rainbow Cube : O “Rainbow Cube – Ready to Shine” não requer soldagem e vem pré-montado com um controlador driver de LED Rainbowduino (compatível com Arduino). Basta conectá-lo ao seu PC ou Mac, obter uma cópia do software de design gratuito, e você descobrirá como é fácil programar este dispositivo espetacular e ver os resultados em tempo real.

*   Rainbow Cube Kit Acrylic Harness: Um estojo acrílico requintado, transparente e fácil de montar, feito sob medida para o Rainbow Cube Kit, projetado por Riley Porter @Synthetos. Este Harness é composto por seis peças de placas acrílicas, dois sacos de chaves, quatro colunas plásticas de 16 mm de altura e diversos parafusos e porcas.
