O Arnês Acrílico do Rainbow Cube Kit é uma caixa acrílica transparente, requintada e fácil de montar, feita sob medida para o kit Rainbow_Cube_Kit_Acrylic_Harness, projetada por Riley Porter @Synthetos. Este arnês é composto por seis peças de placa acrílica, dois sacos de travas, quatro colunas plásticas de 16 mm de altura e vários parafusos com porcas.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/Rainbow-Cube-Kit-Acrylic-Harness-p-1021.html)

<font color="red">Atenção</font>: ao desmontar a caixa, por favor, preste atenção e siga as instruções de desmontagem:

As travas não são fortes o suficiente para suportar puxões fortes. Para desmontar a caixa, você deve usar a mão esquerda para empurrar as duas pernas e, ao mesmo tempo, usar a mão direita para puxar
a trava para fora. Isto é ilustrado na imagem abaixo:

![](https://files.seeedstudio.com/wiki/Rainbow_Cube_Kit_Acrylic_Harness/img/Rainbow_Cube_key.jpg)
