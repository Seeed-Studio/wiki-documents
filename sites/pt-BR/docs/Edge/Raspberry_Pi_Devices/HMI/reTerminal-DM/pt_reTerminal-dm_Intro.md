description: Apresentando o reTerminal DM, uma Interface Homem-Máquina (HMI) industrial open-source de 10,1" que funciona como um Integrated Device Master. Este dispositivo tudo-em-um, baseado em Raspberry Pi CM4, funciona como um Panel PC, HMI, PLC e Gateway IIoT. Com uma tela grande de grau industrial IP65, o reTerminal DM é um hub de detecção interativo de próxima geração, simplificando o fluxo de dados e o gerenciamento de dispositivos no local.
