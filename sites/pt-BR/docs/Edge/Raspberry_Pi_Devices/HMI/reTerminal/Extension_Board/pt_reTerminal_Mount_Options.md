# Opções de Montagem do reTerminal

## Introdução

O reTerminal, como uma interface Homem-Máquina (HMI) bastante adequada, foi adotado em muitos sistemas de diferentes tipos. Como interface do sistema, é uma boa ideia montar o reTerminal, em vez de apenas segurá-lo na mão.
Nesta seção, discutiremos as possibilidades de soluções de montagem do reTerminal. O conteúdo desta seção irá abranger a [Especificação dos Parafusos de Hardware](https://wiki.seeedstudio.com/pt-br/reTerminal_Mount_Options/#Hardware_Specification_of_the_Screw) e o [Design da Comunidade](https://wiki.seeedstudio.com/pt-br/reTerminal_Mount_Options/#Community_Design).

## Especificação de Hardware dos Parafusos

Todas as porcas embutidas na parte traseira e lateral do dispositivo são compatíveis com parafusos M4; as 2 porcas no meio do dispositivo são compatíveis com parafusos **M4 18mm**, e as demais são compatíveis com parafusos **M4 6mm**.
A montagem na parte inferior é um **suporte de câmera padrão** com diâmetro de ¼ de polegada, então você pode conectar o reTerminal a um tripé padrão.

## Design da Comunidade

### Módulo Giratório para reTerminal "Rota Terminal"

Este [módulo giratório](https://protopedia.net/prototype/2903) permite ao usuário girar e segurar o reTerminal; com o novo firmware, quando a tela gira para a vertical, a imagem também se orienta para a vertical.
Além disso, com futuros desenvolvimentos, existem mais possibilidades com este módulo.
*Referência: [https://protopedia.net/prototype/2903](https://protopedia.net/prototype/2903)*
<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reTerminal_Mount_Options/5.png" alt="pir" width="1000" height="auto"/></p>

### Módulo de Teto para reTerminal

O [módulo de teto para reTerminal](https://protopedia.net/prototype/2943) é um projeto que transforma o reTerminal em um dispositivo de controle de IoT; os recursos deste módulo são controlar a alimentação da tomada e fazer o monitoramento por meio da câmera.
*Referência: [https://protopedia.net/prototype/2943](https://protopedia.net/prototype/2943)*
<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reTerminal_Mount_Options/6.png" alt="pir" width="500" height="auto"/></p>

### Adaptador de conexão Hat para reTerminal 2

Aplicações industriais também são um dos cenários de uso do reTerminal; portanto, o [adaptador de conexão Hat para reTerminal](https://protopedia.net/prototype/2972) foi criado para uma integração mais fácil na estrutura de perfil de alumínio tipo T-slot.
*Referência: [https://protopedia.net/prototype/2972](https://protopedia.net/prototype/2972)*
