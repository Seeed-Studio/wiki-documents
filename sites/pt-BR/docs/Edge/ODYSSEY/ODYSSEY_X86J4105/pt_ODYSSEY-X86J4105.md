A série de SBC ODYSSEY - X86J41x5 consiste em ODYSSEY - X86J4105, ODYSSEY - X86J4125 e ODYSSEY - X86J4125 V2. Elas são baseadas em Intel Celeron J4105/ J4125 e têm todos os ótimos recursos que um computador padrão precisa, incluindo 8GB de RAM LPDDR4, 64GB de armazenamento eMMC (apenas versão eMMC), Wi‑Fi/BLE onboard, portas Dual 1GbE/ 2.5GbE, Entrada e Saída de Áudio, portas USB, HDMI, conectores SATA, PCIe e mais.

## Principais Recursos

- Intel® Celeron® J4105/ J4125
- WiFi Dual-Band 2.5GHz/5GHz e Bluetooth 5.0
- Intel® UHD Graphics 600
- Dual 1GbE/ 2.5GbE
- Coprocessador Integrado: Arduino ATSAMD21 ARM® Cortex®-M0+/ Raspberry Pi RP2040 Dual-Core ARM® Cortex®-M0+
- Compatível com Raspberry Pi 40 pinos
- 2 x M.2 PCIe (B Key e M Key)
- Pré-instalado com Windows 10 Enterprise/ Windows 11 Pro
- Compatível com Ecossistema Grove

:::

### Instalando o Sistema Operacional

ODYSSEY - X86J41x5 é compatível com sistemas operacionais Windows e Linux.

- Para a versão sem EMMC, conecte o armazenamento externo seguindo as etapas anteriores e instale o sistema operacional desejado por meio de um pendrive USB inicializável.

- Para a versão EMMC, o Windows 10 Enterprise vem pré‑instalado.

#### Etapa 1

Conecte o pendrive USB inicializável a uma das portas USB do ODYSSEY - X86J41x5.

![](https://files.seeedstudio.com/wiki/ODYSSEY-X86J4105864/img/USB.png)

:::note
Visite Creating Bootable USB and Installing OS para mais informações sobre como criar um pendrive USB inicializável.
:::

#### Etapa 2

Pressione o botão liga/desliga e continue pressionando a tecla **F7** no teclado até aparecer a tela do Boot Manager.

![](https://files.seeedstudio.com/wiki/ODYSSEY-X86J4105864/img/F7.jpg)

#### Etapa 3

Selecione o pendrive USB conectado como o primeiro dispositivo de boot e pressione Enter.

![](https://files.seeedstudio.com/wiki/ODYSSEY-X86J4105864/img/boot.png)

#### Etapa 4

Siga as instruções da instalação para concluir a instalação do sistema operacional.

:::note
Para acessar a configuração da BIOS, continue pressionando a tecla **DEL** ao iniciar.
:::

## Usando o Arduino Core (ATSAMD21G18) no ODYSSEY - X86J4105/ X86J4125 no Linux OS

Se você instalou o Linux OS, baixe a versão para Linux do [Arduino IDE](https://www.arduino.cc/en/main/software) e instale o IDE da seguinte forma:

### Instalando o Arduino IDE

1. Abra o terminal e vá para Downloads

```sh
cd ~/Downloads
```

2. Clique em `File`->`Preferences`->`Additional Boards Manager URL:` e copie o seguinte link nele `https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json`.

2. Use o comando tar para descompactar o arquivo baixado

```sh
tar -xvf arduino -1.8.10-linux64.tar.xz
```

3. Mova o arquivo para opt

```sh
sudo mv arduino-1.8.10 /opt
```

4. Instale o Arduino IDE e crie um atalho na Área de Trabalho

```sh
cd /opt/arduino-1.8.10/ && chmod +x install.sh && ./install.sh
```

5. Conceda permissões para o Arduino fazer upload

```sh
cd /opt/arduino-1.8.10 && ./arduino-linux-setup.sh
```

## FAQs

### Como posso acessar a configuração da BIOS

Pressione o Botão de Energia e continue pressionando a tecla DEL até ver a Tela de Configuração da BIOS.

### O Arduino IDE não reconhece o microcontrolador onboard no ODYSSEY - X86J4105/ X86J4125

Adicione um fio jumper entre o **Pino RST** e o **Pino GND** no conector de 4 pinos (à esquerda dos 28 pinos do SAMD21) para redefinir o AMSAMDG21.

### Não consigo conectar ao Wi-Fi e Bluetooth

Verifique as configurações da BIOS e ative Wi-Fi e Bluetooth na BIOS

### ODYSSEY - X86J41x5 não liga

Certifique-se de usar o adaptador de energia 12V/2A fornecido na embalagem e verifique a conexão.

### Diferentes estados do botão de energia do ODYSSEY - X86J41x5

Ele possui o mesmo estado de botão de energia que outros computadores:

- `Short Press(While it's off)` -> `Turn on`

- `Short Press(While it's on)` -> `Sleep`

- `Long Press(While it's on)` -> `Force shutdown`

### O ventilador interno é controlável

Atualmente, o ventilador é controlado pela BIOS e não é controlado pelo usuário. A velocidade do ventilador é definida de acordo com a temperatura da CPU. Verifique `Chipset` -> `FAN Contorl` na tela de configuração da BIOS para mais informações.

### Como atualizar a BIOS

Para as instruções de atualização da BIOS, verifique a seção Installing OS.

### Como configurar o ODYSSEY - X86J41x5 para ligar automaticamente quando a energia for conectada

Isso também precisa ser configurado na BIOS. Entre nas configurações da BIOS pressionando a tecla DEL. Navegue até **Chipset** -> **Restore on AC Power Loss** e altere as configurações para **Last State**.

<div align="center"><img width={500} src="https://files.seeedstudio.com/wiki/ODYSSEY-X86J4105864/img/Auto-power.png" /></div>

### O ventilador não está ligando

O ventilador do ODYSSEY - X86J41x5 é controlado pelo controlador embarcado (EC), cuja função é inicializar o dispositivo antes de o sistema subir. A temperatura na BIOS é detectada pelo EC e o sensor de temperatura é colocado próximo à CPU Intel, que não possui o pino de sensor. Em outras palavras, a temperatura não é o valor direto da CPU, podendo haver um erro de 5 graus centígrados. O valor de temperatura que você vê no sistema é fornecido internamente pela CPU, a temperatura na tela da BIOS é fornecida pelo EC, e o ventilador liga ou desliga de acordo com o valor do EC.

- O valor detectado pelo EC (tela da BIOS) e a tabela de velocidade do ventilador são assim:

**Estado de ventilador desativado**: parado

**Estado de ventilador normal**: menos de 40°C–parado，45-50°C–50%，50-60℃–60%，acima de 60℃–80%

**Estado de ventilador positivo**: menos de 40°C–parado，45-50°C–70%，50-60℃–80%，acima de 60℃–100%

### Pinagem do ventilador

Alguns de vocês podem precisar conhecer a pinagem do ventilador PWM de 5V para fazer DIY/substituir pelos seus próprios ventiladores. O Odyssey possui um pino PWM de 5V para o ventilador com um conector menor do que o conector de pino de 5V usual. Talvez seja necessário substituir o conector para que ele se encaixe.

<div align="center"><img src="https://files.seeedstudio.com/wiki/ODYSSEY-X86J4105864/img/x86-fan.png" /></div>

### Reinstalando o Windows original

As versões com eMMC do ODYSSEY - X86J41x5 terão o Windows 10 pré-instalado no dispositivo. Se você instalar outro sistema operacional e quiser voltar ao Windows 10 original, verifique aqui:

- [**Imagem original do Windows 10**](https://files.seeedstudio.com/wiki/ODYSSEY-X86J4105-Ant-image/SD-JX-CJ41G-M-101-H.zip)

  - Esta imagem suporta **Auto Flash**. Basta baixar a imagem acima, descompactar os arquivos e colocá-los na **localização raiz de um pendrive USB**.

  - Conecte o pendrive USB ao ODYSSEY-X86J41x5 e faça a inicialização pelo pendrive USB. Isto irá fazer automaticamente o flash da Imagem Original do Windows 10 de volta no eMMC.

### O ODYSSEY-X86J41x5 tem TPM?

ODYSSEY-X86J4105, ODYSSEY-X86J4125 e ODYSSEY-X86J4125 V2, todos têm FTPM integrado no processador. Além disso, o ODYSSEY-X86J4125 V2 possui um TPM externo opcional

### A placa ODYSSEY possui Boot Guard para Secure Boot?

Sim, você pode habilitar a opção "Security Boot" na BIOS. Quando isso estiver habilitado, a BIOS desativará a inicialização a partir de dispositivos não autenticados.

### Por que o GPIO ainda funciona depois que o Odyssey é desligado?

Para configurar isso, você precisa [atualizar para a BIOS mais recente](https://wiki.seeedstudio.com/pt-br/ODYSSEY-X86J4105-Updating-Firmware/) que fornecemos. Na BIOS mais recente, você pode alterar de enable para disable aqui para desligar tanto o GPIO quanto o ODYSSEY.
