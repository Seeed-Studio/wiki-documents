### reComputer Robotics J50 Mini

#### O que você precisa

- reComputer Robotics J50 Mini com a placa de extensão GMSL
- Uma câmera ZED X-series GMSL2 compatível
- Um cabo ou chicote GMSL2 Fakra/Mini-Fakra compatível
- JetPack 6.2.x ou JetPack 7.2
- Acesso à Internet, um monitor, teclado e mouse para o ZED Studio

:::info
Este guia abrange o driver da plataforma Seeed e a configuração do ZED SDK. A compatibilidade do modelo de câmera pode depender da versão do ZED SDK instalada. Use o ZED SDK mais recente compatível com a sua versão JetPack/L4T.
:::

#### 1. Conectar a câmera

1. Desligue completamente o reComputer.
2. Desconecte a entrada de alimentação DC.
3. Conecte a câmera ZED X a uma porta GMSL2 usando o cabo ou chicote compatível. Certifique-se de que o conector esteja totalmente encaixado e travado.
4. Reconecte a alimentação e inicialize o dispositivo.

:::warning
Não conecte ou desconecte a câmera GMSL com o sistema ligado (hot-plug). Sempre remova a alimentação antes de conectar ou desconectar a câmera ou o chicote GMSL.
:::

#### 2. Ativar o suporte a ZED X GMSL

Escolha **um** dos caminhos a seguir. Gravar o BSP mais recente é recomendado para uma implantação limpa; instalar o DEB é mais rápido quando você deseja manter um sistema existente.

<Tabs groupId="j50-mini-zed-driver-method">
  <TabItem value="latest-bsp" label="Opção 1 · Gravar BSP mais recente" default>

Verifique as informações da compilação do BSP já instalado no dispositivo:

```bash
cat /etc/nv_tegra_release
```

Procure pelo campo `DATE`. Se o BSP tiver sido compilado em **24 de setembro de 2026 ou depois**, o suporte a ZED X GMSL já está incluído e você pode continuar para a instalação do ZED SDK.

Se a compilação for mais antiga, grave a imagem mais recente **JetPack 7.2 / L4T 39.2.0** datada de **24 de setembro de 2026** seguindo as etapas abaixo. As duas variantes de módulo usam imagens diferentes, então selecione a aba que corresponde ao módulo Jetson instalado no seu J50 Mini.

:::warning
A gravação reescreve o armazenamento de destino. Faça backup dos dados de aplicativos, arquivos de configuração e credenciais antes de começar.
:::

1. Desligue o J50 Mini e desconecte sua alimentação.
2. Pressione e segure o botão **REC**.

#### 3. Instalar o ZED SDK

Acesse a [página de download do Stereolabs ZED SDK](https://www.stereolabs.com/developers/release/) e selecione o instalador NVIDIA Jetson que corresponde à versão informada por `cat /etc/nv_tegra_release`:

| Sistema instalado | Selecione na página do ZED SDK |
| --- | --- |
| JetPack 6.2.x / L4T 36.4.x | ZED SDK for JetPack 6.1 and 6.2 (L4T 36.4) |
| JetPack 7.2 / L4T 39.2 | ZED SDK for JetPack 7.2 (L4T 39.2) |

Instale `zstd`, torne o instalador baixado executável e execute-o. Substitua o espaço reservado abaixo pelo nome de arquivo realmente baixado.

```bash
sudo apt update
sudo apt install -y zstd
cd ~/Downloads
chmod +x ZED_SDK_Tegra_L4T<release>_v<version>.zstd.run
./ZED_SDK_Tegra_L4T<release>_v<version>.zstd.run
```

Siga as instruções do instalador e mantenha as ferramentas ZED selecionadas. Reinicie após a conclusão da instalação:

```bash
sudo reboot
```

:::tip
A versão L4T no nome do instalador do ZED SDK deve corresponder à versão L4T no reComputer. Um SDK ou DEB de câmera incompatível pode impedir que a câmera seja detectada.
:::

## Solução de problemas

- **Câmera não detectada:** Confirme que o DEB, o BSP e o ZED SDK correspondem à versão L4T instalada. Em seguida, desligue e reconecte o cabo da câmera.
- **APT relata incompatibilidade de pacote:** Não force a instalação. Baixe o pacote para a versão L4T exibida por `cat /etc/nv_tegra_release`.
- **ZED Studio não abre:** Confirme que a área de trabalho gráfica está em execução e inicie `/usr/local/zed/tools/ZED_Studio` a partir de um terminal para ver a saída de erro.
- **A imagem aparece, mas a profundidade não está disponível:** Confirme que você instalou o ZED SDK completo com ferramentas e que o modelo de câmera selecionado é compatível com essa versão do SDK.
- **Vídeo intermitente:** Desligue e verifique o cabo Fakra/Mini-Fakra, a posição de travamento e o comprimento de cabo suportado antes de testar novamente.
