# Ferramentas de Desenvolvedor Jetson AI

Implantar uma ideia de IA pode ser mais rápido, flexível e até escalável para todos. A Plataforma Seeed para Jetson tem como objetivo ajudar educadores, desenvolvedores e empresas a implantar ML no mundo real. Ao consolidar o hardware de melhor classe da Seeed, a tecnologia de ponta de nossos parceiros de software e todos os desenvolvedores da comunidade, nosso objetivo é fazer emergir todos os tipos de cenários de IA em nossa plataforma de código aberto para acelerar a transformação digital da indústria. Estamos em busca de parceiros para se juntar ao nosso ecossistema e, juntos, entregar soluções para diferentes indústrias. Envie um e-mail para edgeai@seeed.cc para mais informações sobre o ecossistema de parceria.
