# Primeiros passos com o reServer J2032

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/J2032_product_image.png" alt="pir" width={800} height="auto" /></p>

O reServer J2032 é o novo e poderoso dispositivo de computação Edge IA que apresentamos com orgulho à nossa família reThings. Ele adotou o elegante design de gabinete no formato reServer, que acomodou a poderosa unidade em um formato extremamente compacto. Este pequeno servidor inteligente não só consegue trabalhar com facilidade e eficiência da borda à nuvem, como também adiciona poder de processamento de IA à equação.

O reServer J2032 está equipado com o avançado módulo Nvidia Jetson™ Xavier NX 16GB (módulo opcional Jetson™ Xavier NX 8GB), que pode fornecer até 21 TOPS para processar tarefas comuns de IA. A grande quantidade de RAM de GPU permite o processamento paralelo de múltiplas redes neurais. Ele possui portas Ethernet duplas, consistindo em uma porta Ethernet de alta velocidade de 2,5 Gigabit e uma de 1 Gigabit, e também oferece conectividade híbrida, incluindo 5G, LoRa® e BLE. O reServer 2032 também, tendo conectores de dados SATA III duplos de 6,0 Gbps, é capaz de equipar até dois discos rígidos internos SATA de 3,5"/2,5" para obter mais armazenamento.

Enquanto isso, o reServer possui um design compacto para trabalhar de forma eficiente em quase qualquer cenário de servidor. A estrutura organizada do reServer também torna simples o acesso aos discos rígidos e aos extensos slots de expansão de módulos de comunicação, o que permite fácil instalação, upgrades e manutenção.

Tendo conectores de dados SATA III duplos de 6,0 Gbps, o reServer é capaz de equipar até dois discos rígidos internos SATA de 3,5"/2,5" para obter mais armazenamento.

## Recursos

- Design compacto para um servidor de mesa com dimensão total de 132mm x124mm x233mm
- Alimentado pelo módulo Nvidia Jetson™ Xavier NX 16Gb.
- Periféricos ricos, incluindo porta LAN dupla (1 x porta de 2,5 Gigabit e 1 x porta de 1 Gigabit), 2 x USB 3.2 gen 2 Type-A, porta HDMI e porta DP, 1 x M.2 Key B, 1 x porta Mini-PCIe.
- Suporte a conectividade híbrida, incluindo 5G, LoRa® e BLE (5G e LoRa® precisam de módulos adicionais)
- Conectores de dados SATA III duplos de 6,0 Gbps para discos rígidos SATA de 3,5"/2,5", com espaço suficiente dentro do gabinete para armazenar ambos
- M.2 B-Key para expansões, como módulos 4G/5G.
- Porta Mini-PCIe para expansões, como módulos 4G/5G e módulo LoRaWAN® (**WM1302-USB-XXXX**)
- Ventoinha de resfriamento silenciosa com um grande dissipador de calor VC para excelente dissipação térmica
- Fácil de instalar, atualizar e manter, com acesso simples aos componentes internos após abrir o gabinete
- Pré-instalado com NVIDIA Jetpack 4.6.1 (Jetson™ Linux R32.7.1)

> LoRaWAN® é uma marca usada sob licença da LoRa Alliance®.
A marca LoRa® é uma marca registrada da Semtech Corporation ou de suas subsidiárias.

#### Instalação do Módulo LoRaWAN® na Porta Mini-PCIe

!!! Nota:
    O seguinte guia de configuração para instalar o módulo LoRaWAN® na porta Mini-PCIe foi testado apenas com os seguintes módulos [WM1302-USB-US915](https://www.seeedstudio.com/WM1302-LoRaWAN-Gateway-Module-USB-US915-p-4891.html?queryID=6e7ba3140d26416085ce7ea85c0be886&objectID=4891&indexName=bazaar_retailer_products) ou [WM1302-USB-868](https://www.seeedstudio.com/WM1302-LoRaWAN-Gateway-Module-USB-EU868-p-4892.html?queryID=6e7ba3140d26416085ce7ea85c0be886&objectID=4892&indexName=bazaar_retailer_products). o módulo LoRaWAN® não está incluído.

- **Passo 1.** Localize o slot Mini-PCIe na parte de trás da placa carrier e instale o módulo LoRaWAN®.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/j2032_wm1302_minipcie.png" alt="pir" width={500} height="auto" /></p>

- **Passo 2.** Conecte o cabo da antena e localize o slot de fixação da antena na parte de trás do gabinete do reServer J2032, que deve ter uma inserção de borracha bloqueando o furo.

!!! Nota:
     O reServer J2032 não é enviado com adaptadores de antena e antena.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/antenna.jpg" alt="pir" width={650} height="auto" /></p>

- **Passo 3.** modifique o reServer J2032 para ser usado com o módulo LoRaWAN® digitando o seguinte comando no `Terminal`:

```
cd /sys/class/gpio/
echo 268 > export; echo out > gpio268/direction; echo 1 > gpio268/value
echo 495 > export; echo out > gpio495/direction; echo 0 > gpio495/value
```

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/enable_lorawan.png" alt="pir" width={700} height="auto" /></p>

- **Passo 4.** verifique se o módulo LoRaWAN® está conectado corretamente，abra o `Terminal` e digite o seguinte comando:

#### Instalação de Módulo 4G/5G na Porta Mini-PCIe

!!! Nota:
     O **módulo 4G QC25-EUX** é usado com o seguinte guia de configuração e o módulo não está incluído.

- **Passo 1.** Localize o slot Mini-PCIe na parte de trás da placa carrier e instale o módulo LoRaWAN®.

!!! Nota:
     Você precisa inserir um cartão SIM padrão no slot de cartão SIM do reServer J2032 para habilitar a rede 4G/5G.
     Se você observar de perto, a **bandeja do cartão SIM** tem duas camadas, a porta **Mini-PCIe** está utilizando o **Slot SIM 2** conforme indicado na imagem abaixo.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/j2032_sim2_minipcie.png" alt="pir" width={550} height="auto" /></p>

- **Passo 2.** Conecte o cabo da antena e localize o slot de fixação da antena na parte de trás do gabinete do reServer J2032, que deve ter uma inserção de borracha bloqueando o furo.

!!! Nota:
     O reServer J2032 não é enviado com adaptadores de antena e antena.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/antenna.jpg" alt="pir" width={650} height="auto" /></p>

- **Passo 3.** modifique o reServer J2032 para ser usado com o **módulo 4G QC25-EUX** digitando o seguinte comando no `Terminal`:

```
sudo -i
cd /sys/class/gpio/
echo 436 > export; echo in > gpio436/direction;
export; echo in > gpio268/direction;
export; echo out > gpio393/direction; echo 1 > gpio393/value
echo 495 > export; echo out > gpio495/direction;
echo 1 > gpio495/value
echo 0 > gpio495/value
```

- **Passo 4.** verifique se o **módulo 4G QC25-EUX** está conectado corretamente ligando e inicializando o sistema, depois abra o `Terminal` e digite o seguinte comando:

!!! Nota:
    As etapas a seguir para habilitar o **módulo 4G QC25-EUX** foram testadas e aplicadas apenas na **Versão 4.6.1 do Jetpack OS Padrão de Fábrica**

```
lsusb -t
```

Você deverá ver a seguinte saída:

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/4G_lsusb_t.png" alt="pir" width={650} height="auto" /></p>

- **Passo 5.** Para habilitar o **módulo 4G QC25-EUX** para se conectar à rede 4G, abra o ```Terminal``` e digite:

Abra o monitor serial minicom com o módulo 4G conectado

```
sudo apt install -y minicom
sudo minicom -D /dev/ttyUSB2 -b 115200m1
```

Uma vez que a conexão serial for aberta, digite AT e pressione 'Enter', e você deverá ver OK.

Na mesma janela serial do minicom, digite:

```
AT+QCFG="usbnet"
```

Será retornado algo como +QCFG: "usbnet",0, mas precisamos que isso seja definido como 1 (modo ECM), então insira o seguinte comando:

```
AT+QCFG="usbnet",1
```

Em seguida, insira o seguinte comando para forçar o modem a reiniciar:

```
AT+CFUN=1,1
```

Depois você pode reiniciar ou esperar um pouco para o módulo obter internet da operadora do seu cartão SIM.

Agora, se você digitar `ifconfig` no `Terminal`, deverá ver uma saída semelhante à imagem abaixo, na qual você recebeu um endereço IP da operadora móvel do seu cartão SIM:

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/4Gnetwork.png" alt="pir" width={700} height="auto" /></p>

#### Instalação de Módulo 4G/5G na Porta M.2 B-key

!!! Nota:
    A M.2 B-Key no reServer J2032 suporta o formato 3042/3052 (USB3.2 GEN2) e é compatível com módulo sem fio 4G/5G **(o módulo 4G/5G não está incluído no reServer)**. O módulo 5G SIM8202G-M2 é utilizado nas etapas a seguir.

- **Passo 1.** Instale o módulo SIM8202G-M2 na M.2 B-Key.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/j2032_installM2.png" alt="pir" width={500} height="auto" /></p>

- **Passo 2.** Conecte o cabo da antena ao módulo.

!!! Nota:
     O reServer J2032 não é enviado com adaptadores de antena e antena. Para usar o módulo 5G **SIM8202G-M2** para conectar-se à rede, você precisa ter antenas conectadas ao módulo.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/antenna.jpg" alt="pir" width={650} height="auto" /></p>

- **Passo 3.** Modifique o reServer J2032 para ser usado com o **módulo 5G SIM8202G-M2** na porta M.2 B-Key digitando o seguinte comando no `Terminal`:

```
sudo -i
cd /sys/class/gpio/
echo 419 > export; echo out > gpio419/direction; echo 0 > gpio419/valueexport; echo in > gpio268/direction;
echo 417 > export; echo out > gpio417/direction; echo 1 > gpio417/value
echo 266 > export; echo out > gpio266/direction; echo 1 > gpio266/value
```

- **Passo 4.** verifique se o **módulo 5G SIM8202G-M2** está conectado corretamente ligando o dispositivo e inicializando o sistema, depois abra o `Terminal` e digite o seguinte comando:

!!! Note:
    As etapas a seguir para habilitar o **módulo 5G SIM8202G-M2** foram testadas e aplicadas apenas na **Versão de Fábrica Padrão do Jetpack OS 4.6.1**

```
lsusb -t
```

Você deverá ver saídas semelhantes às mostradas abaixo:

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/enable5G.png" alt="pir" width={700} height="auto" /></p>

**Passo 5.** Habilite o módulo 5G **SIM8202G-M2** para conectar à rede 5G

!!! Note:
     Você precisa inserir um cartão SIM padrão no slot de cartão SIM do reServer J2032 para habilitar a rede 4G/5G.
     Se você olhar de perto, a **bandeja do cartão SIM** tem dois slots, superior e inferior, a porta **M.2 B-key** está utilizando o **slot inferior**.

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/j2032_sim1.png" alt="pir" width={500} height="auto" /></p>

Abra o monitor serial minicom com o módulo 5G SIM8202G-M2 conectado

```
sudo apt install -y minicom
sudo minicom -D /dev/ttyUSB2 -b 115200m1
```

Quando a conexão serial for aberta, digite `AT` e pressione 'Enter'; você deverá ver `OK` na próxima linha.

Agora, para conseguir conectar à rede 4G/5G, siga o comando para instalar o driver necessário para o módulo 5G SIM8202G-M2 para habilitar a conexão de rede:

```
cd ~
wget https://files.seeedstudio.com/wiki/reServerJ2032/SIM8200.tar.gz
tar xvf SIM8200.tar.gz
sudo chmod 777 -R SIM8200/
cd SIM8200/
sudo ./install.sh
cd Goonline
make
sudo ./simcom-cm -i wwan0
```

Agora, se você digitar `ifconfig` no `Terminal`, deverá ver uma saída semelhante à mostrada na imagem abaixo, onde você recebeu um endereço IP da operadora móvel do seu cartão SIM:

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/reServerJ2032/5Gnetwork.png" alt="pir" width={700} height="auto" /></p>
