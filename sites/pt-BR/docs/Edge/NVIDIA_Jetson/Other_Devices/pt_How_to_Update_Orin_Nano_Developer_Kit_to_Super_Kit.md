## O que é o Jetson Orin Nano Super Developer Kit

<div align="center">
  <img width ="1000" src="https://files.seeedstudio.com/wiki/reComputer-Jetson/Orin-Nano-Developer-Kit/jetson-orin-nano-dev-kit.png"/>
</div>

O NVIDIA Jetson Orin Nano™ Super Developer Kit é um computador compacto, porém poderoso, que redefine a IA generativa para pequenos dispositivos de borda. Ele oferece até 67 TOPS de desempenho de IA — uma melhoria de 1,7X em relação ao seu antecessor — para executar perfeitamente os modelos de IA generativa mais populares, como transformadores de visão, grandes modelos de linguagem, modelos visão-linguagem e muito mais. Custando apenas US$ 249, ele fornece a desenvolvedores, estudantes e makers a plataforma mais acessível, com o suporte do software de IA da NVIDIA e de um amplo ecossistema de software de IA. Usuários atuais do Jetson Orin Nano Developer Kit podem experimentar esse aumento de desempenho apenas com uma atualização de software, para que todos possam agora desbloquear novas possibilidades com IA generativa.

:::info
O surpreendente é que o Jetson Orin Nano Developer Kit pode ser atualizado para o Jetson Orin Nano Super Developer Kit apenas com uma atualização de software.
:::

## Como Atualizar para o Super Developer Kit
Contanto que você tenha um Nvidia Jetson Orin Nano 8GB em mãos, pode atualizá‑lo seguindo estas etapas: 
- Etapa 1: Conecte os dispositivos de hardware. 
- Etapa 2: Abra o SDKManager. 
- Etapa 3: Configure e faça o flash do sistema.

## Desempenho real do Orin Nano Super Developer Kit

### Liberação total de desempenho

<div class="video-container">
  <iframe width="800" height="480" src="https://www.youtube.com/embed/Xlr3gO7tRfM" title="Power Consumption of Orin Nano Super Developer Kit" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe>

Use o programa de burn‑in para carregar totalmente a CPU e a GPU; nessa condição, a potência máxima do módulo atinge 21W, próxima ao nível de potência do Jetson Orin NX.

:::note
Programa de burn da CPU e GPU do Jetson Orin [download link](https://github.com/anseeto/jetson-gpu-burn).
:::

### Velocidade de inferência aprimorada

<div class="video-container">
  <iframe width="800" height="480" src="https://www.youtube.com/embed/gyHM9xJCPxw" title="Ollama on Jetson Orin Nano Super Developer Kit" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe>

Aqui, usamos o Ollama para carregar o modelo Llama3.2-3B e comparamos a velocidade de inferência do modelo em diferentes modos de energia. É evidente que, com a potência máxima ativada, a velocidade de inferência do modelo é significativamente maior, mostrando uma melhora de 1,28x em comparação com seu antecessor.

Consulte [este tutorial](https://www.jetson-ai-lab.com/tutorial_ollama.html) para aprender como implantar rapidamente o Ollama no Nvidia Jetson.

## Conclusão
O Jetson Orin Nano Super Developer Kit é sua plataforma definitiva para liderar o desenvolvimento de IA generativa para computação de borda. Agora é o momento ideal para começar e se juntar à comunidade vibrante e diversa de desenvolvedores avançados e pesquisadores que trabalham junto com a NVIDIA para enfrentar desafios do mundo real com IA física. 
Para usuários atuais do Jetson Orin Nano Developer Kit, atualize seu JetPack SDK para desbloquear hoje mesmo o desempenho aprimorado.
