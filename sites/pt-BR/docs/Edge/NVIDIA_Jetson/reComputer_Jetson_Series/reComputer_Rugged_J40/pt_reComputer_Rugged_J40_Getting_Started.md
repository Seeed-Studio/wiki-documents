No host Ubuntu, verifique o arquivo baixado com `sha256sum` e compare a saída completa com o valor correspondente acima:

```bash
# Orin NX 16GB (J4012)
sha256sum mfi_recomputer-rugged-orin-nx-16g-j401-5.1-35.5.0-2026-04-01.tar.gz

# Orin Nano 8GB (J3011)
sha256sum mfi_recomputer-rugged-orin-nano-8g-j401-5.1-35.5.0-2026-04-01.tar.gz
```

:::warning
Use a imagem que corresponda tanto à placa-carregadora Rugged quanto ao módulo Jetson instalado. Aguarde o término do download e confirme o SHA-256 antes de extrair o arquivo compactado.

  <span className="jetson-product-step-number">2</span>
  <div className="jetson-product-step-content">
    <h3>Prepare o Equipamento</h3>
    <p className="jetson-product-step-label">Etapa 2 · Configure o host Ubuntu e os cabos</p>

Prepare os seguintes itens antes de desconectar ou energizar o dispositivo:

- reComputer Rugged J4012 ou J3011
- Fonte de alimentação DC de 19–48 V
- PC host físico com Ubuntu 20.04 para estes pacotes JetPack 5.1.3
- Cabo de dados USB Type-C para gravação
- Monitor externo e cabo HDMI
- Teclado e mouse

:::tip
Use um host Ubuntu físico sempre que possível. O passthrough USB em uma máquina virtual pode interromper o processo de gravação.
:::

<section className="jetson-product-step-item">
  <span className="jetson-product-step-number">3</span>
  <div className="jetson-product-step-content">
    <h3>Entre no Modo de Recuperação Forçada</h3>
    <p className="jetson-product-step-label">Etapa 3 · Conecte a porta DEVICE e verifique o ID USB</p>

<img className="jetson-product-step-image" src="https://files.seeedstudio.com/wiki/rugged_J401/1.jpg" alt="Botão de recuperação e porta DEVICE usados para gravar o reComputer Rugged J40" />

1. Conecte um cabo de dados USB Type-C entre a porta **DEVICE** e o host Ubuntu.
2. Pressione e segure o botão **REC**.
3. Mantendo o **REC** pressionado, conecte a fonte de alimentação para ligar o dispositivo.
4. Solte o botão **REC**.
5. No host Ubuntu, verifique se o Jetson foi detectado:

```bash
lsusb
```

Saída esperada por configuração:

| Produto | Módulo Jetson | ID USB esperado |
| --- | --- | --- |
| reComputer Rugged J4012 | Orin NX 16GB | `0955:7323 NVidia Corp` |
| reComputer Rugged J3011 | Orin Nano 8GB | `0955:7523 NVidia Corp` |

Se o ID esperado não aparecer, reconecte o cabo USB, tente outra porta USB do host e repita a sequência de recuperação antes de continuar.

  </div>
</section>

<section className="jetson-product-step-item">
  <span className="jetson-product-step-number">4</span>
  <div className="jetson-product-step-content">
    <h3>Extraia e Grave a Imagem</h3>
    <p className="jetson-product-step-label">Etapa 4 · Execute o pacote de gravação em massa a partir do host Ubuntu</p>

Altere para o diretório que contém a imagem baixada e extraia o arquivo compactado para o seu módulo:

```bash
cd <path-to-image>
# Orin NX 16GB (J4012)
sudo tar xpf mfi_recomputer-rugged-orin-nx-16g-j401-5.1-35.5.0-2026-04-01.tar.gz

# Orin Nano 8GB (J3011): use this archive instead
# sudo tar xpf mfi_recomputer-rugged-orin-nano-8g-j401-5.1-35.5.0-2026-04-01.tar.gz
```

Entre no diretório BSP extraído que contém `tools/kernel_flash/l4t_initrd_flash.sh` e inicie a gravação. Substitua `<extracted-bsp-directory>` pelo nome real desse diretório:

```bash
cd <extracted-bsp-directory>
sudo ./tools/kernel_flash/l4t_initrd_flash.sh \
  --flash-only --massflash 1 --network usb0 --showlogs
```

Aguarde até que o terminal informe que a gravação foi concluída com sucesso. Em seguida, desconecte o cabo USB, desligue e ligue novamente o reComputer, conecte o monitor e os dispositivos de entrada e conclua a configuração inicial do Ubuntu.
