# Especificações de Hardware
| Parâmetro | Especificação |
| --- | --- |
| Processador | RV1126B |
| CPU | 1,2GHz Quad-Core Cortex-A53 |
| NPU | 3 TOPS, suporta computação mista INT8/INT16 |
| Memória | LPDDR4 2GB / 4GB |
| Armazenamento | 16GB eMMC, slot para cartão SD (máx. 512GB) |
| Câmera | SC850SL (4K@30FPS) |
| IMU | IMU de 6 eixos (sensor ICM-42670-P) (acelerômetro de 3 eixos + giroscópio de 3 eixos) |
| Saída de Áudio | Alto-falante de 8 ohms com potência nominal de 1W |
| Entrada de Áudio | Microfone de eletreto x2 |
| Fonte de Alimentação | Suporta gerenciamento de carga e descarga de bateria de lítio 7,4V, entrada DC (12V~24V, conector barril 5525), alimentação PoE |
| Rede e Conectividade Sem Fio | Wi-Fi 5.2, Bluetooth 5.2, Ethernet 1000Mbps |
| Interfaces | Type-C de função completa (OTG), UART de depuração, CAN ×2, MIPI DSI de 22 pinos, GPIO ×2 |
