# Encontrar Gravações e Armazenamento

Depois de configurar os gatilhos de gravação de eventos (consulte [Configurar Gravação de Eventos](/pt-br/recamera_pro_record_settings/)), use a página **Recording Settings** na interface Web para encontrar seus arquivos e gerenciar o armazenamento do dispositivo.

## Gerenciamento de Armazenamento

Em **Storage Management** você pode visualizar o uso atual do disco e o local onde os arquivos são salvos.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_65N6rhHetJ.png" />

Na área de configuração de armazenamento, você pode definir o tamanho de armazenamento disponível, configurar cotas e escolher se deseja sobrescrever arquivos antigos para que as gravações mais recentes sejam sempre salvas.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_WZBl9MEr7Z.png" />
