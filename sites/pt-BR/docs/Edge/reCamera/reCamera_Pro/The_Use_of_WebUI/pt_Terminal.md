## Log do sistema

A área de log do sistema é usada para visualizar em tempo real os logs de operação do reCamera Pro, facilitando para os usuários entender o status atual do dispositivo, o status de operação dos serviços e solucionar problemas anormais.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/20260708190224_6_2.png" />


Os usuários podem realizar as seguintes operações nesta área:

- Visualizar em tempo real a saída do log do sistema
- Filtrar logs por nível de log ou palavras-chave
- Limpar o conteúdo exibido atualmente no log
- Baixar os arquivos de log para análise de problemas ou suporte técnico.

Esta função é aplicável à depuração de equipamentos, confirmação do status de serviço, investigação de anomalias e registro de reprodução de problemas.

## Console do terminal

O console do terminal permite que os usuários façam login diretamente no terminal do sistema reCamera Pro por meio da Web UI, sem a necessidade de usar uma ferramenta SSH adicional.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_2dvKqObUbo.png" />

Os usuários podem fazer login usando as seguintes contas padrão:

```bash
Username: root
Password: recamera
```
