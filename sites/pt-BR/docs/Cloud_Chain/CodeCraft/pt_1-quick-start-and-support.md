## 1.1 Introdução ao CodeCraft

### 1.1.1 “Você Diz, Ele Funciona”

CodeCraft é um assistente de programação com IA projetado especificamente para cenários de hardware. Você só precisa descrever o que deseja em linguagem natural, e o CodeCraft pode gerar programas de hardware executáveis para você.

Ele é adequado para usuários que desejam concluir rapidamente a criação de hardware sem configurar um ambiente de desenvolvimento do zero. Seja você estudante, professor, maker ou iniciante em programação de hardware, é possível concluir todo o processo da ideia à execução por meio de conversas.

### 1.1.2 Da Ideia à Execução em Quatro Etapas

<!--![CodeCraft Workflow](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/codecraft-how-it-works.png)-->

O fluxo de trabalho básico do CodeCraft é muito simples:

1. **Descrever**  
   Use linguagem natural para descrever sua ideia, como “construir um timer Pomodoro” ou “fazer a placa de desenvolvimento detectar temperatura e umidade”.

2. **Gerar**  
   O CodeCraft gera automaticamente código executável e documentação do projeto com base na sua descrição.

3. **Gravar**  
   Envie o programa para sua placa de desenvolvimento com um clique via web.

4. **Compartilhar**  
   Após a conclusão, você pode publicar o projeto na comunidade SenseCraft AI para reutilização ou compartilhamento.

### 1.1.3 CodeCraft Entende o Seu Hardware

<!--![CodeCraft vs General Coding Tools Comparison](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/codecraft-comparison.png)-->

Comparado com ferramentas gerais de codificação com IA, o CodeCraft é mais focado em cenários de hardware. Ele não apenas gera código, mas também entende placas de desenvolvimento, sensores, protocolos de comunicação e bibliotecas de hardware.

| Capacidade | Ferramentas Gerais de Codificação | CodeCraft |
| :--- | :---: | :---: |
| Geração de código de software | Suportado | Suportado |
| Compreensão de pinos de MCU e especificações de placas | Nem sempre suportado | Suportado |
| Suporte a sensores e protocolos de comunicação | Nem sempre suportado | Suportado |
| Compilação em nuvem, sem configuração de ambiente local | Nem sempre suportado | Suportado |
| Gravação na placa de desenvolvimento com um clique | Nem sempre suportado | Suportado |
| Compartilhamento na comunidade de hardware SenseCraft AI | Nem sempre suportado | Suportado |

## 1.2 Preparação e Login

O CodeCraft oferece vários métodos de login. Seja você desenvolvedor, estudante ou educador, pode começar rapidamente.

### 1.2.1 Registro e Login Pessoais

Ao usar o CodeCraft pela primeira vez, uma conta será criada automaticamente — sem necessidade de registro complexo. Você pode fazer login usando:

* Login por e-mail
* Login com Google
* Login com GitHub
* Login com Apple
* Login com Bazaar (conta da loja oficial Seeed Studio)

Recomenda-se usar um método de login que você utilize com frequência para garantir a sincronização de projetos e dados em nuvem entre dispositivos.

![Sign-up / Log-in](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/Sign-up-Log-in-EN.png)

### 1.2.2 Login com Código de Sala de Aula

O CodeCraft também oferece suporte a login com código de sala de aula, projetado para cenários educacionais.

O login com código de sala de aula permite que os alunos pulem o registro e entrem diretamente em um ambiente de sala de aula atribuído pelo professor.

Etapas:

1. Selecione “Classroom Code Login” na tela de login.
2. Insira o código de sala de aula fornecido pelo professor.
3. Entre no ambiente de sala de aula e comece a usar o CodeCraft.

Os códigos de sala de aula geralmente são fornecidos por professores ou escolas. Para necessidades educacionais, você pode entrar em contato com o suporte ou visitar a página de Soluções Educacionais do CodeCraft para mais detalhes.

![Classroom Code Login](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/Class-Code-Login-EN.png)

### 1.3.3 Resgatando um Código de Assinatura

Se você obtiver um código de resgate pelo Taobao, loja oficial ou promoções:

1. Abra https://codecraft.seeed.cc
2. Faça login
3. Entre no workspace
4. Clique em Settings
5. Vá para Account ou Billing
6. Encontre “Redeem Code”
7. Insira e confirme o código

Observações:

* Cada código é normalmente de uso único.
* Certifique-se de que a conta está correta antes de resgatar.
* A validade depende dos detalhes do pedido.
* Se não for ativado, atualize a página ou faça login novamente.

## 1.5 Ajuda e Suporte

### 1.5.1 FAQ

**P: Por que meu código de resgate é inválido?**  
R: Verifique a correção, o status de uso e a conta em que você fez login.

**P: Não recebi o código após comprar no Taobao.**  
R: Verifique os detalhes do pedido ou entre em contato com o suporte da loja.

**P: A assinatura não foi ativada após o resgate?**  
R: Atualize a página ou faça login novamente. Se ainda estiver inválido, entre em contato com o suporte com as informações do pedido.
