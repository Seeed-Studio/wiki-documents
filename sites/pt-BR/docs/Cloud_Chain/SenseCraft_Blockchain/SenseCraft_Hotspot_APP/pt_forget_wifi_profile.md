**Como faço para esquecer o perfil de Wi‑Fi no meu Hotspot?**
====================================================

Se você já se conectou primeiro via Wi‑Fi, depois conectou o cabo Ethernet para uma conexão estável e quer que o Hotspot funcione apenas via Ethernet, será necessário remover e esquecer o Wi‑Fi atual.

Desconecte o cabo Ethernet e conclua as etapas abaixo. Você pode reconectar o cabo Ethernet novamente quando terminar.

1.  Abra o aplicativo Helium
2.  Emparelhe seu Hotspot pressionando o botão na parte de trás do dispositivo por 5–6 segundos
3.  Selecione a rede Wi‑Fi
4.  Escolha um novo Wi‑Fi
5.  Você verá a opção "Forget Network"
6.  Em seguida, selecione voltar
7.  Conecte novamente o cabo Ethernet
