# Introdução à SenseCraft Data Platform API

![Visão geral da SenseCraft Data Platform API](https://sensecap-docs.seeed.cc/images/open_api/introduction.png)

A SenseCraft Data Platform API, anteriormente documentada como SenseCAP API, permite que aplicações gerenciem dispositivos IoT compatíveis e acessem seus dados.

## Escolha uma API

| Objetivo | API | Comece aqui |
| --- | --- | --- |
| Gerenciar dispositivos e grupos ou recuperar dados atuais e históricos | HTTP API | [HTTP API Quickstart](/pt-br/sensecraft-data-platform/api/http-api/quick-start/) |
| Revisar detalhes de requisição HTTP, resposta e autenticação | HTTP API | [HTTP API Access Guide](/pt-br/sensecraft-data-platform/api/http-api/http-api-access-guide/) |
| Assinar mensagens de dispositivos em tempo real | Data OpenStream API | [Data OpenStream API Quickstart](/pt-br/sensecraft-data-platform/api/data-openstream-api/data_openstream_api_quickstart/) |
| Revisar detalhes de conexão, tópicos e o modelo de publicação-assinatura | Data OpenStream API | [Data OpenStream API Reference](/pt-br/sensecraft-data-platform/api/data-openstream-api/data_openstream_api_reference/) |

A Data OpenStream API oferece suporte a MQTT e MQTT sobre WebSocket para assinaturas de mensagens em tempo real. Use a Data OpenStream API Reference para obter o host, porta, autenticação e detalhes de tópicos atuais.

Consulte [API Pricing for SenseCraft Data Platform](/pt-br/sensecraft-fee/sensecraft-data-platform-api-pricing/) para regras de cobrança e exemplos.
