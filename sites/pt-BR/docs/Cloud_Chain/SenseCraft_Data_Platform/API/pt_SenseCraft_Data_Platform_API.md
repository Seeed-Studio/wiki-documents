# Introdução à SenseCraft Data Platform API


=============================

![](https://sensecap-docs.seeed.cc/images/open_api/introduction.png)

SenseCAP API é destinada a usuários que desejam gerenciar dispositivos e dados de IoT. Ela combina três tipos de métodos de API: protocolo HTTP, protocolo MQTT e protocolo Websocket.

*   Com a HTTP API, os usuários podem gerenciar dispositivos LoRa e NB-IoT para obter dados RAW ou dados históricos.
*   Com a MQTT API, os usuários podem assinar os dados de medição em tempo real dos sensores por meio do protocolo MQTT.
*   Com a Websocket API, os usuários podem obter dados de medição em tempo real dos sensores por meio do protocolo Websocket.
