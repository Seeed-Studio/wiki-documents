# Visão geral do SenseCraft App

SenseCraft App é um aplicativo móvel para visualização de dados e gerenciamento de dispositivos.

## Destaques do App

- Economize tempo - oferece uma experiência de escanear e usar para permitir que os usuários concluam toda a configuração em 4 etapas
- Funciona para pessoas com pouca ou nenhuma experiência técnica começarem facilmente com dados de sensores
- Adquira e visualize dados em interfaces de usuário limpas
- Defina intervalos de tempo: melhore a eficiência da bateria
- Defina valores de limite: foque nos dados para os quais você precisa tomar uma ação - em breve
- Envie alarmes se os dados estiverem fora da faixa segura - em breve

## Download

SenseCraft App está disponível nas versões para iOS e Android.

[Baixe o aplicativo SenseCraft na Central de Downloads oficial da SenseCraft](https://sensecraft.seeed.cc/en/download?utm_source=seeedstudio_wiki&utm_medium=referral&utm_campaign=wiki_to_sensecraft&utm_content=sensecraft_data_app).

## Conta

SenseCraft oferece suporte à configuração de dispositivos e ao gerenciamento remoto. Para usar a SenseCraft Data Platform (anteriormente SenseCAP Portal) e outras funções, registre uma conta.

:::tip Note
Selecione `Global` como Server Location. Você também pode criar uma conta por meio da <a href="https://sensecap.seeed.cc">SenseCraft Data Platform</a>.
:::

## Evento

Adicione Eventos para receber notificações.
<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/add-event.PNG" alt="Create an event alert in SenseCraft App" width={300} height="auto" /></p>

1. Clique no ícone Adicionar ou no botão Add Event para criar um alerta de Evento, na página Add Event em Conditions adicione opções de condição e clique no botão Add para selecionar um dispositivo.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_2.png" alt="Select a device when creating an event" style={{width:1000, height:'auto'}}/></div>

2. Selecione o dispositivo, selecione o tipo de medição, defina as condições de alarme, selecione condições como maior que ou menor que, arraste a barra de progresso para definir o valor e clique em próximo passo.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_3.png" alt="Configure an event measurement and threshold" style={{width:1000, height:'auto'}}/></div>

3. Na página Add Event, em Back to normal actions quando o dispositivo voltar ao normal, selecione se deseja enviar uma notificação, clique em Save, insira o nome do Evento, clique em Submit para adicionar um alarme de Evento com sucesso e retornar à lista de Eventos.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_4.png" alt="Configure event recovery actions and notifications" style={{width:1000, height:'auto'}}/></div>

4. Na página do dispositivo, clique em Message Center para visualizar as mensagens de alarme, exibindo Device warning para mensagens de alarme acionadas pelo dispositivo e System notification para mensagens do sistema.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_5.png" alt="View event notifications in the message center" style={{width:1000, height:'auto'}}/></div>

5. Clique na mensagem de alarme, o dispositivo aciona o item de condição, envia a mensagem de alarme, clique para ver os detalhes do alarme. Ao retornar à lista de alarmes, o status muda para lido; clique no botão de edição para selecionar a mensagem, você pode marcar como lida, excluir e realizar outras operações.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_6.png" alt="View and manage an event alarm message" style={{width:1000, height:'auto'}}/></div>

6. Alterne para mensagens do sistema e clique para ver os detalhes das mensagens enviadas pelo sistema.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_7.png" alt="View a system notification in SenseCraft App" style={{width:1000, height:'auto'}}/></div>

## Template

O SenseCraft app fornece um conjunto de funções de template, incluindo **Add New Template, Import Template, Download Template e Apply Preset Template**, para simplificar e acelerar a configuração de dispositivos. Essas funções ajudam os usuários a reduzir o tempo de configuração e a otimizar a implantação em instalações em grande escala.

### Add New Template

Há duas maneiras de adicionar um novo template.

**Method 1** <br />

1. Vá para `User` → `Device Bluetooth Configuration`. <br />
2. Toque no botão `Template` no canto superior direito. <br />
3. Toque no ícone `+` → `Add New Template`. <br />
4. Selecione o tipo de dispositivo. <br />
5. Configure os parâmetros do template de acordo com suas necessidades. <br />
6. Toque em `Confirm` para salvar o template. <br />
7. Retorne à página Template, você verá `Save successful`. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/add_new_template1.png" alt="Open the template page from Bluetooth configuration" width={800} height="auto" /></p>

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/add_new_template2.png" alt="Add a new device configuration template" width={800} height="auto" /></p>

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/add_new_template3.png" alt="Confirm a new device configuration template" width={300} height="auto" /></p>

**Method 2** <br />

1. Entre no modo de Configuração via Bluetooth e selecione `Advanced Configuration`. <br />
2. Vá para a página `Setting`. <br />
3. Toque no ícone `Template` no canto superior direito. <br />
4. Ajuste os parâmetros do template conforme necessário. <br />
5. Selecione `Save as Template`. <br />
6. Insira um nome para o Template. <br />
7. Toque em `Confirm` para salvar. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/add_new_template4.png" alt="Save Bluetooth configuration settings as a template" width={800} height="auto" /></p>

### Download Template

1. Navegue até a página `Template` e selecione o template que você deseja baixar. <br />
2. Toque no menu de três pontos no canto superior direito. <br />
3. Selecione `Download Template`. <br />
4. Salve o arquivo no armazenamento do seu dispositivo móvel. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/downlaod_template.png" alt="Download a device configuration template" width={800} height="auto" /></p>

### Import Template

1. Vá para `User` → `Device Bluetooth Configuration`. <br />
2. Toque em `Template` no canto superior direito. <br />
3. Na página Template, toque no ícone `+`. <br />
4. Selecione `Import Template`. <br />
5. Toque no ícone `file`. <br />
6. No gerenciador de arquivos do sistema, selecione o arquivo de configuração com a extensão `“.seeed”`. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/import_template.png" alt="Import a Seeed device configuration template" width={800} height="auto" /></p>

### Apply Preset Template

1. Entre no modo de Configuração via Bluetooth do dispositivo e selecione `Advanced Configuration`. <br />
2. Abra a página `Settings` e toque no ícone `Template` no canto superior direito. <br />
3. Selecione `Choose Template`. <br />
4. Na página Preset Template, selecione o template desejado. <br />
5. Retorne à página Settings e toque em `Send` para aplicar a configuração. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/apply_template.png" alt="Choose a preset device configuration template" width={800} height="auto" /></p>

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/apply_template2.png" alt="Apply a preset template to a device" width={600} height="auto" /></p>
