# Introdução e Uso

SenseCraft APP é um poderoso APP para visualização de dados e gerenciamento de dispositivos.

## Destaques do App

- Economize tempo - fornece uma experiência de escanear e usar, permitindo que os usuários concluam toda a configuração em 4 etapas
- Funciona para pessoas com pouca ou nenhuma experiência técnica para começar facilmente com dados de sensores
- Adquira e visualize dados em interfaces de usuário limpas
- Defina intervalos de tempo: melhore a eficiência da bateria
- Defina valores de limite: foque nos dados para os quais você precisa tomar ações - em breve
- Envie alarmes se os dados estiverem fora da faixa segura - em breve

## Evento

Adicione Eventos para receber notificações.
<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/add-event.PNG" alt="pir" width={300} height="auto" /></p>

1. Clique no ícone Adicionar ou no botão Add Event para criar um alerta de Evento, na página Add Event Conditioins para adicionar opções de condição e clique no botão Add para selecionar um dispositivo.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_2.png" style={{width:1000, height:'auto'}}/></div>

2. Selecione o dispositivo, selecione o tipo de medição, defina as condições de alarme, selecione as condições, como maior que ou menor que, arraste a barra de progresso para definir o valor e clique no próximo passo.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_3.png" style={{width:1000, height:'auto'}}/></div>

3. Na página Add Event Back to normal actions device back to normal, selecione se deseja enviar uma notificação, clique em Save, insira o nome do Evento, clique em Submit para adicionar um alerta de Evento com sucesso e retornar à lista de Eventos.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_4.png" style={{width:1000, height:'auto'}}/></div>

4. Na página do dispositivo, clique em Message Center para visualizar as mensagens de alarme, mostrando Device warning device triggered alarm push messages, System notification system messages.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_5.png" style={{width:1000, height:'auto'}}/></div>

5. Clique na mensagem de alarme, o dispositivo aciona o item de condição, envia a mensagem de alarme, clique para ver os detalhes do alarme. Ao retornar à lista de alarmes, o status muda para lido; clique no botão de edição para selecionar a mensagem, você pode marcar como lida, excluir e realizar outras operações.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/sensecap_mate_app/mate_app_6.png" style={{width:1000, height:'auto'}}/></div>

6. Altere para mensagens do sistema, clique para ver os detalhes das mensagens enviadas pelo sistema.

## Template

O app SenseCraft oferece um conjunto de funções de template, incluindo **Add New Template, Import Template, Download Template e Apply Preset Template**, para simplificar e acelerar a configuração de dispositivos. Essas funções ajudam os usuários de forma eficiente a reduzir o tempo de configuração e a otimizar a implantação em instalações em grande escala.

### Add New Template
Há duas maneiras de adicionar um novo template.

**Method 1** <br />
1. Vá para `User` → `Device Bluetooth Configuration`. <br />
2. Toque no botão `Template` no canto superior direito. <br />
3. Toque no ícone `+` → `Add New Template`. <br />
4. Selecione o tipo de dispositivo. <br />
5. Configure os parâmetros do template conforme suas necessidades. <br />
6. Toque em `Confirm` para salvar o template. <br />
7. Volte para a página Template, você verá `Save successful`. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/add_new_template1.png" alt="pir" width={800} height="auto" /></p>

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/add_new_template2.png" alt="pir" width={800} height="auto" /></p>

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/add_new_template3.png" alt="pir" width={300} height="auto" /></p>

**Method 2** <br />
1. Entre no Modo de Configuração via Bluetooth e selecione `Advanced Configuration`. <br />
2. Vá para a página `Setting`. <br />
3. Toque no ícone `Template` no canto superior direito. <br />
4. Ajuste os parâmetros do template conforme necessário. <br />
5. Selecione `Save as Template`. <br />
6. Insira um nome para o Template. <br />
7. Toque em `Confirm` para salvar. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/add_new_template4.png" alt="pir" width={800} height="auto" /></p>

### Download Template
1. Navegue até a página `Template` e selecione o template que você deseja baixar. <br />
2. Toque no menu de três pontos no canto superior direito. <br />
3. Selecione `Download Template`. <br />
4. Salve o arquivo no armazenamento do seu dispositivo móvel. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/downlaod_template.png" alt="pir" width={800} height="auto" /></p>

### Import Template
1. Vá para `User` → `Device Bluetooth Configuration`. <br />
2. Toque em `Template` no canto superior direito. <br />
3. Na página Template, toque no ícone `+`. <br />
4. Selecione `Import Template`. <br />
5. Toque no ícone `file`. <br />
6. No gerenciador de arquivos do sistema, selecione o arquivo de configuração com a extensão `“.seeed”`. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/import_template.png" alt="pir" width={800} height="auto" /></p>

### Apply Preset Template
1. Entre no modo de Configuração via Bluetooth do dispositivo e selecione `Advanced Configuration`. <br />
2. Abra a página `Settings` e toque no ícone `Template` no canto superior direito. <br />
3. Selecione `Choose Template`. <br />
4. Na página Preset Template, selecione o template desejado. <br />
5. Volte para a página Settings e toque em `Send` para aplicar a configuração. <br />

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/SenseCAP/introduction/App_Template/apply_template.png" alt="pir" width={800} height="auto" /></p>
