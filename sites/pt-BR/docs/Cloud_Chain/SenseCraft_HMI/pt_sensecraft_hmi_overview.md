# Visão Geral do SenseCraft HMI

## Introdução

[SenseCraft HMI](https://sensecraft.seeed.cc/hmi) é a poderosa plataforma de design de interfaces em nuvem da Seeed Studio que permite criar interfaces visuais profissionais para dispositivos com tela sem necessidade de programação. Com um editor intuitivo de arrastar e soltar, modelos pré-construídos e recursos de design com IA, o SenseCraft HMI torna fácil transformar seu hardware em belos painéis de informação, dashboards, sinalização digital e painéis de controle.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/reterminal_e10xx/img/23.png" style={{width:1000, height:'auto'}}/></div>

### Principais Recursos

- **Construtor de Interface Sem Código**: Crie displays profissionais com simples ferramentas de arrastar e soltar

- **Design com IA**: Gere layouts completos e imagens usando descrições em linguagem natural

- **Integração de Dados em Tempo Real**: Conecte-se a clima, ações, GitHub, YouTube e muito mais

- **Múltiplas Funções de Exibição**: Funções de Gallery, Canvas, RSS e Web para diferentes casos de uso

- **Modelos Prontos para Uso**: Layouts pré-desenhados para aplicações comuns

- **Implantação com Um Clique**: Envie designs diretamente para dispositivos conectados

- **Integração com Sensores do Dispositivo**: Exiba automaticamente temperatura, umidade e dados de bateria do seu dispositivo

## Primeiros Passos

Para começar a usar o SenseCraft HMI:

1. **Acesse a Plataforma**: Visite [SenseCraft HMI](https://sensecraft.seeed.cc/hmi)

2. **Crie uma Conta**: Cadastre-se para obter uma conta gratuita SenseCraft se ainda não tiver uma

3. **Conecte Seu Dispositivo**: Siga as instruções na tela para parear seu dispositivo compatível

4. **Escolha uma Função**: Selecione entre as funções Gallery, Canvas, RSS ou Web com base nas suas necessidades

5. **Desenhe Sua Interface**: Use as ferramentas intuitivas para criar seu display

6. **Implante no Dispositivo**: Envie seu design para o dispositivo conectado com um clique

## Documentação das Funções

O SenseCraft HMI oferece várias funções especializadas, cada uma projetada para diferentes necessidades de exibição:

### [Função de Geração com IA](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-ai-generator/)

Crie belos layouts e imagens simplesmente descrevendo o que você deseja em linguagem natural, eliminando a necessidade de habilidades de design.

### [Função Gallery](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-gallery/)

Transforme seu dispositivo em uma moldura digital para fotos com exibições de imagens personalizáveis, transições e efeitos visuais.

### [Função Canvas](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-canvas/)

Desenhe interfaces e dashboards personalizados combinando elementos estáticos com dados dinâmicos de várias fontes.

### [Função RSS](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-rss/)

Exiba conteúdo atualizado automaticamente de veículos de notícias, blogs e outras fontes de informação usando feeds RSS.

### [Função Web](https://sensecraft-hmi-docs.seeed.cc/en/guides/sensecraft-hmi-web/)

Mostre conteúdo da web diretamente no seu dispositivo, perfeito para dashboards, documentação ou sistemas de monitoramento.
