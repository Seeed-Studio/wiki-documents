<!-- ### Q1: Qual é a senha do usuário padrão "recomputer"? -->

O sistema já possui um nome de usuário e uma senha predefinidos. Defina o nome de usuário padrão como "**recomputer**" e a senha padrão como "**12345678**" ao fazer login. Se você definir credenciais diferentes, poderá encontrar problemas. Esse problema está sendo resolvido no momento.
