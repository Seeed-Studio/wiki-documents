# Perguntas frequentes sobre o módulo reComputer RK

Esta página contém respostas verificadas para o reComputer RK Module. Cada resposta indica a variante do produto e o modo de firmware ao qual se aplica, juntamente com a data em que foi verificada pela última vez em relação às fontes oficiais atuais.
