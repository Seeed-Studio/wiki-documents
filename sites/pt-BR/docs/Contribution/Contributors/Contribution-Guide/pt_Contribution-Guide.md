# Guia de Contribuição (Pull Request)

<strong><font color={'8DC215'} size={"5"}>Obrigado pelo seu esforço! <br /> Siga as etapas abaixo para concluir sua submissão no GitHub.</font></strong>

## Opção 1: Etapas completas para PR

1. Primeiro, certifique-se de que você consegue [build the wiki platform page locally](/pt-br/Deploy_Page_Locally)
2. Agora você pode fazer as alterações ou adicionar os arquivos, enquanto visualiza as mudanças localmente. Depois, faça um PR para o nosso repositório. 

- [Etapas completas para PR](/pt-br/full_steps_pull_request)

## Opção 2: Etapas rápidas para PR

Você pode simplesmente baixar todos os arquivos necessários e adicionar o arquivo md, bem como as imagens, e então fazer um PR diretamente para o nosso repositório.

- [Etapas rápidas para PR](/pt-br/quick_pull_request)
