# Open Source na Seeed Studio

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/open_source_topic/open_source_topic.png" style={{width:1000, height:'auto'}}/></div>

<div>Open source é uma força poderosa que impulsiona a inovação e a colaboração no mundo da tecnologia. Ela promove o compartilhamento de ideias, conhecimentos e código, permitindo que desenvolvedores e entusiastas trabalhem juntos e construam sobre soluções existentes.</div>
<div>Como uma empresa inovadora, a Seeed Studio adota os princípios de open source em projetos de hardware e software e desenvolveu e fabricou uma ampla gama de produtos eletrônicos, desde placas de desenvolvimento e sensores até robótica e dispositivos de Internet das Coisas (IoT).</div>
<div>Apresentado nesta página, e mantido continuamente, a Seeed Studio apresentará seu hardware open source e seu software open source.</div>

## Open Source Hardware

### Wio Terminal - Hardware de Manufatura Aberta

A Seeed Studio está comprometida com o movimento de hardware open source e, nesse espírito, demos um passo além em direção à manufatura aberta. Desejamos tornar possível que qualquer pessoa reproduza e fabrique este dispositivo. Acreditamos que abrir o processo de fabricação irá desbloquear um imenso potencial de inovação e criatividade.

## Open Source Software

### CodeCraft - Open Source Software

Codecraft é um software de programação gráfica, usando uma interface de arrastar e soltar, projetado para ajudar iniciantes a programar sem a necessidade de escrever código em linguagens tradicionais baseadas em texto. Lançado em 2018, reconhecido como finalista do Bett Awards e finalista do The Edtech Awards Cool Tool em 2022, este software foi totalmente aberto.

## Serviço Fusion

### Manufatura Ágil e Personalização de Hardware

Seeed Studio Fusion é uma plataforma global on-line tudo‑em‑um para fabricação de PCB, montagem e personalização de hardware. Seja para prototipagem, produção em massa, soluções personalizadas para produtos open source ou a transformação de suas ideias criativas em produtos lucrativos, o Seeed Studio Fusion pode atender às suas necessidades.
