WM1302 Pi HAT é uma placa de expansão adicional projetada especificamente para conectar o módulo WM1302 LoRaWAN Gateway baseado no SX1302 a versões de Raspberry Pi até Raspberry Pi 4B. Ela também integra o chip de autenticação LoRaWAN e o módulo GPS.

O [WM1302 module](https://www.seeedstudio.com/WM1302-LoRaWAN-Gateway-Module-SPI-EU868-p-4889.html) é uma nova geração de módulo de gateway LoRaWAN com formato mini-PCIe. Baseado no chip Semtech® SX1302 baseband LoRaWAN®, o WM1302 desbloqueia um potencial de capacidade muito maior de transmissão sem fio de longa distância para produtos de gateway. Ele apresenta maior sensibilidade, menor consumo de energia e temperatura de operação mais baixa do que os chips LoRa® anteriores SX1301 e SX1308.

WM1302 Pi HAT suporta o formato mini-PCIe do módulo WM1302 e pode configurar automaticamente os dedos dourados padrão de 52 pinos para o conector GPIO do Raspberry Pi com um cabeçalho compatível de 40 pinos. Isso simplifica o processo de desenvolvimento para que os usuários integrem com Raspberry Pi. WM1302 Pi HAT funciona como uma placa de extensão e ajuda a adicionar a funcionalidade do SX1302 ao Raspberry Pi, para suportar os protocolos LoRaWAN e LoRa para transmissão sem fio de longa distância. O módulo GPS integrado também aumenta a precisão do tempo e da localização do módulo WM1302.

WM1302 Pi HAT, juntamente com o Módulo Gateway WM1302 e o Raspberry Pi, pode ajudar a construir gateways de comunicação sem fio LoRaWAN muito completos e compactos, suportando agricultura inteligente, cidades inteligentes e outros cenários de IoT.

## Recursos

- Fator de forma padrão Pi Hat com cabeçalho de pinos fêmea de 40 pinos

- Compatível com Raspberry Pi 3 Model B+/ Raspberry 4

- Módulo GPS integrado

- Chip de autenticação LoRaWAN integrado
