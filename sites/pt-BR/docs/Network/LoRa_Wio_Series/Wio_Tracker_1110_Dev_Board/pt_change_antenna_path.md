A placa de desenvolvimento Wio Tracker 1110 utiliza a antena LoRa onboard por padrão; para obter um sinal melhor, podemos precisar de uma antena externa. Este capítulo orientará os usuários a alterar o caminho da antena para conectar uma antena LoRa externa.

- Remova `R3`.
- Altere `R4` para 0R.
