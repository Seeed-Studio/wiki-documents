## Início rápido com o Mini Router

### OpenWrt pré-instalado

O Compute Module 4 vem com o <a href="https://wiki.seeedstudio.com/pt-br/OpenWrt-Getting-Started/" target="_blank"><span>Firmware OpenWrt</span></a> pronto para uso. Isso significa que você só precisa abrir a embalagem, retirar a placa, conectá-la à sua rede doméstica existente e terá o seu próprio mini roteador!

OpenWrt é um sistema operacional Linux de código aberto que roda em dispositivos/ roteadores embarcados. Ele oferece mais recursos, desempenho e segurança do que um roteador tradicional. Possui um sistema de arquivos totalmente gravável e inclui um sistema de gerenciamento de pacotes. Você pode fazer uso desses pacotes para atender às suas aplicações de várias maneiras. Depois de conectar esta placa à sua rede doméstica e acessar o roteador a partir de um navegador da web, você verá um painel bonito e interativo como o seguinte.

## 2 Passos para rodar o Mini Router com OpenWrt

**Hardware necessário**

Você precisa preparar o seguinte hardware antes de começar com OpenWRT no Mini Router
- 1 x Mini Router
- 1 x Fonte de alimentação (5V/3A) com cabo USB Type-C
- 2 x Cabos Ethernet

**Instruções**

Depois que os cabos Ethernet estiverem conectados,
- **Passo 1.** Ligue a placa
- **Passo 2.** Abra um navegador da web e digite 192.168.2.1
Você verá aqui a interface web Luci do OpenWrt. A imagem OpenWrt compilada pela Seeed inclui muitos pacotes prontos para uso. Assim, você pode usar esses pacotes para realizar muitas aplicações!
