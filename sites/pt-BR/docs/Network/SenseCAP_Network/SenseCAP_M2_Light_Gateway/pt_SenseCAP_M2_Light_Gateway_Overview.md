**Várias** **Bandas** **de** **Frequência** **e** **Certificados**

O SenseCAP M2 oferece diferentes versões de bandas de frequência e certificados correspondentes para atender aos requisitos da sua aplicação em vários países e regiões, incluindo, mas não se limitando a: Austrália (RCM), Brasil (Anatel), Canadá (ICES/IC IC), UE (CE/RoHS/REACH/WEEE/VerpackG), Índia (WPC), Japão (TELEC/PSE), Coreia    (KC), Filipinas (NTC), Taiwan (BSMI/NCC) e Estados Unidos (FCC).

Certificações adicionais também são esperadas.

**Desempenho** **Excelente** **e** **Estável**

Com hardware maduro apresentando o chip LoRa de banda base MediaTek MT7628 e Semtech SX1302/SX1303, o SenseCAP M2 oferece desempenho excelente e estável com BLE integrado e suporte para conexão de internet via Wi‑Fi e Ethernet.

Para usuários que precisam alimentar o gateway via Ethernet em vez de um cabo de alimentação extra, ele suporta PoE, portanto, não há necessidade de um [divisor PoE](https://www.seeedstudio.com/PoE-Splitter-DC-Jack-12V-p-5427.html) adicional. Se o seu roteador não suportar a função PoE, o [SenseCAP Injector](https://www.seeedstudio.com/SenseCAP-PoE-Injector-48V-US-p-5462.html) também está disponível para você.

**Cobertura** **Ampla** **e** **Sinal** **Forte**

Para aprimorar a cobertura e a intensidade do sinal do SenseCAP M2, ele vem equipado com uma antena de alto desempenho de 3 dBi, que pode fornecer cobertura de longo alcance de milhas na rede LoRaWAN. Além disso, a antena pode ser atualizada para uma [antena de fibra de vidro](https://www.seeedstudio.com/catalogsearch/result/?q=fiberglass%20antenna) de dBi mais alto para atender a vários cenários e ambientes de uso.

**Ferramentas** **Profissionais** **de** **Gerenciamento** **e** **Serviços** **em** **Nuvem**

O SenseCAP Hotspot oferece uma solução sem complicações para configurar e gerenciar um hotspot. Os usuários podem configurar facilmente o hotspot em algumas etapas simples por meio do aplicativo SenseCAP Hotspot. O Painel SenseCAP Hotspot e o SenseCAP Local Console também foram desenvolvidos para que os usuários monitorem e gerenciem o Hotspot de maneira eficiente e simples.

![](https://files.seeedstudio.com/wiki/SenseCAP/LoRaWAN_Gateway/image4.png)

**Seguro** **e** **Confiável**

Para um gateway que lida com grandes cargas de transmissão de dados, a segurança nunca é algo em que se preocupe demais. O SenseCAP M2 utiliza o chip de segurança ECC608 para fornecer autenticação confiável e segura, garantindo uma conexão segura e estável com a People's Network.

**Suporte** **On-line** **Eficiente** **e** **Pontual**

A SenseCAP recebeu muitos elogios dos clientes por seu suporte técnico de primeira linha. Se você encontrar um problema técnico, pode contar com o eficiente serviço de suporte técnico on-line da SenseCAP para fornecer assistência rápida e eficaz. Com o excepcional suporte ao cliente da SenseCAP, você pode confiar que receberá a ajuda necessária para manter seus dispositivos e serviços funcionando sem problemas.

**Atualize** **para** **Hotspot** **Externo** **Facilmente**

A [SenseCAP Outdoor Enclosure](https://www.seeedstudio.com/SenseCAP-Outdoor-Enclosure-p-5353.html), que se adapta aos hotspots gerais do mercado, também está disponível para você atualizar seu hotspot SenseCAP interno para um externo, o que possibilita a concretização de vários cenários de aplicação LoRaWAN ao ar livre.

Etapas simples com todos os acessórios necessários para atualizar seus gateways internos para externos, sendo também adequada para outros hotspots, como SenseCAP M1, SenseCAP M2, BobCat, RAK, Helium hotspot, etc.

**Nota:**

O slot para cartão MicroSD é reservado para uso futuro. Nenhum cartão Micro SD é necessário para o SenseCAP M2 como gateway LoRaWAN.

O slot para cartão Nano SIM só estará disponível em hotspots da versão 4G. O cartão SIM não está incluído no dispositivo. A interface Type‑C é reservada para gerenciamento avançado de desenvolvedores. Por favor, não a utilize para alimentar o dispositivo.
