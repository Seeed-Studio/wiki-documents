## FAQ

### Uma licença SenseCAP é necessária para o funcionamento normal do SenseCAP M2?

Sim. A licença do SenseCAP M2 é necessária para a funcionalidade do light hotspot. Se a licença do seu SenseCAP M2 tiver expirado, seu hotspot não poderá transferir pacotes nem atualizar para o firmware mais recente. Certifique-se de verificar o período de validade da licença regularmente.

### Quando o SenseCAP M2 light hotspot expira, preciso comprar novamente o cartão físico de resgate?

Não, você pode adquirir a licença de software SenseCAP M2 no SenseCAP Dashboard e aplicar a licença ao seu dispositivo online.

### Qual é a diferença entre a Helium Onboarding Fee e a licença SenseCAP?

A Helium Onboarding Fee é uma taxa imposta pela Helium para integrar o hotspot ao servidor Helium. Essa taxa já foi incluída no pacote do SenseCAP Hotspot. Além disso, é necessária uma licença de software SenseCAP para ativar o software SenseCAP e os serviços em nuvem.

### Por que meu hotspot pisca luz branca depois de ser integrado à Helium?

Uma luz branca lenta significa que o seu SenseCAP M2 não possui uma licença válida. Acesse o dashboard para resgatar a licença que você comprou com o SenseCAP M2. Para futuras renovações de licença, você pode comprá-las e aplicá-las diretamente pelo SenseCAP Dashboard.

### A licença no cartão de resgate pode ser reutilizada para múltiplos SenseCAP M2 light hotspots?

Não, um cartão de resgate resgata e se aplica apenas à licença de um único SenseCAP M2 light hotspot
