**O que é o SenseCAP M2 Data Only**

SenseCAP M2 Data Only é um Gateway LoRaWAN conectado à Helium LongFi Network e capaz de fornecer quilômetros de cobertura de rede sem fio e capacidade de transmissão de dados para dispositivos de Long Range / LoRaWAN.

Como um gateway LoRaWAN, ele é capaz de fornecer quilômetros de cobertura de rede sem fio e capacidade de transmissão de dados para dispositivos de Long Range / LoRaWAN.

Como um gateway que oferece suporte à Helium LongFi Network, ele pode ajudá-lo a construir a rede LoRaWAN local e desenvolver várias aplicações LoRaWAN com baixo custo, enquanto desfruta dos benefícios de fazer parte da People's Network.

SenseCAP M2 está agora disponível nas versões US915 e EU868 com certificados FCC e CE. E em breve terá mais versões de bandas de frequência e certificados correspondentes disponíveis para diferentes países e regiões.

**Recursos**
============

![](https://www.sensecapmx.com/wp-content/uploads/2022/07/sensecap-m2-DO-features.png)

**· Cobertura de longo alcance e sinal forte**

Com uma antena de alto desempenho de 3dBi, o SenseCAP M2 pode fornecer quilômetros de cobertura LoRaWAN e um sinal forte. E você sempre pode atualizar a antena para se adequar ao seu cenário de uso com base em diferentes ambientes.

**· Desempenho excelente e estável**

O SenseCAP M2 é alimentado pela solução de hardware madura MT7628 e pelo chip Long Range baseband Semtech SX1302/SX1303. Ele possui BLE integrado e suporta conexão à internet tanto por Wi‑Fi quanto por Ethernet. Para usuários que precisam alimentar o gateway via Ethernet em vez de um cabo de alimentação extra, o recurso PoE também foi adicionado ao M2.

**· Ferramentas profissionais de gerenciamento e serviços em nuvem**

Os usuários podem configurar facilmente o hotspot em algumas etapas simples por meio do aplicativo SenseCAP Hotspot. O SenseCAP Hotspot Dashboard e o SenseCAP Local Console também foram desenvolvidos para que os usuários monitorem e gerenciem o Hotspot de maneira eficiente e simples.

**· Suporte online eficiente e oportuno**

Além dessas ferramentas profissionais de gerenciamento e serviços em nuvem, a SenseCAP tem sido altamente elogiada pelos clientes por seu suporte técnico. Sempre que encontrar um problema técnico, o serviço eficiente de suporte técnico online está sempre disponível para ajudá-lo de forma oportuna.

**· Seguro e confiável**  
Para um gateway que lida com grandes cargas de transmissão de dados, segurança nunca é algo em excesso para se preocupar. O SenseCAP M2 Data Only sempre garante autenticação de alta segurança e conectividade confiável à People's Network.、

**· Configuração fácil em etapas simples**

Pronto para uso com o aplicativo SenseCAP Hotspot em etapas simples

**Acessórios ricos**

Além dos recursos poderosos do próprio dispositivo SenseCAP, a SenseCAP vem oferecendo opções ricas de acessórios para que os usuários obtenham o máximo desempenho dos Hotspots. Como, por exemplo, as antenas IoT de alto desempenho mais vendidas, cabos de antena, suportes de montagem e para-raios.

**Conteúdo da embalagem**
====================

- SenseCAP M2 LoRaWAN Indoor Gateway \*1
- Adaptador de energia (EU/US) \*1
- Antena de 3dBi com base \*1
- Guia de início rápido \*1

**Observação:**

**Observe que as taxas de onboarding NÃO estão incluídas no produto. Uma taxa de onboarding de US\$ 0,50 e uma taxa de localização (location asserting) de US\$ 0,50 serão deduzidas das carteiras dos usuários para o onboarding**. Certifique-se de que você tenha crédito de dados Helium (Helium Data Credit) suficiente e pelo menos US\$ 1 em SOL na Wallet ao prosseguir com o processo de onboarding.

**Interface**
=============

![](https://www.sensecapmx.com/wp-content/uploads/2022/07/插图-01.jpg)

**Observação:**

- O slot para cartão MicroSD está reservado para uso futuro. Não é necessário cartão Micro SD para o SenseCAP M2 como gateway LoRaWAN.
- O slot para cartão Nano SIM estará disponível apenas na versão hotspot 4G. O cartão SIM não está incluído no dispositivo.
- A interface Type‑C está reservada para gerenciamento avançado de desenvolvedores. Não a utilize para alimentar o dispositivo.
