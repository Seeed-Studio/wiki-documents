**O que é o SenseCAP M2 Data Only**

SenseCAP M2 Data Only é um gateway LoRaWAN conectado à Helium LongFi Network e capaz de fornecer muitos quilômetros de cobertura de rede sem fio e capacidade de transmissão de dados para dispositivos de Long Range /LoRaWAN.

Como um gateway LoRaWAN, ele é capaz de fornecer muitos quilômetros de cobertura de rede sem fio e capacidade de transmissão de dados para dispositivos de Long Range /LoRaWAN.

Como um gateway que suporta a Helium LongFi Network, ele pode ajudar você a construir a rede LoRaWAN local e desenvolver várias aplicações LoRaWAN com baixo custo, enquanto desfruta dos benefícios de fazer parte da People's Network.

SenseCAP M2 agora oferece versões US915 e EU868 com certificações FCC e CE. E terá mais versões de faixas de frequência e certificações correspondentes disponíveis para diferentes países e regiões em um futuro próximo.

**Recursos**
============

![](https://www.sensecapmx.com/wp-content/uploads/2022/07/sensecap-m2-DO-features.png)

**· Cobertura de longo alcance e sinal forte**

Com uma antena de alto desempenho de 3dBi, o SenseCAP M2 pode fornecer quilômetros de cobertura LoRaWAN e um sinal forte. E você sempre pode atualizar a antena para se adequar ao seu cenário de uso com base em diferentes ambientes.

**· Desempenho excelente e estável**

SenseCAP M2 é alimentado pela solução de hardware madura MT7628 e pelo chip Long Range de banda base Semtech SX1302/SX1303. Ele possui BLE integrado e suporta conexão à internet tanto por Wi‑Fi quanto por Ethernet. Para usuários que precisam alimentar o gateway pela Ethernet em vez de um cabo de fonte de alimentação extra, o recurso PoE também foi adicionado no M2.

**· Ferramentas de gerenciamento profissionais e serviços em nuvem**

Os usuários podem configurar facilmente o hotspot em algumas etapas simples por meio do aplicativo SenseCAP Hotspot. O SenseCAP Hotspot Dashboard e o SenseCAP Local Console também foram desenvolvidos para que os usuários monitorem e gerenciem o Hotspot de maneira eficiente e simples.

**· Suporte online eficiente e oportuno**

Além dessas ferramentas profissionais de gerenciamento e serviços em nuvem, a SenseCAP tem sido altamente elogiada pelos clientes por seu suporte técnico. Sempre que você encontrar um problema técnico, o serviço eficiente de suporte técnico online estará sempre aqui e oferecerá suporte em tempo hábil.

**· Seguro e confiável**  
Para um gateway que lida com grandes quantidades de transmissão de dados, a segurança nunca é uma preocupação demais. SenseCAP M2 Data Only sempre garante autenticação de alta segurança e conectividade confiável à People's Network.、

**· Configuração fácil em etapas simples**

Pronto para uso com o aplicativo SenseCAP Hotspot em etapas simples

**Acessórios ricos**

Além dos poderosos recursos do próprio dispositivo SenseCAP, a SenseCAP vem oferecendo ricas opções de acessórios para que os usuários obtenham o desempenho máximo dos Hotspots. Como os acessórios mais vendidos de antenas IoT de alto desempenho, cabos de antena, bases de montagem e protetores contra surtos (lightning arrestors).

**Interface**
=============

![](https://www.sensecapmx.com/wp-content/uploads/2022/07/插图-01.jpg)

**Observação:**

- O slot para cartão MicroSD é reservado para uso futuro. Nenhum cartão Micro SD é necessário para o SenseCAP M2 como gateway LoRaWAN.
- O slot para cartão Nano SIM estará disponível apenas na versão hotspot 4G. O cartão SIM não está incluído no dispositivo.
- A interface Type‑C é reservada para gerenciamento avançado por desenvolvedores. Por favor, não a use para alimentar o dispositivo.
