O SenseCAP M2 Multi-Platform LoRaWAN Gateway é um gateway LoRaWAN® padrão que oferece suporte à conexão com diferentes servidores de rede. Ele suporta planos de frequência LoRaWAN® globais de 865 MHz a 923 MHz e pode ser usado em múltiplas aplicações LoRaWAN®, como edifícios inteligentes, sistemas de monitoramento ambiental, agricultura de precisão, etc. Possui ampla cobertura e forte capacidade de saída de sinal, entre outros recursos, tornando‑o o gateway perfeito para construir uma rede LoRaWAN®.

:::tip Observação

- O SenseCAP M2 Multi-Platform LoRaWAN® Gateway não suporta a rede Helium. Ele **não pode** ser conectado ao SenseCAP Hotspot APP e ao SenseCAP Dashboard.
- Entre em contato com a equipe SenseCAP MX no canal oficial do [**SenseCAP MX Community Discord**](https://discord.com/invite/sensecap) para suporte técnico.
:::

### Principais Recursos

- **Suporta múltiplos servidores de rede LoRaWAN®:** Compatível com múltiplos LNS como AWS, TTN, ChirpStack, etc., utilizando o modo Packet Forwarder / Basics™ Station.
- **Servidor de rede LoRaWAN integrado**: Fornece uma solução rápida e confiável para iniciar uma rede LoRaWAN.
- **Suporte a Power-over-Ethernet (PoE):** Para usuários que precisam alimentar o gateway pela Ethernet em vez de um cabo de alimentação extra, o recurso PoE também foi adicionado a este dispositivo, tornando sua implantação mais confiável e rápida.
- **Ampla cobertura e sinal forte:** Fornece até 10 km de cobertura LoRaWAN® e sinal forte, permitindo que os usuários enviem dados a distâncias extremamente longas com baixas taxas de dados.
- **Desempenho excelente e estável:** O gateway é alimentado pela solução de hardware madura MT7628 e pelo chip baseband Long Range Semtech SX1302. Ele suporta conexão à internet via celular (opcional), Wi‑Fi e Ethernet.
- **Ferramentas profissionais de gerenciamento e serviços em nuvem:** Os usuários podem configurar facilmente o gateway em apenas alguns passos simples por meio da interface web. SenseCAP Portal e SenseCAP Local Console também foram desenvolvidos para que os usuários monitorem e gerenciem o gateway de forma eficiente e fácil.

### Descrição

O SenseCAP M2 Multi-Platform LoRaWAN® Gateway é um gateway LoRaWAN® padrão que oferece suporte à conexão com diferentes servidores de rede.

Como um gateway LoRaWAN®, ele é capaz de fornecer quilômetros de cobertura de rede sem fio e capacidade de transmissão de dados para seus dispositivos LoRaWAN®.

O SenseCAP M2 Multi-Platform LoRaWAN® Gateway suporta múltiplas aplicações, como agricultura inteligente, cidade inteligente ou qualquer projeto inteligente que exija adensamento de rede, oferecendo uma combinação única de cobertura superior e excelência operacional.

O Gateway pode ser configurado facilmente assim que sai da caixa. Os usuários podem vincular e gerenciar o dispositivo por meio do **SenseCAP Mate APP** e do **[SenseCAP Portal](https://sensecap-docs.seeed.cc/quickstart.html)** em 4 etapas. Depois disso, os usuários podem começar a configurar os sensores da mesma forma para criar soluções de rede LoRaWAN®.

1. Escanear o código QR para vincular o dispositivo
2. Conectar o gateway à internet e ligar
3. Verificar o status do gateway na plataforma SenseCAP
4. Conectar os sensores à rede e enviar dados para a nuvem
