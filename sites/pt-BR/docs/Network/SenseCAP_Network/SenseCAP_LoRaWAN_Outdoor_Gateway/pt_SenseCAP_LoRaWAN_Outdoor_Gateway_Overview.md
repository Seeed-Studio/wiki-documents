### DETALHES DO PRODUTO

O SenseCAP Gateway - LoRaWAN é um produto industrial externo com classificação IP66, que suporta uma faixa estendida de temperatura de operação, tornando-o aplicável a cenários de IoT de coleta de dados de longo alcance e baixo consumo de energia, como agricultura inteligente.

:::tip
Esteja ciente de que este produto não é compatível com a rede Helium LongFi. Observe que produtos sem qualquer defeito de qualidade não são elegíveis para devolução e reembolso.
:::

### Principais Recursos

- Processador Cortex A8 1GHz de alto desempenho, sistema Linux.

- Suporta o protocolo LoRaWAN Classe A, suporta o sensor SenseCAP de ultrabaixo consumo de energia

- Suporta transceptor com 8 RX e 1 TX, potência máxima de transmissão de 27dBm

- Suporta múltiplas bandas ISM: CN470, EU868, US915

- Suporta múltiplos métodos de acesso à rede: 4G, Ethernet

- Transmissão de distância ultralonga: 10 km em cenário com linha de visada, 2 km em cenário urbano

- Proteção de nível industrial: gabinete IP66, temperatura de -40℃~70℃, adequado para aplicações externas

- Implantação fácil e provisionamento rápido (veja o vídeo "how to install" abaixo)

### Descrição

O SenseCAP Gateway - LoRaWAN é baseado no protocolo LoRaWAN, aplicável para coleta de dados ambientais de longo alcance e baixo consumo de energia e para cenários de monitoramento remoto, como agricultura inteligente e cidade inteligente.

Como o dispositivo central da rede LoRaWAN SenseCAP, o gateway é usado para coletar dados de diferentes [SenseCAP Sensors](https://www.seeedstudio.com/catalogsearch/result/?q=SenseCAP+Sensor "SenseCAP Sensor") e transmitir os dados para a plataforma em nuvem via LTE celular ou Ethernet. Equipado com um processador de alto desempenho AM3358 e um chip Long Range de nível de operadora SX1301, este dispositivo garante robustez e alto desempenho em redes de grande escala. Autenticação mútua e criptografia são estabelecidas em toda a rede para aumentar a segurança.

O gateway é projetado com um gabinete IP66 e suporta uma faixa estendida de temperatura de operação, tornando-o adequado para aplicações industriais em ambientes internos e externos severos.

O Gateway pode ser configurado facilmente fora da caixa. Os usuários podem vincular e gerenciar o dispositivo por meio do **SenseCAP Mate APP** e do **[SenseCAP Portal](https://sensecap-docs.seeed.cc/quickstart.html)** em 4 passos. Depois disso, os usuários podem começar a configurar os sensores da mesma maneira para criar as soluções de rede LoRaWAN®.

1. Escanear o código QR para vincular o dispositivo
2. Conectar o gateway à internet e ligá-lo
3. Implantação do dispositivo
4. Conectar os sensores à rede e enviar dados para a nuvem
