### Ride Trace

### Gateway Wio Tracker L1

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage4.png" alt="Wio Tracker L1 Gateway" width={800} height="auto" /></p>

### Meshy: Um Case 3D Robusto para Wio Tracker L1 E-ink

<p style={{textAlign: 'center'}}><img src="https://files.seeedstudio.com/wiki/wiki%20images/3d%20Enclosure/6.23dimage7.png" alt="Meshy 3D-printed case for Wio Tracker L1 E-ink" width={800} height="auto" /></p>

<p style={{textAlign: 'center', fontSize: '0.85rem'}}><strong>Fonte:</strong> <a href="https://www.hackster.io/akashedamana/meshy-wio-tracker-l1-e-ink-3d-printed-case-affad1" target="_blank" rel="noopener noreferrer">meshy-wio-tracker-l1-e-ink-3d-printed-case-affad1</a></p>

Este é um case protetor impresso em 3D para o Wio Tracker L1 E-ink, projetado para melhorar a durabilidade, portabilidade e conveniência de fixação para uso externo e no dia a dia. Seu design paramétrico suporta diferentes tamanhos de bateria e estruturas de montagem, e inclui um suporte de encaixe para cintos, mochilas ou equipamentos MOLLE.

**Quem fez:** [Akash](https://www.hackster.io/akashedamana)

**Onde baixar:** [a360](https://a360.co/3KNHxqQ)
