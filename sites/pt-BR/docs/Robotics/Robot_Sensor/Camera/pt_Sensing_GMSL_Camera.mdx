Esses 4 canais são rotulados como **'A'**, **'B'**, **'C'** e **'D'** no dispositivo,
recomendamos aos nossos clientes conectar a câmera seguindo a ordem alfabética,
nesse caso, seus dispositivos de vídeo serão mapeados como **'/dev/video0'**, **'/dev/video1'**, **'/dev/video2'**, **'/dev/video3'** no seu Jetson Linux, respectivamente。

Mas se você tiver apenas uma câmera conectada, apenas 'video0' será exibido。

Em seguida, vamos configurar o overlay da árvore de dispositivos com o Jetson IO para habilitar nosso dispositivo (você não verá nós de vídeo na pasta **'/dev'** até configurá-lo e reiniciar)。

### Configurar Jetson IO

Inicie o JetsonIO com 

``` sh
sudo /opt/nvidia/jetson-io/jetson-io.py
```

### Configurar Informações de Vídeo

Caso você ainda não tenha instalado o `v4l-utils`

``` sh
sudo apt-get update 
sudo apt-get install v4l-utils -y
```

+ Sincronização de Quadros

``` sh
v4l2-ctl -d /dev/video0 --set-ctrl=trig_mode=1
```

:::note
Você pode alternar **'trig_mode=0'** para desativar a sincronização de quadros. Ou usar **'trig_mode=1'** para ativar a sincronização de quadros quando tiver múltiplas câmeras conectadas。
:::


+ Formato de Vídeo

``` sh
v4l2-ctl -V --set-fmt-video=width=1920,height=1536 -c sensor_mode=0  -d /dev/video0
```

:::note
Dependendo de qual câmera você está usando, pode haver diferentes 'sensor_mode' pré-definidos aqui, principalmente:

|Sensor Mode|Frame Type|
|   :----:  | :----:   |
|0|YUYV8_1X16/1920x1536|
|1|YUYV8_1X16/1920x1080|
|2|YUYV8_1X16/3840x2160|


:::

### Gst Launch

Inicie o visualizador com `gst-launch-1.0`

``` sh
gst-launch-1.0 v4l2src device=/dev/video0 ! \
    video/x-raw,format=YUY2,width=1920,height=1080,framerate=30/1 ! \
    videoconvert ! videoscale ! xvimagesink
```
