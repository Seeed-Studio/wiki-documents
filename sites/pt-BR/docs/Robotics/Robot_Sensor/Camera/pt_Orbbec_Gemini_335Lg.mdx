O Gemini 335Lg é um modelo de destaque da série Gemini 330, servindo como a versão GMSL2/FAKRA do comprovado Gemini 335L na indústria.

O serializador GMSL2 combinado com o conector FAKRA garante conectividade segura e confiável para robôs móveis autônomos (AMRs) que navegam em ambientes complexos e braços robóticos que exigem cabeamento flexível.

## Especificações

<Orbbec335LgTable lang="pt" />

<p>[1] Alcance máximo teórico de profundidade de até 65 metros;</p>
<p>[2] Dados medidos durante a calibração de fábrica;</p>
<p>[3] O nível padrão de energia do laser do Gemini 335Lg é definido como Nível 4 para reduzir o consumo de pico de energia e evitar falhas operacionais. Quando houver energia suficiente disponível, os usuários podem ajustar manualmente o laser para o Nível máximo 6 para obter desempenho ideal;</p>
<p>[4] Tanto o Gemini 335L quanto o 335Lg exigem o uso de cabos compatíveis com IP65 durante a operação para alcançar proteção IP65;</p>
<p>[5] Não mais que 16h de operação por dia.</p>


## Configuração do Dispositivo

Neste tutorial, demonstramos conexões USB 3 e GMSL2. Especificação do dispositivo host:

+ reComputer Robotics J4012 com GMSL
+ JetPack 6.2 (Ubuntu 22.04)

:::note
Para tutoriais em Windows/Linux x86_64, ou MacOS (x86_64, potencialmente Apple Silicon), consulte o README do [repositório SDK](https://github.com/orbbec/OrbbecSDK_v2)
:::

### Baixar e Instalar o Orbbec Viewer

+ Abra um terminal no seu dispositivo Jetson e baixe o pacote pré-compilado do release no GitHub.

```sh
wget -L https://github.com/orbbec/OrbbecSDK_v2/releases/download/v2.4.8/OrbbecSDK_v2.4.8_arm64.deb
```

+ Instalar o SDK

```sh
sudo dpkg -i OrbbecSDK_v2.4.8_arm64.deb
```

<Flex justify="center">
  <Image width={600} src="https://files.seeedstudio.com/wiki/robotics/Sensor/Camera/Orbbec_Gemini_335lg/Install_Orbbec_SDK.webp" />
</Flex>

+ Visualização usando o Orbbec Viewer, baixar

```sh
wget -L https://github.com/orbbec/OrbbecSDK_v2/releases/download/v2.4.8/OrbbecViewer_v2.4.8_202507031357_a1355db_linux_aarch64.zip
```

+ Extrair o conteúdo

```sh
# Caso você não tenha instalado 'unzip'
# sudo apt-get update && sudo apt-get install unzip

unzip OrbbecViewer_v2.4.8_202507031357_a1355db_linux_aarch64.zip
```

+ Iniciar o Orbbec Viewer

```sh
cd OrbbecViewer_v2.4.8_202507031357_a1355db_linux_aarch64
./OrbbecViewer
```

### Conexão GMSL2

Defina o DIP switch na parte superior da câmera (remova primeiro a tampa metálica) para a posição da letra **'M'**.

  margin: '24px 0',

  src="https://files.seeedstudio.com/wiki/robotics/Sensor/Camera/Orbbec_Gemini_335lg/GMSL2_DIP_Switch.webp" />

O que você pode precisar:

+ [Um cabo Mini-Fakra](https://www.seeedstudio.com/Mini-fakra-Coaxial-Cable-4-in-1-0-5m-Female-to-Female-p-6484.html)
+ [Placa de extensão GMSL2 reComputer Robotics](https://www.seeedstudio.com/reComputer-Robotics-GMSL-board-p-6511.html)

Conecte a câmera e inicie o Jetson IO no seu dispositivo com

```sh
sudo /opt/nvidia/jetson-io/jetson-io.py
```
