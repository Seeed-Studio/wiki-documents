# Tirar foto

Este exemplo demonstra como capturar um único quadro da câmera do Reachy Mini e salvá-lo como um arquivo de imagem.

Execute com:
```bash
python take_picture.py --backend [default|local|webrtc]
```

A imagem capturada será salva como `reachy_mini_picture.jpg` no diretório atual.

Veja o exemplo completo em: [take_picture.py](https://github.com/pollen-robotics/reachy_mini/tree/main/examples/take_picture.py)
