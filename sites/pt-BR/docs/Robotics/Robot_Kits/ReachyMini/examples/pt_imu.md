# IMU

Este exemplo demonstra como acessar os dados do sensor IMU (acelerômetro, giroscópio, orientação por quaternions e temperatura) a partir de um Reachy Mini sem fio.

Observação: a IMU está disponível apenas na versão sem fio do Reachy Mini.

Veja o exemplo completo em: [imu_example.py](https://github.com/pollen-robotics/reachy_mini/tree/develop/examples/imu_example.py)
