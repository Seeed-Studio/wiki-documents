# Playground de Interpolação Goto

Este código demonstra os diferentes métodos de interpolação disponíveis no Reachy Mini para mover a cabeça e/ou as antenas até uma pose-alvo. Ele testa vários métodos, como linear, minjerk, ease_in_out e cartoon, permitindo observar como cada método afeta o movimento da cabeça e das antenas.

Veja o exemplo completo em: [goto_interpolation_playground.py](https://github.com/pollen-robotics/reachy_mini/tree/develop/examples/goto_interpolation_playground.py)
