# Visão geral da placa controladora de ePaper

## Introdução

A série de placas controladoras de ePaper é projetada para aplicações versáteis de ePaper de baixo consumo. Essas placas suportam uma ampla gama de telas de ePaper — desde telas universais de 24 pinos e 50 pinos até telas especializadas de grande formato, como 10,3” (atualização em alta velocidade) e 13,3” (Spectra™ 6). Cada placa compartilha funcionalidades centrais, incluindo um conector de bateria JST 2,0 mm com interruptor de energia, CI de carregamento integrado, botão de reset e três botões configuráveis pelo usuário. Alimentadas por diversos microcontroladores (por exemplo, XIAO ESP32-S3 Plus, XIAO nRF52840 Plus), alguns modelos também contam com recursos NFC, tornando-as ideais para sinalização digital, etiquetas eletrônicas de prateleira, painéis portáteis e outros projetos de display energeticamente eficientes.

A **EE02** é uma placa controladora de tela E-ink de alto desempenho, projetada especificamente para telas de papel eletrônico de **13,3 polegadas**. Alimentada pelo chip ESP32-S3, ela oferece suporte a conectividade Wi-Fi e Bluetooth, tornando-se uma solução ideal para aplicações de display sem fio.

### Características

- **Controlador poderoso**: Baseada no ESP32-S3, oferecendo capacidade robusta de processamento e recursos sem fio.
- **Dedicada a telas grandes**: Otimizada especificamente para acionar telas E-ink de 13,3 polegadas com alta estabilidade e nitidez.
- **Conectividade sem fio**: Suporta Wi-Fi e Bluetooth 5.0 (LE), permitindo atualizações remotas de dados e integração com a nuvem.
- **Baixo consumo de energia**: Projetada para eficiência energética, adequada para aplicações alimentadas por bateria.
- **Integração fácil**: Compatível com SenseCraft HMI para design de interface por arrastar e soltar e gerenciamento remoto.
- **Interfaces versáteis**: Inclui Type-C para alimentação/programação e conectores padrão para telas E-ink.

- **Botões fáceis de usar:** Possui 1 botão de reset e 3 botões programáveis pelo usuário, proporcionando flexibilidade para acelerar projetos e funções personalizáveis.
