O Grove Starter Kit para Wio LTE é uma escolha simples e econômica para você começar rapidamente com a placa Wio LTE. Grove é um conjunto de ferramentas pronto para uso, open source, otimizado para simplicidade e prototipagem rápida. Integramos 6 interfaces Grove na [placa Wio LTE](https://www.seeedstudio.com/s/wio%20lte.html), o que significa que você não precisa de uma placa de expansão desta vez, basta conectar o módulo e começar a utilizá‑lo. Atualmente existem mais de 150+ Groves diferentes; se você não estiver familiarizado com Grove, este kit é definitivamente uma escolha perfeita.

O kit inclui sete módulos Grove bem selecionados por nós. Há um sensor de luz e um sensor de temperatura e umidade que podem monitorar a luz ambiente, temperatura e umidade, um sensor acelerômetro digital que pode detectar dados de movimento, atuadores como relé e entradas e saídas digitais como botão e buzzer. Eles são simples, mas com funções completas para aprendizado e prototipagem rápida.

## Primeiros Passos

### Fundamentos com Arduino

Você precisa conhecer alguns conhecimentos essenciais se esta é a primeira vez que você se envolve com Arduino. Preparamos algumas documentações para que você possa começar a usar o
Arduino de forma rápida e eficaz. Você pode visitar [https://www.arduino.cc/en/Tutorial/Foundations](https://www.arduino.cc/en/Tutorial/Foundations).

### Sketches Arduino (exemplo básico para cada módulo)

Depois de fazer um LED piscar (para usuários Windows, você pode encontrar em [https://www.arduino.cc/en/Guide/Windows](https://www.arduino.cc/en/Guide/Windows); você pode encontrar outras versões para Mac OS e variantes Linux em
[https://www.arduino.cc/en/Guide/HomePage](https://www.arduino.cc/en/Guide/HomePage) ), você ainda precisa se familiarizar com o sistema Seeedstudio Grove em Grove_System. E agora, você pode fazer alguns questionários mais práticos que são especialmente projetados para este kit. Baixe os sketches dos questionários em [https://github.com/Seeed-Studio/Sketchbook_Starter_Kit_for_Arduino](https://github.com/Seeed-Studio/Sketchbook_Starter_Kit_for_Arduino).
