O Kit de Eventos Wio Link é um kit de monitoramento de eventos que inclui alguns módulos funcionais Grove típicos acionados por eventos para construir dispositivos inteligentes de IoT. A parte mais incrível deste kit é a placa de desenvolvimento Wio Link, que pode ser utilizada para vários dispositivos: sem exigir nenhuma habilidade de programação. Todas as ações que você deseja que seus módulos executem e a operação de gravação de código no Wio Link podem ser concluídas com toques em um aplicativo móvel. E você pode enviar instruções para seus dispositivos pela internet de qualquer lugar. Portanto, o Wio Link será uma ferramenta perfeita para tornar as coisas ao seu redor mais inteligentes para todos. Agora vamos nos familiarizar com alguns módulos acionados por eventos incluídos neste kit.

[![](https://files.seeedstudio.com/wiki/common/Get_One_Now_Banner.png)](https://www.seeedstudio.com/depot/Wio-Link-Event-Kit-p-2611.html)


:::caution
     A função Wio IFTTT está em fim de vida (EOL). Mas o aplicativo Wio APP está disponível. Você pode usar a API do Wio APP para ler o status do sensor e controlar o atuador. 
:::
Características
--------

-   Inclui módulos funcionais comuns de monitoramento de eventos frequentemente usados.
-   Totalmente fácil para tornar as coisas ao seu redor mais inteligentes.
-   Porta Grove integrada, função mais prática e menos trabalho.
-   Peso: 145 g
