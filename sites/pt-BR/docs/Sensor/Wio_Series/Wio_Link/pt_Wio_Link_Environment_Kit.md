Nós estamos sempre intimamente conectados com o ambiente ao nosso redor. Portanto, é importante para nós obter alguns detalhes de um ambiente. Este kit foi projetado para executar essa tarefa perfeitamente, pelo menos em um nível básico. Neste kit, você pode encontrar módulos funcionais comuns para coletar dados do ambiente em nossa casa, como umidade ou nível de luz em ambientes internos. A parte mais surpreendente deste kit é a placa de desenvolvimento Wio Link, que pode ser utilizada para vários propósitos, sem exigir nenhuma habilidade de programação. Todas as ações que você deseja que seus módulos executem e a operação de gravação de código no Wio Link podem ser concluídas com toques em um aplicativo móvel. E você pode enviar instruções para seus dispositivos pela Internet de qualquer lugar. Portanto, o Wio Link será uma utilidade perfeita para tornar as coisas ao redor mais inteligentes para todos. Então vamos entender melhor as condições em que você se encontra.

[![](https://files.seeedstudio.com/wiki/common/Get_One_Now_Banner.png)](https://www.seeedstudio.com/depot/Wio-Link-Environment-Kit-p-2612.html)


:::caution
     A função Wio IFTTT está em fim de vida (EOL). Mas o Wio APP está disponível. Você pode usar a API do Wio APP para ler o estado do sensor e controlar o atuador. 
:::

--------

-   Inclui módulos funcionais de monitoramento ambiental comuns e frequentemente usados
-   Porta Grove integrada, função mais prática e menos trabalho
-   Custo-benefício
-   Peso: 154 g
