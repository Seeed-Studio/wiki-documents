  # **SenseCAP Indicator X ChatGPT**

ChatGPT é um modelo de IA conversacional desenvolvido pela OpenAI. Ele é especificamente projetado para aplicações de chatbot e foi treinado em um grande corpus de dados conversacionais para permitir que entenda e gere respostas em linguagem natural às entradas do usuário. O ChatGPT tem sido utilizado em várias aplicações, incluindo chatbots de atendimento ao cliente, assistentes virtuais e chatbots de mídias sociais.


O SenseCAP Indicator integra o ChatGPT via API da OpenAI
no firmware nativo, o que pode ajudá-lo a experimentar rapidamente a conversa com o ChatGPT.


## Passo 1. Conexão Wi-Fi

Selecione o Wi-Fi, insira a senha e conecte-se.

## Passo 2. Definir a Chave de API

Clique em "Set API Key" e escaneie o código QR, depois faça a configuração de acordo com o [tutorial](/pt-br/Sensor/SenseCAP/SenseCAP_Indicator/Set_An_API_Key).

<div align="center"><img width={480} src="https://files.seeedstudio.com/wiki/SenseCAP/SenseCAP_Indicator/apikey.png"/></div>




## Passo 3. Comece a se Comunicar com o ChatGPT

Quando você tiver configurado o Wi-Fi e a APIKey, está tudo pronto.

**Pergunte ao ChatGPT tudo o que você quiser saber!**

# **FAQ**

**O dispositivo está conectado ao Wi-Fi, mas ainda exibe "Please check the wifi connection"**

- Tente conectar a outro Wi-Fi ou verifique as configurações do seu roteador.


**Please set the Open AI API key first**

- A API Key não está definida ou a configuração falhou; por favor, defina-a novamente.


**Request fail**

- Verifique se a API Key está correta.
