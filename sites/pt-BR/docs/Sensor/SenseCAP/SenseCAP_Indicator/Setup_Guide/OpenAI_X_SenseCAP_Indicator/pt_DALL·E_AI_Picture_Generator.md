# **SenseCAP Indicator X DALL·E**

DALL-E é um modelo avançado de IA desenvolvido pela OpenAI que pode gerar imagens a partir de descrições textuais. DALL-E foi treinado com um conjunto de dados massivo de imagens e suas respectivas descrições textuais.

Dada uma instrução textual, o DALL-E pode gerar uma imagem única que corresponda à descrição. O modelo demonstrou capacidades impressionantes, como gerar imagens de criaturas, objetos e cenas fictícias que não existem no mundo real. O DALL-E tem aplicações potenciais em vários campos, incluindo arte, design e publicidade.

Siga as Etapas 1 e 2 para configurar o Wi-Fi e a API Key.


**Dê uma descrição em texto e crie sua própria imagem!**

# **FAQ**



**O dispositivo está conectado ao Wi-Fi, mas ainda mostra a mensagem "Please check the wifi connection"**

- Tente conectar a outra rede Wi-Fi ou verifique as configurações do seu roteador.


**Defina primeiro a Open AI API key**

- A API Key não está definida ou a configuração falhou, defina-a novamente.


**Falha na requisição**

- Verifique se a API Key está correta.
