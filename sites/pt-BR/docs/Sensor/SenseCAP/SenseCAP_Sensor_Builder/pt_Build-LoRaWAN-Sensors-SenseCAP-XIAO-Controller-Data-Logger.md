# SenseCAP S2110 Sensor Builder

SenseCAP S2110 Sensor Builder é uma solução inovadora que possibilita a fusão de módulos de nível industrial com módulos de nível maker. É uma ferramenta open-source com capacidade de construir módulos funcionais RS485 com mais de 500 módulos Grove.

<div align="center"><img width={600} src="https://files.seeedstudio.com/wiki/SenseCAP_S2110_builder/SenseCAP-S2110-Sensor-Builder-105.jpg"/></div>

## Visão Geral

### Objeto pequeno, funcionalidade industrial

Ele possui o Seeed Studio XIAO RP2040 como processador dual-core ARM Cortex M0+ e conta com um conector Grove e um conector RS485, permitindo que desenvolvedores se conectem a mais de 500 sensores Grove e vários sensores MODBUS RS485 para desenvolver sensores MODBUS RS485 personalizados de nível industrial para várias aplicações de IoT.

<div align="center"><img width={600} src="https://files.seeedstudio.com/wiki/SenseCAP-S2110/107.jpg"/></div>

### Com LoRaWAN® adicional para transmissão de dados sem fio de longo alcance

Para aplicações sem fio de longo alcance (LoRaWAN®), os desenvolvedores podem facilmente conectá-lo a um [SenseCAP LoRaWAN Data Logger](https://www.seeedstudio.com/SenseCAP-S2100-LoRaWAN-Data-Logger-p-5361.html) para transferir os dados para a SenseCAP Cloud, o que leva apenas 5 minutos de uma simples configuração BLE no aplicativo SenseCAP Mate. Resultados de dados claros e análises adicionais podem ser facilmente obtidos a partir do SenseCAP Dashboard e do aplicativo SenseCAP Mate. Plataformas de IoT como Helium, TTN, LORIOT, etc. também são suportadas.

<div align="center"><img width={800} src="https://files.seeedstudio.com/wiki/SenseCAP_S2110_builder/SenseCAP-S2110-Sensor-Builder-106.jpg"/></div>

## Recursos

- **Construa facilmente sensores Modbus RS485 de nível industrial:** Com código-fonte open-source e gabinete IP66, converta facilmente mais de 500 sensores Grove existentes em sensores Modbus RS485 de nível industrial. Seis dos sensores ambientais Grove mais populares já são totalmente compatíveis com o firmware nativo, com mais por vir
- **Compatível com SenseCAP Data Logger e plataforma de IoT:** Converta para um sensor LoRaWAN® SenseCAP com SenseCAP Data Logger e aproveite a configuração rápida e fácil em apenas 5 minutos com o aplicativo SenseCAP Mate
- **Suporta Data Loggers e plataformas de IoT de terceiros:** Além do SenseCAP Data Logger, os desenvolvedores podem conectar-se a outros data loggers que suportem o protocolo Modbus RS485 e plataformas de IoT de terceiros
- **Gabinete pronto para implantação, de nível industrial para uso externo:** Gabinete externo à prova d’água com classificação IP66, com janela e orifício de ventilação à prova d’água reservado para sensores de luz e gás, também vem com um painel de montagem personalizado, adequado para instalação em poste e parede
- **Alimentado por Seeed Studio XIAO RP2040:** Aproveite o poderoso processador dual-core ARM M0+ do Seeed Studio XIAO RP2040 e os vastos recursos open-source para personalizar o seu próprio sensor. Carregue código facilmente via porta USB-C

<div align="center"><img width={800} src="https://files.seeedstudio.com/wiki/SenseCAP-S2110/108.png"/></div>

O produto vem com um gabinete de nível industrial IP66 e também com os suportes de montagem e conjunto de parafusos, o que permite implantar o sensor em ambientes externos de forma fácil e segura.

## Gravação do Firmware de Fábrica

Agora vamos passar pelas etapas de gravação do firmware no SenseCAP S2110 Sensor Builder. Aqui iremos gravar o firmware inicial de fábrica, baixe [o firmware uf2 mais recente](https://github.com/Seeed-Studio/Seeed_Arduino_S2110/releases) antes de começar.

- **Passo 1:** Desaperte os quatro parafusos da tampa do SenseCAP S2110 Sensor Builder para abrir a tampa e desaperte o conector PG (com uma moeda)

<div align="center"><img width={400} src="https://files.seeedstudio.com/wiki/SenseCAP-S2110/92.jpg"/></div>

- **Passo 2:** Se você já fez a conexão entre o SenseCAP S2110 Sensor Builder e o Data Logger com os 4 fios, é recomendável remover o fio vermelho que se conecta ao pino de 5V do SenseCAP S2110 Sensor Builder

<div align="center"><img width={400} src="https://files.seeedstudio.com/wiki/SenseCAP-S2110/97.jpg"/></div>

- **Passo 3:** Conecte uma extremidade de um cabo USB Type-C ao SenseCAP S2110 Sensor Builder. Enquanto mantém pressionado o botão **B**, conecte a outra extremidade do cabo USB ao PC para entrar no modo de armazenamento em massa.

<div align="center"><img width={400} src="https://files.seeedstudio.com/wiki/SenseCAP-S2110/98.jpg"/></div>

- **Passo 4:** Se o disco **RPI-RP2** for exibido no PC e o LED de alimentação do XIAO estiver aceso, a conexão está concluída.

<div align="center"><img width={400} src="https://files.seeedstudio.com/wiki/SenseCAP-S2110/91.png"/></div>

- **Passo 5:** Copie o arquivo de firmware sensorBuilder.ino.uf2 para o disco **RPI-RP2**.

O disco **RPI-RP2** desaparecerá assim que a gravação do firmware estiver concluída.
