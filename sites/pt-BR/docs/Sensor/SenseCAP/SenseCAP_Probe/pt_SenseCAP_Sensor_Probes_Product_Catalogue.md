## Sobre o SenseCAP

Entre os primeiros lançamentos da série de produtos IIoT da Seeed, o SenseCAP é focado em aplicações de detecção ambiental sem fio: agricultura inteligente, agricultura de precisão e cidades inteligentes, entre outras. Ele é composto por produtos de hardware (sensores, registradores de dados & gateways, etc.), serviços de software (SenseCAP Mate App, SenseCAP Web Portal, dashboard aberto) e API para gerenciamento de dispositivos & dados.

## Sobre as sondas de sensores

Nossa linha de sondas de sensores industriais SenseCAP é projetada para suportar ambientes hostis, como vibração e exposição a produtos químicos e gases, o que é comum em aplicações industriais, e nossa linha industrial de sensores é equipada com sérias classificações de IP de IP66 a IP68 para garantir que os produtos tenham um bom desempenho em seus respectivos ambientes severos.
As sondas de sensores SenseCAP também apresentam conexões de processo para garantir um encaixe seguro no meio sendo medido, juntamente com transmissores de dados de sensores que convertem o sinal para se adequar a sistemas de instrumentação industrial.
Alguns dos Sensores Industriais MODBUS RS485 vêm em duas versões. A principal diferença é o conector do cabo. Escolha a versão que melhor se adapta às suas necessidades:
（1） A versão com fios de ligação é recomendada para uso com o [SenseCAP LoRaWAN® Data Logger](https://www.seeedstudio.com/SenseCAP-S2100-LoRaWAN-Data-Logger-p-5361.html?queryID=82d7de6ca64b8316686bdfe2c05664d2&objectID=5361&indexName=bazaar_retailer_products) para conectar à rede LoRaWAN®, aproveitando os benefícios de comunicação de baixo consumo e longo alcance.
（2）A versão com conector de aviação já pré-configurou o [SenseCAP Sensor Hub 4G Data Logger](https://www.seeedstudio.com/SenseCAP-Sensor-Hub-4G-Data-Logger-with-builtin-battery-p-4852.html?queryID=b8ef1fa7e141765c30033fc3d8eddf10&objectID=4852&indexName=bazaar_retailer_products) com experiência plug-and-play para coletar vários dados de sensores via 3G/4G LTE.
