# Registrador de Dados SenseCAP Sensor Hub

## Introdução ao Produto

SenseCAP Sensor Hub é uma solução compacta para monitoramento ambiental remoto. Ele consiste em um poderoso registrador de dados que pode conectar no máximo 40 sensores RS-485 e uma ampla gama de seleção de sensores; você pode usá-lo para aplicações como estação meteorológica e monitoramento da qualidade do ar. Com IP66 e alimentação por energia solar, você pode contar com ele para fornecer um serviço confiável e não volátil de coleta de dados. Duas versões do Registrador de Dados SenseCAP Sensor Hub estão disponíveis: 2G e 4G.

# Arquitetura

![architecture](https://files.seeedstudio.com/products/102991154/wiki%20images/sensor%20hub%20architecture%20.png)

O Sensor Hub Data logger é uma estação celular de fácil implantação; 2 opções de fonte de energia estão disponíveis: energia solar com uma bateria recarregável e alimentação por adaptador.

Ele consiste em 4 canais de dados RS485 e uma ampla gama de sensores. Com um hub de expansão, ele pode ser conectado a até 40 sensores ao mesmo tempo. Os dados são coletados e enviados para a nuvem por meio de 2G ou 4G. Uma memória integrada de 10MB é equipada para armazenar mais de 700.000 medições localmente em caso de conexão ruim. Design de grau industrial e IP66, adequado para ambientes externos e severos como UV, chuva e poeira. GNSS está incorporado para rastreamento de localização.

Em comparação com SenseCAP LoRa, este registrador de dados é adequado para sensores de maior consumo de energia, como amônia. Os dados do sensor serão coletados pelo Sensor Hub e enviados para o SenseCAP Server ou para um servidor designado com 2G ou 4G.

Projetado para fácil implantação, o gabinete é adequado para montagem em poste e parede.
