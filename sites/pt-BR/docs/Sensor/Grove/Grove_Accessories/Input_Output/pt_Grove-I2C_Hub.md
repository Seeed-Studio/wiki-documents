![](https://files.seeedstudio.com/wiki/Grove-I2C_Hub/img/I2C_hub.jpg)

O I2C Hub Grove é um módulo de extensão Grove para conectar vários dispositivos I2C ao Grove Base Shield. Ele pode ser usado com o [Universal 4 Pin to X2 4 Pin cable](https://www.seeedstudio.com/depot/universal-4-pin-to-x2-4-pin-cable-5-pcs-pack-p-847.html?cPath=178_179) e conectar até 3 dispositivos I2C, o que pode cobrir a maioria dos propósitos de desenvolvimento.

[![](https://files.seeedstudio.com/wiki/common/Get_One_Now_Banner.png)](https://www.seeedstudio.com/Grove-I2C-Hub-p-851.html)

Recursos
--------

- Encadeável

:::

Ideias de Aplicação
-----------------

- Usar mais dispositivos I2C do que você teria espaço de outra forma na sua plataforma Grove.

Uso
-----

Não há conflito se você usar o mesmo soquete I2C simultaneamente porque cada dispositivo I2C tem seu próprio endereço. A instalação de hardware é mostrada abaixo.

![](https://files.seeedstudio.com/wiki/Grove-I2C_Hub/img/I2C_Hub_Connect.jpg)

Aqui não listamos um exemplo específico.
