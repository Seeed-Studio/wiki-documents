Grove - FM Receiver é um módulo receptor FM de banda larga, este módulo é baseado no SX6119, ele oferece um verdadeiro receptor de voz FM em chip único, que possui amplificador, VCO, filtro e demodulador integrados. O botão multifunção proporciona maior conveniência para os usuários controlarem.

[![](https://files.seeedstudio.com/wiki/common/Get_One_Now_Banner.png)](https://www.seeedstudio.com/Grove-FM-Receiver-p-1841.html)

Recursos
--------

- Interface Grove
- Receptor FM com uma faixa de sintonia de 64 MHz a 108 MHz cobrindo as bandas da Europa Oriental (OIRT), Japão, Europa e EUA
- Menor consumo de energia
- Botão multifunção
- Indicador LED
- Interface para fones de ouvido

:::tip
Para mais detalhes sobre módulos Grove, consulte o [Grove System](https://wiki.seeedstudio.com/pt-br/Grove_System/)
:::

Visão Geral do Hardware
------------------

![](https://files.seeedstudio.com/wiki/Grove-FM_Receiver/img/Grove-FM_v2.0_Top.jpg)

- ①: Interface para fones de ouvido: pode acionar fones ou áudio de 16 ohms ou 32 ohms.
- ②: Botão multifunção: alterar volume e selecionar canal

  - Centro: Ligar FM/Desligar FM (manter pressionado por 1 s)
  - Cima: aumentar volume
  - Baixo: diminuir volume
  - Esquerda: busca para baixo
  - Direita: busca para cima

- ③: Interface Grove
- ④: Indicador LED

  - FM desligado: LED apagado
  - FM ligado: LED aceso
  - FM buscando: LED piscando
