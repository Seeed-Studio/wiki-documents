Este módulo Grove fornece a função de uma [porta lógica NOT](https://en.wikipedia.org/wiki/Inverter_%28logic_gate%29). Ele é baseado no chip 74HC1G04GW. O 74HC1G04GW é um dispositivo CMOS Si-gate de alta velocidade que fornece o buffer inversor. O módulo NOT possui uma entrada à esquerda e uma saída à direita. Quando o sinal de entrada está em HIGH, o sinal de saída está em LOW. Quando o sinal de entrada está em LOW, o sinal de saída está em HIGH.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/Mixer-Pack-V2-(Electronic-blocks%2Cwithout-Arduino%2Cplug-and-play-system)-p-1867.html)

##  Recursos

*   Função simples de porta NOT com uma entrada e uma saída

*   Torna a integração de uma lógica NOT no seu circuito muito fácil

*   Usa cabos Grove padrão de 4 pinos para conectar a outros módulos Grove

##  Uso

*   Veja o exemplo de Cordão de LEDs que Brilham no Escuro na página wiki do Grove Mixer Pack V2 para aprender como construir um circuito que usa lógica NOT.
