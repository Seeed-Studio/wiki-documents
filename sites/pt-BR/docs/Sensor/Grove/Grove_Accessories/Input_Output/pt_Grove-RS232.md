A maioria dos MCUs usa níveis TTL, e a porta serial do computador geralmente usa níveis 232. Se quisermos que o computador se comunique com o MCU, precisamos deste **Grove - 232**. A comunicação entre o seu Arduino e o seu computador será extremamente conveniente com a interface Grove integrada.

Este módulo é baseado no Max3232, suporta comunicação em múltiplos baud rates e teoricamente suporta comunicação até 230400bps de baud.

## Primeiros Passos

Este é um módulo simples que só precisa conectar a interface correspondente ao dispositivo correspondente para transferir dados usando a ferramenta de porta serial. Você deve observar que, ao conectar um dispositivo TTL, o pino RX do módulo precisa ser conectado ao pino TX do dispositivo e, inversamente, o pino TX do módulo precisa ser conectado ao pino RX do dispositivo.
