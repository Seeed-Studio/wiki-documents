O Grove – DMX512 é um adaptador da interface Grove para a interface DMX512 (interface padrão industrial EIA-485). O módulo é baseado no chip SN75176, que pode balancear linhas de transmissão e atender ao padrão ANSI EIA-485. Agora é conveniente controlar iluminação de palco e console DMX512 com Arduino.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/Grove-DMX512-p-1447.html)

## Recurso

---

* Interface Grove e interface padrão EIA-485

* Fácil de usar

* Forte praticidade

## Uso

---
O Arduino pode controlar facilmente o dispositivo DMX512 usando o módulo Grove - DXM512. Tome a luz de bola mágica de cristal de LED como exemplo. A operação específica é a seguinte:

* Conecte a interface Grove do Grove - DMX512 à porta D3 do Grove - Base Shield e encaixe o Grove - Base Shield no Arduino.

* Conecte a interface DMX512 do Grove - DMX512 à interface DMXIN da luz de bola mágica de cristal de LED usando um cabo DMX. E alimente a luz de bola mágica de cristal de LED.

* Defina a luz de bola mágica de cristal de LED para o modo de controle DMX512. O painel de controle exibirá "A001" neste momento.

![](https://files.seeedstudio.com/wiki/Grove-DMX512/img/DMX512_Usage.jpg)

* Baixe o [File: DmxSimple Library](https://files.seeedstudio.com/wiki/Grove-DMX512/res/DmxSimple.zip) e descompacte-o na pasta libraries da IDE do Arduino pelo caminho: ..\arduino-1.0.1\libraries.

* Abra o código diretamente pelo caminho:File -&gt; Example -&gt;DmxSimple-&gt;Fadup1.

* Você pode ver uma cena interessante. Tente alterar o código para se divertir.
