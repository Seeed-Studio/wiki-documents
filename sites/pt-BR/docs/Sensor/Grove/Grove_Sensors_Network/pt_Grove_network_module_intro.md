# Guia do Módulo de Rede Grove

Os Módulos de Rede Grove são componentes eletrônicos modulares introduzidos pela Seeed Studio, fazendo parte da sua série Grove. Os módulos da série Grove são projetados para simplificar o processo de prototipagem, tornando a construção de projetos eletrônicos mais intuitiva e rápida. Os módulos de rede fornecem principalmente capacidades de conectividade, permitindo que dispositivos se conectem à rede por meios com ou sem fio.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/Grove_Intro/Grove_Network_Module.png" style={{width:1000, height:'auto'}}/></div>

De modo geral, os módulos de rede Grove reduzem significativamente a barreira para o desenvolvimento de projetos eletrônicos ao simplificar o processo de conexão e configuração, permitindo que você se concentre na implementação das funcionalidades e na inovação das aplicações.

## Recursos

- Design Modular: os módulos Grove se conectam por meio de interfaces padronizadas (geralmente conectores de 4 pinos), tornando conveniente a integração com várias placas de controle principal (como Arduino, Raspberry Pi, etc.).

- Plug and Play: a maioria dos módulos Grove vem com documentação detalhada e código de exemplo, permitindo que os usuários comecem a desenvolver rapidamente.

- Diversidade: a série Grove inclui uma variedade de sensores, atuadores e módulos de comunicação, adequados para múltiplos cenários de aplicação.

## Diferentes tipos de módulos de rede Grove

Temos vários tipos de módulos de rede Grove que podem ser aplicados a diferentes cenários, como projetos de IoT, redes de sensores sem fio e casas inteligentes.
