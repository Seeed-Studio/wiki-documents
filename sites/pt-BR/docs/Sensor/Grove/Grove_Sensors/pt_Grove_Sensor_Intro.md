# Guia de Sensores Grove

O sensor Grove é um sensor modular introduzido pela Seeed Studio e faz parte do sistema Grove. O sistema Grove utiliza um design de interface unificada, tornando fácil para os usuários construir rapidamente vários projetos eletrônicos. Existem muitos tipos de sensores Grove, incluindo, mas não se limitando a sensores de temperatura, sensores de umidade, sensores de luz, sensores de gás e muito mais.

<div style={{textAlign:'center'}}><img src="https://files.seeedstudio.com/wiki/Grove_Intro/Grove_Sensor.png" style={{width:1000, height:'auto'}}/></div>

De modo geral, o sistema de sensores Grove fornece uma solução conveniente para entusiastas de eletrônica e desenvolvedores, simplificando muito o uso de sensores e o desenvolvimento de projetos.

## Recursos

- Fácil de usar: o design de interface unificada não requer soldagem, permitindo uma configuração de projeto rápida e conveniente.
- Design modular: uma grande variedade de sensores está disponível, permitindo que os usuários os combinem de forma flexível de acordo com suas necessidades.
- Alta compatibilidade: suporta várias plataformas de desenvolvimento, como Arduino, Raspberry Pi, BeagleBone e outras.

## Diferentes tipos de sensores Grove

Temos vários tipos de sensores Grove, incluindo, mas não se limitando a sensores de temperatura, sensores de umidade, sensores de luz, sensores de gás e muito mais.

Normalmente, o emissor infravermelho emite raios infravermelhos, os fototransistores detectores recebem os raios infravermelhos, então o fototransistor é ligado, ambas as saídas ficam em nível alto (High) e os indicadores de LED on-board se acendem. Quando há um obstáculo bloqueando, o fototransistor não pode receber os raios infravermelhos, portanto o fototransistor será desligado e ambas as saídas ficarão em nível baixo (Low), os indicadores de LED on-board se apagam. </font>
