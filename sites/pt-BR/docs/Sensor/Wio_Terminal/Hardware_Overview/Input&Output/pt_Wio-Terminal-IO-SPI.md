# Usando SPI no Wio Terminal

Este repositório demonstrará como usar SPI no Wio Terminal. Você pode usá-lo para controlar outros dispositivos!

## Configurações de Porta

<div align="center"><img width={600} src="https://files.seeedstudio.com/wiki/Wio-Terminal/img/Xnip2020-03-03_12-28-09.jpg" /></div>

Como você pode ver, os pinos físicos de SPI são os seguintes:

- **MOSI** -> `GPIO 19`

- **MISO** -> `GPIO 21`

- **SCK** -> `GPIO 23`

- **SS** -> `GPIO 24`

## Configurações de Software

No Arduino, todos os pinos SPI são pré-definidos e você pode acessá-los da seguinte forma:

- **MOSI** -> `PIN_SPI_MOSI`

- **MISO** -> `PIN_SPI_MISO`

- **SCK** -> `PIN_SPI_SCK`

- **SS** -> `PIN_SPI_SS`
