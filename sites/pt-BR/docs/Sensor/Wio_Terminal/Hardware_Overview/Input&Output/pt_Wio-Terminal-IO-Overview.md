# Visão geral

Este repositório apresenta como usar os IOs Grove no Wio Terminal. Isso permite que você aproveite a funcionalidade plug and play do Ecossistema Grove, bem como use o GPIO de 40 pinos compatível com Raspberry Pi!

## Esquemáticos de hardware

### Pinout RPI do Wio Terminal

<div align="center"><img src="https://files.seeedstudio.com/wiki/Wio-Terminal/img/WioT-Pinout.jpg" /></div>

O Wio Terminal possui um GPIO de 40 pinos saindo do SAMD51, que tem o mesmo breakout que o Raspberry Pi!

Para usá-los, simplesmente use os nomes de pinos definidos acima! Alguns pinos são multifuncionais, portanto podem ser referenciados de maneiras diferentes.

#### *Para mais informações, consulte `variant.h` para mais informações*

### Pinout da porta Grove do Wio Terminal

<div align="center"><img width={400} src="https://files.seeedstudio.com/wiki/Wio-Terminal/img/Xnip2020-03-03_12-28-29.jpg" /></div>

Como você pode ver, há duas portas Grove disponíveis no Wio Terminal. Uma é a **Porta I2C** padrão e a outra é um **pino Digital/Analógico configurável**, que também pode ser usado para saídas PWM. Ambas as portas Grove podem ser usadas como Digitais.
