# Exemplos de API de LCD TFT

Este repositório fornece alguns GIFs para os exemplos da biblioteca de LCD TFT; todos os exemplos podem ser encontrados em `File`->`Example`->`Seeed_Arduino_LCD` -> `320 x 240`. Você pode usar esses exemplos para implementar no seu projeto.

Para mais informações sobre a tela LCD TFT, visite [Noções básicas da tela LCD TFT](https://wiki.seeedstudio.com/pt-br/Wio-Terminal-LCD-Basic/).
