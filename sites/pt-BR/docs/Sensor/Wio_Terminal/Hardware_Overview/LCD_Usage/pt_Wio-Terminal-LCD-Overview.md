# Visão geral

Este repositório apresenta como instalar a biblioteca TFT LCD usada no Wio Terminal. Ela fornece funções gráficas básicas ao Wio Terminal com o mínimo de esforço!

## Instalação Padrão da Biblioteca TFT LCD

Por padrão, a Biblioteca TFT LCD está **incluída dentro da Biblioteca da Placa do Wio Terminal**. Portanto, não é necessário fazer o download da biblioteca TFT LCD novamente. Siga os próximos tutoriais para começar a usar o display!

## Instalando a Biblioteca TFT LCD Separadamente

Se você quiser instalar a biblioteca TFT LCD separadamente, ou atualizar apenas a biblioteca TFT LCD, siga as etapas abaixo:

1. Visite o repositório [Seeed_Arduino_LCD](https://github.com/Seeed-Studio/Seeed_Arduino_LCD) e faça o download de todo o repositório para o seu drive local.

2. Agora, a biblioteca TFT LCD pode ser instalada na Arduino IDE. Abra a Arduino IDE e clique em `sketch` -> `Include Library` -> `Add .ZIP Library`, e escolha o arquivo `Seeed_Arduino_LCD` que você acabou de baixar.

![InstallLibrary](https://files.seeedstudio.com/wiki/Wio-Terminal/img/Xnip2019-11-21_15-50-13.jpg)

### Instalando a Biblioteca Adafruit Zero DMA

Algumas funções da Biblioteca TFT LCD requerem esta biblioteca.

1. Navegue até `sketch` -> `Include Library` -> `Manager Library`, e uma janela do gerenciador de bibliotecas irá aparecer.

2. Pesquise por **Adafruit Zero DMA** e clique em Install.
