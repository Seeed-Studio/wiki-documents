# Conectando o Wio Terminal ao Microsoft Azure IoT

<div align="center"><img src="https://files.seeedstudio.com/wiki/Wio-Terminal-Azure-IOT/Wio-terminal-azureiot.jpeg" /></div>


>Este é um documento escrito por [**@Benjamin Cabé**](https://twitter.com/kartben). Obrigado, Benjamin, pelo excelente trabalho! Você também pode encontrar [o trabalho de Benjamin](https://github.com/kartben) aqui.

Este aplicativo de exemplo mostra como conectar seu [Wio Terminal](https://www.seeedstudio.com/Wio-Terminal-p-4509.html) ao [Azure IoT Hub](https://azure.microsoft.com/services/iot-hub). Ele é baseado no [Azure SDK for Embedded C](https://github.com/Azure/azure-sdk-for-c), uma biblioteca de baixo consumo de recursos e fácil de portar para se comunicar com os serviços Azure.

Para se conectar ao Microsoft Azure IoT com o Wio Terminal, consulte o [**Guia do Benjamin**](https://github.com/kartben/wioterminal-azureiothub-sample).
