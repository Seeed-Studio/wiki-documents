### Recomendações para Design de Caixa Personalizada

Se você estiver projetando sua própria caixa, aqui vão algumas diretrizes importantes para garantir desempenho de áudio ideal:

* Garanta que a distância entre o alto-falante e os dois microfones seja uniforme e minimize a transmissão de vibrações do alto-falante para os microfones, a fim de manter a clareza do áudio.

* A caixa deve permitir que a voz humana alcance cada microfone sem obstrução, garantindo que o som direto (em vez do som refletido) alcance de forma uniforme ambos os microfones para uma captura de áudio precisa.

* Se você estiver projetando uma câmara selada para os microfones, evite criar uma cavidade ressonante que seja estreita nas duas extremidades e larga no meio, pois isso pode interferir no processamento de sinal de front-end. Se uma câmara selada não for viável, incorpore múltiplas perfurações na caixa para impedir que reflexões sonoras fiquem reverberando internamente antes de chegar aos microfones. Isso ajuda a manter a integridade do sinal.
