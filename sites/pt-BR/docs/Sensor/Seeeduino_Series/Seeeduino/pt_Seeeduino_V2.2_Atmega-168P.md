Seeeduino é uma placa compatível com Arduino. Seu design é baseado no esquema Diecimila, 100% compatível com seus programas, shields e IDEs existentes. Na parte de hardware, mudanças notáveis foram feitas para melhorar a flexibilidade e a experiência do usuário.

**Model:ARD130D2P**

##   Recursos

*   Herda todos os recursos do Arduino Diecimila.

*   Compatível com o layout de pinos, furos de parafuso e dimensões do Diecimila.

*   Evoluído com componentes SMD

*   Melhorado em extensibilidade e conveniência

##   Histórico de atualização de versão

###   v2.2

1.  Seleção automática de energia USB/EXT

2.  Atualização do capacitor de alimentação

3.  Limpeza dos layouts

4.  Reset mais fácil

5.  Cristal de quartzo real

6.  Diodo de alimentação externa alterado para 1N4004 (mais potência no pino Vin)

###   V2.12

1.  Zero consumo de energia externa quando desligado

2.  Interruptores mais robustos

3.  Segunda fonte de alimentação para entrada direta de 5V. [Caution] USE 5V ONLY!

4.  Capacidade de acionamento de 150mA sob 3,3V

5.  PCB fina de 1,0mm para menor peso

6.  Linha extra reservada para conectores de pinos

###   V1.1

1.  Correção de bug - via desnecessária no fio do pino 4.

2.  Correção de bug - etiqueta coberta por engano pelos interruptores.

3.  Adicionada porta I2C e de sensor.

4.  Adicionado um capacitor de 100uF para a chave de vcc.

5.  Agrupados novos pinos em grade de 100mil.

6.  Botões de reset substituídos por metálicos.

7.  Textos e etiquetas reorganizados para indicações mais claras.
