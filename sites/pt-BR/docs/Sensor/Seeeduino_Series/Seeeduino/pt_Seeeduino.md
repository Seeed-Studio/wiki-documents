Seeeduino é uma placa compatível com Arduino. Ela é 100% compatível com o software, shields e IDEs do Arduino.

Na parte de hardware, foram feitas mudanças notáveis para melhorar a flexibilidade e a experiência do usuário.

##   Histórico de atualização de versão  ##

| Revisão|Descrições|Data de lançamento|
|---|---|---|
|Seeeduino V0.9| Primeira versão pública inicial||
|Seeeduino v1.1|1.Corrigido bug - via desnecessária no fio do pino 4.2.Corrigido bug - rótulo coberto por engano pelos switches.3.Adicionada porta I2C e de sensor.4.Adicionado capacitor de 100uF para a chave vcc.5.Agrupados novos pinos em grade de 100 mil.6.Substituídos botões de reset por botões de metal.7.Reorganizados textos e rótulos para indicações mais claras.||
|Seeeduino v2.12|1.Consumo de energia externa zero quando desligado2.Switches mais fortes3.Segunda fonte de alimentação para entrada direta de 5V. [Caution] USE 5V ONLY!4.Capacidade de drive de 150mA sob 3.3V5.PCB fino de 1,0mm para peso mais leve6.Linha extra reservada para pinos de cabeçalho||
|Seeeduino v2.2|1.Seleção automática de energia USB/EXT2.Atualização do capacitor de alimentação3.Limpeza de layouts4.Reset mais fácil5.Cristal de quartzo real6.Diodo de energia externa alterado para 1N4004 (mais potência no pino Vin)|16 de dez. de 2010|
|Seeeduino v2.21|1.Atualizado para conector mini USB mais forte.|12 de jan. de 2011|
|Seeeduino v3.0|1.alterado conector JST para conector DC Jack.2.Adicionados dois conectores Grove.|1 de jan. de 2012|
|Seeeduino v4.0|1.Conversor DC-DC para reduzir a dissipação de energia.|2.Removido switch RST.
|Seeeduino v4.2|1.Adicionado um conector Grove2.Melhorado o projeto de alimentação|24 de ago. de 2015|
