## Instalação de Hardware

### Lista de componentes

* [Seeeduino Lotus v1.0](https://www.seeedstudio.com/Seeeduino-Lotus-ATMega328-Board-with-Grove-Interface-p-1942.html)
* [Grove - LCD RGB Backlight](https://www.seeedstudio.com/Grove-LCD-RGB-Backlight-p-1643.html)
* [Grove - I2C FM Receiver](https://www.seeedstudio.com/Grove-I2C-FM-Receiver-p-1953.html)
* [Grove - Button](https://www.seeedstudio.com/Grove-Button-p-766.html)
* [Grove - Rotary Angle Sensor](https://www.seeedstudio.com/Grove-Rotary-Angle-Sensor-p-770.html)

### Conexão de Hardware

A conexão de hardware é muito fácil, Grove - LCD RGB Backlight e Grove - I2C FM Receiver se comunicam via I2C, Grove - Button é uma entrada digital, Grove - Rotary Angle Sensor é uma entrada analógica. Portanto, eles podem ser conectados como mostrado abaixo.

![enter image description here](https://files.seeedstudio.com/wiki/Seeeduino_Lotus/img/Seeeduino_Lotus_usage.jpg)

## Parte de Software

* Para baixar o código de demonstração no GitHub, clique [aqui](https://github.com/Seeed-Studio/Seeeduino_lotus_Usage).
* Abra o sketch de exemplo I2C_FM_RGB_LCD, compile e envie para a sua placa.
* Pressione o botão para começar a buscar estações FM e gire o Rotary Angle Sensor para ajustar o volume.
