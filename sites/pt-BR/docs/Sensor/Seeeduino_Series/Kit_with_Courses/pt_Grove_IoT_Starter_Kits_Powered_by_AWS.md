**Grove IoT Starter Kits Powered by Amazon Web Service (AWS)** são quatro kits diferentes projetados para _AWS_ para facilitar o uso de IoT. Cada kit consiste em uma Plataforma de Desenvolvimento (placa principal) que pode ser conectada à nuvem e um conjunto de módulos Grove. Esses módulos Grove fornecem sensores e atuadores essenciais para qualquer pessoa interessada em AWS IoT.

_**NOTA:**_ AWS IoT e as placas de desenvolvimento que vêm com o kit possuem muitos recursos. O tutorial abaixo cobre as etapas essenciais para conectar a Plataforma de Desenvolvimento ao [AWS IoT](https://aws.amazon.com/). Escolha um dos quatro kits com base na _Plataforma de Desenvolvimento_ de sua preferência e familiaridade.

**Recursos**

* Módulos Grove prontos para uso, plug and play, sem necessidade de protoboard ou soldagem.

* Totalmente compatíveis com os serviços e práticas da AWS.

* Tutoriais passo a passo para desenvolvedores e makers para prototipagem mais rápida.

## Familiarizando-se com AWS IoT &amp; Kits

1. Leia, estude e entenda sobre [How AWS IoT Works](https://aws.amazon.com/iot/how-it-works/) e [Getting Started](https://aws.amazon.com/iot/getting-started/)

2. Registre-se para uma [conta AWS](https://portal.aws.amazon.com/gp/aws/developer/registration/index.html) (_se ainda não o fez_) para experimentar o AWS IoT.

3. Leia, estude e entenda sobre a plataforma de desenvolvimento que vem com o seu kit. O link para a documentação da placa principal é fornecido no manual do usuário do kit. Consulte a seção de cada kit abaixo.

4. A documentação do kit fornece instruções de como configurar as placas de desenvolvimento para conectar à AWS. Use estas instruções para baixar o software e firmware necessários para a placa.

5. Explore as possibilidades de uso dos módulos Grove com a placa principal. Um link para a documentação de cada módulo Grove é fornecido na documentação do kit.

## Seeeduino Cloud e Grove IoT Starter Kit Powered by AWS

![enter image description here](https://files.seeedstudio.com/wiki/Grove_IoT_Starter_Kits_Powered_by_AWS/img/Aws_kit_seeeduino_cloud.JPG)

**[Seeeduino Cloud](/pt-br/Sensor/Seeeduino Series/Seeeduino_Cloud "Seeeduino Cloud")** é uma placa microcontroladora baseada no módulo Dragino WiFi IoT [HE](http://www.dragino.com/products/linux-module/item/87-he.html) e ATmega32u4. **HE** é um módulo WiFi 2,4G, 150M, de alto desempenho e baixo custo, que possui um sistema Open Source OpenWrt embarcado. Seeeduino Cloud também é uma placa compatível com [Arduino Yun](https://www.arduino.cc/en/Main/ArduinoBoardYun). O Grove IoT Starter Kit inclui os sensores e atuadores mais frequentemente usados para transformar suas ideias em aplicações tangíveis com computação em nuvem AWS.

## LinkIt One e Grove IoT Starter Kit com tecnologia AWS

![enter image description here](https://files.seeedstudio.com/wiki/Grove_IoT_Starter_Kits_Powered_by_AWS/img/Aws_kit_linkit.JPG)

_Artigo principal: [LinkIt ONE](https://wiki.seeedstudio.com/pt-br/LinkIt_ONE/ "LinkIt ONE")_

A placa de desenvolvimento **[LinkIt ONE](https://wiki.seeedstudio.com/pt-br/LinkIt_ONE/ "LinkIt ONE")** é uma placa de desenvolvimento de código aberto e alto desempenho para criação de protótipos de dispositivos vestíveis e IoT. Ela é baseada no MT2502 (MCU ARM7EJ-S™) e integra GSM, GPRS, Wi-Fi, Bluetooth BR/EDR/BLE, GPS, codec de áudio e conector para cartão SD em uma única placa de desenvolvimento. O kit permite criar projetos conectados à computação em nuvem que envolvem comunicações para cidades inteligentes, transporte e logística.
