Este é o primeiro Protoshield para <a href="/pt-br/Seeeduino_Mega" ><span><font size={"3"}> Seeeduino Mega</font></span></a>, que trouxe todos os pinos do <a href="/pt-br/Seeeduino_V2.2" ><span><font size={"3"}> Seeeduino </font></span></a>, e até do <a href="/pt-br/Arduino" ><span><font size={"3"}> Arduino </font></span></a> para o topo! Com este protoshield, os usuários encontrarão uma grande área de prototipagem, você pode até usar Xbee com esta placa para transformá-la em um shield Xbee.

[enter image description here](https://www.seeedstudio.com/seeeduino-mega-protoshield-kit-p-597.html?cPath=132_134)

## Recursos

---

* Compatível com Seeeduino MEGA e Arduino MEGA

* Todos os pinos são trazidos para o nível superior

* Compatível com Xbee/GPS bee

* Botão de reset trazido para o nível superior
