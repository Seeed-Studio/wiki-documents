**Wireless Sensor Node - Solar Kit** é um conjunto fácil de usar criado para experimentos com XBee e módulos sem fio autônomos compatíveis com **XBee**, como RFBee e [Wifi Bee](/pt-br/Wifi_Bee "Wifi Bee"). Todo **maker** se depara com a questão de selecionar o conjunto certo de componentes para construir um **Wireless Sensor Node**. O **Wireless Sensor Node - Solar Kit** preenche essa lacuna de maneira muito adequada. O Grove - XBee Carrier fornece fonte de alimentação LDO, carregador para bateria LiPo e porta de programação para módulos compatíveis com **XBee**. O **Painel Solar** fornece a tensão de carregamento necessária em áreas remotas. A **Bateria LiPo de 500 mAH** fornece a reserva quando o Sol não está presente. Um módulo sem fio devidamente projetado e configurado pode proporcionar muitas horas de uso. Para isso, coloque o nó em modo de suspensão quando não estiver transmitindo o valor do sensor. Este kit vem com uma **Caixa Transparente** perfeitamente feita, conjuntos de **Parafusos** e **Rebites Plásticos**.

- Sugerimos que você compre mais de um kit para criar uma matriz distribuída de Nós de Sensores.

- Bees Shield juntamente com **Seeeduino** e **Wifi Bee** pode atuar como gateway de internet sem fio para esses nós.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/Wireless-Sensor-Node-Solar-Kit-p-919.html)

## Ideias de Aplicação

---

- Nós de Sensores Sem Fio Distribuídos com **XBee** ou **WifiBee** ou **RFBee**.

- Construa **Registradores de Dados (Data Loggers)** quando conectados a um gateway sem fio.

- Rede Residencial Inteligente

- Automação Industrial

- sistemas **SCADA** (Supervisory control and data acquisition.)

### Guia de Início Rápido

Esta seção fornece uma construção passo a passo de um Wireless Sensor Node. As imagens servem apenas para ilustrar o procedimento daquela etapa. Usamos duas configurações diferentes de Grove - Xbee Carrier e módulos Grove. Portanto, apenas siga o procedimento.

| Etapa | Procedimento                                                                                                        | Ilustração                                                                                                                                 |
|------|------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------|
| 1    | Abra a caixa como mostrado                                                                                       | ![](https://files.seeedstudio.com/wiki/Wireless_Sensor_Node-Solar_Kit/img/Wireless_Sensor_Node-Solar_Kit_Top_PlaceForOpening.jpg)   |
| 1.1  | Coloque a Bateria LiPo dentro da Caixa                                                                           | ![](https://files.seeedstudio.com/wiki/Wireless_Sensor_Node-Solar_Kit/img/Wireless_Sensor_Node-Solar_Kit_Placing_Battery.jpg)       |
| 1.2  | Insira o Conector do Painel Solar                                                                                | ![](https://files.seeedstudio.com/wiki/Wireless_Sensor_Node-Solar_Kit/img/Wireless_Sensor_Node-Solar_Kit_Construction1.jpg)         |
| 1.3  | Abra o rebite de plástico                                                                                        | ![](https://files.seeedstudio.com/wiki/Wireless_Sensor_Node-Solar_Kit/img/Wireless_Sensor_Node-Solar_Kit_Box_Plastic_Rivet1.jpg)    |
| 1.4  | Um rebite aberto se parece com isto                                                                              | ![](https://files.seeedstudio.com/wiki/Wireless_Sensor_Node-Solar_Kit/img/Wireless_Sensor_Node-Solar_Kit_Box_Plastic_Rivet2.jpg)    |
| 1.5  | Prenda um módulo Grove com a ajuda dos rebites. Mantenha o Grove - Bee Carrier como mostrado dentro da caixa transparente. | ![](https://files.seeedstudio.com/wiki/Wireless_Sensor_Node-Solar_Kit/img/Wireless_Sensor_Node-Solar_Kit_Construction2.jpg)         |
| 2.3  | Um rebite totalmente fechado se parece com isto                                                                  | ![](https://files.seeedstudio.com/wiki/Wireless_Sensor_Node-Solar_Kit/img/Wireless_Sensor_Node-Solar_Kit_Rivet_Bottom.jpg)          |
| 3.0  | Conecte o Cabo Grove de 4 fios, os conectores da Bateria e do Painel Solar ao Grove - XBee Carrier               | ![](https://files.seeedstudio.com/wiki/Wireless_Sensor_Node-Solar_Kit/img/Wireless_Sensor_Node-Solar_Kit_TwigConnection.jpg)        |

| 6.0  | Conecte o cabo USB e programe o XBee                                                                            | ![](https://files.seeedstudio.com/wiki/Wireless_Sensor_Node-Solar_Kit/img/Wireless_Sensor_Node-Solar_Kit_USBProgramming.jpg)        |
