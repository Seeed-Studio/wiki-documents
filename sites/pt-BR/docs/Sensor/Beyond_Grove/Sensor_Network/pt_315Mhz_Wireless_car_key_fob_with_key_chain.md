Este é um chaveiro de carro sem fio com 4 botões: travar, destravar, mudo e alarme ligado. Um LED azul acenderá quando qualquer botão for pressionado. Use este chaveiro para se comunicar com o relé [Codec-Adaptive Wireless](https://www.seeedstudio.com/depot/codecadaptive-wireless-relay-p-550.html) para o seu projeto de controle remoto.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/depot/315mhz-wireless-car-key-fob-with-key-chain-battery-included-p-557.html?cPath=139_140)

##   Recursos
---
*   Faixa de frequência: Alta: 315,15MHZ  Média: 315,025MHZ  Baixa: 314,85MHZ

*   Esquemas de modulação: modulação em amplitude (AM)

*   Taxa de transferência de dados: 625HZ

*   Potência de saída: ≤ 12mW

*   Tensão da bateria: DC12V

*   Temperatura de operação: -30 ℃ ~ +85 ° C
