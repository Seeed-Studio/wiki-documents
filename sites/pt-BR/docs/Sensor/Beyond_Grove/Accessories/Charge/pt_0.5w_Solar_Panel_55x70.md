Este é um painel solar personalizado, que se conecta diretamente a muitas das nossas placas de desenvolvimento e possui alta eficiência de 17%. A unidade tem um revestimento de epóxi transparente com suporte rígido. Vedação robusta para aplicações ao ar livre!

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/0-5W-Solar-Panel-55x70-p-632.html)
