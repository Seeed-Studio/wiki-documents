RF Explorer é uma notável ferramenta de diagnóstico usada para monitoramento e solução de problemas em sistemas e comunicações sem fio. É uma nova série de analisadores de espectro de RF portáteis e de baixo custo, projetados por Ariel, disponíveis em uma variedade de faixas de frequência.

A série de analisadores e geradores RF Explorer redefine o analisador de espectro de RF portátil de mão. A unidade é pequena e leve, mas oferece desempenho e recursos comparáveis a dispositivos maiores e mais caros.

Enquanto antes o uso de analisadores de espectro de RF era limitado a empresas/organizações que podiam arcar com seu alto preço, o baixo custo do RF Explorer agora oferece a todo engenheiro, técnico e hobbista experiente a oportunidade de possuir um analisador de espectro de RF.

Abaixo estão aplicativos de software que podem interessar a você — eles rodam em múltiplas plataformas. Isso permite que você experimente os diversos recursos fornecidos pelo software e determine qual se adapta melhor às suas necessidades. Para mais detalhes e a lista completa de softwares compatíveis com RF Explorer disponíveis para todas as plataformas, visite [aqui](http://www.rf-explorer.com/software).

## Opções de Software Windows para RF Explorer

### [RF Explorer para Windows](http://www.rf-explorer.com/windows)  

![](https://files.seeedstudio.com/wiki/RF_Explorer_Software/img/Windows.jpg)

Dos [desenvolvedores do RF Explorer](http://www.rf-explorer.com), o aplicativo RF Explorer para Windows fornece visualizações tradicionais de traço de espectro juntamente com visualizações de waterfall mais gráficas. Ele também inclui todo o software necessário para executar o Signal Generator e funcionar como um analisador de rede escalar.

Nuts About Nets criou duas variações diferentes do software -- padrão e profissional. **[A versão padrão](http://rfexplorer.com/touchstone)** é gratuita e **[a versão profissional](http://rfexplorer.com/touchstone)** custa apenas US$ 49.

O software Touchstone, da [Nuts About Nets](http://rfexplorer.com/), transforma dados coletados de analisadores de espectro RF Explorer em gráficos e exibições altamente visuais, permitindo que os usuários visualizem mais facilmente o ambiente de RF, monitorem sinais de RF, solucionem problemas de RF e detectem fontes de interferência de RF.


## Opções de Software MacOS para RF Explorer

### [iRF Explorer para MacOS X - gratuito](https://itunes.apple.com/app/irfexplorer/id474348349?mt=12)
![](https://files.seeedstudio.com/wiki/RF_Explorer_Software/img/Mac.jpeg)
Disponível na Mac Store, oferece funcionalidade básica e fácil de usar de analisador de espectro padrão para Mac. Mac OS X 10.7 e posterior, certifique-se de instalar o driver Silicon Labs conforme as instruções de instalação.
### [Vantage - US$ 99](http://www.rfvenue.com/vantage)
![](https://files.seeedstudio.com/wiki/RF_Explorer_Software/img/rfvenue.jpg)
Funcionalidade robusta e fácil de usar de analisador de espectro padrão para Mac, com suporte a todos os modelos RF Explorer. Inclui exportação de arquivos para as principais ferramentas de software de coordenação de terceiros. Recursos avançados futuros estão no roadmap.

## Opções de Software Android para RF Explorer

### [RFTrack para Android - gratuito](http://wireless.ictp.it/tvws/rftrack/)

Disponível para telefones e tablets Android OTG, combina a localização por GPS do Android e a atividade de RF do RF Explorer para criar um banco de dados global de TVWS.

### [Touchstone Mobile  - US$ 49](http://rfexplorer.com/touchstone-mobile)

![](https://files.seeedstudio.com/wiki/RF_Explorer_Software/img/touchstone-mobile.jpg)

Disponível para telefones e tablets Android OTG, transforma dados coletados de analisadores de espectro RF Explorer em gráficos e exibições altamente visuais, permitindo que os usuários visualizem mais facilmente o ambiente de RF, monitorem sinais de RF, solucionem problemas de RF e detectem fontes de interferência de RF.
