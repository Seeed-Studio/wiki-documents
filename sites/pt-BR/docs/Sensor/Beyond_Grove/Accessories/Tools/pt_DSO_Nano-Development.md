Alguns recursos para desenvolvimento (em) o [DSO Nano](/pt-br/DSO_Nano "DSO Nano").

## Desenvolvimento de firmware

* Obtenha o código-fonte e faça a compilação

Veja [Compilando o código-fonte com gcc](/pt-br/DSO_Nano-gcc "DSO Nano/gcc"). Para compilar com IAR, veja a seção Links abaixo.

* Contribua com patches

Por favor, compartilhe suas modificações no fórum do DSO Nano. O ideal é postar um "diff" a partir do repositório git. Por exemplo, "git diff &gt; mypatch.diff e postar o mypatch.diff em vez de enviar toda a árvore de código. Ainda melhor é aprender [git](http://git-scm.com/) e criar séries de patches de verdade. Ou publicar a sua própria árvore git em algum lugar (gitourious.org, github.com etc).

## Depuração

* Depurar código ARM em execução no [emulador qemu usando gdb](/pt-br/DSO_Nano-Qemu_gdb "DSO Nano/Qemu gdb")

* Depurar código ARM em execução em uma placa com JTAG usando [OpenOCD e gdb](/pt-br/DSO_Nano-OpenOCD_gdb "DSO Nano/OpenOCD gdb")
