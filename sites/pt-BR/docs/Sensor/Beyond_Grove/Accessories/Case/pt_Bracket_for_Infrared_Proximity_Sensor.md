Este é um kit de suporte de sensor de proximidade infravermelho de alumínio para Sensor de Proximidade Infravermelho. Com este kit, um servo RB-421 e um Sensor de Proximidade Infravermelho você pode montar um conjunto de suporte de servo com 2 graus de liberdade.
Este kit é profissional para direcionar o sensor de proximidade infravermelho em um robô, permitindo rotação de 180° de um lado para o outro e de frente para trás.
Essas peças também possuem furos com espaçamento de 20 mm, de forma que podem ser fixadas ao Starter Bundle Harness da Seeed (https://www.seeedstudio.com/depot/starter-bundle-harness-p-906.html?cPath=178_184), que também possui espaçamento de 20 mm.
