O BusPirate v3 é uma interface de barramento universal que se comunica com componentes eletrônicos a partir de um terminal serial no PC, eliminando uma enorme quantidade de esforço inicial de prototipagem ao trabalhar com chips novos ou desconhecidos.

**Protocolos:** 1-Wire, I2C, SPI, JTAG, serial assíncrono (UART), MIDI, teclado de PC, LCDs HD44780 e bibliotecas genéricas de 2 e 3 fios para protocolos personalizados.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/bus-pirate-v3-assembled-p-609.html?cPath=174)

##   Recursos
---
*   Interface USB, alimentado por USB

*   Pinos tolerantes a 0–5,5 volts

*   Sonda de medição de 0–6 volts

*   Medição de frequência de 1 Hz–40 MHz

*   Modulador de largura de pulso de 1 kHz–4 MHz, gerador de frequência

*   Resistores de pull-up multivoltagem on-board

*   Fontes de alimentação on-board de 3,3 volts e 5 volts com redefinição por software

*   Macros para operações comuns

*   Sniffers de tráfego de barramento (SPI, I2C)

*   Um bootloader para atualizações fáceis de firmware via USB

*   Modo de ponte transparente USB-&gt;serial

*   Analisador lógico de baixa velocidade de 10 Hz–1 MHz

*   Suporte personalizado em AVRDUDE, Flashrom

*   Clone de gravador AVR STK500 v2

*   Programável por script em Perl, Python, etc.

*   Traduções (atualmente espanhol e italiano)
