##   Recursos

*   Pode ser usado para programar a maioria dos microcontroladores AVR via USB (compatível com USBASP. Consulte [http://www.fischl.de/usbasp/](http://www.fischl.de/usbasp/) para detalhes)
*   Uma placa AVR Mega48 de uso geral com [todas as E/S trazidas para as laterais da placa](http://www.jyetech.com/Products/073/07302_1.jpg) e furos correspondentes às placas de protótipo com passo de 0,1 polegada. Excelente para experimentos e desenvolvimento com AVR. (Observação: o modelo 07302 é enviado com ATmega48 na placa)
*   Pode ser alimentado separadamente adicionando dois componentes de furo passante comumente disponíveis
*   Cabeçalho compatível fornecido para programação de osciloscópios 062
*   Pode ser convertido em conversor Uart/USB simplesmente regravando-o com o firmware AVRCDC (disponível em [http://www.recursion.jp/avrcdc/](http://www.recursion.jp/avrcdc/) ) e adicionando um resistor
