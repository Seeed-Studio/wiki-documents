Este é um medidor de capacitância simples, porém muito útil. A nova versão corrigiu erros de projeto da versão anterior e trouxe várias melhorias:

*   Layout da PCB aprimorado.
*   Adicionado conector DC popular para fácil conexão da fonte de alimentação.
*   Adicionado interruptor. Isso é desejável quando operando com bateria.
*   Adicionados furos de fixação.
*   Polaridade indicada.
*   Tamanho menor.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/Capacitance-Meter-Kit-p-268.html)

##   Recursos

*   Aproximadamente 1% de precisão
*   Faixa de medição: 1pF - 500uF
*   Troca automática de faixa
*   Função de zeragem disponível
*   Saída serial em tempo real das leituras de medição com carimbo de data/hora
*   Baixo custo e fácil de montar


##   Lista de Materiais (BOM) / lista de peças

**O kit inclui:**

*   Todas as peças, exceto fonte de alimentação
*   Esquemático
*   Manual
