Esta demonstração mostrará como usar o Relé. Na verdade, o relé é um interruptor eletrônico que pode ser controlado por um IO.

O relé é usado principalmente para controle de alta potência por baixa potência. Por exemplo, para usar o seu Arduino para controlar uma lâmpada, você precisa de um relé. Aqui usaremos o relé para controlar um LED.

**Hardware Necessário：**

* Arduino

* Relé

* LED

* resistor de 220 ohms

**Circuito：**

Conecte o relé ao pino D2 do Arduino.

![](https://files.seeedstudio.com/wiki/Relay_Control_LED/img/Sidekick_37_1.png)

**Código:**

Abra a IDE do Arduino e clique em File -&gt; Sketchbook -&gt; relay_led.

Envie o código e você verá o LED piscar.
