**As etapas específicas para carregar o código são:**

1. Selecione o tipo de placa Arduino que você está usando pelo caminho: Tools --&gt; Board --&gt; por exemplo, Arduino UNO depois de abrir um demo.
![](https://files.seeedstudio.com/wiki/Upload_Code/img/Open_code.jpg)

Pode ser que você tenha escolhido o tipo de placa errado se aparecer a imagem abaixo; por favor selecione novamente a placa Arduino que você está usando.

![](https://files.seeedstudio.com/wiki/Upload_Code/img/Error_score.jpg)

2. Selecione a porta serial correta que você está usando pelo caminho: Tools --&gt; Serial Port --&gt; por exemplo, COM3.
3. Carregue o código de demonstração como mostrado abaixo:

![](https://files.seeedstudio.com/wiki/Upload_Code/img/Upload_state.jpg)

Quando aparecer "Done uploading", parabéns, o envio foi concluído com sucesso.
