Algumas pessoas acham que a interface de edição da Arduino IDE não é tão amigável: indentação fora do padrão, sem realce de sintaxe, sem autocompletar e assim por diante. Resumindo, se você já usou outros excelentes editores como emacs, vim ou até mesmo notepad++, você provavelmente está muito insatisfeito com a interface de edição do Arduino.

Mas você pode usar um editor externo: abra a Arduino IDE, clique em File -&gt; Preferences e selecione Use external editor:

![](https://files.seeedstudio.com/wiki/Use_External_Editor/img/外部编辑器1.png)

Em seguida, você perceberá que não consegue digitar na Arduino IDE; agora você só pode usar o editor externo.

A seguir está o meu editor favorito: Vim. Ele não é mais bonito do que a Arduino IDE?

![](https://files.seeedstudio.com/wiki/Use_External_Editor/img/外部编辑器2.png)
