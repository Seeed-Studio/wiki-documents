O Sidekick Advanced Kit inclui um conjunto de componentes básicos, bem como vários sensores e outros módulos.

Temos um sketchbook para o capítulo de Sensor. Você pode baixá-lo [aqui](https://github.com/Seeed-Studio/sketch_sidekick).

Depois de baixar o código, extraia-o para a unidade F: ou para qualquer outro local de sua preferência.

Em seguida, abra a Arduino IDE, clique em File -&gt; Preferences:

![](https://files.seeedstudio.com/wiki/Sketchbook_of_Sidekick_Advanced_Kit/img/Sidekick_40_1.png)

Defina o local do Sketchbook para a pasta do código que você baixou e clique em OK para concluir. Reabra a Arduino IDE.

Clique em File -&gt; Sketchbook; agora você poderá encontrar alguns projetos, que são os códigos de demonstração deste capítulo.

![](https://files.seeedstudio.com/wiki/Sketchbook_of_Sidekick_Advanced_Kit/img/Sidekick_40_2.png)
