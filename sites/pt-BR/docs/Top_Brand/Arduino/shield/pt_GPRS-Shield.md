O GPRS Shield oferece uma forma de usar a rede de telefonia celular GSM para receber dados de um local remoto. O shield permite que você faça isso por meio de qualquer um destes três métodos:

- Serviço de Mensagens Curtas

- Áudio

- Serviço GPRS
  - [Rastreamento por GPS](http://vamostech.com/gps-tracking)
  - [Rastreador GPS](http://vamostech.com/gps-tracking)
  - [Properti semarang](http://www.raywhitesemarang.com)
  - [Jual sepatu online](http://mariposa-store.com/)

Há duas versões para você escolher:

|![](https://files.seeedstudio.com/wiki/GPRS-Shield/img/GPRS_shield_v1.4.jpg)|![](https://files.seeedstudio.com/wiki/GPRS-Shield/img/GPRSshield_01.jpg)|
|---|---|
|GPRS Shield V1.0|GPRS Shield V2.0|

Aqui está a comparação entre várias versões do GPRS Shield que você pode encontrar em [myamplifiers.com](http://www.myamplifiers.com/):

|  Parâmetro|GPRS Shield V1.0|GPRS Shield V2.0|
|---|---|---|
|  **Tensão de Operação** | +5V|+5V  |
|  **Modo de Alimentação**|Conector de Energia ou pino de 5V do Arduino/Seeeduino|Pino de 5V ou pino Vin do Arduino/Seeeduino |
| **Interface de Áudio**|Conectores para alto-falante e fone de ouvido|Conector de headset 2 em 1  |
| **Shield Padrão**|Não|Sim  |
|  **Antena**|0,4W|0,8W(29dBm)  |
|**potência de transmissão**|0,4W|0,8W(29dBm)|
