Estes são shields de cartão SD. Ele fornece um espaço de armazenamento para o seu Arduino. Os usuários podem ler/gravar o cartão SD por meio da biblioteca SD integrada do Arduino. Ele suporta cartões SD, SDHC e Micro SD.

| | |
|---|---|
|![](https://files.seeedstudio.com/wiki/SD_Card_Shield/img/Sdcardshield_01.jpg) |![](https://files.seeedstudio.com/wiki/SD_Card_Shield/img/Sdcardshield_01.jpg)|
|[SD Card Shield V3.0](https://seeeddoc.github.io/SD_Card_Shield_V3.0/) |[SD Card shield V4.0](https://seeeddoc.github.io/SD_Card_shield_V4.0/) |

Aqui está a comparação entre várias versões do SD Card Shield:

| Parâmetro | SD Card Shield V3.0 | SD Card Shield V4.0 |
|-----------|-------------------|-------------------|
| **Tensão de operação** | +2.7V~+3.6V | +5V |
| **Protocolo de comunicação** | SPI | SPI |
| **Soquete de cartão SD** | Dois soquetes (soquete de cartão SD e soquete de cartão Micro SD) | um soquete SD padrão (inclui adaptador que permite o uso de cartões Micro SD) |
| **Shield padrão** | Não | Sim |
| **Tipo de cartão suportado** | Cartão SD (≤2G); cartão Micro SD (≤2G); cartão SDHC (≤16G) | Cartão SD (≤16G); cartão Micro SD (≤2G); cartão SDHC (≤16G) |
| **Compatibilidade** | Não compatível com Mega | Compatível com Mega |
