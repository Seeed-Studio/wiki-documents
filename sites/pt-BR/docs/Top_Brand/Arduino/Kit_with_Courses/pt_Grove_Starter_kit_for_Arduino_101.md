O sistema Grove é projetado para conectar um processador ao mundo real por meio de diferentes transdutores (como sensores e motores), placas de expansão e cabos Grove que se parecem com um cabo flat. Com o sistema Grove, você não precisará mais lidar com conexões excessivas e complicadas como costumava fazer. Nenhuma ferramenta de solda, protoboard ou jumpers é necessária. Você só precisa conectar vários transdutores à placa de desenvolvimento com placas de expansão base shield e cabos Grove. O sistema Grove é muito útil para acelerar o processo de desenvolvimento do seu projeto, especialmente para iniciantes.

**Observação** que todo o conteúdo aqui também se aplica ao Genuino 101.

## Primeiros passos

### Fundamentos com Arduino

Você precisa conhecer alguns conceitos essenciais se for a primeira vez que tem contato com Arduino. Preparamos algumas documentações para você começar com
Arduino de forma rápida e eficaz. Você pode visitar [https://www.arduino.cc/en/Tutorial/Foundations](https://www.arduino.cc/en/Tutorial/Foundations).

### Sketches Arduino (exemplo básico para cada módulo)

Depois que você fizer um LED piscar (para usuários Windows, você pode encontrá-lo em [https://www.arduino.cc/en/Guide/Windows](https://www.arduino.cc/en/Guide/Windows), você pode encontrar outras versões para Mac OS e variantes Linux em
[https://www.arduino.cc/en/Guide/HomePage](https://www.arduino.cc/en/Guide/HomePage) ), você ainda precisa se familiarizar com o sistema Seeedstudio Grove em [https://www.seeedstudio.com/wiki/Grove_System](#/Grove_System). E agora, você pode fazer alguns exercícios mais práticos que são especialmente projetados para este kit. Baixe os sketches dos exercícios em [https://github.com/Seeed-Studio/Sketchbook_Starter_Kit_for_Arduino](https://github.com/Seeed-Studio/Sketchbook_Starter_Kit_for_Arduino).
