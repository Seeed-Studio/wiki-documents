O Kit de Cuidados Inteligentes com Plantas Grove é um kit de ferramentas avançado e fácil de usar para você desenvolver um sistema inteligente para plantas.
Ele favorece a extensibilidade para alcançar mais aplicações com apenas alguns ajustes.
O kit implementa duas funções. Uma é detectar fatores ambientais que afetam o crescimento das plantas, como umidade do solo, intensidade de iluminação, temperatura e umidade do ar; todos os dados detectados podem ser lidos no display OLED. A outra é regar as plantas automaticamente por meio do monitoramento do ambiente.

[![](https://files.seeedstudio.com/wiki/Seeed-WiKi/docs/images/300px-Get_One_Now_Banner-ragular.png)](https://www.seeedstudio.com/Grove-Smart-Plant-Care-Kit-for-Arduino-p-2528.html)
