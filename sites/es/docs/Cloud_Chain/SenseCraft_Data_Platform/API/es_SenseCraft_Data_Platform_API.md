# Introducción a la SenseCraft Data Platform API

![Descripción general de la SenseCraft Data Platform API](https://sensecap-docs.seeed.cc/images/open_api/introduction.png)

La SenseCraft Data Platform API, anteriormente documentada como SenseCAP API, permite que las aplicaciones gestionen dispositivos IoT compatibles y accedan a sus datos.

## Elige una API

| Objetivo | API | Comienza aquí |
| --- | --- | --- |
| Gestionar dispositivos y grupos, o recuperar datos actuales e históricos | HTTP API | [Inicio rápido de HTTP API](/es/sensecraft-data-platform/api/http-api/quick-start/) |
| Revisar los detalles de solicitud HTTP, respuesta y autenticación | HTTP API | [Guía de acceso a HTTP API](/es/sensecraft-data-platform/api/http-api/http-api-access-guide/) |
| Suscribirse a mensajes de dispositivos en tiempo real | Data OpenStream API | [Inicio rápido de Data OpenStream API](/es/sensecraft-data-platform/api/data-openstream-api/data_openstream_api_quickstart/) |
| Revisar los detalles de conexión, temas y el modelo de publicación-suscripción | Data OpenStream API | [Referencia de Data OpenStream API](/es/sensecraft-data-platform/api/data-openstream-api/data_openstream_api_reference/) |

La Data OpenStream API admite MQTT y MQTT sobre WebSocket para suscripciones a mensajes en tiempo real. Utiliza la Referencia de Data OpenStream API para consultar el host, el puerto, la autenticación y los detalles de los temas actuales.

Consulta [Precios de la API para SenseCraft Data Platform](/es/sensecraft-fee/sensecraft-data-platform-api-pricing/) para conocer las reglas de facturación y ejemplos.
