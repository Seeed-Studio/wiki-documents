# Inicio rápido y soporte de CodeCraft

## 1.1 Introducción a CodeCraft

### 1.1.1 “Lo dices, funciona”

CodeCraft es un asistente de programación con IA diseñado específicamente para escenarios de hardware. Solo necesitas describir lo que quieres en lenguaje natural y CodeCraft puede generar programas de hardware ejecutables para ti.

Es adecuado para usuarios que quieren completar rápidamente la creación de hardware sin configurar un entorno de desarrollo desde cero. Tanto si eres estudiante, profesor, maker o principiante en programación de hardware, puedes completar todo el proceso desde la idea hasta la ejecución mediante conversación.

### 1.1.2 De la idea a la ejecución en cuatro pasos

<!--![CodeCraft Workflow](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/codecraft-how-it-works.png)-->

El flujo de trabajo básico de CodeCraft es muy sencillo:

1. **Describe**  
   Usa lenguaje natural para describir tu idea, como “construir un temporizador Pomodoro” o “hacer que la placa de desarrollo detecte temperatura y humedad”.

2. **Genera**  
   CodeCraft genera automáticamente código ejecutable y documentación del proyecto según tu descripción.

3. **Flashea**  
   Sube el programa a tu placa de desarrollo con un solo clic a través de la web.

4. **Comparte**  
   Tras finalizar, puedes publicar el proyecto en la comunidad SenseCraft AI para reutilizarlo o compartirlo.

### 1.1.3 CodeCraft entiende tu hardware

<!--![CodeCraft vs General Coding Tools Comparison](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/codecraft-comparison.png)-->

En comparación con las herramientas generales de programación con IA, CodeCraft está más enfocado en escenarios de hardware. No solo genera código, sino que también entiende placas de desarrollo, sensores, protocolos de comunicación y librerías de hardware.

| Capacidad | Herramientas generales de programación | CodeCraft |
| :--- | :---: | :---: |
| Generación de código de software | Compatible | Compatible |
| Comprensión de pines de MCU y especificaciones de placas | No siempre compatible | Compatible |
| Compatibilidad con sensores y protocolos de comunicación | No siempre compatible | Compatible |
| Compilación en la nube, sin configuración de entorno local | No siempre compatible | Compatible |
| Flasheo con un clic a la placa de desarrollo | No siempre compatible | Compatible |
| Compartir en la comunidad de hardware SenseCraft AI | No siempre compatible | Compatible |

### 1.1.4 Capacidades principales

<!--![CodeCraft Core Features](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/codecraft-core-features.png)-->

Las capacidades principales de CodeCraft incluyen:

| Flujo de trabajo de desarrollo tradicional (demasiado complejo ❌) | Capacidades principales de CodeCraft (muy sencillo ✅) |
| :--- | :--- |
| ❌ Instalar IDEs grandes | ✨ Cero instalación: totalmente basado en la web, no requiere cliente |
| ❌ Configurar entornos complejos | ✨ Cero configuración: no requiere drivers ni configuración de entorno |
| ❌ Escribir código desde cero | 🤖 Nativo de IA: entiende pines y sensores, genera directamente código de hardware |
| ❌ Gestionar toolchains complejas | ☁️ Compilación en la nube: compilación de backend totalmente automatizada |
| ❌ Exportación y flasheo manuales | 🚀 Flasheo con un clic: subida directa al dispositivo |
| ❌ Desarrollo aislado | 🌐 Compartir en comunidad: publica y reutiliza proyectos a través de SenseCraft AI |

### 1.1.5 Ecosistema de hardware compatible

![CodeCraft Hardware Ecosystem](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/codecraft-hardware-ecosystem-EN.png)

CodeCraft se integra perfectamente con el ecosistema de hardware de Seeed Studio y es compatible con los siguientes dispositivos:

* **Wio Terminal**: Una placa de desarrollo todo en uno con pantalla de 2,4 pulgadas, múltiples sensores y compatibilidad con Wi-Fi y Bluetooth.
* **XIAO ESP32S3 Sense**: Una placa de desarrollo compacta con cámara y micrófono, adecuada para proyectos de visión y voz con IA.
* **Grove Beginner Kit**: Una placa todo en uno con módulos integrados, sin necesidad de cableado, ideal para principiantes y educación.
* **300+ sensores Grove**: Compatible con detección de movimiento, monitorización ambiental, salida de visualización, control de actuación, detección de luz y sonido e imagen.

## 1.2 Preparación e inicio de sesión

CodeCraft proporciona múltiples métodos de inicio de sesión. Tanto si eres desarrollador, estudiante o educador, puedes empezar rápidamente.

### 1.2.1 Registro e inicio de sesión personal

Cuando uses CodeCraft por primera vez, se creará una cuenta automáticamente, sin necesidad de un registro complejo. Puedes iniciar sesión usando:

* Inicio de sesión con correo electrónico
* Inicio de sesión con Google
* Inicio de sesión con GitHub
* Inicio de sesión con Apple
* Inicio de sesión con Bazaar (cuenta de la tienda oficial de Seeed Studio)

Se recomienda usar un método de inicio de sesión habitual para garantizar la sincronización de proyectos y datos en la nube entre dispositivos.

![Sign-up / Log-in](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/Sign-up-Log-in-EN.png)

### 1.2.2 Inicio de sesión con código de aula

CodeCraft también admite inicio de sesión con código de aula, diseñado para escenarios educativos.

El inicio de sesión con código de aula permite a los estudiantes omitir el registro y entrar directamente en un entorno de aula asignado por el profesor.

Pasos:

1. Selecciona “Classroom Code Login” en la pantalla de inicio de sesión.
2. Introduce el código de aula proporcionado por el profesor.
3. Entra en el entorno de aula y empieza a usar CodeCraft.

Los códigos de aula suelen ser proporcionados por profesores o centros educativos. Para necesidades educativas, puedes contactar con soporte o visitar la página de Soluciones Educativas de CodeCraft para más detalles.

![Classroom Code Login](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/Class-Code-Login-EN.png)

![CodeCraft Subscription Plans](https://files.seeedstudio.com/SenseCraft/sensecraft-wiki/codecraft/1-quick-start-and-support/codecraft-plans-EN.jpg)

| Plan | Usuarios objetivo | Descripción |
| :--- | :--- | :--- |
| FREE | Usuarios primerizos | Capacidades básicas de creación con IA |
| Pro | Estudiantes, aficionados | Adecuado para aprendizaje, proyectos y uso moderado |
| Max | Profesores, makers, desarrolladores | Cuota más alta para enseñanza, desarrollo y uso intensivo |

### 1.3.3 Canjear un código de membresía

Si obtienes un código de canje desde Taobao, la tienda oficial o promociones:

1. Abre https://codecraft.seeed.cc
2. Inicia sesión
3. Entra en el espacio de trabajo
4. Haz clic en Settings
5. Ve a Account o Billing
6. Busca “Redeem Code”
7. Introduce y confirma el código

Notas:

* Cada código suele ser de un solo uso.
* Asegúrate de que la cuenta sea correcta antes de canjear.
* La validez depende de los detalles del pedido.
* Si no se activa, actualiza la página o vuelve a iniciar sesión.

## 1.5 Ayuda y soporte

### 1.5.1 Preguntas frecuentes (FAQ)

**P: ¿Por qué mi código de canje no es válido?**  
R: Comprueba la corrección, el estado de uso y la cuenta con la que has iniciado sesión.

**P: No recibí el código después de comprar en Taobao.**  
R: Revisa los detalles del pedido o contacta con el soporte de la tienda.

**P: ¿La suscripción no se activó después del canje?**  
R: Actualiza la página o vuelve a iniciar sesión. Si sigue sin funcionar, contacta con soporte con la información del pedido.
