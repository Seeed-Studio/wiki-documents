# Demostración de Modo Compliant

Esta demostración pone el Reachy Mini en modo compliant y compensa la gravedad de la plataforma del robot para evitar que se caiga.

Puedes empujar suavemente el robot y seguirá tus movimientos. Cuando dejes de empujarlo, se mantendrá en su lugar. Esto es útil para aplicaciones como la interacción humano-robot, donde quieres que el robot sea compliant y siga los movimientos del usuario.

Nota: Esta demostración actualmente solo funciona con Placo como motor de cinemática.

Consulta el ejemplo completo en: [reachy_compliant_demo.py](https://github.com/pollen-robotics/reachy_mini/tree/develop/examples/reachy_compliant_demo.py)
