# Tomar foto

Este ejemplo muestra cómo capturar un solo fotograma de la cámara de Reachy Mini y guardarlo como un archivo de imagen.

Ejecutar con:
```bash
python take_picture.py --backend [default|local|webrtc]
```

La imagen capturada se guardará como `reachy_mini_picture.jpg` en el directorio actual.

Consulta el ejemplo completo en: [take_picture.py](https://github.com/pollen-robotics/reachy_mini/tree/main/examples/take_picture.py)
