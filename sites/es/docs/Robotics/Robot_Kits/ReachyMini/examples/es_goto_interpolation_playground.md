# Goto Interpolation Playground

Este código demuestra los diferentes métodos de interpolación disponibles en Reachy Mini para mover la cabeza y/o las antenas a una pose objetivo. Prueba varios métodos como linear, minjerk, ease_in_out y cartoon, lo que te permite observar cómo cada método afecta el movimiento de la cabeza y las antenas.

Consulta el ejemplo completo en: [goto_interpolation_playground.py](https://github.com/pollen-robotics/reachy_mini/tree/develop/examples/goto_interpolation_playground.py)
