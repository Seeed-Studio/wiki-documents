# Movimientos Grabados

Este ejemplo muestra cómo reproducir todos los movimientos disponibles de un conjunto de datos para Reachy Mini. Puedes usar bibliotecas preconstruidas para bailes y emociones, o proporcionar tu propio conjunto de datos personalizado.

Ejecutar con:
```bash
python recorded_moves.py -l [dance, emotions]
```

O con un conjunto de datos personalizado:
```bash
python recorded_moves.py --dataset path/to/your/dataset
```

Consulta el ejemplo completo en: [recorded_moves.py](https://github.com/pollen-robotics/reachy_mini/tree/develop/examples/recorded_moves.py)
