# Plataforma unificada JetPack 7.2, ISO y SBSA

:::info Contenido planificado
Esta página está reservada para una guía validada por Seeed sobre la arquitectura de la plataforma unificada JetPack 7.2. Explicará qué flujos de trabajo de instalación y BSP se aplican a Jetson Orin, cuáles se aplican a Jetson Thor y en qué puntos las dos familias de plataformas difieren de forma intencionada.
:::

La guía planificada cubrirá:

- la ruta de instalación unificada mediante ISO introducida con Jetson Linux 39.2;
- las diferencias de instalación, recuperación, almacenamiento y aprovisionamiento entre Orin y Thor;
- el comportamiento SBSA y las consideraciones de portabilidad de software en Jetson Thor;
- cuándo usar un flujo de trabajo de kit de desarrollo de NVIDIA frente a un BSP de producto de Seeed;
- puntos de validación antes de desplegar una aplicación común en Orin y Thor.

Hasta que se complete la validación, utiliza las páginas de flasheo específicas de producto de JetPack 7.2 en el [centro de recursos](/es/jetpack_7_2_resource_hub/).
