# Buscar grabaciones y almacenamiento

Después de configurar los disparadores de grabación de eventos (consulta [Configure Event Recording](/es/recamera_pro_record_settings/)), utiliza la página **Recording Settings** en la interfaz web para encontrar tus archivos y gestionar el almacenamiento del dispositivo.

## Gestión de almacenamiento

En **Storage Management** puedes ver el uso actual del disco y la ubicación donde se guardan los archivos.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_65N6rhHetJ.png" />

En el área de configuración de almacenamiento puedes establecer el tamaño de almacenamiento disponible, configurar cuotas y elegir si sobrescribir archivos antiguos para que las grabaciones más recientes siempre se guarden.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_WZBl9MEr7Z.png" />

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_hkMMlkzm7i.png" />
