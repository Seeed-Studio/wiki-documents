# Uso de la interfaz MIPI DSI
Hay una interfaz MIPI DSI en la parte trasera del dispositivo para conectar pantallas MIPI.
## Conectar la pantalla MIPI
Abra la tapa trasera de la placa base y localice la interfaz ***22PIN MIPI DSI*** como se muestra a continuación.
::: note
¡Apague el dispositivo antes de conectar la pantalla MIPI!
:::
![BASE_BOARD_PIN](https://files.seeedstudio.com/wiki/reCamera-Pro/getting_started/base_board_pin.png)

Localice el extremo TCON del cable de la pantalla MIPI e insértelo hacia adentro como se muestra en la siguiente figura:
![CONNECT_MIPI_SCREEN](https://files.seeedstudio.com/wiki/reCamera-Pro/Hardware_Usage/MIPI-DSI-ton-duan.jpg)

## Encendido
Después de conectar la pantalla MIPI, encienda el dispositivo y la imagen en tiempo real de la cámara se mostrará en la pantalla MIPI.
![SHOW_GIF](https://files.seeedstudio.com/wiki/reCamera-Pro/Hardware_Usage/MIPI_DSI_SHOW_CAMERA.gif)

::: note
La pantalla requiere una fuente de alimentación independiente; el dispositivo no proporciona una salida de alimentación dedicada para la pantalla.
:::
