## Registro del sistema

El área de registro del sistema se utiliza para ver en tiempo real los registros de funcionamiento de reCamera Pro, lo que facilita a los usuarios comprender el estado actual del dispositivo, el estado de funcionamiento de los servicios y solucionar problemas anómalos.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/20260708190224_6_2.png" />


Los usuarios pueden realizar las siguientes operaciones en esta área:

- Ver la salida del registro del sistema en tiempo real
- Filtrar registros por nivel de registro o palabras clave
- Borrar el contenido de visualización de registro actual
- Descargar los archivos de registro para el análisis de problemas o soporte técnico.

Esta función es aplicable a la depuración de equipos, confirmación del estado del servicio, investigación de anomalías y registro de reproducción de problemas.

## Consola de terminal

La consola de terminal permite a los usuarios iniciar sesión directamente en el terminal del sistema de reCamera Pro a través de la Web UI, sin necesidad de utilizar una herramienta SSH adicional.

<img width={800} src="https://files.seeedstudio.com/wiki/reCamera-Pro/web_ui_wiki/msedge_2dvKqObUbo.png" />

Los usuarios pueden iniciar sesión utilizando las siguientes cuentas predeterminadas:

```bash
Username: root
Password: recamera
```
