Este kit está dirigido a principiantes que quieren convertirse en makers. Los módulos funcionales incluidos en este kit se seleccionan especialmente para principiantes, todos ellos son módulos que se requieren con frecuencia y es rentable. La parte más sorprendente de este kit es la placa de desarrollo Wio Link, que se puede utilizar para varios dispositivos sin necesidad de ninguna habilidad de programación. Todas las acciones que quieras que realicen tus módulos y la operación de carga de código en Wio Link se pueden completar con toques en una aplicación móvil. Y puedes enviar instrucciones a tus dispositivos a través de Internet desde cualquier lugar. Así que Wio Link será una herramienta perfecta para hacer que todo a tu alrededor sea más inteligente para todo el mundo. Ahora disfrutemos siendo makers.

[![](https://files.seeedstudio.com/wiki/common/Get_One_Now_Banner.png)](https://www.seeedstudio.com/depot/Wio-Link-Starter-Kit-p-2614.html)

:::caution
     La función Wio IFTTT está en EOL. Pero la Wio APP está disponible. Puedes usar la API de Wio APP para leer el estado del sensor y controlar el actuador. 
:::
Características
--------

-   Incluye módulos funcionales de monitorización ambiental comunes y de uso frecuente
-   Puerto Grove como interfaz, función más práctica y menos trabajo
-   Completamente fácil hacer que las cosas a tu alrededor sean más inteligentes y añadir diversión a la vida diaria.
-   Rentable
-   Peso: 267 g
