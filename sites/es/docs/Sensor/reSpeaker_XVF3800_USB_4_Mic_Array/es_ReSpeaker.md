## ¿Qué es reSpeaker?

reSpeaker es una plataforma modular de interfaz de voz de código abierto desarrollada por Seeed Studio, diseñada para creadores, desarrolladores y empresas que deseen crear productos de interacción de voz inteligente. Integra matrices de micrófonos, procesadores de audio y varias opciones de conectividad, lo que facilita añadir capacidades de reconocimiento e interacción por voz a tus proyectos.

## Series de productos

### reSpeaker XVF3800

La serie reSpeaker XMOS XVF3800 está diseñada para creadores, desarrolladores y diseñadores de productos que exigen una captura de voz nítida incluso en entornos reales y ruidosos. Impulsada por el avanzado procesador de audio con IA XVF3800 y una precisa matriz circular de 4 micrófonos, ofrece captación de campo lejano de 360°, potente formación de haces y cancelación de ruido y eco de grado industrial hasta 5 metros de distancia. Elige entre opciones versátiles para adaptarse a tu proyecto: **reSpeaker XVF3800 with pre-soldered XIAO ESP32S3** para una integración instantánea con ESPHome o sistemas embebidos, o **reSpeaker XVF3800 enclosed AI voice solution** para una interfaz de voz pulida y lista para usar. Ya sea para asistentes inteligentes, robótica o quioscos interactivos, la serie XVF3800 ofrece un rendimiento de voz de nivel profesional en un formato compacto y amigable para makers.

### reSpeaker Lite

La serie reSpeaker Lite es tu puerta de entrada para crear potentes proyectos habilitados por voz y de alta calidad con facilidad. Impulsada por el chipset de audio con IA XMOS XU316 y una precisa matriz de micrófonos dual, ofrece una captura de voz de campo lejano nítida (hasta 3 metros), supresión avanzada de ruido y cancelación de eco, ideal para reconocimiento de voz, asistentes inteligentes y dispositivos interactivos. Elige entre varias versiones según tus necesidades: **reSpeaker Lite 2-Mic Array Voice Kit** con un XIAO ESP32S3 listo para ESPHome y pre-soldado para una configuración instantánea, o **reSpeaker Lite Voice Assistant Kit** con una carcasa acrílica y altavoz para una solución completa y lista para usar. Tanto si eres maker, desarrollador o innovador, reSpeaker Lite te ofrece el rendimiento, la flexibilidad y la libertad de código abierto para dar vida a tus proyectos de voz.

### reSpeaker 2-Mics Pi HAT

El reSpeaker 2-Mics Pi HAT V2.0 transforma tu Raspberry Pi en una potente plataforma habilitada por voz, perfecta para crear asistentes inteligentes, dispositivos controlados por voz y proyectos de IA interactivos. ### reSpeaker XVF3000

El reSpeaker XVF3000 USB Mic Array es una solución de captura de voz de campo lejano lista para usar y plug-and-play, diseñada para una integración instantánea en tus aplicaciones, sin necesidad de placas de desarrollo desnudas ni configuraciones complejas. Con una matriz de 4 micrófonos, compatibilidad con USB Audio Class 1.0 y 12 LED RGB programables, es perfecto para crear asistentes inteligentes, sistemas de conferencias y proyectos de voz interactivos. Con algoritmos de voz integrados como VAD, DOA, formación de haces, supresión de ruido, desreverberación y cancelación de eco acústico, ofrece una captación de voz nítida incluso en entornos difíciles. Para una configuración pulida y lista para despliegue, también puedes elegir la versión con una elegante carcasa protectora, ideal tanto para prototipos como para producción.

## Funciones principales

**Tecnología avanzada de matriz de micrófonos**

Incluye matrices circulares o lineales con 2-4 micrófonos MEMS, que admiten reconocimiento de voz de campo lejano, localización de la fuente de sonido y supresión de ruido. Captura con precisión los comandos de voz dentro de 5 metros incluso en entornos ruidosos.

**Potente procesamiento de audio**

Algoritmos de procesamiento de audio profesionales integrados, incluidos Acoustic Echo Cancellation (AEC), Noise Suppression (NS), Voice Activity Detection (VAD) y tecnología de formación de haz, lo que garantiza una calidad clara de la señal de voz.

**Opciones de desarrollo flexibles**

Admite múltiples plataformas de desarrollo y lenguajes de programación, incluidos Python, JavaScript y C/C++. Compatible con Raspberry Pi, Arduino y varias placas de desarrollo Linux, con SDK y API completos.

**Ecosistema de código abierto**

Diseño de hardware y pila de software completamente de código abierto, con una comunidad de desarrolladores activa que proporciona soporte técnico continuo. Personaliza y amplía libremente la funcionalidad para satisfacer requisitos de aplicación específicos.
