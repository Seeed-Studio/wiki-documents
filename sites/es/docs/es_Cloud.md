SenseCraft reúne software para crear aplicaciones de IA y hardware, entrenar robots, conectar dispositivos IoT, crear interfaces hombre-máquina y operar sistemas perimetrales desplegados. Los productos están relacionados, pero cada uno sirve a una etapa diferente del flujo de trabajo.

## Elegir por objetivo


| Tu objetivo | Empieza con |
| --- | --- |
| Crear, entrenar o desplegar una aplicación de IA en el borde | [SenseCraft AI](#sensecraft-ai) |
| Convertir una idea en código de hardware ejecutable | [CodeCraft](#codecraft) |
| Ejecutar modelos y herramientas de IA optimizados en hardware reComputer | [reComputer AI Lab](#recomputer-ai-lab) |
| Recopilar demostraciones, entrenar y validar el comportamiento de un brazo robótico | [SenseCraft Robotics](#sensecraft-robotics) |
| Conectar dispositivos IoT y recopilar o ver datos de sensores | [SenseCraft Data Platform](#sensecraft-data-platform) |
| Configurar dispositivos compatibles y supervisarlos desde un teléfono | [SenseCraft App](#sensecraft-app) |
| Crear paneles y experiencias de visualización para reTerminal | [SenseCraft HMI](#sensecraft-hmi) |
| Operar dispositivos perimetrales distribuidos y desplegar aplicaciones | [SenseCraft Device Management Platform](#sensecraft-device-management-platform) |
| Desplegar o gestionar gateways SenseCAP para redes descentralizadas | [SenseCAP MX / Hotspot](#sensecap-mx-hotspot) |

:::info Límites del producto

- **reComputer AI Lab** es el nombre oficial actual de los modelos, herramientas, tutoriales y centro de recursos de proyectos enfocados en reComputer.
- **SenseCraft Device Management Platform** es la capa de operaciones para gestionar dispositivos de borde y aplicaciones desplegadas; comienza con una aplicación o solución concreta y luego utiliza la gestión de dispositivos para operarla a escala.
- **SenseCraft App** y **SenseCAP Hotspot App** son productos móviles diferentes. Utiliza SenseCraft App para los dispositivos IoT compatibles y flujos de trabajo de datos, y SenseCAP Hotspot App para los flujos de trabajo de gateway y hotspot compatibles.

:::
