# Centro de Preguntas Frecuentes de reComputer

Este centro recopila respuestas verificadas a nivel de producto para la familia reComputer. Cada pregunta se publica en la página de preguntas frecuentes de su producto y se contrasta con las fuentes oficiales actuales, y la fecha de **Última verificación** en cada respuesta muestra cuándo se revisó por última vez.

## Cómo usar este centro de preguntas frecuentes

1. Escribe un nombre de producto, SKU, mensaje de error o palabra clave de una función en el cuadro de búsqueda.
2. ¿No estás seguro de qué palabra clave usar? Elige primero un producto y luego un dominio como **Hardware** o **OS & Firmware**.
3. Haz clic en un resultado para saltar a la pregunta exacta en la página de preguntas frecuentes del producto.
4. Antes de seguir los pasos, revisa los campos **Se aplica a**, variante de SoC y **Última verificación**.
5. Si la pregunta no se resuelve, ten preparado tu modelo de producto, SKU, versión de la imagen, sistema host y una reproducción mínima antes de contactar con el soporte técnico.
