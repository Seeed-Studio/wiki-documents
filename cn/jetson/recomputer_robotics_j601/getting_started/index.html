reComputer Robotics J601 入门指南

快速开始概览与烧录硬件与接口接口与扩展应用感知与传感器融合
机器人与物理 AI · NVIDIA Jetson AGX Thor

在一块机器人载板上连接感知与控制

reComputer Robotics J601 载板支持 NVIDIA Jetson AGX Thor T5000 和 T4000 模组，用于多摄像头感知、传感器融合和具身 AI 开发。将高速以太网、GMSL2 摄像头扩展和隔离机器人 I/O 与 Jetson 软件平台相结合。

购买单板 · J601 载板 ↗从 JetPack 开始 ↓
最高 2070 TFLOPS搭配 Jetson AGX Thor T5000 模组的 AI 性能
最高 4× 10GbET5000 提供 4 个 RJ45 端口；T4000 提供 3 个
最高 8× GMSL2通过两块 GMSL 扩展板实现多摄像头输入
19–48 V DC通过 XT30 电源接口提供宽范围输入

选择你的 Jetson 配置​

J601 是一块载板。请为你的方案选择兼容的 Jetson AGX Thor 模组、NVMe SSD 和散热方案。下面的 J6015 和 J6014 名称用于标识本指南中使用的、针对不同模组的配置和 BSP 软件包。

T5000 配置

reComputer Robotics J6015

对于拥有 4 个激活的 10GbE 端口和 4 路隔离 CAN 接口的配置，请使用 T5000 BSP。

AGX Thor T50004× 10GbE4× CAN FD
T4000 配置

reComputer Robotics J6014

对于拥有 3 个激活的 10GbE 端口和 2 路隔离 CAN 接口的配置，请使用 T4000 BSP。

AGX Thor T40003× 10GbE2× CAN FD

兼容模组：NVIDIA Jetson AGX Thor T5000 和 NVIDIA Jetson AGX Thor T4000。

为什么选择 reComputer Robotics J601​

多摄像头感知GMSL 扩展板最多支持 8 路 GMSL2 摄像头，实现环视感知和传感器融合。
高速网络最多 4 路 10GbE RJ45 连接，在传感器、计算节点和开发系统之间传输数据。
机器人 I/O隔离 CAN FD、RS-232/422/485、I2C、I2S 和数字 I/O 用于连接控制器、传感器和执行器。
模块化扩展M.2 Key M 支持 NVMe 2280 SSD；Key E 和 Key B 支持兼容的 Wi-Fi/Bluetooth 以及 4G/5G 模组。
开发连接性4 个 USB 3.2 Type-A 端口和 HDMI 2.1 用于连接外设和显示器，并提供独立的调试和恢复 USB-C 端口。
物理 AI 工作流基于 Jetson 使用 NVIDIA Isaac、ROS、PyTorch 和 Hugging Face 等框架构建应用，并遵循各框架的平台要求。

刷写 JetPack​

本流程会在 J601 载板上的 NVMe SSD 上安装 JetPack 7.1（L4T 38.4.0）。请根据已安装的模组选择 BSP：T5000 使用 J6015，T4000 使用 J6014。

caution

刷写会清除目标 NVMe SSD 上的数据。开始前请备份重要数据，并在刷写完成前保持电源和 USB 连接。

1

准备设备

步骤 1 · 准备 Ubuntu 主机和目标硬件

准备以下设备：

  • 搭载 Jetson AGX Thor T5000 或 T4000 模组并配备合适散热的 J601 载板
  • 安装在 Key M 插槽中的 NVMe M.2 2280 SSD
  • 通过 XT30 连接的 19–48 V DC 电源
  • 物理 Ubuntu 22.04 或 24.04 主机 PC，且至少有 220 GB 可用存储空间
  • USB Type-C 数据线
  • 用于首次启动的 HDMI 显示器、键盘和鼠标
tip

原生 Ubuntu 主机能提供最稳定的刷写体验。Seeed Jetson DevelopTool 也通过 WSL2 支持 Windows；主机环境搭建请参考其安装指南。

2

进入强制恢复模式

步骤 2 · 连接 J4 并验证已安装的模组

  1. 在开发板断电的情况下，将主机 PC 连接到 USB 3.0 Type-C 恢复/烧录接口 (J4)。USB 2.0 Type-C 调试接口 (J3) 是一个单独的连接器。
  2. 按住并保持 RECOVERY。
  3. 通过 XT30 连接 19–48 V 直流电源。
  4. 2 秒后松开 RECOVERY。
  5. 在 Ubuntu 主机上运行以下命令：
lsusb
配置模组预期恢复 USB ID
J6015AGX Thor T50000955:7026 NVIDIA Corp.
J6014AGX Thor T40000955:7226 NVIDIA Corp.

如果未看到预期的 ID，请检查数据线和恢复接口，然后在继续之前重新执行恢复步骤。

3

准备匹配的 BSP

步骤 3 · 选择图形工具或命令行烧录方式

  • 图形工具烧录
  • 命令行烧录

安装并启动 Seeed Jetson DevelopTool，然后准备固件：

  1. 打开 Flash Center，选择 reComputer J601 和 JetPack 7.1 (L4T 38.4.0)。
  1. 确认步骤 2 中的恢复连线。
  1. 点击 Detect Device，确认已安装的模组，然后点击 Next。
  1. 点击 Download / Prepare BSP。工具会下载固件、验证其 SHA-256 校验和，并解压缩固件包。
观看 Jetson DevelopTool 烧录教程

在下方下载针对模组的 BSP 压缩包。该压缩包体积较大，下载可能需要约 60 分钟。请等待下载完成后再进行解压。

  • AGX Thor T5000 (J6015)
  • AGX Thor T4000 (J6014)

sha256sum <downloaded-archive.tar.gz>
4

烧录 NVMe SSD

步骤 4 · 使用相同的烧录方式和模组选择

  • 图形工具烧录
  • 命令行烧录

在 Jetson DevelopTool 中点击 Start Flash，并等待界面提示烧录成功。在整个过程中请保持电源和 USB 数据线始终连接。

在 Ubuntu 主机上解压缩压缩包，然后根据已安装的模组运行对应命令。将 YYYY-MM-DD 替换为下载压缩包文件名中的日期。

  • AGX Thor T5000 (J6015)
  • AGX Thor T4000 (J6014)
cd <path-to-image>
sudo tar xpf mfi_recomputer-thor-carrier-j6015-7.1-38.4.0-YYYY-MM-DD.tar.gz
cd mfi_recomputer-thor-carrier-j6015
sudo ./tools/kernel_flash/l4t_initrd_flash.sh --flash-only --showlogs --external-device nvme0n1p1 -c tools/kernel_flash/flash_l4t_t264_nvme.xml -S 80GiB --network usb0 recomputer-thor-carrier-j6015 external
cd <path-to-image>
sudo tar xpf mfi_recomputer-thor-carrier-j6014-7.1-38.4.0-YYYY-MM-DD.tar.gz
cd mfi_recomputer-thor-carrier-j6014
sudo ./tools/kernel_flash/l4t_initrd_flash.sh --flash-only --showlogs --external-device nvme0n1p1 -c tools/kernel_flash/flash_l4t_t264_nvme.xml -S 80GiB --network usb0 recomputer-thor-carrier-j6014 external

烧录命令通常需要 2–10 分钟。请等待终端提示烧录成功。

5

完成首次启动

步骤 5 · 配置 Ubuntu 并检查各接口

连接 HDMI 显示器、键盘和鼠标，完成 Ubuntu 的初始系统配置。如果烧录完成后未出现设置界面，请在烧录工具提示成功后对开发板断电重启。

继续阅读 硬件与 I/O 以验证你的外设，或体验 感知演示。Seeed 的载板设备树和 BSP 源码可在 Linux_for_Tegra 中获取。

可选：探索其他 Jetson 载板

完成设置后，你可以查看其他 Seeed Jetson 载板的固件下载和烧录说明。
