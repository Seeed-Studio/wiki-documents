术语表、文档地图和许可

术语表​

平台与硬件​

术语含义
RV1126BRockchip 面向 IPC 的 SoC，带有 NPU 和 ISP35。reCamera Pro 的主芯片；RK_CHIP=rv1126b，RK_ARCH=arm64
RV1126BPRV1126B 封装 / 衍生版本，用于某些 EVB 板卡配置
RK801reCamera Pro 使用的 PMIC
RK817带集成音频编解码器的 PMIC（CONFIG_SND_SOC_RK817=y）
ES7202Everest 多通道 ADC，用于麦克风阵列采集
ISP35RV1126B 的 ISP 版本；相关 IQ 文件位于 iqfiles/isp35/ 下
eMMC板载存储（RK_BOOT_MEDIUM=emmc）
Maskrom内置于 SoC ROM 的下载模式；烧录入口（USB VID 2207）
loader / idblockDDR 初始化和第一阶段引导加载程序；输出包括 idblock.img 和 download.bin
board ID通过 ADC 分压电阻电平检测的底板 / 扩展板变体；结果写入 /run/board_id.env
DTBO设备树 Blob Overlay，在运行时用于通过一个固件镜像支持多种硬件变体

SDK 与构建系统​

术语含义
BSP板级支持包：包括 U-Boot、内核、rootfs 和驱动的板级支持
BoardConfigproject/cfg/<series>/BoardConfig-*.mk；一次构建所用的完整板级参数集合
lunch选择一个 BoardConfig；术语来自 Android 构建系统。会生成 .BoardConfig.mk 符号链接
sysdrv系统驱动组件 SDK，包含 U-Boot / 内核 / MCU 源码；可使用 make 独立构建
media多媒体组件 SDK，包含 mpp / rockit / rkaiq / rga / iva 等；可使用 make 独立构建
app位于 project/app/ 下的用户空间应用程序
fragment增量内核 / U-Boot defconfig，按顺序叠加在基础 defconfig 之上
overlay在打包过程中复制到 rootfs 上的文件目录；启用的条目列在 RK_POST_OVERLAY 中
IQ file图像质量文件，包含 rkaiq 传感器调参参数（JSON）
rootfsBuildroot 生成的 ext4 根文件系统，位于 3 G 分区上
oem/oem 目录。本板设置了 RK_BUILD_APP_TO_OEM_PARTITION=n，因此它是 rootfs 内的普通目录，而不是单独分区
userdata挂载在 /userdata 的可写分区；存储配置和用户数据，也是默认 HOME
misc包含恢复 / 恢复出厂标志的小分区
RK_APP_TYPE参考应用类型；本板使用 RKIPC_RV1126B_RECAMERA2
allsaveall + save；在不带参数运行 ./build.sh 时的默认行为
RK_APP_xxx控制是否构建某个应用程序的板级配置开关
MAROC_*Makefile.param 中的一组宏，包括 MAROC_COPY_PKG_TO_APP_OUTPUT、MAROC_STRIP_DEBUG_SYMBOL 和 MAROC_PKG_RELEASE

多媒体（rockit / MPI）​

术语含义
MPIMedia Process Interface，rockit 的统一编程接口
rockitRockchip MPI 运行时实现；链接选项为 -lrockit
MPPMedia Process Platform，底层编解码库；链接选项为 -lrockchip_mpp
VIVideo Input；通过 ISP 从传感器采集帧
VPSSVideo Process Sub System；多通道缩放 / 裁剪 / 格式转换
VENC / VDEC视频编码 / 解码
VO输出视频到显示设备
RGN用于 OSD 叠加和水印的区域模块
AI / AOAudio In / Audio Out
AENC / ADEC音频编码 / 解码
AVS多摄像头环视拼接的全景系统
IVS智能视频监控，用于运动检测等分析
TDETwo Dimensional Engine，用于 2D 加速
RGARaster Graphic Acceleration，2D 加速器，用于缩放、NV12↔RGB 转换和旋转
MBMedia Buffer / 缓冲池
BindRK_MPI_SYS_Bind() 连接两个模块的通道，使数据自动流动
EIS / DIS电子 / 数字图像稳定
ePTZ电子云台变焦
SVC可伸缩视频编码
AOVAlways-On Vision，低功耗常开视觉
FEC鱼眼 / 畸变校正硬件（CONFIG_VIDEO_ROCKCHIP_FEC=y）
IRFPA红外焦平面阵列（热成像）
rkaiqRockchip AI ISP 引擎，用于 3A 和调参；链接选项为 -lrkaiq
uAPI / uAPI2两代 rkaiq 用户空间接口；新代码应使用 uAPI2（rk_aiq_user_api2_*.h）
AINRAI 降噪；相关 IQ 文件位于 iqfiles/isp35/ainr/ 下
AI-ISP使用 NPU 增强 ISP 输出；在本板上禁用（RK_AIISP_MODEL=NONE）

AI / NPU​

术语含义
NPU集成在 RV1126B 中的神经处理单元
RKNNRockchip 神经网络模型格式和运行时（.rknn + librknnrt.so）
RKNN-Toolkit2PC 端模型转换工具，适用于 x86_64 / Python；不包含在 SDK 中，需单独安装。内部基线版本：2.3.2
rknn-toolkit-lite2设备端 Python 推理封装，仅适合验证用途。生产应用中请使用 C API
RKLLMRockchip 大语言模型运行时（.rkllm + librkllmrt.so）
rkllm-toolkit位于 media/rknn-llm-mk/rknn-llm/rkllm-toolkit/ 下的 PC 端 LLM 转换工具
ROCKIVA打包的 Rockchip 视觉算法（人 / 人脸 / 宠物检测等）；链接选项为 -lrockiva
RKAI位于 project/app/rkai/ 下的 Rockchip AI 封装，覆盖 LLM 和 VLM 工作流
VLMVision-Language Model；用于图像和文本的多模态模型
TTFTTime To First Token，RKLLM 的基准测试指标
RKNN_NPU_CORE_xNPU 核分配掩码（AUTO / 0 / 0_1 / 0_1_2）
INT8 quantization / calibration set量化使用具有代表性的图像列表；请将校准集与验证集分开

网络与流媒体​

术语含义
rkipcRockchip IPC 参考应用；reCamera Pro 主应用（recamera_ipc）基于它实现
go2rtc开源流媒体网关，将内部 RTSP 转换为 WebRTC / HLS 等；以预编译二进制形式随 overlay 提供
RTSP实时流传输协议。内部源为 127.0.0.1:5554；外部端口 :554 按需启用
WebRTC基于浏览器的实时音视频；go2rtc 监听 :8555 端口
ONVIF由 recamera_onvif 实现的网络设备互操作标准
ttyd通过网页在端口 7681 暴露终端
main / sub stream与 live/0 和 live/1 对应的 go2rtc 流名称

reCamera 服务​

术语含义
gmgrGPIO Manager：Rust 编写的 GPIO HTTP / WebSocket 服务，监听端口 8080 和 /dev/shm/gmgr.sock
skt2ws将 rkipc-record-events 转发的 Socket-to-WebSocket 桥接服务
tmirTTY Mirror；将串口 ttyS4 流量复用到 socket / WebSocket
rcisdreCamera Intellisense 守护进程，用于事件排队和文件传输
RkLunch.sh位于 /oem/usr/bin/ 下的系统级应用启动入口
vigil位于 recamera_ipc/common/vigil* 下的模块；依赖 protobuf 和 libblkid
VQEVoice Quality Enhancement，音频前端算法（AEC / ANS / AGC）
AECAcoustic Echo Cancellation；需要扬声器参考信号（asound.conf 中的 Ch4）
dsnoopALSA 共享采集插件，使多个进程可以读取同一个硬件设备
KWS / ASRKeyword Spotting / Automatic Speech Recognition；对应的虚拟设备为 ai_kws / ai_asr
