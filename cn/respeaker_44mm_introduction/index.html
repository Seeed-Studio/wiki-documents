reSpeaker XVF3800 44mm 4-Mic Array 入门指南

reSpeaker XVF3800 4-Mic Array 44mm 是一款紧凑的圆形语音处理模块，基于 XMOS XVF3800 音频处理器构建，适用于语音识别、语音控制、智能助理和机器人等应用。四颗 PDM MEMS 麦克风以环形排布，间距为 44 mm，在一块明显小于 66 mm 间距 reSpeaker XVF3800 Circular 4-Mic Array 的电路板上实现 360° 远场拾音，同时保持相同的 XMOS 处理平台和相同的音频质量。

该模块运行完整的 XVF3800 语音处理链路——声学回声消除（AEC）、60 dB 范围的自动增益控制（AGC）、多通道波束成形、声源到达方向（DoA）检测、语音活动检测（VAD）、动态噪声抑制以及混响消除——并且所有参数都支持用户调节。外圈配有 24 颗 WS2812 RGB LED、三个物理按键（音量加、音量减、静音）以及一个硬件静音指示灯，开箱即可使用；同时支持 USB Audio Class 2.0 和 I2S 模式，既可即插即用，也便于嵌入式集成。可选的 XIAO ESP32-S3 Plus 可直接焊接在板上，可选的扬声器扩展板则提供一个 5 W 扬声器和一块 1200 mAh 电池。

特性​

  • 紧凑的 44 mm 设计：麦克风间距从 66 mm 减小到 44 mm，缩小了电路板直径，使其能够安装在空间受限的产品中。

  • XMOS XVF3800 音频处理：AEC、AGC（60 dB 范围）、多通道波束成形、DoA、VAD、动态噪声抑制和混响消除，并支持参数调节。

  • 高音频质量：设计目标与现有的 66 mm 间距 reSpeaker XVF3800 Circular 4-Mic Array 保持同等音质。

  • 双工作模式：USB Audio Class 2.0 适用于与 PC 和 SBC 的即插即用，或 I2S/INT-Device 模式适用于嵌入式主机——通过固件进行选择。

  • 灵活的控制与升级：通过 USB 或 I2C 进行配置，根据烧录的固件支持 USB DFU 和 I2C DFU。

  • 唯一设备标识：可读写 UUID/SN，用于多设备管理、识别和数据追踪。

  • 可编程 RGB 反馈：24 × WS2812 LED 显示设备状态、启动动画和 DoA 方向；静音状态由专用红色 LED 指示。

  • 三个可自定义按键：默认连接到 XMOS 处理器时分别为音量加、音量减和静音，可通过开关将其切换连接到 XIAO。

  • 扬声器就绪：板载 D 类功放、用于 5 W 4 Ω 扬声器的垂直 JST 扬声器连接器、3.5 mm AUX 插孔，以及用于硬连线扬声器的焊盘。

  • 广泛的平台兼容性：支持 Windows、macOS 和 Raspberry Pi OS 等 USB 主机，以及与 XIAO、ESP32 和 Arduino 级开发板的 I2S 集成。

硬件概览​

电路板正面放置了四个麦克风以及最外圈的 24 颗 RGB LED，因此在将电路板安装到外壳中后，声学开孔和灯环都能保持可见。背面则放置了 USB-C 接口、3.5 mm 插孔、JST 扬声器连接器、复位按键、XIAO ESP32-S3 Plus 焊盘以及所有引出焊盘。

XIAO ESP32-S3 Plus 支持​

XIAO ESP32-S3 Plus 可以直接焊接在板子的背面。安装后，它会与 XVF3800 以及板载按键和 LED 相连：

功能描述
XIAO ESP32-S3 Plus 支持将 XIAO ESP32-S3 Plus 模组直接焊接到阵列上，实现集成语音处理和应用开发
XVF3800 通信通过 I2S 进行录音和回放，共享 BCLK、MCLK 和 LRCLK，并通过 I2C 实现对 XVF3800 的控制和配置

扩展 GPIO 访问其余 XIAO I/O 通过带标签的焊盘引出（用于传感器、外设和应用硬件），并与 XVF3800 I/O 区域对齐

reSpeaker Sound Base（扬声器扩展）​

扬声器扩展可将麦克风阵列变成一个独立的语音终端。它在一个模块化外壳中集成了一个 5 W、4 Ω 扬声器、一个 1200 mAh 可充电电池、充电与电源管理电路、一个 USB-C 充电口以及一个物理电源开关，该外壳可以卡扣或滑动安装到阵列外壳的底部。

  • 外壳可以拆卸，用户可以自行更换电池和扬声器。
  • 暴露的 XMOS I/O 连接器在两块板之间传输扬声器输出、5 V 电源和电池电量信号。
  • 充电 LED 灯环在充电时显示电池电量百分比，在未连接电池时保持熄灭。
  • 开关只控制输出；在开关关闭的情况下仍会继续充电。

入门指南​

硬件准备​

  • USB Type-C 线缆
  • 主机电脑，或 Raspberry Pi
  • 可选：用于回放的 5 W 4 Ω 扬声器
  • 可选：用于无线 / 嵌入式运行的 XIAO ESP32-S3 Plus

软件准备​

  • 用于录音和回放测试的 Audacity
  • 用于固件更新的 dfu-util
  • 带有 pyusb 的 Python 3，用于参数调节

开箱即用​

note

为确保最佳的语音拾取效果以及音频算法的正确运行，请将设备背面麦克风端口（麦克风进音口 / 声孔）朝向声源。麦克风端口位于印有 Seeed Studio 标志的一侧。

DoA（到达方向）​

LED 灯环会跟随来声方向变化，因此无需任何软件就能看到检测到的角度。DoA 数值也可以通过 USB/I2C 读取，用于你自己的应用。

静音按键​

静音按键会暂时禁用来自麦克风阵列的采集。

  • 麦克风被静音，因此外部声音将不再被采集或处理。
  • 静音激活时红色 LED 会点亮。
  • 不会向主机发送任何音频输入。
  • 再次按下按键会取消静音。设备上电时默认为非静音状态。

音量增大 / 减小​

当按键被路由到 XVF3800 时，剩下的两个按键默认用于调节回放音量。它们是单次触发控制：每按一次，音量调整一个步进。同样的音量级别也可以通过主机上的 Python 控制工具或操作系统的混音器来设置。

复位按键​

复位（RST）按键提供 XVF3800 的硬件复位。按下它会重新启动芯片，并从头重新初始化系统，与完整断电重启的效果完全相同。

扬声器连接​

你可以根据自己的音频输出偏好，通过板载 JST 连接器或 3.5 mm AUX 插孔连接扬声器。使用 JST 连接器并配合 4 Ω、5 W 扬声器，可由板载 LM48511 功放驱动。

安全模式​

安全模式是一种恢复模式，允许你通过 USB DFU 或 I2C DFU 烧录固件。如果你之前烧录了 I2S 固件并希望切换回 USB 固件，或者开发板不再被识别时，可以使用该模式。

固件USB DFUI2C DFU
USB 固件支持不支持
I2S 固件不支持支持
安全模式固件（出厂分区）支持支持

何时使用安全模式

  • 固件工作异常（USB 未被检测到、LED 行为异常）。
  • 需要重新烧录，但当前固件没有响应。
  • 烧录了错误的固件，希望恢复开发板。

如何进入安全模式

  1. 将设备完全断电。
  2. 按住 Mute 按键。
  3. 在按住的同时重新接通电源。
  4. 红色 LED 开始闪烁——设备现在正在从出厂分区运行安全模式固件。

更新固件​

官方 GitHub 仓库中提供了两个固件镜像：

  • 面向 Windows、Linux 和 macOS 等主机系统的 USB 固件
  • 面向 XIAO ESP32-S3 Plus 等微控制器主机的 I2S 固件
note

从 GitHub 下载固件文件时 不要 使用 “Save as”（另存为）——这样得到的二进制文件会损坏。请克隆仓库，或使用 Download ZIP 获取包含所有文件的完整仓库。

仓库： reSpeaker_XVF3800_4MIC_44mm

USB 固件​

USB 固件会枚举为 UAC 2.0 声卡，适用于 Windows、Linux 和 macOS 主机。

固件镜像USB 音频配置
respeaker_44mm_usb_c48k2ch_v1.0.0.bin48 kHz、2 通道 USB 音频

固件目录中不包含 USB 音频类描述符转储文件。烧录完成后，请在配置录音应用之前，先在主机上验证设备报告的格式——不要在未从设备描述符确认的情况下，擅自假定采样位宽或额外的采样率 / 通道配置。

I2S 固件​

当阵列连接到 XIAO ESP32-S3 Plus 等微控制器主机时，需要使用 I2S 固件。音频通过 I2S 传输，XVF3800 通过 I2C 控制。

固件通道数说明
respeaker_44mm_i2s_c48k2ch_v1.0.0.bin2处理后的 2 通道输出：通道 0 = Conference，通道 1 = ASR

要烧录 XMOS 固件，请使用 USB 线将开发板连接到电脑。使用靠近 3.5 mm 音频插孔的 XMOS USB-C 接口。

安装 DFU Util​

dfu-util 是一个用于通过 USB 进行设备固件升级（DFU）的命令行工具。

  • Windows
  • macOS
  • Linux

  • 下载 dfu-util-0.11-binaries.tar.xz 并解压，例如解压到 D:\dfu-util-0.11-binaries\win64\

    Download Link

  • 将 dfu-util.exe 的路径添加到系统的 Path 变量中：

    My Computer > Properties > Advanced > Environment Variables > Path

  • 打开 Command Prompt（cmd）并验证安装：

dfu-util -V

  • 连接 reSpeaker XVF3800 44mm 并检查设备是否被检测到：
dfu-util -l

如果你看到： Cannot open DFU device 2886:0024 ... (LIBUSB_ERROR_NOT_SUPPORTED) 请继续进行下面的驱动安装。

  • 安装 Zadig
    • 打开 Zadig → Options > List All Devices
    • 选择 reSpeaker 3800 44 mm 或 reSpeaker XVF3800 4-Mic Array 44mm
    • 安装 WinUSB 驱动
    • 重新上电该设备
    • 再次运行 dfu-util -l 以确认已检测到
  • 使用 Homebrew 安装 dfu-util：
brew install dfu-util
  • 检查设备是否被检测到：
dfu-util -l

烧录固件​

  • 运行以下命令，并将 -D 指向你想要烧录的 .bin 文件：
dfu-util -R -e -a 1 -D /path/to/dfu_firmware.bin
  • 在 Linux 上，请使用 sudo 运行：
sudo dfu-util -R -e -a 1 -D /path/to/dfu_firmware.bin

-R 选项会在烧录完成后自动重启开发板。

再次运行 dfu-util -l 以确认新的固件版本已经在运行。

调参​

调参可以让你配置内置音频算法，并直接与 XMOS 芯片通信。我们提供了一个 Python 控制接口，用于参数配置和设备交互。

Python Control Directory

使用提供的脚本，你可以：

  • 配置内置音频算法参数
  • 获取 DoA（到达方向）数据
  • 获取 VAD（语音活动检测）数据
  • 控制板载 LED
  • 控制语音处理流水线
  • 读写设备 UUID
  • 将信号路由到 USB 输出通道

系统要求

  • Python 3.6 或更高版本
  • pyusb Python 库
  • libusb 系统库

安装与依赖​

pip install pyusb

在 Windows 上，libusb-package pip 包是提供 libusb 的最简单方式。在 Linux 上，请通过你的包管理器安装 libusb。

用法​

基本语法

python xvf_host.py [options] command [--values value(s)...]

命令选项

OptionDescription
-l, --list列出所有支持的命令及其详细信息
--vid设置 USB Vendor ID（默认：0x2886）
--pid设置 USB Product ID；如果省略，则通过 VID 自动发现设备
--values为写命令提供数值（可选），十进制或十六进制（0x7B）

使用示例​

1. 列出所有可用命令

python xvf_host.py --list

2. 读取固件版本

python xvf_host.py VERSION
VERSION: [1, 0, 0]

返回的元组格式取决于你烧录的固件。

3. 读取到达方向（DoA）

python xvf_host.py DOA_VALUE
DOA_VALUE: [135]

角度以度为单位，范围 0–359。

4. 设置 LED 颜色

python xvf_host.py LED_COLOR --values 0xFF0000

5. 设置 LED 亮度

python xvf_host.py LED_BRIGHTNESS --values 50

6. 读取麦克风阵列几何结构

python xvf_host.py AEC_MIC_ARRAY_GEO
AEC_MIC_ARRAY_GEO:
[0.033, -0.033, 0.000,
 0.033,  0.033, 0.000,
-0.033,  0.033, 0.000,
-0.033, -0.033, 0.000]

这些数值是波束形成器使用的麦克风 X/Y 坐标（单位：米）。在进行声学测量或校准之前，请检查报告的几何结构是否与你的开发板麦克风间距以及你烧录的固件镜像相匹配。

USB 输出通道选择​

USB 固件通过 AUDIO_MGR_OP_L 和 AUDIO_MGR_OP_R 将信号路由到立体声输出。每条命令需要两个数值：category（信号组）和 source（该组内的信号）。省略 --values 可读取当前路由配置。

python xvf_host.py AUDIO_MGR_OP_L
python xvf_host.py AUDIO_MGR_OP_L --values 6 3
python xvf_host.py AUDIO_MGR_OP_R --values 1 0

最后两条命令会将自动选择的波束路由到左声道，将原始麦克风 0 路由到右声道。原始麦克风数据流会绕过语音增强，通常比处理后的音频更安静。

保存路由配置，使其在重启后仍然生效：

python xvf_host.py SAVE_CONFIGURATION --values 1

故障排除​

在 Linux 上扬声器回放声音太小​

XVF3800 声卡有自己的 ALSA 混音器音量级别。如果回放声音太小：

  1. 打开混音器：

    alsamixer

  2. 按 F6，选择 reSpeaker XVF3800 4-Mic 44mm 声卡，然后按 Enter。

  3. 使用方向键选择 PCM-1 并将其调到 100%。

  4. 按 ESC 退出并保存设置：

    sudo alsactl store

  5. 如果仍然很小，安装 PulseAudio Volume Control 并将输出提高到 100% 以上：

    sudo apt install pavucontrol -y

刷写后开发板未在 Windows 中显示为声音设备​

打开 设备管理器（Device Manager），找到相关的 reSpeaker 条目，右键点击每一项并选择 卸载设备（Uninstall device）。然后拔下并重新插入 USB 线缆——Windows 会重新安装正确的声卡驱动。

dfu-util -l 报告 LIBUSB_ERROR_NOT_SUPPORTED​

WinUSB 驱动未绑定到 DFU 接口。安装 Zadig，启用 Options > List All Devices，选择 reSpeaker 3800 44 mm，安装 WinUSB，对开发板断电重上电，然后再次运行 dfu-util -l。

开发板完全无法枚举​

进入 安全模式（Safe Mode）（在上电时按住静音按钮，等待红色 LED 闪烁），然后重新刷写 USB 固件。安全模式固件同时支持 USB DFU 和 I2C DFU，因此始终可以恢复。
