SenseCAP M2 Light Gateway 概述

什么是 SenseCAP M2 Light Gateway

SenseCAP M2 Light Hotspot 是一款高性能的 LoRaWAN 网关，允许用户以最低成本加入 Helium 网络。

SenseCAP M2 的 SenseCAP 软件许可证低至每天 0.05 美元，按需付费，让您能够以最小的投资享受 PoC 和数据传输的好处。

立即购买

软件许可证

SenseCAP M2 Light Hotspot 需要软件许可证激活才能为 Helium 提供 LoRaWAN 覆盖。SenseCAP 提供三种许可证计划供您按需购买。

许可证套餐：

许可证有效期90 天365 天无限制

套餐计划

$7.99 低至 $0.09/天$19.99 低至 $0.05/天$49.99 无限制许可证

注意： 此许可证仅适用于 SenseCAP M2 Light Hotspot，不能用于激活其他热点设备。

SenseCAP 软件许可证与 Helium 入网费不同，需要激活 SenseCAP 软件和云服务。Helium 为将热点设备接入 Helium 服务器而收取的 50 美元入网费已包含在 SenseCAP Hotspot 套装中。

特性

多频段和认证

SenseCAP M2 提供不同频段版本和相应认证，以满足您在各个国家和地区的应用需求，包括但不限于：澳大利亚 (RCM)、巴西 (Anatel)、加拿大 (ICES/IC IC)、欧盟 (CE/RoHS/REACH/WEEE/VerpackG)、印度 (WPC)、日本 (TELEC/PSE)、韩国 (KC)、菲律宾 (NTC)、台湾 (BSMI/NCC) 和美国 (FCC)。

还有更多认证正在进行中。

卓越稳定的性能

采用成熟的硬件，配备联发科 MT7628 和 Semtech SX1302/SX1303 基带 LoRa 芯片，SenseCAP M2 提供卓越稳定的性能，内置 BLE 并支持 Wi-Fi 和以太网互联网连接。

对于需要通过以太网为网关供电而不使用额外电源线的用户，它支持 PoE，因此无需额外的 PoE 分离器。如果您的路由器不支持 PoE 功能，SenseCAP 注入器 也可供您使用。

广域覆盖和强信号

为了增强 SenseCAP M2 的覆盖范围和信号强度，它配备了高性能 3dBi 天线，可在 LoRaWAN 网络上提供数英里的广域覆盖。此外，天线可以升级为更高 dBi 的 玻璃纤维天线，以适应各种使用场景和环境。

专业管理工具和云服务

SenseCAP Hotspot 为设置和管理热点设备提供无忧解决方案。用户可以通过 SenseCAP Hotspot App 轻松完成几个简单步骤来设置热点设备。SenseCAP Hotspot Dashboard 和 SenseCAP Local Console 也为用户提供了高效便捷的热点设备监控和管理方式。

安全可靠

对于处理大量数据传输的网关，安全性永远不会过度关注。SenseCAP M2 采用 ECC608 安全芯片提供可靠安全的身份验证，确保与 People's Network 的安全稳定连接。

高效及时的在线支持

SenseCAP 凭借其一流的技术支持赢得了客户的高度赞誉。如果您遇到技术问题，可以依靠 SenseCAP 高效的在线技术支持服务提供及时有效的帮助。凭借 SenseCAP 卓越的客户支持，您可以相信会得到所需的帮助，让您的设备和服务平稳运行。

轻松升级为户外热点设备

SenseCAP 户外外壳 适合市场上的通用热点设备，也可供您将室内 SenseCAP 热点设备升级为户外设备，从而实现各种户外 LoRaWAN 应用场景。

通过简单步骤和所需的全部配件，将您的室内网关升级为户外网关，它也适用于其他热点设备，如 SenseCAP M1、SenseCAP M2、BobCat、RAK、Helium hotspot 等。
