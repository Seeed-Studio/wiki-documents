什么是 Grove 生态系统？ ​

Grove 是一个模块化、标准化连接器的原型系统。与使用跳线或焊接的系统相比，Grove 采用模块化积木式的方式，使真实电子电路的搭建变得简单。Grove 系统由一个基座单元和带有标准化连接器的各种模块组成。这些最初被称为“stems”和“twigs”，但这些名称已经逐步废弃。

基座单元通常是一个微处理器，可以轻松连接来自 Grove 模块的任何输入或输出。每个 Grove 模块通常只负责一个功能，例如一个简单的按钮，或更复杂的心率传感器。你并不一定需要基座单元才能连接其他 Grove 模块，你可以使用一根线缆（Grove 转 Pin Header 转接线）从树莓派或 Arduino 的引脚连接到 Grove 接口。

Grove 生态系统中有什么？ ​

Grove 生态系统为原型制作和搭建电子系统提供了一种方便、易用的方法。其模块化特性、标准化连接器以及种类繁多的模块，使得无论是初学者还是有经验的创客，都可以快速组装并试验真实的电子电路。

Grove 传感器 ​

Grove 生态系统提供了种类丰富的传感器，可以轻松集成到你的电子项目中。这些传感器针对特定功能设计，能够提供多种类型的输入数据。

Grove 网络模块​

Grove 系统还包含网络模块，使你的项目具备通信和连接能力。这些模块可以让你的电子设备连接到不同的网络，例如 Wi-Fi、Bluetooth、LoRa、NFC 或其他标准协议。

借助 Grove 网络模块，你可以轻松为项目添加无线功能，实现数据传输、远程控制，或与其他设备以及互联网进行交互。

📖 Wiki 平台 🖱️ 购买

Grove 配件 ​

除了传感器和网络模块之外，Grove 生态系统还提供了多种配件，用来补充和增强你的电子项目。这些配件包括 LCD 显示屏、LED 点阵、电机驱动、继电器模块等组件。

Grove 模块的接口​

你可能注意到 Grove 线缆有 4 种不同的颜色。

  • 引脚 1 - 黄色（例如 I2C Grove 接口上的 SCL）
  • 引脚 2 - 白色（例如 I2C Grove 接口上的 SDA）
  • 引脚 3 - 红色 - 所有 Grove 接口上的 VCC
  • 引脚 4 - 黑色 - 所有 Grove 接口上的 GND

Grove 模块的接口主要有 4 种类型。

Grove 数字接口​

一个数字 Grove 接口由进入 Grove 插头的标准四条线组成。两条信号线通常被称为 D0 和 D1。大多数模块只使用 D0，但有些（如 LED Bar Grove 显示模块）会同时使用两条信号线。通常底板单元的第一个接口称为 D0，第二个称为 D1，它们的连线方式是 D0/D1，然后是 D1/D2，依此类推。

Grove 数字模块的示例有：开关模块、风扇模块和 LED 模块。在图 8 中，你可以看到 LED Grove 模块原理图上的 Grove 接口长什么样。它们可以从非常简单到非常复杂不等。

引脚功能说明
pin1Dn主数字输入/输出
pin2Dn+1次数字输入/输出
pin3VCCGrove 模块供电，5V/3.3V
pin4GND地

Grove 模拟接口​

一个 Grove 模拟接口由进入 Grove 插头的标准四条线组成。两条信号线通常被称为 A0 和 A1。大多数模块只使用 A0。通常底板单元的第一个接口称为 A0，第二个称为 A1，它们的连线方式是 A0/A1，然后是 A1/A2，依此类推。

引脚功能说明
pin1An主模拟输入
pin2An+1次模拟输入
pin3VCCGrove 模块供电，5V/3.3V
pin4GND地

Grove UART​

Grove UART 模块是 Grove 数字模块的一种特化版本。它使用引脚 1 和引脚 2 来进行串行输入和发送。Grove UART 插头是从底板单元的角度来标注的。换句话说，引脚 1 是 RX 线（底板单元用它来接收数据，因此是输入），而引脚 2 是 TX 线（底板单元用它向 Grove 模块发送数据）。

引脚功能说明
pin1RX串行接收
pin2TX串行发送
pin3VCCGrove 模块供电，5V/3.3V
pin4GND地

Grove I2C​

长期关注这个博客的读者都知道，我们最喜欢的器件是 I2C 传感器。市面上有许多类型的 I2C Grove 传感器可供选择。大部分是 5V/3.3V 器件，但也有少数只支持 3.3V 或 5.0V。你需要查看其规格说明。

Grove I2C 接口的布局是标准的。引脚 1 是 SCL 信号，引脚 2 是 SDA 信号。电源和地与其他接口相同。这是 Grove 数字接口的另一种特化版本。实际上，控制器（如 ESP8266、Raspberry Pi 和 Arduino）上的 I2C 总线往往就是使用数字 I/O 引脚来实现 I2C 总线的。Raspberry Pi 和 Arduino 上的这些引脚具有 I2C 总线的硬件支持，因此是特殊的。

引脚功能说明
pin1SCLI2C 时钟
pin2SDAI2C 数据
pin3VCCGrove 模块供电，5V/3.3V
pin4GND地
