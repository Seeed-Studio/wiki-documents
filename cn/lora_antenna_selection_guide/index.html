LoRa 天线选型指南

本指南帮助用户在购买或部署 SenseCAP 系列产品及兼容的 Seeed Studio LoRa 设备时，选择合适的替换天线。文中提供了天线频段、连接器类型、所需射频线缆、兼容设备以及实用选型建议的完整概览。

首先选择与设备频段匹配的天线，然后检查设备是需要直接连接器还是需要转接线缆。

warning

不要将 2.4/5 GHz 天线连接到 868/915 MHz LoRa 端口。切勿在未连接合适天线的情况下发射。

天线总览​

860-930MHz 天线​

这些天线适用于亚 GHz 频段的 LoRa、LoRaWAN 和 Meshtastic 设备。下面的产品按天线外形分组，方便你快速决定是需要高增益玻璃钢天线、紧凑型棒状天线，还是室内磁吸底座天线。

玻璃钢天线​

玻璃钢天线通常用于网关、屋顶节点以及其他需要更好室外覆盖范围的固定安装场景。请检查设备是否已经包含所需的射频线缆，或者你是否需要一根 RP-SMA 转 N 型线缆。

3 dBi 玻璃钢天线

SKU 318020652
频率902-928 MHz
增益3 dBi
长度360 mm
包含磁吸底座

可连接设备：SenseCAP M1 室内网关。随附的底座适合可移动或临时安装。

棒状天线​

棒状天线是用于开发板和便携式 LoRa 设备的紧凑型 SMA 天线。带有 I-PEX 天线座的设备，在使用这些天线前需要配合 120 mm SMA 转 I-PEX 天线线缆（SKU 321990397）。

2.8 dBi 远距离天线

SKU 318020269
频率868 MHz
增益2.8 dBi
长度195 mm
接口SMA 公头

可连接设备：直接连接 Wio-E5 Dev Board 或 Wio-E5 mini；通过 120 mm SMA 转 I-PEX 天线线缆（SKU 321990397）连接 Wio-SX1262 或 Wio Tracker L1 Pro。

连接到：可直接连接 Wio-E5 Dev Board 或 Wio-E5 mini；通过 120 mm SMA-to-I-PEX 天线线缆（SKU 321990397）连接 Wio-SX1262 或 Wio Tracker L1 Pro。

室内天线​

室内天线适用于桌面网关、轻热点，或临时室内放置的场景，此时磁吸底座比固定的室外安装更方便。

3 dBi 室内天线

SKU 110991765
频率860-930 MHz
增益3 dBi
长度295 mm
安装方式磁吸底座

连接到：SenseCAP M2 Data Only Hotspot 和 SenseCAP M2 Light Hotspot。
