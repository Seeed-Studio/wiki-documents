Orbbec Gemini2 3D Camera

紧凑型 Gemini 2 3D 相机基于主动立体 IR 技术，配备 Orbbec 最新定制 ASIC，用于高质量深度处理、IMU，以及单线 USB 3.0 供电与连接。其宽视场角和宽深度感知范围使 Gemini 2 能适应多种应用场景，尤其适用于机器人。借助 Orbbec SDK，易于安装和操作，并且在从全黑到半户外等各种光照条件下都能提供极其精确且可靠的数据。

立即获取 🖱️

特性​

  • 主动立体 IR 采用主动立体 IR 技术输出深度信息，可在各种光照条件下实现精确且可靠的数据输出
  • 宽感知范围 在 0.15m 到 10m 范围内提供高质量深度数据输出
  • 宽视场角 提供 91° 水平、66° 垂直的宽视场数据
  • 多相机同步 支持深度图像和 RGB 图像的多相机同步
  • USB 连接 使用单根 USB 3.0 Type-C 线缆实现供电和数据连接

规格参数​

Gemini 系列快速上手指南​

  • 连接 Orbbec 相机 ① 将云台与三脚架组装好，然后按照下方步骤 1 所示，将相机固定在已组装好的三脚架上。

    ② 使用 USB-C 转 USB-A 线缆连接相机的 Type-C 接口，如下方步骤 2 所示。

    ③ 使用同一根 USB-C 转 USB-A 线缆，将 USB-A 接头连接到主机，如下方步骤 3 所示。

  • 获取 Orbbec Viewer

根据你的系统和版本选择并下载对应的 Orbbec Viewer。

  • 启动 Orbbec Viewer
  1. 启动 Orbbec Viewer 后，请确认工具已识别到 3D 相机，如下图所示。 【备注】如果未识别到相机，请检查相机与主机是否正确连接。你可以尝试先断开再重新连接 USB 线缆。如果仍无法识别，请考虑更换 USB 线缆，或检查主机电源供给是否满足要求。
  1. 切换工具顶部的 ‘Depth’ 按钮，以启动并预览深度图像流。
  1. 切换工具顶部的 ‘Color‘ 按钮，以启动并预览彩色图像流。彩色图像流和深度图像流将并排显示。
  1. 切换工具顶部的 ‘IR Left’ 和 ‘IR Right’ 按钮，以启动并预览 IR 图像流。
  1. 切换工具顶部的 ‘IMU’ 按钮，以启动并预览 IMU 数据流。
  1. 切换每个窗口顶部的按钮，以显示元数据信息。
  1. 切换工具顶部的 ‘PointCloud‘ 按钮，以启动并预览 3D 点云。
  1. 在左侧 ‘Image View’ 菜单下切换 ‘Display’ 按钮，以启动并预览 D2C（深度到彩色配准）图像流。3D 点云和 D2C 图像流将并排显示。

在 reComputer 上开始使用​

步骤 1. 下载并安装适用于 ARM64 架构的 Orbbec SDK：

# Download Orbbec SDK
wget https://github.com/orbbec/OrbbecSDK_v2/releases/download/v2.4.11/OrbbecSDK_v2.4.11_202508040936_058db73_linux_aarch64.zip

# Unzip the SDK
unzip OrbbecSDK_v2.4.11_202508040936_058db73_linux_aarch64.zip

步骤 2. 构建示例并进行测试：

# Install udev rules
cd OrbbecSDK_v2.4.11_202508040936_058db73_linux_aarch64/shared/
sudo chmod +x ./install_udev_rules.sh
sudo ./install_udev_rules.sh
sudo udevadm control --reload-rules && sudo udevadm trigger
# Build examples and setup
cd ..
./build_examples.sh
./setup.sh

常见问题​

我可以在 Orbbec Viewer 中预览哪些数据流类型？ 深度、彩色、左 IR、右 IR、IMU、3D 点云以及 D2C 配准流。每一种在查看器顶部都有自己的开关，并且点云和 D2C 可以并排显示。

查看器中没有列出相机。我首先应该检查什么？ USB 连接。重新插拔 USB-C 转 USB-A 线缆，尝试另一根线缆，并确认主机端口能够提供足够的电力——Gemini 2 的功耗高于低功率集线器端口所能提供的电力。

除了查看器之外，Jetson 端还需要什么？ Orbbec SDK v2.4.11 aarch64 软件包。先从 shared/install_udev_rules.sh 安装 udev 规则，然后在任何应用程序与相机通信之前运行 ./build_examples.sh 和 ./setup.sh。

这和 Gemini 336 指南中的相机是同一款吗？ 不是。本页面介绍的是 Gemini 2；三脚架和查看器截图与 Gemini 336 快速入门共享，因为这两款相机都使用同一个 Orbbec Viewer。不同型号的 SDK 软件包和深度范围是不同的。

我可以用它做距离测量或跟踪吗？ 可以——末尾链接的两个示例都在 reComputer 上运行：使用 YOLOv11 的距离测量，以及在无人机上结合 PX4 的目标跟踪。两者都通过 Orbbec SDK 读取深度数据流。
