SO-ARM 数据集工具

立即购买 SO-ARM101 套件

简介​

使用 lerobot-edit-dataset 编辑数据集，使用 lerobot-dataset-viz 在本地查看剧集。

还没录制数据？请参阅 SO-ARM100 / SO-ARM101 机械臂入门教程。

命令示例以 Seeed LeRobot 的数据集工具实现为准；不同版本的参数可能不同。

任务用途
删除剧集移除指定编号的剧集。
拆分数据集按比例或剧集编号切分数据。
合并数据集把多个数据集合并成一个新数据集。
移除特征移除指定特征，例如某个相机的图像。
转换为视频将图像帧编码为视频，可在转换后上传 Hugging Face Hub。
数据集在线可视化在浏览器中查看已上传的数据集。
数据集本地可视化用命令行工具查看 Hub 或本地数据集。

删除剧集​

这里的「剧集」指一次完整的机器人动作录制。

  • 另存为新数据集
  • 修改原数据集

用 --new_repo_id 指定输出数据集，保留原始数据。示例移除剧集 0、2 和 5。

# Delete episodes and save to a new dataset (preserves original dataset)
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --new_repo_id lerobot/pusht_after_deletion \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]"
caution

此命令会修改原数据集。先核对数据集 ID 和剧集编号。如果要保留原始数据，请选择「另存为新数据集」。

# Delete episodes 0, 2, and 5 (modifies original dataset)
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]"
参数用途
--repo_id输入数据集的 ID，例如 lerobot/pusht。
--new_repo_id另存时使用的新数据集 ID。
--operation.episode_indices要删除的剧集编号列表。

拆分数据集​

  • 按比例拆分
  • 按剧集编号拆分

示例将剧集约按 80%、10%、10% 分到训练、测试和验证集。

# Split by fractions (e.g. 80% train, 10% test, 10% val)
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type split \
    --operation.splits '{"train": 0.8, "test": 0.1, "val": 0.1}'

示例将剧集 0–3 分给 task1，将剧集 4–5 分给 task2。

lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type split \
    --operation.splits '{"task1": [0, 1, 2, 3], "task2": [4, 5]}'

各拆分结果以输入数据集 ID 加拆分名作为后缀，例如 lerobot/pusht_train。示例将结果写到本地，上传需显式指定 --push_to_hub true。

合并数据集​

lerobot-edit-dataset \
    --new_repo_id lerobot/pusht_merged \
    --operation.type merge \
    --operation.repo_ids "['lerobot/pusht_train', 'lerobot/pusht_val']"
参数用途
--new_repo_id合并后的新数据集 ID。
--operation.repo_ids要合并的源数据集 ID 列表。

移除特征​

如果只需要保留腕部相机画面，可以移除桌面相机的图像特征。这个示例从数据集中移除 observation.images.top。

lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type remove_feature \
    --operation.feature_names "['observation.images.top']"

转换为视频​

将图像帧编码为视频，生成新的数据集，可减少存储占用并改善读取性能。

1

选择输出方式

第 1 步

  • 保存到本地目录
  • 使用新数据集 ID
  • 转换并上传 Hub

用 --new_root 指定输出目录，结果保留在本地。

# Local-only: Save to a custom output directory (no hub push)
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --new_root /path/to/output/pusht_video

用 --new_repo_id 指定结果的数据集 ID，文件保存在本地。

# Save with new repo_id (local storage)
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --new_repo_id lerobot/pusht_video \
    --operation.type convert_image_to_video

确认你有目标数据集仓库的写权限。--push_to_hub true 会在转换后上传结果。

# Convert and push to Hugging Face Hub
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --new_repo_id lerobot/pusht_video \
    --operation.type convert_image_to_video \
    --push_to_hub true
2

检查转换结果

第 2 步

检查输出目录中的 videos/ 是否包含相机的 MP4 文件，并确认剧集、统计信息和任务定义仍在。.parquet 文件保留元数据，图像帧存放在视频文件中。

可组合的转换选项​

以下选项可根据需要与输出设置一起使用。

自定义编码参数​

# Convert with custom video codec and quality settings
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --new_root outputs/pusht_video \
    --operation.rgb_encoder.vcodec libsvtav1 \
    --operation.rgb_encoder.pix_fmt yuv420p \
    --operation.rgb_encoder.g 2 \
    --operation.rgb_encoder.crf 30

设置并行进程​

# Convert with multiple workers for parallel processing
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --new_root outputs/pusht_video \
    --operation.num_workers 8

限制每批处理量​

# For memory-constrained systems, users can now specify limits:
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.max_episodes_per_batch 50 \
    --operation.max_frames_per_batch 10000
参数用途
--new_root自定义本地输出目录。
--operation.rgb_encoder.vcodecRGB 视频编码器，例如 h264、hevc 或 libsvtav1。
--operation.rgb_encoder.pix_fmtRGB 视频像素格式，例如 yuv420p。
--operation.rgb_encoder.g关键帧间隔。
--operation.rgb_encoder.crf编码质量参数，较低的值通常使画质更高、文件更大。
--operation.rgb_encoder.fast_decode快速解码调优选项，具体取值由编码器决定。
--operation.episode_indices要转换的剧集编号。省略时转换全部剧集。
--operation.num_workers并行工作进程数，默认为 4。
--operation.max_episodes_per_batch每批最多处理的剧集数。
--operation.max_frames_per_batch每批最多处理的帧数。

数据集在线可视化​

在 Hugging Face 数据集可视化工具 中打开已上传的数据集。

数据集本地可视化​

  • 查看 Hub 数据集
  • 查看本地数据集

使用 Hub 中的数据集 ID。示例查看编号为 0 的剧集。

lerobot-dataset-viz \
    --repo-id lerobot/pusht \
    --episode-index 0

用 --root 指定本地数据根目录，并选择 --mode local。

lerobot-dataset-viz \
    --repo-id lerobot/pusht \
    --root ./my_local_data_dir \
    --mode local \
    --episode-index 0
参数用途
--repo-id要查看的数据集 ID。
--episode-index要查看的剧集编号，从 0 开始。
--root本地数据集目录。
--mode local从本地文件系统读取数据集。

FAQ​

  • 从 Seeed LeRobot 仓库获取这篇教程对应的工具。其他版本可能使用不同的命令或数据格式。
  • 如果终端长时间没有刷新，可以按 Enter 查看有无新输出。压缩格式的数据集处理可能需要较长时间，请留意进度条。
