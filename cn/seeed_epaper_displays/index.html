Seeed ePaper 显示屏 — 产品矩阵概览

介绍​

ePaper（电子纸）只有在内容发生变化时才会消耗电能，这使其成为始终在线信息面板的理想显示技术——数字标牌、智能家居仪表盘、电子价签、会议室看板、相框等。

Seeed Studio 提供端到端的 ePaper 产品组合，围绕三个产品线进行组织：

  1. reTerminal E 系列 — 完全集成、开箱即用的 ePaper 终端（只需上电即可使用）。
  2. 驱动 / 扩展板 — 将 MCU 与通用或大尺寸 ePaper 屏幕配对，构建你自己的产品。
  3. DIY 套件与裸屏 — 为创客社区设计，针对 TRMNL 或 XIAO 等特定平台进行了优化。

这三条产品线共享同一软件生态系统：SenseCraft HMI（零代码）、Home Assistant / ESPHome、TRMNL、Arduino / ESP-IDF / PlatformIO、Zephyr，以及 SquareLine Vision、EEZ Studio 和 Lopaka 等可视化 UI 工具。选择任意一款硬件系列，其余工具链保持一致。

软件生态一览​

每一款 Seeed 电子纸产品都汇聚到同一个软件生态中。选择与你技能水平匹配的工作流——你也可以自由组合使用：

工具 / 平台类型功能说明兼容产品
SenseCraft HMI零代码（云端）AI 生成器、图库、画布、RSS / 网页内容、OTA 部署。reTerminal E 系列的默认固件。reTerminal E1001 / E1002 / E1003 / E1004 · EE02 · EE03 · EE04 · EE05
ESPHome / Home Assistant基于 YAML原生 Home Assistant 集成；使用 YAML 声明式构建仪表盘。reTerminal E1001 / E1002 / E1004 · EE04 · TRMNL DIY Kit · XIAO 7.5" Panel
TRMNL云端仪表盘插件驱动的仪表盘（日历、新闻、天气、金融、自定义数据）。reTerminal E1001 · E1002（单色模式）· TRMNL 7.5" DIY Kit · XIAO 7.5" Panel
Arduino / PlatformIO / ESP-IDF代码（C/C++）完整的编程控制：GPIO、传感器、网络、自定义渲染。所有 ESP32-S3 产品（E1001–E1004、EE02–EE05、TRMNL Kit、XIAO Panel）
Zephyr RTOSRTOS上游 Zephyr 开发板工作流，包含 west、设备树、内核服务、驱动、烧录和调试。reTerminal E1001 / E1002 / E1003
SquareLine Vision可视化 UI 设计在浏览器中拖拽式创建 LVGL UI，然后导出可直接编译的代码。reTerminal E1001 / E1002
EEZ Studio可视化 UI 设计以可视化方式设计 HMI 界面，并通过 Arduino IDE 部署。reTerminal E1001 / E1002 · EE04
Lopaka可视化 UI 设计基于 Web 的绘图工具，可为单色和彩色电子纸布局导出代码。reTerminal E1001 / E1002
OpenEPaperLink / OpenDisplay开源固件（BLE）基于 BLE 的开源电子纸固件。OpenDisplay 开箱即用支持 EN04；OEPL Config Builder 面向 Breakout Board + XIAO nRF52840 DIY 路径。EN04 · XIAO ePaper Breakout Board
