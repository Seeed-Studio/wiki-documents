## ¿Qué es ReSpeaker?

ReSpeaker es una plataforma modular de interfaz de voz de código abierto desarrollada por Seeed Studio, diseñada para creadores, desarrolladores y empresas que deseen crear productos de interacción de voz inteligente. Integra matrices de micrófonos, procesadores de audio y varias opciones de conectividad, lo que facilita añadir capacidades de reconocimiento e interacción por voz a tus proyectos.

## Serie de productos

### ReSpeaker Lite

La serie ReSpeaker Lite es tu puerta de entrada para crear proyectos potentes y de alta calidad habilitados por voz con facilidad. Impulsada por el chipset de audio de IA XMOS XU316 y una matriz de micrófonos dual de precisión, ofrece una captura de voz de campo lejano nítida (hasta 3 metros), supresión de ruido avanzada y cancelación de eco, perfecta para reconocimiento de voz, asistentes inteligentes y dispositivos interactivos. Elige entre varias versiones para adaptarse a tus necesidades: el **ReSpeaker Lite 2-Mic Array Voice Kit** con un XIAO ESP32S3 preparado para ESPHome y pre-soldado para una configuración instantánea, o el **ReSpeaker Lite Voice Assistant Kit** con una carcasa acrílica y altavoz para una solución completa y lista para usar. Tanto si eres un maker, desarrollador o innovador, ReSpeaker Lite te ofrece el rendimiento, la flexibilidad y la libertad de código abierto para dar vida a tus proyectos de voz.

### ReSpeaker XVF3800

La serie ReSpeaker XMOS XVF3800 está diseñada para creadores, desarrolladores y diseñadores de productos que exigen una captura de voz nítida incluso en entornos ruidosos y del mundo real. Impulsada por el avanzado procesador de audio de IA XVF3800 y una matriz circular de 4 micrófonos de precisión, ofrece captación de campo lejano de 360°, potente formación de haces y cancelación de ruido y eco de nivel industrial hasta 5 metros de distancia. Elige entre opciones versátiles para adaptarse a tu proyecto: el **ReSpeaker XVF3800 with pre-soldered XIAO ESP32S3** para una integración instantánea con ESPHome o sistemas embebidos, o la **ReSpeaker XVF3800 enclosed AI voice solution** para una interfaz de voz pulida y lista para usar. Ya sea para asistentes inteligentes, robótica o quioscos interactivos, la serie XVF3800 ofrece un rendimiento de voz de nivel profesional en un factor de forma compacto y amigable para makers.

### ReSpeaker 2-Mics Pi HAT

El ReSpeaker 2-Mics Pi HAT V2.0 transforma tu Raspberry Pi en una potente plataforma habilitada por voz, perfecta para crear asistentes inteligentes, dispositivos controlados por voz y proyectos de IA interactivos. Equipado con el códec de audio TLV320AIC3104, micrófonos analógicos duales y algoritmos NLU integrados para VAD, DOA y KWS, ofrece una captura de voz clara y precisa para interacciones receptivas. Sus LED RGB programables, botón de usuario y diseño sencillo de conectar y usar facilitan la creación de prototipos y la personalización, ya sea que estés integrando Alexa, Google Assistant o tu propia interfaz de voz.

### ReSpeaker XVF3000

El ReSpeaker XVF3000 USB Mic Array es una solución de captura de voz de campo lejano lista para usar y plug-and-play, diseñada para una integración instantánea en tus aplicaciones, sin necesidad de una placa de desarrollo desnuda ni de una configuración compleja. Con una matriz de 4 micrófonos, compatibilidad con USB Audio Class 1.0 y 12 LED RGB programables, es perfecto para crear asistentes inteligentes, sistemas de conferencias y proyectos de voz interactivos. Con algoritmos de voz integrados como VAD, DOA, formación de haces, supresión de ruido, desreverberación y cancelación de eco acústico, ofrece una captación de voz nítida incluso en entornos difíciles. Para una configuración pulida y lista para el despliegue, también puedes elegir la versión con una elegante carcasa protectora, lo que la hace ideal tanto para prototipos como para producción.

## Funciones principales

**Tecnología avanzada de matriz de micrófonos**

Incluye matrices circulares o lineales con 2-4 micrófonos MEMS, que admiten reconocimiento de voz de campo lejano, localización de la fuente de sonido y supresión de ruido. Captura con precisión los comandos de voz dentro de 5 metros incluso en entornos ruidosos.

**Potente procesamiento de audio**

Algoritmos de procesamiento de audio profesionales integrados, incluidos Acoustic Echo Cancellation (AEC), Noise Suppression (NS), Voice Activity Detection (VAD) y tecnología de conformación de haz, lo que garantiza una calidad clara de la señal de voz.

**Opciones de desarrollo flexibles**

Admite múltiples plataformas de desarrollo y lenguajes de programación, incluidos Python, JavaScript y C/C++. Compatible con Raspberry Pi, Arduino y varias placas de desarrollo Linux, con SDK y API completos.

**Ecosistema de código abierto**

Diseño de hardware y pila de software completamente de código abierto, con una comunidad de desarrolladores activa que proporciona soporte técnico continuo. Personaliza y amplía libremente la funcionalidad para satisfacer requisitos de aplicación específicos.
