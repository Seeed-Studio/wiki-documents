详细教程: reCamera + Wifi Halow模块配置 + reTerminal配置
    整个系统的总体思路是, 让reCamera通过Wifi HaloW与终端设备形成一个网络. 首先在终端设备(reTerminal)和reCamera上配置静态IP, 因为户外或者移动应用不能有路由器, 就没有DHCP服务, 需要手动分配IP. 分配完IP之后, 这些设备就形成
    一个'局域网', 它们之间可以通过IP互相访问, 此时在reCamera上通过Node-RED创建流节点和http post节点, 将视频流以rtsp推流形式发送, 将yolo detection结果以http post形式发送 最终在终端设备上访问视频流和AI检测结果, 
    比如在Windows/Linux上用VLC Media Player访问, 这篇教程将演示在Linux上通过fflag获取rtsp推流

    阶段1: 配置reCamera
        步骤1.1 用USB-C线将reCamera连接到电脑, 设备刚上电需要一些时间启动, 等待1-2分钟之后, 打开任意网页浏览器, 输入192.68.42.1进入reCamera系统. 第一次登录需要自己配置密码, 请一定记住自己的密码, 后续会用到. 进入reCamera系统之后应该看到这个页面. 
        >图2: reCamera默认页,

        如果刷新还是无法解决, 请重置设备或者联系技术支持解决

        步骤1.2.2 点击页面右下角的绿色按钮, 进入Workspace. 上面提到, 我们需要在Node RED上配置rtsp推流, 配置方法请参考: [Node Red rtsp链接], 配置之后应该得到如下结果:

    阶段3: 配置终端设备(reTerminal)
        我们现在要在reTerminal上配置静态IP, 理论上有很多种方法, 比如通过NetworkManager, NetworkManager是Linux系统里的一个网络管理守护进程自动帮你管理Wi-Fi/以太网/IP 地址/DHCP/热点/路由等所有网络连接的工具
        您可以尝试通过NetworkManager. 但是为了降低学习成本, 我们用在reCamera上配置静态IP一样的方法, 为reTerminal配置IP. 

        >Note: 再次强调, reTerminal可以换成任意带有网口和屏幕的(边缘)计算设备, 包括但不限于笔记本, 台式机, 开发板等等. 如果想要做静态应用, 比如在固定位置观看监控, 可以使用Window笔记本/台式机. 如果想要
        移动应用, 其他基于树莓派, Jetson等带有屏幕的边缘计算设备都可以. 我们在这篇教程中使用reTerminal + reTerminal E10扩展板, 这个扩展板只是为了给设备室外供电, 您可以自己选择给终端设备的供电方式

        步骤3.1: 启动reTerminal, reTerminal出厂自带系统. 理论上可以直接进入Raspbian, 但如果您给设备上电之后, 设备左下角绿色LED点亮/闪烁但黑屏, 请参考这篇教程重新烧录reTerminal系统, 而在这一步, 需要用到显示器对reTerminal进行调试
        reTerminal刷机链接: [reTerminal刷机链接] 
        
        步骤3.2: 连接键盘鼠标到reTerminal, ctrl+alt+T 打开终端, 由于NetworkManager服务和上述方法有冲突, 我们需要手动禁用NetworkManager服务. 在reTerminal终端中输入命令:
        >代码4: 
            sudo systemctl stop NetworkManager
            sudo systemctl disable NetworkManager
            sudo systemctl mask NetworkManager

        步骤3.3: 在终端里输入以下命令:
        >代码6: sudo vi /etc/network/interfaces
        还是通过vi编辑器进入网络配置文件, 在文件末尾添加几行代码, 这里我将reTerminal的静态IP设置为192.168.10.3
        >代码7: auto eth0
                iface eth0 inet static
                address 192.168.10.3
                netmask 255.255.255.0
                gateway 192.168.10.1

        >Note: 如果因为其他原因, 您想要重新使用NetworkManager, 在刚刚的/etc/network/interfaces文件中, 删掉刚刚添加的auto eth0以及下面的4行, 总计5行代码. 之后请在reTerminal上输入以下命令:
        >代码8: 

            sudo systemctl enable NetworkManager
            sudo systemctl restart NetworkManager
        
        步骤3.4 同样, 按Esc, 直接输入下面的代码, 输入代码之后退出vi编辑器, 返回
        >代码9: :wq

        步骤3.5 返回reTerminal的终端, 输入ifconfig检查静态IP是否配置成功, 比如现在结果如下:
        >图11: reTerminal ifconfig结果
        在'eth0'这一项, ip变成了192.168.10.3我们的配置成功
        
        很好, 感谢您看到这里, 所有设备设置完毕现在可以尝试连接了:) 

    阶段4: 连接和play
        还记得我们在步骤1.2中配置了rtsp推流节点吗? 现在已经有一个rtsp视频流在 rtsp://admin:admin@192.168.xxx.xxx:554/live. 这里的192.168.xxx.xxx是你在步骤1.6中, 手动配置的reCamera静态IP, 不是边缘设备的静态IP. 那么在我的案例中
        对应的rtsp推流是 rtsp://admin:admin@192.168.10.100:554/live 实际上您也可以使用任意的软件, 方法打开这个视频流, 比如VLC Player, 不过为了简便使用, 我们使用ffmpeg里的ffplay命令, 直接在终端打开rtsp视频流

        步骤4.1 安装ffmpeg和nmap, ffmpeg用来获取rtsp推流. nmap用来监听http post 在reTerminal的Terminal里执行:
        >代码10: 
            sudo apt install ffmpeg
            sudo apt install nmap

        步骤4.2 执行fflay命令获取reCamera的rtsp推流, 该命令属于ffmpeg
        ffplay -rtsp_transport udp -max_delay 20000 -probesize 2M rtsp://admin:admin@192.168.10.100:554/live
        解释这行命令里的参数
        此时会弹出一个新的窗口, rtsp视频流会在里面显示, 双击该窗口即可全屏播放
        >图12: ffplay视频流

        步骤4.3 现在 ctrl + alt + T 打开新的终端. 执行ncat命令监听来自reCamera的yolo检测结果, 该命令属于nmap
        >代码11: 
            ncat -l -p 8123
        在这个终端, 可以看到reCamera检测到的人员数量
        >图13: ncat返回检测数量
