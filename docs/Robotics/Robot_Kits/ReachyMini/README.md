# ReachyMini Documentation

Welcome to the **ReachyMini** documentation! Reachy Mini is an open-source, expressive desktop robot designed for human-robot interaction and AI development.

## 📖 Overview

- **Developer:** Tienjui Wong
- **Robot Kits:**
  - **ReachyMini Lite** - Tethered version for education and development (USB connection to computer)
  - **ReachyMini Wireless** - Autonomous version with Raspberry Pi 4, battery, and Wi-Fi
  - **Simulation** - MuJoCo physics-based simulation for prototyping without hardware
