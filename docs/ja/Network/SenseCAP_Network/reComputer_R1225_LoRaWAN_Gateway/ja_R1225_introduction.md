reComputer R1225は、AI機能を備えたCM4搭載の強力で柔軟な産業用Raspberry Pi IoT LoRaWANゲートウェイ＆コントローラーです。3*RS485、デュアルイーサネット、BACnet、Modbusサポートを備え、堅牢で信頼性の高い産業用エッジIoTデバイスに必要なすべての機能を装備しています。AI NPUアクセラレータとの互換性により、特にBMS、BAS、iBMSなどのリモートアクセス制御に最適です。
