reComputer R1225 是一款功能强大且灵活的工业级 Raspberry Pi IoT LoRaWAN 网关和控制器，采用 CM4 供电，具备 AI 功能。配备 3*RS485、双以太网、BACnet 和 Modbus 支持，具备强大可靠的工业边缘 IoT 设备所需的所有必要功能。兼容 AI NPU 加速器，非常适合远程访问控制，特别是 BMS、BAS 和 iBMS。
