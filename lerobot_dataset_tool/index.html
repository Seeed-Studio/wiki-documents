SO-ARM Dataset Tool

Get the SO-ARM101 Kit

Overview​

Use lerobot-edit-dataset to edit datasets and lerobot-dataset-viz to view episodes locally.

To record a dataset first, see Getting started with SO-ARM100 and SO-ARM101.

The examples follow the Seeed LeRobot dataset tool implementation. Other versions may use different options.

TaskPurpose
Delete episodesRemove episodes by index.
Split a datasetSplit data by fraction or episode index.
Merge datasetsCombine multiple datasets into a new dataset.
Remove featuresRemove selected features such as images from a camera.
Convert to videoEncode image frames as video and optionally upload the result to the Hugging Face Hub.
Visualize a dataset onlineView an uploaded dataset in your browser.
Visualize a dataset locallyUse the command-line viewer with a Hub or local dataset.

Delete episodes​

Here, an episode is one complete recording of a robot action.

  • Save as a new dataset
  • Modify the original

Set --new_repo_id to save the result while keeping the original dataset. This example removes episodes 0, 2, and 5.

# Delete episodes and save to a new dataset (preserves original dataset)
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --new_repo_id lerobot/pusht_after_deletion \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]"
caution

This command modifies the original dataset. Check the dataset ID and episode indices first. Select Save as a new dataset to keep the original data.

# Delete episodes 0, 2, and 5 (modifies original dataset)
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]"
OptionPurpose
--repo_idID of the input dataset, such as lerobot/pusht.
--new_repo_idID of the new dataset when saving a copy.
--operation.episode_indicesList of episode indices to delete.

Split a dataset​

  • Split by fraction
  • Split by episode index

This example allocates about 80%, 10%, and 10% of episodes to training, test, and validation sets.

# Split by fractions (e.g. 80% train, 10% test, 10% val)
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type split \
    --operation.splits '{"train": 0.8, "test": 0.1, "val": 0.1}'

This example puts episodes 0–3 in task1 and episodes 4–5 in task2.

lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type split \
    --operation.splits '{"task1": [0, 1, 2, 3], "task2": [4, 5]}'

Each split appends its name to the input ID, for example lerobot/pusht_train. These examples save the results locally. Uploading requires --push_to_hub true.

Merge datasets​

lerobot-edit-dataset \
    --new_repo_id lerobot/pusht_merged \
    --operation.type merge \
    --operation.repo_ids "['lerobot/pusht_train', 'lerobot/pusht_val']"
OptionPurpose
--new_repo_idID of the new merged dataset.
--operation.repo_idsIDs of the source datasets to merge.

Remove features​

If you only need wrist camera footage, you can remove the overhead camera feature. This example drops observation.images.top from the dataset.

lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type remove_feature \
    --operation.feature_names "['observation.images.top']"

Convert to video​

Encode image frames into video in a new dataset. This can reduce storage usage and improve read performance.

1

Choose an output

Step 1

  • Save to a local folder
  • Use a new dataset ID
  • Convert and upload to the Hub

Set the output directory with --new_root. The result stays local.

# Local-only: Save to a custom output directory (no hub push)
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --new_root /path/to/output/pusht_video

Set the ID for the resulting dataset with --new_repo_id. Files stay local.

# Save with new repo_id (local storage)
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --new_repo_id lerobot/pusht_video \
    --operation.type convert_image_to_video

Confirm you have write access to the target repository. --push_to_hub true uploads the result after conversion.

# Convert and push to Hugging Face Hub
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --new_repo_id lerobot/pusht_video \
    --operation.type convert_image_to_video \
    --push_to_hub true
2

Check the result

Step 2

Check the output videos/ directory for the camera MP4 files and confirm the episodes, statistics, and task definitions are still present. The .parquet files hold metadata while the image frames are stored in the videos.

Conversion options you can combine​

Use the following options with the output settings as needed.

Customize encoding​

# Convert with custom video codec and quality settings
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --new_root outputs/pusht_video \
    --operation.rgb_encoder.vcodec libsvtav1 \
    --operation.rgb_encoder.pix_fmt yuv420p \
    --operation.rgb_encoder.g 2 \
    --operation.rgb_encoder.crf 30

Set parallel workers​

# Convert with multiple workers for parallel processing
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --new_root outputs/pusht_video \
    --operation.num_workers 8

Limit batch size​

# For memory-constrained systems, users can now specify limits:
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.max_episodes_per_batch 50 \
    --operation.max_frames_per_batch 10000
OptionPurpose
--new_rootCustom local output directory.
--operation.rgb_encoder.vcodecRGB video codec, such as h264, hevc, or libsvtav1.
--operation.rgb_encoder.pix_fmtRGB video pixel format, such as yuv420p.
--operation.rgb_encoder.gKeyframe interval.
--operation.rgb_encoder.crfEncoding quality setting. Lower values usually increase quality and file size.
--operation.rgb_encoder.fast_decodeFast decoding tuning. Supported values depend on the codec.
--operation.episode_indicesEpisode indices to convert. Omit to convert all episodes.
--operation.num_workersNumber of parallel workers. Defaults to 4.
--operation.max_episodes_per_batchMaximum number of episodes per batch.
--operation.max_frames_per_batchMaximum number of frames per batch.

Visualize a dataset online​

Open an uploaded dataset in the Hugging Face dataset visualizer.

Visualize a dataset locally​

  • View a Hub dataset
  • View a local dataset

Use the dataset ID from the Hub. This example opens episode 0.

lerobot-dataset-viz \
    --repo-id lerobot/pusht \
    --episode-index 0

Give the local dataset directory with --root and select --mode local.

lerobot-dataset-viz \
    --repo-id lerobot/pusht \
    --root ./my_local_data_dir \
    --mode local \
    --episode-index 0
OptionPurpose
--repo-idID of the dataset to view.
--episode-indexEpisode index, starting at 0.
--rootLocal dataset directory.
--mode localRead from the local filesystem.

FAQ​

  • Get the tool used in this guide from the Seeed LeRobot repository. Other versions may use different commands or dataset formats.
  • If terminal output has not refreshed for a while, press Enter to see whether there is new output. Operations on compressed datasets can take time. Watch the progress bar.

See the LeRobot dataset tools documentation.
