Getting Started with reComputer Robotics J601

Quick StartOverview & flashHardware & I/OInterfaces & expansionApplicationPerception & sensor fusion
Robotics & Physical AI · NVIDIA Jetson AGX Thor

Connect perception and control on one robotics carrier board

The reComputer Robotics J601 carrier board supports NVIDIA Jetson AGX Thor T5000 and T4000 modules for multi-camera perception, sensor fusion, and embodied AI development. Combine high-speed Ethernet, GMSL2 camera expansion, and isolated robotics I/O with the Jetson software platform.

Up to 2070 TFLOPSAI performance with a Jetson AGX Thor T5000 module
Up to 4× 10GbEFour RJ45 ports with T5000; three with T4000
Up to 8× GMSL2Multi-camera input through two GMSL extension boards
19–48 V DCWide-range input through an XT30 power connector

Choose Your Jetson Configuration​

The J601 is a carrier board. Select a compatible Jetson AGX Thor module, NVMe SSD, and cooling solution for your build. The J6015 and J6014 names below identify the module-specific configurations and BSP packages used in this guide.

T5000 configuration

reComputer Robotics J6015

Use the T5000 BSP for the configuration with four active 10GbE ports and four isolated CAN interfaces.

AGX Thor T50004× 10GbE4× CAN FD
T4000 configuration

reComputer Robotics J6014

Use the T4000 BSP for the configuration with three active 10GbE ports and two isolated CAN interfaces.

AGX Thor T40003× 10GbE2× CAN FD

Compatible modules: NVIDIA Jetson AGX Thor T5000 and NVIDIA Jetson AGX Thor T4000.

Why reComputer Robotics J601​

Multi-Camera PerceptionGMSL extension boards support up to eight GMSL2 cameras for surround perception and sensor fusion.
High-Speed NetworkingUp to four 10GbE RJ45 connections carry data between sensors, compute nodes, and development systems.
Robotics I/OIsolated CAN FD, RS-232/422/485, I2C, I2S, and digital I/O connect controllers, sensors, and actuators.
Modular ExpansionM.2 Key M supports an NVMe 2280 SSD; Key E and Key B support compatible Wi-Fi/Bluetooth and 4G/5G modules.
Development ConnectivityFour USB 3.2 Type-A ports and HDMI 2.1 connect peripherals and a display, with separate debug and recovery USB-C ports.
Physical AI WorkflowsBuild on Jetson with frameworks such as NVIDIA Isaac, ROS, PyTorch, and Hugging Face, following each framework's platform requirements.

Flash JetPack​

This workflow installs JetPack 7.1 (L4T 38.4.0) to an NVMe SSD on the J601 carrier board. Choose the BSP for the installed module: J6015 for T5000 or J6014 for T4000.

caution

Flashing erases data on the target NVMe SSD. Back up important data before starting, and keep power and USB connected until flashing completes.

1

Prepare the Equipment

Step 1 · Set up the Ubuntu host and target hardware

Prepare the following equipment:

  • J601 carrier board with a Jetson AGX Thor T5000 or T4000 module and suitable cooling
  • NVMe M.2 2280 SSD installed in the Key M slot
  • 19–48 V DC power supply connected through XT30
  • Physical Ubuntu 22.04 or 24.04 host PC with at least 220 GB of free storage
  • USB Type-C data cable
  • HDMI display, keyboard, and mouse for first boot
tip

A native Ubuntu host provides the most reliable flashing experience. Seeed Jetson DevelopTool also supports Windows through WSL2; follow its installation guide for host setup.

2

Enter Force Recovery Mode

Step 2 · Connect J4 and verify the installed module

  1. With the board powered off, connect the host PC to the USB 3.0 Type-C recovery/flashing port (J4). The USB 2.0 Type-C debug port (J3) is a separate connector.
  2. Press and hold RECOVERY.
  3. Connect the 19–48 V DC power supply through XT30.
  4. Release RECOVERY after two seconds.
  5. Run the following command on the Ubuntu host:
lsusb
ConfigurationModuleExpected recovery USB ID
J6015AGX Thor T50000955:7026 NVIDIA Corp.
J6014AGX Thor T40000955:7226 NVIDIA Corp.

If the expected ID is missing, check the data cable and recovery port, then repeat the recovery sequence before continuing.

3

Prepare the Matching BSP

Step 3 · Choose software or command-line flashing

  • Software Flashing
  • Command-Line Flashing

Install and launch Seeed Jetson DevelopTool, then prepare the firmware:

  1. Open Flash Center and select reComputer J601 and JetPack 7.1 (L4T 38.4.0).
  1. Confirm the recovery wiring from Step 2.
  1. Click Detect Device, confirm the installed module, and click Next.
  1. Click Download / Prepare BSP. The tool downloads the firmware, verifies its SHA-256 checksum, and extracts the package.
Watch the Jetson DevelopTool flashing tutorial

Download the module-specific BSP package below. The archive is large; downloading may take around 60 minutes. Wait for the download to finish before extracting it.

  • AGX Thor T4000 (J6014)

On the Ubuntu host, verify the downloaded archive and compare the full result with the checksum for your module:

sha256sum <downloaded-archive.tar.gz>
4

Flash the NVMe SSD

Step 4 · Use the same flashing method and module selection

  • Software Flashing
  • Command-Line Flashing

Click Start Flash in Jetson DevelopTool and wait for the interface to report success. Keep the power supply and USB data cable connected throughout the process.

Extract the archive on the Ubuntu host, then run the command for your installed module. Replace YYYY-MM-DD with the date in the downloaded archive's filename.

  • AGX Thor T5000 (J6015)
  • AGX Thor T4000 (J6014)
cd <path-to-image>
sudo tar xpf mfi_recomputer-thor-carrier-j6015-7.1-38.4.0-YYYY-MM-DD.tar.gz
cd mfi_recomputer-thor-carrier-j6015
sudo ./tools/kernel_flash/l4t_initrd_flash.sh --flash-only --showlogs --external-device nvme0n1p1 -c tools/kernel_flash/flash_l4t_t264_nvme.xml -S 80GiB --network usb0 recomputer-thor-carrier-j6015 external
cd <path-to-image>
sudo tar xpf mfi_recomputer-thor-carrier-j6014-7.1-38.4.0-YYYY-MM-DD.tar.gz
cd mfi_recomputer-thor-carrier-j6014
sudo ./tools/kernel_flash/l4t_initrd_flash.sh --flash-only --showlogs --external-device nvme0n1p1 -c tools/kernel_flash/flash_l4t_t264_nvme.xml -S 80GiB --network usb0 recomputer-thor-carrier-j6014 external

The flash command usually takes 2–10 minutes. Wait for the terminal to report a successful flash.

5

Complete the First Boot

Step 5 · Configure Ubuntu and check your interfaces

Connect the HDMI display, keyboard, and mouse, and complete Ubuntu's initial system configuration. If the setup screen does not appear after flashing, power-cycle the board after the flashing tool reports success.

Continue with Hardware & I/O to verify your peripherals, or explore the perception demo. Seeed's carrier-board device-tree and BSP sources are available in Linux_for_Tegra.
